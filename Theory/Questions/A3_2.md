可以把你现在整套研究浓缩成一句话：

你真正研究的不是“SOM 怎么做 SLAM”，而是：在 full-wave coherent inverse scattering 里，能不能把最有价值、同时也最脆弱的 complex phase 保留下来，并把 geometry、clock、gain 等造成的相位错误当作低维结构化未知量一起估计；同时严格判断什么时候这些未知量可辨、什么时候会和材料混淆、什么时候应该主动再采一组数据。

而 SOM 现在已经从“研究本体”降成了一个待证伪的 numerical tool：如果它真的能让状态求解、初始化或 phase branch capture 更好，就留下；如果不能，就删掉 SOM，整个研究依然成立。这个转变其实让课题比原来更干净了。当前主审查也明确认为，direct coherent calibration 的价值已经有证据，而 SOM-specific advantage 尚未建立。 FINAL_REVIEW.md

1. 你现在整套路线到底是什么？

最容易理解的方式，是把它看成一个 “带自校准能力的定量微波成像系统”。

正常 inverse scattering 假设：

\text{Tx/Rx 位置已知}
\quad\Longrightarrow\quad
\text{根据 complex field 反演材料 } \chi.

你的问题是：

\boxed{
\text{材料未知}
+
\text{阵列几何也不完全准}
+
\text{电子 phase/clock 也可能不准}.
}

于是物理模型变成

M_\ell(\chi)j_\ell=b_\ell(\chi,x),

y_\ell
=
d_\ell(x)
+
S_\ell(x)j_\ell
+
\varepsilon_\ell,

这里

* \chi：介电率/电导率等材料；
* x：Tx/Rx geometry、rigid offset、rotation 等；
* j：由 Maxwell/Helmholtz state equation 决定的 induced current；
* d,S：direct path 和 sensing operator。

最重要的是：

\boxed{j\text{ 不是额外自由变量，而是 dependent physical state}.}

这就是现在的

r_{\rm free}=0.

你不允许算法随便加一个 current 把 geometry error “吃掉”。

⸻

然后整条路线分成五层。

第一层：Full-wave self-calibration

直接联合估计

(\chi,x,\tau,g,c,\ldots),

其中除了 geometry x，还允许：

\text{clock }\tau,\qquad
\text{complex gain }g,\qquad
\text{phase center},\qquad
\text{structured coupling}.

所以你的目标并不是：

residual 小就行。

而是：

residual 为什么小？到底是 geometry 被校准了，还是 clock/gain/material 在替它背锅？

⸻

第二层：Observability / attribution theory

在当前状态附近：

\delta y
=
A_\chi\delta\chi
+
B_x\delta x
+
B_\tau\delta\tau
+
B_g\delta g
+
B_c\delta c+\cdots.

然后问：

\operatorname{Range}(B_x)

和其他 nuisance signature 到底重不重叠。

如果

B_xh\in
\operatorname{Range}[A_\chi,B_\tau,B_g,B_c],

那这个 geometry direction 在局部就可以被材料、clock 或 gain 模仿。

所以你的理论不只是算 Fisher information，而是研究：

\boxed{
\text{谁和谁混淆，以及混淆到什么程度。}
}

你之前的 \rho_i、principal angle、Schur complement 都在这里，但现在已经明确：

\rho
=
\text{relative map-information retention},

而不是绝对 pose information。

真正要同时看的是

\boxed{
\rho
+
\sigma(B_{\rm vis})
+
\text{model/truncation bias}.
}

这也是你理论目前比较扎实的一部分。 A2.md

⸻

第三层：Phase branch / multifrequency continuation

这是现在最重要的 nonlinear 部分。

因为对于传播路径，

\delta\phi_{\rm geo}
\sim
k\,\delta r.

所以：

k\uparrow

一方面意味着：

\text{geometry sensitivity}\uparrow,

另一方面意味着：

\text{phase wrapping/cycle skipping}\uparrow.

所以不能简单说：

高频更好。

真正策略应当是

\boxed{
\text{低频找到正确 branch}
\rightarrow
\text{中频把 geometry 校准准}
\rightarrow
\text{高频恢复细节}.
}

而且未来不是死板地 f_1\to f_2\to f_3，而是：

当前仍有两个 plausible geometry branches，就暂时不给你更高频。

也就是说你最终想做的是 frequency unlock rule。

⸻

第四层：主动 acquisition

如果当前数据不能分辨：

\text{geometry}
\quad\text{vs}\quad
\text{clock},

算法不应该硬猜。

它应该问：

我下一次应该换哪个 receiver？
换哪个 frequency？
转一下阵列？
换一个 Tx？
机器人移动一点？

你已经有 shared-map information innovation：

I_{\rm acq},

可以解释“这一组新观测真正增加了多少 calibration information”。

所以最终系统不是纯 inverse solver，而是：

\boxed{
\text{estimate}
\rightarrow
\text{detect ambiguity}
\rightarrow
\text{choose measurement}
\rightarrow
\text{re-estimate}.
}

这是非常漂亮的一条闭环。

⸻

第五层：SOM / reduced model 只是加速器

这里是现在研究最重要的一次“降温”。

Chen SOM 的核心思想是利用 induced current 的低维可观测结构，而不是每次都在整个高维 current space 里盲目搜索。Chen 本人也明确把 induced source 视为 inverse scattering 中非常核心的桥梁，并强调通过 singular vectors、degrees of freedom 等结构降低非线性求解难度。 Computational Methods for Electromagnetic Inverse Scattering -- Xudong Chen -- 1, 2018 -- John Wiley & Sons Singapore Pte_ Ltd_IEEE Press -- 9781119311980 -- c7653891d0cb690657248a0fd771a608 -- Anna’s Archive.pdf

但你现在已经确认：

\boxed{
\text{完整 current coordinate}
\neq
\text{新增 physical information}.
}

如果 SOM 只是 exact reparameterization，那它和 direct inversion 在物理上是同一个问题。

所以现在只允许 SOM 从三个地方赢：

\boxed{
\begin{array}{l}
\text{更小 numerical basis};\\
\text{更好的 nonlinear initialization / basin};\\
\text{更便宜的 state/Jacobian solve}.
\end{array}
}

如果这三个都赢不了，就把 SOM 从标题里删掉。

这也是目前最科学的状态。

2. 这个研究背景为什么会出现？

根本矛盾只有一句话：

\boxed{
\text{phase 是最有信息量的东西之一，
也是最容易被硬件和几何搞坏的东西之一。}
}

传统 quantitative microwave imaging 想要的不只是“这里有个目标”，而是：

* permittivity；
* conductivity；
* object shape；
* internal material distribution。

full-wave 模型还考虑 multiple scattering，所以它比 Born approximation 更真实，但也更 nonlinear。Chen 的书本身就明确指出 full-wave ISP 的两大困难：

1. ill-posedness；
2. multiple-scattering 导致的非凸非线性。

而 nonlinear optimizer 很容易落入 false solution。 Computational Methods for Electromagnetic Inverse Scattering -- Xudong Chen -- 1, 2018 -- John Wiley & Sons Singapore Pte_ Ltd_IEEE Press -- 9781119311980 -- c7653891d0cb690657248a0fd771a608 -- Anna’s Archive.pdf

与此同时，coherent measurement 给你的是

y=Ae^{i\phi},

phase 对距离极其敏感。

例如厘米/毫米级微波中，位置只错一点点就会出现明显 phase error：

\Delta\phi
\simeq
\frac{2\pi}{\lambda}\Delta r.

所以工程上存在一个非常尴尬的问题：

你为了得到更高 resolution，想用更高频；但频率越高，你对 antenna position、clock、phase center 的 calibration 要求越变态。

一种方案是：

\text{phase unreliable}
\Rightarrow
\text{throw phase away}.

也就是 phaseless / intensity imaging。

但已有文献早就说明 phaseless SOM 仍然可以保留 current structure，所以你不能说“phaseless 没有 SOM/current constraint”。 EVIDENCE.md

你的研究选择的是另一条路线：

\boxed{
\text{如果 phase corruption 其实只来自几个低维结构参数，}
\\
\text{为什么不估计这些参数，而要把整个 phase channel 丢掉？}
}

这才是整个科研问题真正的起点。

4. 你和他们真正的区别是什么？

我会把你的差异归纳成 四个核心点。

⸻

第一：你不是“修 phase”，而是“解释 phase 为什么错”

这应该成为你最大的 scientific identity。

普通 calibration 很多时候相当于：

\phi_{\rm corr}
=
\text{whatever phase makes data fit}.

而你想区分：

\boxed{
\phi_{\rm error}
=
\phi_{\rm geometry}
+
\phi_{\rm clock}
+
\phi_{\rm gain}
+
\phi_{\rm phase-center}
+
\phi_{\rm coupling}
+
\phi_{\rm model}.
}

而且最终算法可以说：

当前数据无法区分 geometry 和 clock。

这一步非常重要。

因为一个 optimizer 总能告诉你：

\hat x=\arg\min \|F(x)-y\|.

但科研上真正难的是：

\boxed{
\hat x\text{ 到底是不是 geometry？}
}

这是 attribution 问题。

⸻

第二：你研究的是 full-wave material + calibration coupling

不是：

\text{先定位几个 point scatterers，再修轨迹}.

而是材料本身也未知：

\chi(r).

更麻烦的是 induced current

j=\chi E_{\rm tot}

又依赖 geometry 改变后的 illumination。

所以 geometry error 不只是简单的 receive phase shift，而会通过 state equation 重新改变整个 scattered field。

因此：

\[
\boxed{
\text{geometry calibration}
\leftrightarrow
\text{material reconstruction}
\]

是双向耦合的。

这比普通 array calibration 更接近一个真正的 nonlinear inverse problem。

⸻

第三：你把“能不能估”也做成算法的一部分

这一点我认为其实比 SOM 更有潜力。

你的系统不是永远输出：

\hat x,\hat\chi.

它允许输出：

\boxed{\text{UNKNOWN / AMBIGUOUS}.}

例如：

\operatorname{Range}(B_x)
\approx
\operatorname{Range}(B_\tau)

时，就应该说：

geometry 和 clock 目前高度 confounded。

然后主动请求另一种 acquisition。

这使你的方法从：

\text{inverse solver}

升级成

\boxed{
\text{self-aware inverse sensing system}.
}

⸻

第四：你不允许 current flexibility 偷偷制造“成功”

这是很重要的一条理论洁癖。

你现在明确区分：

L_{\rm det},
\qquad
r_{\rm num},
\qquad
r_{\rm free}.

其中：

* L_{\rm det}：SOM data-supported current modes；
* r_{\rm num}：只是 numerical approximation dimension；
* r_{\rm free}：真的增加了 independent nuisance。

只有

r_{\rm free}\uparrow

才真的会自动吃 calibration information。

这个区分已经通过理论和 negative controls 变成当前框架的基本原则。 summary.md

所以你不会再说：

“SOM rank 大，所以 pose information 低。”

正确说法是：

如果额外放开的 current directions 被允许独立变化，而且和 pose signature overlap，它才会吸收 pose information。

这是比早期版本成熟很多的地方。

5. 它可以用在哪里？意义到底是什么？到底牛逼在哪？

先讲最现实的。

第一优先：Coherent microwave tomography

这是目前最适合你论文的应用。

例如：

* biomedical microwave tomography；
* material characterization；
* industrial NDE；
* dielectric imaging；
* near-field quantitative imaging；
* microwave diffraction tomography。

真实系统中，antenna 的 nominal geometry 可能已知，但存在：

1\text{–}5\ {\rm mm}

级 phase-center、安装、机械定位、cable delay 误差。

如果 frequency 高，这种误差就已经足以让 quantitative reconstruction 明显变坏。

而你已有 direct full-wave exploratory experiment 表明：

\mathrm{RMSE}_{\rm wrong\ geometry}=0.1054,

联合 coherent self-calibration 后：

0.0261,

known-pose reference：

0.0251.

matched intensity joint inversion：

0.0430.

也就是说，在这个实验族里：

\boxed{
\text{self-calibrated coherent}
\approx
\text{known-geometry coherent}
}

而且明显优于错误 geometry。

这已经是非常重要的现象。 PAPER_DRAFT_A2.md

注意：它证明的是 self-calibration 值得做，不是 SOM 牛逼。

第二优先：Flexible / mechanically scanned arrays

这个场景其实非常适合你的理论。

* synthetic aperture microwave scanner。

这些系统的特点恰好是：

\boxed{

\text{small structured deviation unknown}.

这正是最适合 self-calibration 的 regime。

第三优先：Robot-mounted coherent imaging

比如机器人拿着 microwave antenna 扫描：

* 墙后结构；
* 管道；
* 混凝土内部；
* 设备缺陷；

这时机器人 odometry 给你 nominal pose：

x_{\rm odo},

x_{\rm EM}
=
x_{\rm odo}
+
\Delta x.

你的 full-wave scattering 数据可以反过来校准 \Delta x。

这就开始接近你最早说的 inverse-scattering SLAM。

所以现在不能跳得太远。

最后：它真正“牛逼”的地方到底是什么？

我觉得要分成已经成立的牛逼和如果未来做出来会非常牛逼的地方。

已经成立的核心价值

不是 SOM。

而是这个观察：

\boxed{
\text{coherent phase 的脆弱性本身，
可能包含 calibration information。}
}

通常工程思路是：

geometry 不准 → phase 不可信 → phase 扔掉。

你的思路是：

geometry 不准 → phase 发生高度结构化变化 → 利用这种变化反过来估 geometry。

也就是说，你把：

\boxed{\text{phase sensitivity}}

从一个 bug 变成了一个 sensor。

这是真正很漂亮的地方。

⸻

更具体一点：

高频下

\frac{\partial\phi}{\partial r}\sim k.

这意味着高频 phase 非常怕 geometry error。

但反过来说，一旦 branch 找对：

\boxed{
\text{高频 phase 也是一个非常精密的 geometry ruler}.
}

所以你想做的是：

\boxed{
\text{低频负责“不走错路”}
+
\text{高频负责“校得很准、看得很细”}.
}

这就是整项工作的核心物理美感。

⸻

如果最终做成功，真正可能很强的点

是把现在很多系统的逻辑：

\boxed{
\text{先花很大成本把阵列机械标定得极准}
\rightarrow
\text{再做 coherent imaging}
}

变成：

\boxed{
\text{只需要 nominal calibration}
+
\text{成像数据自己完成剩余 electromagnetic calibration}.
}

也就是某种意义上的：

software-defined electromagnetic calibration。

它可能允许：

* 更柔性的阵列；
* 更廉价的机械结构；
* 可移动 Tx/Rx；
* 更高频 operation；
* 更小 phase-center tolerance；
* 成像过程中在线重新 calibration。

这才可能是非常有工程冲击力的部分。

⸻

而它最有理论味道的地方则是：

你不是只说“我们优化成功了”。

而是想回答：

\boxed{
\begin{array}{c}
\text{什么时候 geometry 真能估？}\\
\text{什么时候只是 clock/gain 在假装 geometry？}\\
\text{什么时候 phase branch 还没确定？}\\
\text{什么时候必须再测一组数据？}
\end{array}}

这使得研究从一个普通的 joint optimizer，变成了一套：

\boxed{
\text{phase-preserving full-wave self-calibration theory}.
}

⸻

因此我现在对你整个项目最准确的定位是：

你正在研究一种“保留 coherent phase 的自校准式 full-wave quantitative imaging”：不是在相位不可靠时简单放弃 phase，而是利用多频、多视角和 full-wave self-consistency 去估计造成 phase corruption 的低维结构参数，并用 observability、bias 与 acquisition theory 判断什么时候这个解释可信。SOM 只是候选的 current-space numerical accelerator，而不是研究成立的前提。

如果最后 SOM 真的证明能显著扩大 basin 或减少 state/Jacobian cost，那它会成为一个很漂亮的 Chen-style realization。

如果 SOM 最后失败，这个研究依然有一个很完整、甚至可能更普适的核心。
