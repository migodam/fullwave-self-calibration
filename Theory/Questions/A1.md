# 总结判断

这个题目**在数学上是成立的，而且核心结构比“子空间旋转”更干净**。将所有变量在真实状态 \((\chi_0,X_0)\) 附近线性化并正确处理复数据、实位姿后，整套理论可以压缩为：

\[
\boxed{
K_{\rm eff}=A^*W_XA
}
\]

其中无位姿先验时

\[
W_X=P_{\operatorname{Ran}(B)^\perp},
\]

有位姿先验 \(J_X\) 时

\[
W_X=I-B(B^*B+J_X)^\dagger B^*.
\]

最核心的精确结果是

\[
\boxed{
\operatorname{rank}K_{\rm IS}
-
\operatorname{rank}K_{\rm SLAM}
=
\dim\!\left(
\operatorname{Ran}(A)\cap\operatorname{Ran}(B)
\right)
}
\]

以及，在 \(K_{\rm IS}\) 的可观测支撑空间上，

\[
\boxed{
\rho_i=\sin^2\theta_i
}
\]

其中 \(\theta_i\) 是 **map-induced data tangent space**
\(\operatorname{Ran}(A)\) 与 **pose-induced data tangent space**
\(\operatorname{Ran}(B)\) 的主夹角。

因此你的判断是对的：

> \(A^*P_{B^\perp}A\) 不是一个任意构造的矩阵，而是把“环境变化与位姿变化在数据空间中的混淆”变成有效 Fisher 信息算子。

但有四个必须从一开始修正的技术点：

1. **位姿参数是实数。**  
   对复数测量直接使用复线性空间中的 \(BB^\dagger\)，会允许“不存在的复位姿扰动”，通常会高估位姿混淆。严格做法是先 realification。

2. **Born 模型不能在 \(\chi_0=0\) 处研究一阶 pose–map 混淆。**  
   此时 \(B=D_XF(0,X_0)=0\)。这并不表示位姿误差无害，而表示它以双线性项
   \((D_XA[\delta X])\delta\chi\) 出现。

3. \(\rho_i\) 不是普通 \(K_{\rm IS}\) 第 \(i\) 个 eigenmode 的逐个保留比例。  
   它对应的是经过 \(K_{\rm IS}\)-whitening 后的 principal directions。

4. 内层的 \(J_X\) 与外层的 \(\Delta X\) 表示两类不同不确定性：  
   \(J_X\) 是待联合估计的 pose nuisance information；  
   \(\Delta X\) 是轨迹执行误差或标称几何失配。二者不能无意识地重复计算。

# 1. 严格模型与符号约定

考虑离散后的二维标量 Helmholtz 模型。对第 \(t\) 个照射—接收配置，

\[
j_t=D_\chi\left(e_t^{\rm inc}+G_{D,t}j_t\right),
\]

\[
y_t=G_{S,t}j_t+n_t.
\]

令

\[
M_t=I-D_\chi G_{D,t},
\qquad
E_t^{\rm tot}=e_t^{\rm inc}+G_{D,t}j_t,
\]

于是

\[
M_tj_t=D_\chi e_t^{\rm inc},
\qquad
j_t=M_t^{-1}D_\chi e_t^{\rm inc}.
\]

在固定频率、world-fixed map grid、均匀已知背景下，\(G_D\) 通常不依赖 \(t\) 或机器人位姿，因此 \(M_t\) 实际可写成 \(M\)。保留下标 \(t\) 主要是为了后续容纳多频率、移动坐标网格和时变背景。

| 符号 | 含义 |
|---|---|
| \(\chi\in\mathbb C^N\) 或 \(\mathbb R^N\) | 介质 contrast |
| \(D_\chi=\operatorname{diag}(\chi)\) | contrast 乘法算子 |
| \(j_t\in\mathbb C^N\) | induced/contrast current |
| \(e_t^{\rm inc}\in\mathbb C^N\) | 目标区域内 incident field |
| \(G_D\in\mathbb C^{N\times N}\) | 内部传播算子 |
| \(G_{S,t}\in\mathbb C^{m_t\times N}\) | 区域到接收器的辐射算子 |
| \(x_t\in\mathbb R^{d_x}\) | 第 \(t\) 个机器人位姿 |
| \(X=(x_1,\ldots,x_T)\) | 整条轨迹 |
| \(A=D_\chi F\) | map Jacobian |
| \(B=D_XF\) | pose Jacobian |
| \(\mathcal U=\operatorname{Ran}(A)\) | map-induced data tangent space |
| \(\mathcal V=\operatorname{Ran}(B)\) | pose-induced data tangent space |

以下所有结果都要求名义点满足

\[
M_t(\chi_0,X_0)\quad\text{可逆}.
\]

## 1.1 复数据与实参数：必须先 realify

若

\[
n\sim\mathcal{CN}(0,\Sigma),
\]

先令

\[
\widehat A=\Sigma^{-1/2}A,
\qquad
\widehat B=\Sigma^{-1/2}B.
\]

若 \(\chi\) 和 \(X\) 都是实参数，则定义

\[
A_{\mathbb R}
=
\sqrt 2
\begin{bmatrix}
\Re\widehat A\\
\Im\widehat A
\end{bmatrix},
\qquad
B_{\mathbb R}
=
\sqrt 2
\begin{bmatrix}
\Re\widehat B\\
\Im\widehat B
\end{bmatrix}.
\]

此时真实 Fisher 信息为

\[
\mathcal I
=
\begin{bmatrix}
A_{\mathbb R}^{T}A_{\mathbb R}
&
A_{\mathbb R}^{T}B_{\mathbb R}\\
B_{\mathbb R}^{T}A_{\mathbb R}
&
B_{\mathbb R}^{T}B_{\mathbb R}
\end{bmatrix}.
\]

若 contrast 本身为复数，要把 \(\chi_R,\chi_I\) 视为两个实参数块：

\[
A_{\mathbb R}
=
\sqrt 2
\begin{bmatrix}
\Re\widehat A&-\Im\widehat A\\
\Im\widehat A& \Re\widehat A
\end{bmatrix}.
\]

后文为了保持符号简洁，仍写 \(A,B,*\)，但应理解为：

> 所有物理结论应当在 realified、whitened 数据空间中应用。

否则复数 \(BB^\dagger\) 相当于允许 \(\delta X\in\mathbb C^{d_X}\)，并不符合真实机器人位姿。

# 2. 从 contrast-source 方程严格推导 \(A\) 和 \(B\)

定义隐式状态方程

\[
\Phi_t(j_t,\chi,x_t)
=
j_t-D_\chi
\left(
e_t^{\rm inc}(x_t)+G_D(x_t)j_t
\right)
=0.
\]

其对 \(j_t\) 的导数是

\[
D_j\Phi_t=M_t.
\]

只要 \(M_t\) 可逆，隐函数定理保证 \(j_t=j_t(\chi,x_t)\) 局部可微。

对

\[
j_t=D_\chi E_t^{\rm tot},
\qquad
E_t^{\rm tot}=e_t^{\rm inc}+G_Dj_t
\]

作全变分：

\[
\delta j_t
=
D_{\delta\chi}E_t^{\rm tot}
+
D_\chi
\left(
\delta e_t^{\rm inc}
+
\delta G_D\,j_t
+
G_D\delta j_t
\right).
\]

移项得

\[
\boxed{
M_t\delta j_t
=
D_{E_t^{\rm tot}}\delta\chi
+
D_\chi
\left(
\delta e_t^{\rm inc}
+
\delta G_D\,j_t
\right).
}
\tag{19}
\]

这里

\[
D_{E_t^{\rm tot}}
=
\operatorname{diag}(E_t^{\rm tot}).
\]

因此

\[
\boxed{
\delta j_t
=
M_t^{-1}D_{E_t^{\rm tot}}\delta\chi
+
M_t^{-1}D_\chi
\left(
\delta e_t^{\rm inc}
+
\delta G_D\,j_t
\right).
}
\tag{20}
\]

数据方程的变分为

\[
\delta y_t
=
\delta G_{S,t}\,j_t
+
G_{S,t}\delta j_t.
\]

代入后：

\[
\boxed{
\begin{aligned}
\delta y_t
={}&
G_{S,t}M_t^{-1}
D_{E_t^{\rm tot}}\delta\chi\\
&+
\delta G_{S,t}\,j_t\\
&+
G_{S,t}M_t^{-1}D_\chi
\left(
\delta e_t^{\rm inc}
+
\delta G_D\,j_t
\right).
\end{aligned}
}
\tag{21}
\]

## 2.1 Map Jacobian

固定 \(X\)，令 \(\delta e^{\rm inc}=\delta G_S=\delta G_D=0\)，得到

\[
\boxed{
A_t
=
G_{S,t}
M_t^{-1}
\operatorname{diag}(E_t^{\rm tot}).
}
\tag{22}
\]

所以你的式 (2) **严格成立**，前提是：

- map 使用 world-fixed 坐标；
- \(G_D\) 不依赖 \(\chi\)；
- contrast 的参数化就是网格值 \(\chi_n\)；
- 数据中只包含 scattered field。

如果 contrast 使用基函数

\[
\chi(r)=\sum_\ell c_\ell\varphi_\ell(r),
\]

则最后一项应改为

\[
A_t
=
G_{S,t}M_t^{-1}
D_{E_t^{\rm tot}}S_\chi,
\]

其中 \(S_\chi c\) 把参数系数映射为网格 contrast。

## 2.2 Pose Jacobian

令 \(\delta\chi=0\)，对任意位姿方向 \(h_t\)：

\[
\boxed{
\begin{aligned}
B_th_t
={}&
D_{x_t}G_{S,t}[h_t]\,j_t\\
&+
G_{S,t}M_t^{-1}D_\chi
\left(
D_{x_t}e_t^{\rm inc}[h_t]
+
D_{x_t}G_D[h_t]\,j_t
\right).
\end{aligned}
}
\tag{23}
\]

因此你的式 (3) 在下列情况下正确：

\[
D_{x_t}G_D=0,
\]

也就是场景使用固定世界坐标，内部传播核不随机器人移动。

完整模型还可能需要加入：

\[
G_{S,t}M_t^{-1}
\left(
D_{x_t}D_\chi[h_t]
\right)
E_t^{\rm tot},
\]

若 map 本身表示在机器人坐标系或移动网格中；以及

\[
D_{x_t}y_t^{\rm direct}[h_t],
\]

若测量包含 direct path、背景散射、天线互耦或 calibration channel。

## 2.3 发射机和接收机同时运动时的显式形式

二维自由空间 Green 函数可写成

\[
g_k(r,r')
=
\frac{i}{4}
H_0^{(1)}
\left(k\|r-r'\|\right).
\]

其梯度为

\[
\nabla_r g_k(r,r')
=
-\frac{ik}{4}
H_1^{(1)}(kR)
\frac{r-r'}{R},
\qquad
R=\|r-r'\|.
\]

若机器人位姿为

\[
x_t=(p_t,\theta_t),
\]

机器人载体上的第 \(a\) 个天线世界坐标为

\[
r_{t,a}
=
p_t+R(\theta_t)s_a,
\]

则

\[
D r_{t,a}[\delta p_t,\delta\theta_t]
=
\delta p_t
+
\delta\theta_tR(\theta_t)Js_a,
\]

其中

\[
J=
\begin{bmatrix}
0&-1\\
1&0
\end{bmatrix}.
\]

因此接收算子的导数为

\[
[D_xG_S[h]]_{a,n}
=
\nabla_1g_k(r_{t,a},z_n)^T
D r_{t,a}[h],
\]

而 point-source incident field

\[
[e_t^{\rm inc}]_n
=
q_tg_k(z_n,s_t)
\]

满足

\[
[D_xe_t^{\rm inc}[h]]_n
=
q_t\nabla_2g_k(z_n,s_t)^T
Ds_t[h],
\]

再加上天线方向图、极化和复增益对旋转的导数。

所以 \(B_t\) 的物理含义明确分为：

\[
\boxed{
\text{receiver-coordinate derivative}
+
\text{rescattered transmitter-coordinate derivative}.
}
\]

# 3. 核心有效信息算子

令

\[
\mathcal U=\operatorname{Ran}(A),
\qquad
\mathcal V=\operatorname{Ran}(B),
\]

并令

\[
P_{\mathcal V}=BB^\dagger,
\qquad
P_{\mathcal V^\perp}=I-BB^\dagger.
\]

有限维情况下，这始终是正交投影。无限维情况下应将 \(\mathcal V\) 替换为闭包；但由于有限数量位姿变量对应的 \(B\) 是有限秩算子，其像空间本身是闭的。

定义

\[
K_{\rm IS}=A^*A,
\]

\[
K_{\rm SLAM}=A^*P_{\mathcal V^\perp}A.
\]

其最重要的变分表述是

\[
\boxed{
u^*K_{\rm SLAM}u
=
\min_z\|Au-Bz\|^2.
}
\tag{24}
\]

证明很直接：

\[
\min_z\|Au-Bz\|^2
=
\operatorname{dist}^2(Au,\mathcal V)
=
\|P_{\mathcal V^\perp}Au\|^2.
\]

这说明 \(K_{\rm SLAM}\) 正是：

> 给定一个地图变化后，允许 pose 进行最优补偿，最终仍无法被 pose 解释掉的数据能量。

---

# 4. 基础定理

## 定理 1：信息单调损失

\[
\boxed{
0\preceq K_{\rm SLAM}\preceq K_{\rm IS}.
}
\]

### 证明

因为 \(P_{\mathcal V^\perp}\) 是正交投影，

\[
0\preceq P_{\mathcal V^\perp}\preceq I.
\]

左右同乘 \(A^*,A\)：

\[
0
\preceq
A^*P_{\mathcal V^\perp}A
\preceq
A^*A.
\]

证毕。

由 Courant–Fischer 原理，若特征值按降序排列：

\[
\boxed{
\lambda_i(K_{\rm SLAM})
\le
\lambda_i(K_{\rm IS}).
}
\]

所以“未知 pose 只能减少地图的局部有效信息”成立。

---

## 定理 2：不可辨识方向的精确刻画

\[
\boxed{
\ker K_{\rm SLAM}
=
\left\{
u:
Au\in\operatorname{Ran}(B)
\right\}.
}
\tag{25}
\]

### 证明

\[
u^*K_{\rm SLAM}u
=
\|P_{\mathcal V^\perp}Au\|^2.
\]

因此

\[
u\in\ker K_{\rm SLAM}
\iff
P_{\mathcal V^\perp}Au=0
\iff
Au\in\mathcal V.
\]

证毕。

注意其中自动包含

\[
\ker A\subseteq\ker K_{\rm SLAM},
\]

因为 \(Au=0\in\operatorname{Ran}(B)\)。

---

## 定理 3：自由度损失公式

有限维情况下，

\[
\boxed{
\operatorname{rank}K_{\rm SLAM}
=
\operatorname{rank}A
-
\dim\left(
\operatorname{Ran}(A)\cap\operatorname{Ran}(B)
\right).
}
\tag{26}
\]

### 证明

因为

\[
K_{\rm SLAM}
=
(P_{\mathcal V^\perp}A)^*
(P_{\mathcal V^\perp}A),
\]

所以

\[
\operatorname{rank}K_{\rm SLAM}
=
\operatorname{rank}(P_{\mathcal V^\perp}A).
\]

考察投影限制

\[
P_{\mathcal V^\perp}|_{\mathcal U}:
\mathcal U\rightarrow\mathcal V^\perp.
\]

其核为

\[
\ker(P_{\mathcal V^\perp}|_{\mathcal U})
=
\mathcal U\cap\mathcal V.
\]

由秩—零化度定理：

\[
\dim P_{\mathcal V^\perp}\mathcal U
=
\dim\mathcal U
-
\dim(\mathcal U\cap\mathcal V).
\]

而

\[
\dim\mathcal U=\operatorname{rank}A.
\]

证毕。

因此

\[
\boxed{
r_{\rm IS}-r_{\rm SLAM}
=
\dim(\mathcal U\cap\mathcal V).
}
\tag{27}
\]

这正是你所希望的结论，而且无需额外假设 \(A\) 或 \(B\) 满列秩。

---

## 4.1 等价的可辨识条件

下列条件等价：

\[
\mathcal U\cap\mathcal V=\{0\},
\]

\[
\operatorname{rank}[A\;\;B]
=
\operatorname{rank}A+\operatorname{rank}B,
\]

\[
Au=Bz
\Longrightarrow
Au=Bz=0.
\]

因此，对 known-pose 可观测支撑而言，局部无 pose–map 混淆的条件就是

\[
\boxed{
\operatorname{rank}[A\;\;B]
=
\operatorname{rank}A+\operatorname{rank}B.
}
\]

---

## 4.2 一个纯维数下界

若数据空间实维数为 \(m\)，且

\[
r_A=\dim\mathcal U,
\qquad
r_B=\dim\mathcal V,
\]

则总有

\[
\boxed{
\dim(\mathcal U\cap\mathcal V)
\ge
\max(0,r_A+r_B-m).
}
\tag{28}
\]

因此，当

\[
r_A+r_B>m
\]

时，精确混淆是维数上不可避免的。

对一般位置的两个子空间，通常有

\[
\dim(\mathcal U\cap\mathcal V)
=
\max(0,r_A+r_B-m),
\]

但物理对称性会迫使交集比 generic value 更大。

# 5. 连续方向性信息损失

对 \(Au\neq0\)，定义

\[
R(u)
=
\frac{u^*K_{\rm SLAM}u}
{u^*K_{\rm IS}u}.
\]

则

\[
R(u)
=
\frac{\|P_{\mathcal V^\perp}Au\|^2}
{\|Au\|^2}.
\]

定义向量与子空间的夹角

\[
\cos\angle(w,\mathcal V)
=
\frac{\|P_\mathcal Vw\|}{\|w\|}.
\]

由勾股分解

\[
\|w\|^2
=
\|P_\mathcal Vw\|^2
+
\|P_{\mathcal V^\perp}w\|^2
\]

得到

\[
\boxed{
R(u)
=
\sin^2\angle(Au,\mathcal V).
}
\tag{29}
\]

所以式 (10) 完全正确。

它不是一个人为 threshold，而是一个严格的连续量：

\[
R(u)=0
\iff
Au\in\mathcal V,
\]

\[
R(u)=1
\iff
Au\perp\mathcal V.
\]

# 6. SLAM observability spectrum 的精确解

令 \(A\) 的 thin SVD 为

\[
A=Q\Sigma V^*,
\]

其中

\[
Q^*Q=I_r,
\qquad
V^*V=I_r,
\qquad
r=\operatorname{rank}A.
\]

因此

\[
K_{\rm IS}
=
V\Sigma^2V^*,
\]

\[
K_{\rm SLAM}
=
V\Sigma
Q^*P_{\mathcal V^\perp}Q
\Sigma V^*.
\]

在

\[
\mathcal S=\operatorname{Ran}(A^*)=\ker(A)^\perp
\]

上，

\[
K_{\rm IS}^{\dagger/2}
=
V\Sigma^{-1}V^*.
\]

所以

\[
\boxed{
R_{\rm op}
=
K_{\rm IS}^{\dagger/2}
K_{\rm SLAM}
K_{\rm IS}^{\dagger/2}
=
V
\left(
Q^*P_{\mathcal V^\perp}Q
\right)
V^*.
}
\tag{30}
\]

这立即证明

\[
0\preceq R_{\rm op}\preceq P_\mathcal S,
\]

以及在 \(\mathcal S\) 上

\[
0\le\rho_i\le1.
\]

## 定理 4：保留谱就是主夹角的平方正弦

令 \(Z\) 为 \(\mathcal V=\operatorname{Ran}(B)\) 的正交基：

\[
P_\mathcal V=ZZ^*.
\]

则

\[
Q^*P_{\mathcal V^\perp}Q
=
I-Q^*ZZ^*Q
=
I-(Z^*Q)^*(Z^*Q).
\]

\(Z^*Q\) 的奇异值是两个子空间之间主夹角的余弦：

\[
\sigma_i(Z^*Q)=\cos\theta_i.
\]

所以

\[
\boxed{
\rho_i=\sin^2\theta_i.
}
\tag{31}
\]

若 \(r>\operatorname{rank}B\)，把额外的主夹角补成

\[
\theta_i=\frac{\pi}{2},
\]

相应地这些方向满足

\[
\rho_i=1.
\]

---

## 6.1 对 \(\rho_i\) 的正确解释

广义特征问题

\[
K_{\rm SLAM}v_i
=
\rho_iK_{\rm IS}v_i
\]

应限制在 \(\ker A^\perp\) 上，并归一化为

\[
v_i^*K_{\rm IS}v_i=1.
\]

此时

\[
Av_i
\]

是 \(\mathcal U\) 相对于 \(\mathcal V\) 的 principal data vector。

所以更准确的解释是：

> \(\rho_i\) 是经过 known-pose Fisher metric 白化后的第 \(i\) 个 map data principal direction，在消除 pose nuisance 后的相对信息保留率。

它**不一定是普通 \(K_{\rm IS}\) 第 \(i\) 个 eigenvector 的保留率**。

一个方向可能：

\[
\rho_i\approx1,
\]

但它对应的 known-pose singular value 本来就很小。因此它“不受 pose 干扰”，却仍可能“几乎无法从噪声中恢复”。

必须同时考察两个坐标：

\[
\boxed{
\text{absolute information strength}
\quad\text{与}\quad
\text{pose retention}.
}
\]

---

## 6.2 无 threshold 的连续混淆维数

定义 normalized loss operator

\[
C_{\rm pose}
=
P_\mathcal S-R_{\rm op}
=
K_{\rm IS}^{\dagger/2}
\left(
K_{\rm IS}-K_{\rm SLAM}
\right)
K_{\rm IS}^{\dagger/2}.
\]

其非零特征值是

\[
\cos^2\theta_i.
\]

于是可定义

\[
\boxed{
d_{\rm conf}
=
\operatorname{tr}C_{\rm pose}
=
\sum_i\cos^2\theta_i
=
\|Z^*Q\|_F^2.
}
\tag{32}
\]

它是一个无需 hard threshold 的连续“有效混淆维数”。

三种不同概念必须区分：

\[
\boxed{
\begin{aligned}
\text{完全丢失的 DoF 数}
&=
\#\{i:\theta_i=0\},\\[2mm]
\text{受到任何 pose 影响的模式数}
&=
\#\{i:\theta_i<\pi/2\},\\[2mm]
\text{连续混淆维数}
&=
\sum_i\cos^2\theta_i.
\end{aligned}
}
\]

## 6.3 稳定可辨识条件

最小保留率为

\[
\rho_{\min}
=
\sin^2\theta_{\min}.
\]

对所有 \(u\) 有

\[
\boxed{
u^*K_{\rm SLAM}u
\ge
\rho_{\min}
u^*K_{\rm IS}u.
}
\tag{33}
\]

因此

\[
\boxed{
\rho_{\min}K_{\rm IS}
\preceq
K_{\rm SLAM}
\preceq
\rho_{\max}K_{\rm IS}.
}
\tag{34}
\]

有限维情况下，

\[
\mathcal U\cap\mathcal V=\{0\}
\]

就意味着 \(\theta_{\min}>0\)。

但在无限维逆问题中要更小心：\(\operatorname{Ran}(A)\) 可能不闭。可能出现

\[
\mathcal U\cap\mathcal V=\{0\},
\]

但存在一列 \(Au_n/\|Au_n\|\) 无限逼近 \(\mathcal V\)，使

\[
\theta_{\min}=0.
\]

所以连续算子层面的稳定条件应写成

\[
\inf_{Au\neq0}
\frac{\operatorname{dist}(Au,\mathcal V)}
{\|Au\|}
>0.
\]

这比单纯的零交集更强。

---

## 6.4 体积信息保留

若没有精确混淆，则在 \(\mathcal S\) 上

\[
\boxed{
\frac{\det_{\mathcal S}K_{\rm SLAM}}
{\det_{\mathcal S}K_{\rm IS}}
=
\prod_{i=1}^r\rho_i
=
\prod_{i=1}^r\sin^2\theta_i.
}
\tag{35}
\]

所以

\[
\sum_i\log\rho_i
\]

是一个自然的 log-volume retention criterion。

若存在任意 \(\theta_i=0\)，这个比值为零。

# 7. 一个更强的谱结论：pose loss 是低秩扰动

定义

\[
L_0
=
K_{\rm IS}-K_{\rm SLAM}
=
A^*P_\mathcal VA.
\]

因为

\[
\operatorname{rank}P_\mathcal V
=
\operatorname{rank}B,
\]

所以

\[
\boxed{
\operatorname{rank}L_0
\le
\operatorname{rank}B.
}
\tag{36}
\]

这意味着：

> 有限维 pose nuisance 对地图信息的作用是一个低秩负半定扰动。

若

\[
p=\operatorname{rank}L_0,
\]

按降序排列特征值，则有 rank-\(p\) interlacing：

\[
\boxed{
\lambda_{i+p}(K_{\rm IS})
\le
\lambda_i(K_{\rm SLAM})
\le
\lambda_i(K_{\rm IS}).
}
\tag{37}
\]

因此在无限维 compact inverse-scattering operator 中，只要 pose 参数维数固定，pose nuisance 不会改变高阶谱尾的渐近衰减类别，只会造成有限索引的谱移位。

但若每个时刻都引入独立 pose，自由 pose 维数为

\[
p_X=d_xT,
\]

那么这个低秩上界也随轨迹长度增长。

## 7.1 \(\operatorname{rank}L_0\) 不等于精确丢失 DoF

利用主夹角：

\[
\operatorname{rank}L_0
=
\#\{i:\theta_i<\pi/2\},
\]

而

\[
\operatorname{rank}K_{\rm IS}
-
\operatorname{rank}K_{\rm SLAM}
=
\#\{i:\theta_i=0\}.
\]

所以：

- \(\operatorname{rank}L_0\)：有多少 map 方向受到任何程度的 pose 影响；
- rank difference：有多少 map 方向被 pose 完全吞掉。

两者不能混用。

# 8. 加入 motion prior

联合信息矩阵为

\[
\mathcal I
=
\begin{bmatrix}
A^*A&A^*B\\
B^*A&B^*B+J_X
\end{bmatrix}.
\]

令

\[
C_X=B^*B+J_X.
\]

由于 \(J_X\succeq0\)，若 \(z\in\ker C_X\)，则

\[
0=z^*C_Xz=\|Bz\|^2+z^*J_Xz,
\]

因此 \(Bz=0\)。这保证

\[
\operatorname{Ran}(B^*A)
\subseteq
\operatorname{Ran}(C_X),
\]

所以 generalized Schur complement 合法：

\[
\boxed{
K_{\rm eff}
=
A^*A
-
A^*B
C_X^\dagger
B^*A.
}
\tag{38}
\]

其变分表示为

\[
\boxed{
u^*K_{\rm eff}u
=
\min_z
\left[
\|Au-Bz\|^2+z^*J_Xz
\right].
}
\tag{39}
\]

这立即给出

\[
\boxed{
K_{\rm SLAM}
\preceq
K_{\rm eff}
\preceq
K_{\rm IS}.
}
\tag{40}
\]

而且若

\[
J_{X,1}\succeq J_{X,0},
\]

则

\[
\boxed{
K_{\rm eff}(J_{X,1})
\succeq
K_{\rm eff}(J_{X,0}).
}
\tag{41}
\]

---

## 8.1 两个极限

当

\[
J_X=0,
\]

有

\[
B(B^*B)^\dagger B^*=BB^\dagger=P_\mathcal V,
\]

因此

\[
\boxed{
K_{\rm eff}=K_{\rm SLAM}.
}
\]

若

\[
J_X(\alpha)=\alpha J_0,
\qquad
J_0\succ0,
\]

则

\[
\left\|
A^*B(B^*B+\alpha J_0)^{-1}B^*A
\right\|
\le
\frac{\|A\|^2\|B\|^2}
{\alpha\lambda_{\min}(J_0)},
\]

所以

\[
\boxed{
K_{\rm eff}\rightarrow K_{\rm IS}
\quad
(\alpha\rightarrow\infty).
}
\]

若 \(J_0\) 是奇异的，例如未锚定的 odometry graph Laplacian，那么只会约束 \(J_0\) 的支撑方向；未约束的 global gauge 仍然保留。

## 8.2 Prior-weighted retention spectrum

若 \(J_X\succ0\)，定义 prior-whitened pose Jacobian

\[
D=BJ_X^{-1/2}.
\]

由 Woodbury 恒等式，

\[
\boxed{
I-B(B^*B+J_X)^{-1}B^*
=
(I+DD^*)^{-1}.
}
\tag{42}
\]

所以

\[
\boxed{
K_{\rm eff}
=
A^*(I+DD^*)^{-1}A.
}
\tag{43}
\]

设

\[
D=Z\operatorname{diag}(\eta_\ell)W^*
\]

为 SVD，则

\[
(I+DD^*)^{-1}
=
P_{Z^\perp}
+
Z
\operatorname{diag}
\left(
\frac{1}{1+\eta_\ell^2}
\right)
Z^*.
\]

其中 \(\eta_\ell\) 衡量：

\[
\boxed{
\text{measurement 对 pose 的信息强度}
\Big/
\text{motion prior 强度}.
}
\]

在 map data basis \(Q\) 上，prior-weighted retention operator 为

\[
\boxed{
R_X
=
Q^*(I+DD^*)^{-1}Q.
}
\tag{44}
\]

它的特征值仍在 \((0,1]\)，但一般不再只是简单的 \(\sin^2\theta_i\)，因为不同 pose singular directions 具有不同权重。

连续 prior-weighted confounding dimension 为

\[
\boxed{
d_{\rm conf}(J_X)
=
\sum_\ell
\frac{\eta_\ell^2}{1+\eta_\ell^2}
\|Q^*z_\ell\|^2.
}
\tag{45}
\]

这比单纯主夹角更能描述 IMU、里程计和 waveform data 共同决定的混淆程度。

## 8.3 Pose-induced loss operator

定义

\[
L_X
=
K_{\rm IS}-K_{\rm eff}
=
A^*B C_X^\dagger B^*A.
\]

令

\[
H_X=C_X^{\dagger/2}B^*A,
\]

则

\[
\boxed{
L_X=H_X^*H_X.
}
\]

所以

\[
L_X\succeq0,
\]

\[
\boxed{
\operatorname{rank}L_X
=
\operatorname{rank}H_X
\le
\operatorname{rank}B.
}
\tag{46}
\]

并且

\[
\boxed{
\operatorname{tr}L_X
=
\|C_X^{\dagger/2}B^*A\|_F^2,
}
\tag{47}
\]

\[
\boxed{
\lambda_{\max}(L_X)
=
\|C_X^{\dagger/2}B^*A\|_2^2.
}
\tag{48}
\]

普通

\[
\det L_X
\]

通常没有太大意义，因为当地图维数大于 pose 维数时它几乎必然为零。更合适的是：

\[
\operatorname{pdet}L_X,
\]

或

\[
\frac{\operatorname{pdet}_{\mathcal S}K_{\rm eff}}
{\operatorname{pdet}_{\mathcal S}K_{\rm IS}}.
\]

# 9. SLAM 的必然 gauge：一个物理上的交集定理

考虑群 \(G=SE(2)\) 同时作用于地图和轨迹。若背景均匀且整个传感器系统、场景一起刚体平移或旋转不会改变相对物理几何，则

\[
F(g\cdot\chi,g\cdot X)
=
F(\chi,X).
\]

对群生成元 \(\xi\) 在单位元处求导：

\[
\boxed{
A\,\xi_\chi
+
B\,\xi_X
=
0.
}
\tag{49}
\]

因此

\[
A\xi_\chi
=
-B\xi_X
\in\operatorname{Ran}(B),
\]

从而

\[
\boxed{
\xi_\chi\in\ker K_{\rm SLAM}.
}
\tag{50}
\]

---

## 9.1 二维显式生成元

地图平移 \(v\in\mathbb R^2\)：

\[
\chi_v(r)=\chi(r-v),
\]

因此

\[
\delta\chi_v(r)
=
-v^T\nabla\chi(r).
\]

对应 pose 变化为

\[
\delta p_t=v,
\qquad
\delta\theta_t=0.
\]

旋转生成元 \(\omega\)：

\[
\delta\chi_\omega(r)
=
-\omega(Jr)^T\nabla\chi(r),
\]

\[
\delta p_t=\omega Jp_t,
\qquad
\delta\theta_t=\omega.
\]

在一般非对称场景中，这给出最多三个二维 \(SE(2)\) gauge directions。

若场景具有旋转对称性，旋转生成元可能为零；若有已知 anchor、非均匀已知背景或固定世界边界，gauge 会被部分或全部打破。

这说明：

> \(\operatorname{Ran}(A)\cap\operatorname{Ran}(B)\) 不只是偶然的数值相关性。SLAM 的群不变性会强制产生物理上精确的交集。

# 10. Born approximation

Born 模型为

\[
y_{\alpha}
=
\int_D
g_k(r_\alpha,z)
\chi(z)
e_\alpha^{\rm inc}(z)
\,dz.
\]

离散后写成

\[
y=A(X)\chi.
\]

因此

\[
A(X)
=
G_S(X)D_{e^{\rm inc}(X)}.
\]

在非零名义场景 \(\chi_0\) 处，

\[
\boxed{
B_\ell
=
\frac{\partial A(X)}{\partial X_\ell}
\chi_0.
}
\tag{51}
\]

这使 pose subspace 非常清楚：

\[
\boxed{
\operatorname{Ran}(B)
=
\operatorname{span}
\left\{
A_{X_1}\chi_0,\ldots,A_{X_p}\chi_0
\right\}.
}
\tag{52}
\]

---

## 10.1 \(\chi_0=0\) 的退化

若线性化点是空场景：

\[
\chi_0=0,
\]

则

\[
B=0.
\]

此时

\[
K_{\rm SLAM}=K_{\rm IS},
\]

但这个结论不能解释为“pose uncertainty 没有影响”。

Born 模型的联合展开是

\[
\boxed{
F(\delta\chi,X_0+\delta X)
=
A(X_0)\delta\chi
+
D_XA(X_0)[\delta X]\,\delta\chi
+
O(\|\delta\chi\|\|\delta X\|^2).
}
\tag{53}
\]

第二项是 \(\delta\chi\) 与 \(\delta X\) 的双线性项。它在联合一阶 Jacobian 中消失，但对 sensing operator uncertainty 是主导项。

因此你的研究必须区分：

### 局部联合可辨识性

在非零 \(\chi_0\) 附近分析

\[
A\delta\chi+B\delta X.
\]

### 空场景附近的几何失配稳定性

分析

\[
A(X_0+\delta X)-A(X_0)
\]

如何作用于未知 \(\delta\chi\)。

这两个问题有关，但不是同一个一阶问题。

# 11. Far-field 解析结构

在 plane-wave incidence 和 far-field observation 下，Born 数据可写成

\[
y_{\alpha,k}
=
c_{\alpha,k}
\widehat\chi(q_{\alpha,k}),
\]

其中

\[
q_{\alpha,k}
=
k(\widehat r_\alpha-d_\alpha)
\]

是 Fourier sampling vector，符号取决于 Fourier convention。

对位姿坐标 \(X_\ell\) 求导：

\[
\boxed{
\frac{\partial y_{\alpha,k}}{\partial X_\ell}
=
\frac{\partial\log c_{\alpha,k}}{\partial X_\ell}
\,y_{\alpha,k}
+
c_{\alpha,k}
\nabla_q\widehat\chi(q_{\alpha,k})^T
\frac{\partial q_{\alpha,k}}{\partial X_\ell}.
}
\tag{54}
\]

因此 pose tangent 包含两个部分：

\[
\boxed{
\text{phase/amplitude modulation}
+
\text{Fourier sampling location displacement}.
}
\]

这给出非常清楚的轨迹解释：

- 远距离小平移、方向近似不变时，主要是 phase modulation；
- 有限距离或大孔径运动会改变 \(q\)，从而测到 \(\nabla_q\widehat\chi\)，即空间矩信息；
- 直线、小角度轨迹对应 Fourier missing wedge；
- 圆周和多视角轨迹扩大 \(q\)-coverage，并使单一 pose 补偿难以在所有视角上保持一致。

---

## 11.1 全局平移的精确混淆

若

\[
\chi_v(r)=\chi(r-v),
\]

则

\[
\widehat\chi_v(q)
=
e^{-iq^Tv}\widehat\chi(q).
\]

一阶变化为

\[
\delta y(q)
=
-i(q^Tv)y(q).
\]

而传感器参考系的相反平移会产生相反的相位变化。因此地图平移与全局 pose 平移在数据空间中精确重合，直接验证了前面的 \(SE(2)\) gauge theorem。

---

## 11.2 距离与波长 scaling

二维 Green 函数在 \(kR\gg1\) 时满足

\[
g_k(R)
\sim
\frac{e^{i(kR+\pi/4)}}{\sqrt{8\pi kR}},
\]

以及

\[
\nabla\log g_k(R)
=
\left(
ik-\frac{1}{2R}
\right)\widehat R
+
o(R^{-1}).
\]

因此，一个 Tx Green 与一个 Rx Green 的 Born kernel 幅度近似为

\[
|a(z)|
\propto
(R_{\rm tx}R_{\rm rx})^{-1/2}.
\]

所以

\[
K_{\rm IS}
\quad\text{的尺度约为}\quad
(R_{\rm tx}R_{\rm rx})^{-1}.
\]

monostatic 且 \(R_{\rm tx}\approx R_{\rm rx}\approx R\) 时：

\[
\boxed{
K_{\rm IS}=O(R^{-2})
\quad
\text{in 2D}.
}
\]

位置导数相对场强满足

\[
\frac{\|\partial_xg\|}{\|g\|}
\sim k.
\]

但要注意：

- 无 prior 时，\(P_{\operatorname{Ran}(B)}\) 对 \(B\) 的整体缩放不敏感，因此 \(\rho_i\) 主要由 subspace orientation 决定；
- 有 prior 时，\(B^*B\) 与 \(J_X\) 的相对尺度很重要，距离和波长会改变 prior-weighted retention。

因此“远离场景”可能提高相对 pose retention，却同时大幅降低绝对地图信息。

# 12. 多频率究竟带来什么？

将各频率堆叠：

\[
A=
\begin{bmatrix}
A_1\\ \vdots\\ A_F
\end{bmatrix},
\qquad
B=
\begin{bmatrix}
B_1\\ \vdots\\ B_F
\end{bmatrix}.
\]

若所有频率共享同一个物理 pose perturbation \(z\)，则

\[
u\in\ker K_{\rm SLAM}^{\rm multi}
\]

当且仅当存在一个共同的 \(z\)，满足

\[
\boxed{
A_f u=B_f z,
\qquad
\forall f.
}
\tag{55}
\]

即使每个频率单独都存在补偿 \(z_f\)，也不一定存在同一个 \(z\) 同时补偿所有频率。

这正是多频率打破 pose–map 混淆的主要机制之一。

---

## 定理 5：增加频率不会降低绝对有效信息

由变分表述，

\[
u^*K_{\rm eff}^{(1:F)}u
=
\min_z
\left[
\sum_{f=1}^F
\|A_fu-B_fz\|^2
+
z^*J_Xz
\right].
\]

加入第 \(F+1\) 个频率后，只是在目标中增加非负项，因此

\[
\boxed{
K_{\rm eff}^{(1:F+1)}
\succeq
K_{\rm eff}^{(1:F)}.
}
\tag{56}
\]

所以多频率在绝对信息意义下只会增加或保持有效信息。

但 normalized retention spectrum

\[
\rho_i
\]

不一定单调，因为分母 \(K_{\rm IS}\) 也同时变化。

---

## 12.1 “只是重复已有模式”的精确情形

若新频率或新测量块满足

\[
A_2=cA_1,
\qquad
B_2=cB_1,
\]

则新数据只是独立噪声下的缩放重复：

\[
K_{\rm IS}^{\rm new}
=
(1+|c|^2)K_{\rm IS}^{\rm old},
\]

\[
K_{\rm SLAM}^{\rm new}
=
(1+|c|^2)K_{\rm SLAM}^{\rm old}.
\]

因此绝对信息增加，但

\[
\boxed{
\rho_i^{\rm new}=\rho_i^{\rm old}.
}
\]

真正改善分离需要不同频率改变：

\[
\operatorname{Ran}(A_f)
\quad\text{与}\quad
\operatorname{Ran}(B_f)
\]

的联合几何，而不是仅提高 SNR。

# 13. Full-wave regime 下的结构

Full-wave map Jacobian 为

\[
A_t
=
G_{S,t}M_t^{-1}D_{E_t^{\rm tot}}.
\]

可以将它理解为三层作用：

\[
\boxed{
\delta\chi
\xrightarrow{D_E}
\text{局部 induced-current perturbation}
\xrightarrow{M^{-1}}
\text{multiple-scattering propagation}
\xrightarrow{G_S}
\text{measured data}.
}
\]

相应的基本上界为

\[
\boxed{
\|A_t\|
\le
\|G_{S,t}\|
\|M_t^{-1}\|
\|E_t^{\rm tot}\|_\infty.
}
\tag{57}
\]

Pose Jacobian 满足

\[
\begin{aligned}
\|B_th\|
\le{}&
\|DG_{S,t}[h]\|\,\|j_t\|\\
&+
\|G_{S,t}\|\|M_t^{-1}\|\|D_\chi\|
\left(
\|De_t^{\rm inc}[h]\|
+
\|DG_D[h]\|\,\|j_t\|
\right).
\end{aligned}
\tag{58}
\]

当

\[
\sigma_{\min}(M_t)\rightarrow0
\]

时，\(A,B\) 及其轨迹导数都可能被 resolvent 放大。绝对信息可能增大，但：

- 线性化有效半径缩小；
- 对模型误差和 pose perturbation 的敏感度上升；
- \(DK_{\rm eff}\) 可能比 \(K_{\rm eff}\) 本身增长得更快。

因此 multiple scattering 既可能带来额外信息，也可能造成更差的稳定性。

# 14. 轨迹导数 \(DK_{\rm eff}\)

令

\[
C=B^*B+J_X,
\qquad
H=C^{-1},
\qquad
W=I-BHB^*,
\]

先假设 \(C\) 可逆。则

\[
K_{\rm eff}=A^*WA.
\]

沿轨迹方向 \(h=\Delta X\)，记导数为点号：

\[
\boxed{
\dot K_{\rm eff}
=
\dot A^*WA
+
A^*W\dot A
+
A^*\dot W A.
}
\tag{59}
\]

其中

\[
\boxed{
\dot W
=
-\dot BHB^*
-
BH\dot B^*
+
BH\dot C HB^*,
}
\tag{60}
\]

\[
\boxed{
\dot C
=
\dot B^*B
+
B^*\dot B
+
\dot J_X.
}
\tag{61}
\]

这是 \(DK_{\rm eff}[h]\) 的完整一阶公式。

---

## 14.1 \(\dot A\) 的显式 full-wave 形式

\[
A=G_SM^{-1}D_E.
\]

因此

\[
\boxed{
\dot A
=
\dot G_SM^{-1}D_E
+
G_S\dot M^{-1}D_E
+
G_SM^{-1}D_{\dot E}.
}
\tag{62}
\]

其中

\[
\dot M^{-1}
=
-M^{-1}\dot M M^{-1}.
\]

若 \(G_D\) 随 pose 变化，

\[
\dot M=-D_\chi\dot G_D,
\]

所以

\[
\dot M^{-1}
=
M^{-1}D_\chi\dot G_D M^{-1}.
\]

并且

\[
\dot E
=
\dot e^{\rm inc}
+
\dot G_Dj
+
G_D\dot j.
\]

若 \(G_D\) 与 pose 无关，则

\[
\dot M=0,
\]

并有

\[
\dot j
=
M^{-1}D_\chi\dot e^{\rm inc},
\]

\[
\dot E
=
(I-G_DD_\chi)^{-1}\dot e^{\rm inc}.
\]

---

## 14.2 为什么 \(\dot B\) 需要二阶 forward derivative

因为

\[
B=D_XF,
\]

所以轨迹改变时

\[
\boxed{
\dot B
=
D_X^2F[h,\cdot].
}
\]

在 \(G_D\) 固定的情况下，

\[
Bh=DG_S[h]j+G_SDj[h].
\]

沿另一个方向 \(q\) 求导：

\[
\boxed{
\begin{aligned}
(DB[q])h
={}&
D^2G_S[q,h]j\\
&+
DG_S[h]Dj[q]\\
&+
DG_S[q]Dj[h]\\
&+
G_SD^2j[q,h].
\end{aligned}
}
\tag{63}
\]

所以严格计算 \(DK_{\rm eff}\) 不仅需要 forward Jacobian，还需要 pose Hessian。

忽略 \(\dot B\) 是一个可以使用的近似，但必须明确称为：

\[
\text{frozen nuisance-subspace approximation}.
\]

## 14.3 无 prior 时的 projector derivative

若 \(B\) 在邻域内保持常秩，

\[
P_B=BB^\dagger
\]

的导数为

\[
\boxed{
\dot P_B
=
P_{B^\perp}\dot B B^\dagger
+
\left(
P_{B^\perp}\dot B B^\dagger
\right)^*.
}
\tag{64}
\]

因此

\[
\dot P_{B^\perp}=-\dot P_B.
\]

并得到谱范数 bound：

\[
\boxed{
\|\dot K_{\rm SLAM}\|
\le
2\|A\|\|\dot A\|
+
2\|A\|^2
\|B^\dagger\|
\|\dot B\|.
}
\tag{65}
\]

这个式子很有物理意义：

> 当 \(B\) 的最小非零奇异值很小时，pose tangent subspace 会对轨迹扰动高度敏感。

这正是“子空间不稳定”的严格来源之一。

# 15. 特征值和子空间扰动

若

\[
K_{\rm eff}v_i=\lambda_iv_i,
\qquad
\|v_i\|=1,
\]

且 \(\lambda_i\) 是单特征值，则

\[
\boxed{
D\lambda_i[h]
=
v_i^*
DK_{\rm eff}[h]
v_i.
}
\tag{66}
\]

所以你的式 (15) 正确。

若取相位规范

\[
v_i^*\dot v_i=0,
\]

则

\[
\boxed{
\dot v_i
=
\sum_{j\ne i}
v_j
\frac{
v_j^*\dot K_{\rm eff}v_i
}{
\lambda_i-\lambda_j
}.
}
\tag{67}
\]

因此

\[
\|\dot v_i\|
\lesssim
\frac{\|\dot K_{\rm eff}\|}
{\operatorname{gap}_i},
\]

其中

\[
\operatorname{gap}_i
=
\min_{j\ne i}
|\lambda_i-\lambda_j|.
\]

若研究 generalized retention eigenvalue，并归一化为

\[
v_i^*K_{\rm IS}v_i=1,
\]

则

\[
\boxed{
\dot\rho_i
=
v_i^*
\left(
\dot K_{\rm eff}
-
\rho_i\dot K_{\rm IS}
\right)
v_i.
}
\tag{68}
\]

## 15.1 不要求单特征值的严格稳定 bound

由 Weyl 不等式，

\[
\boxed{
|\lambda_i(K(X+\Delta X))
-
\lambda_i(K(X))|
\le
\|K(X+\Delta X)-K(X)\|.
}
\tag{69}
\]

若

\[
\|DK[h]\|
\le
L_K\|h\|,
\]

则

\boxed{
|\delta\lambda_i|
\le
L_K\|\Delta X\|
+
O(\|\Delta X\|^2).
}
\tag{70}
\]

这个结论不要求 eigenvalue simple。

# 16. Robust trajectory objective

定义

\[
\gamma_r(X,\varepsilon)
=
\min_{\|\Delta X\|\le\varepsilon}
\lambda_r(K_{\rm eff}(X+\Delta X)).
\]

假设：

- \(\lambda_r\) 在邻域内为单特征值；
- 与相邻特征值有正 gap；
- \(K_{\rm eff}\) 二阶连续可微；
- 不确定集合确实是完整范数球。

则

\[
\lambda_r(X+\Delta X)
=
\lambda_r(X)
+
D\lambda_r(X)[\Delta X]
+
O(\|\Delta X\|^2).
\]

由对偶范数定义，

\[
\min_{\|\Delta X\|\le\varepsilon}
D\lambda_r[\Delta X]
=
-\varepsilon
\|\nabla_X\lambda_r\|_*.
\]

因此

\[
\boxed{
\gamma_r(X,\varepsilon)
=
\lambda_r(X)
-
\varepsilon
\|\nabla_X\lambda_r(X)\|_*
+
O(\varepsilon^2).
}
\tag{71}
\]

所以你的式 (18) 正确，但需要上述条件。

若轨迹受到动力学或碰撞约束，不确定方向只能属于 tangent cone \(\mathcal T_X\)，此时惩罚项应改为

\[
-\varepsilon
\sup_{\substack{h\in\mathcal T_X\\\|h\|\le1}}
\left(-D\lambda_r[h]\right).
\]

若 \(\lambda_r\) 是重特征值，不能使用单一梯度；一阶变化由退化 eigenspace 上的压缩矩阵

\[
V_E^*DK[h]V_E
\]

的特征值决定。

## 16.1 一个始终成立的保守下界

若在半径 \(\varepsilon\) 内

\[
\|DK(X)[h]\|
\le
L_K\|h\|,
\]

则

\[
\boxed{
\gamma_r(X,\varepsilon)
\ge
\lambda_r(K_{\rm eff}(X))
-
\varepsilon L_K
+
O(\varepsilon^2).
}
\tag{72}
\]

这比 simple-eigenvalue 近似更保守，但不怕 eigenvalue crossing。

# 17. 独立 pose block 的特殊结构

若每个 \(x_t\) 都完全独立，且没有 motion prior，则

\[
B=
\operatorname{blkdiag}(B_1,\ldots,B_T).
\]

因此

\[
P_{B^\perp}
=
\operatorname{blkdiag}
(P_{B_1^\perp},\ldots,P_{B_T^\perp}),
\]

从而

\[
\boxed{
K_{\rm SLAM}
=
\sum_{t=1}^T
A_t^*P_{B_t^\perp}A_t.
}
\tag{73}
\]

于是

\[
\ker K_{\rm SLAM}
=
\bigcap_{t=1}^T
\left\{
u:A_tu\in\operatorname{Ran}(B_t)
\right\}.
\]

还可得维数上界

\[
\boxed{
\operatorname{rank}K_{\rm SLAM}
\le
\sum_t
\left(
m_t-\operatorname{rank}B_t
\right),
}
\tag{74}
\]

其中 \(m_t\) 是 realified 单帧数据维数。

例如，每个位姿只有一个复标量测量，因此 realified 数据维数为 \(2\)。若 \(B_t\) 对两个实数据分量满行秩，则

\[
P_{B_t^\perp}=0.
\]

在每个位姿完全自由的情况下，该帧对地图不提供任何一阶有效信息。这表明：

> 多通道阵列、跨时刻 motion prior 或共享轨迹结构，不只是提高精度，而可能是可辨识性的必要条件。

## 19.3 计算步骤

1. 求 \(j_t,E_t^{\rm tot}\)。
2. 用式 (22)、(23) 构造 analytic \(A,B\)。

   \[
   \frac{F(\chi+h\delta\chi,X)-F(\chi-h\delta\chi,X)}{2h}
   \]
   与 \(A\delta\chi\) 一致；
   pose 方向同理。
4. whiten、realify。
5. 计算
   \[
   K_{\rm IS},K_{\rm SLAM},K_{\rm eff}.
   \]
6. 对 \(A,B\) 做 rank-revealing QR/SVD，得到 \(Q,Z\)。
7. 验证：
   \[
   \operatorname{eig}(R_{\rm op})
   =
   1-\sigma_i^2(Z^*Q).
   \]
8. 验证 rank identity。
9. 构造 \(SE(2)\) map generator，验证
   \[
   \frac{\|A\delta\chi+B\delta X\|}
   {\|A\delta\chi\|+\|B\delta X\|}

   \]
10. 扫描
    \[

    \qquad
    \alpha=10^{-6},\ldots,10^4,
    \]
    验证
    \[
    K_{\rm SLAM}\preceq K_{\rm eff}(\alpha)\preceq K_{\rm IS}.
    \]
11. 对轨迹施加小扰动，比较
    \[
    \lambda_i(X+\Delta X)-\lambda_i(X)
    \]
    与
    \[
    v_i^*DK[\Delta X]v_i.
    \]
12. 在 \(\|\Delta X\|=\varepsilon\) 边界随机采样，比较真实 worst case 与
    \[
    \lambda_r-\varepsilon\|\nabla\lambda_r\|_*.
    \]

=

\]

不要用 SOM 中的物理 dominant-subspace threshold 来“验证”精确 rank theorem。

# 20. 与现有文献的对应

## 20.1 Chen SOM / dominant-current / SOM-Net

Chen 系列 SOM 的子空间来自外部辐射算子 \(G_S\) 的 SVD。它把 induced current 分为由主要奇异向量决定的 deterministic current 和 complementary/ambiguous current，再交替优化 current 与 contrast。SOM-Net 也明确沿用这一结构：输入 deterministic induced current，并通过网络补足完整 current；论文中的模型正是 \(E^t=E^i+G_DJ\)、\(E^s=G_SJ\)，以及基于 \(G_S\) SVD 的 current decomposition。

你的子空间则是

\[
\operatorname{Ran}
\left(
G_SM^{-1}D_E
\right)
\]

与

\[
\operatorname{Ran}(D_XF)
\]

在**数据空间**中的关系。

两者不相同：

\[
\boxed{
\text{SOM：current recovery ambiguity from }G_S
}
\]

\[
\boxed{
\text{本问题：map–pose tangent ambiguity in data space}
}
\]

它们之间的桥梁是

\[
A=G_SM^{-1}D_E.
\]

也就是说，SOM 研究的是 \(G_S\) 对 current 的压缩；你的理论研究的是 full nonlinear map tangent 经 \(G_SM^{-1}D_E\) 后，与 pose tangent 的交叠。

2025 年底提交、2026 年更新的 CSI/SOM 理论工作重点是对 iteratively regularized CSI/SOM 建立收敛性，而不是 pose nuisance 或 retention spectrum。

---

## 20.2 Full-wave inverse scattering DoF

已有 nonlinear inverse-scattering DoF 工作主要分析 external radiation operator 或 contrast-modified radiation matrix 的奇异值，并通过 significant singular values 的数量定义 NDoF；其中也明确把 SOM 与辐射算子的 step-like singular spectrum 联系起来。

与你的区别是：

- 已有 DoF：已知测量几何下，场本身有多少独立空间模式；
- 你的 DoF：这些模式中多少会与 pose tangent 混淆；
- 已有工作通常仍需要显著奇异值比例，例如 \(99\%\)；
- 你的 \(\rho_i\)、\(\sum\cos^2\theta_i\) 是连续、threshold-free 的相对信息量。

---

## 20.3 EFIM / Schur complement

利用 Schur complement 消除 nuisance parameter 本身是成熟的 equivalent Fisher information 思想。宽带定位文献很早就用 EFIM 把 channel nuisance 和位置参数分离，并从原始波形层面推导有效定位信息。

因此：

\[
A^*P_{B^\perp}A
\]

作为线性高斯 nuisance elimination 的代数形式，本身不宜宣称新颖。

潜在新意在于：

1. 将它放入 full-wave contrast-source inverse-scattering SLAM；
2. 给出 \(A,B\) 的显式 full-wave 结构；
3. 把 normalized spectrum 严格化为主夹角平方正弦；
4. 推出 gauge、低秩扰动、interlacing、轨迹导数和多频率规律。

---

## 20.4 RF-SLAM PCRB 与 identifiability

2025 年的 distributed-MIMO RF-SLAM 工作已经推导了同时包含 localization 和 specular-surface mapping 的 posterior CRB，并考虑 single- 和 double-bounce reflection；它很接近你的“map EFIM after pose elimination”，但 map 是有限维几何表面参数，不是 full-wave volumetric contrast。

2026 年的 double-bounce snapshot radio-SLAM 工作进一步表明，共享 incidence point 的 double-bounce paths 可以提高已有 landmark 和 UE 状态的估计，并使原本不可观测的新 landmark 变得可观测。用你的语言，这相当于新测量块改变了联合 \([A;B]\) 结构，并缩小了 map–pose confounding kernel。

2026 年的 snapshot 6-D radio-SLAM 还专门研究了 angle-delay 几何模型的局部 Jacobian rank 与 minimal-set implications，但仍属于有限维 path/landmark model。

2026 年的 coherent direct multipath SLAM 已经直接从 raw coherent RF signals 做联合地图与定位，并与 PCRLB 比较；这比先提取 MPC 参数的 SLAM 更接近你的 full-wave/direct-data 方向，但其核心仍是 Bayesian algorithm 和 surface-feature model，而不是 volumetric Helmholtz Jacobian 的 retention spectrum。

---

## 20.5 Bilinear identifiability 与 gauge

Born 模型中的

\[
y=A(X)\chi
\]

本质上属于 structured bilinear inverse problem。已有 bilinear inverse-problem 理论会从 transformation group、identifiability up to group action 和 sample complexity 角度研究 blind calibration。

这类理论与你的 \(SE(2)\) gauge theorem 很接近，但通常不包含：

- Helmholtz/full-wave resolvent \(M^{-1}\)；
- map–pose tangent principal-angle spectrum；
- inverse-scattering trajectory geometry；
- effective map information operator。

---

## 20.6 Active sensing / trajectory design

已有 active SLAM 和 observability-aware trajectory work 会预测 landmark covariance 或使用 FIM/eigenvalue 类指标来优化轨迹。

Bayesian inverse-problem OED 也已有针对模型和噪声失配的 robust A-optimal design。

你的潜在区别是优化对象不是简单的

\[
A^*A,
\]

而是

\[
A^*
\left[
I-B(B^*B+J_X)^\dagger B^*
\right]
A,
\]

并进一步加入

\[
-\varepsilon\|\nabla_X\lambda_r\|_*.
\]

也就是同时考虑：

\[
\boxed{
\text{map strength}
-
\text{pose confounding}
-
\text{trajectory execution sensitivity}.
}
\]

# 22. 最可能形成论文贡献的三个结果

## 第一优先级：Pose-confounding spectral theorem

建立一套统一定理：

\[
\ker K_{\rm SLAM}
=
\{u:Au\in\operatorname{Ran}(B)\},
\]

\[
r_{\rm IS}-r_{\rm SLAM}
=
\dim(\operatorname{Ran}(A)\cap\operatorname{Ran}(B)),
\]

\[
\rho_i=\sin^2\theta_i,
\]

\[
\operatorname{rank}L_X\le\operatorname{rank}B,
\]

\[
\lambda_{i+p}(K_{\rm IS})
\le
\lambda_i(K_{\rm eff})
\le
\lambda_i(K_{\rm IS}).
\]

其中最后两个低秩与 interlacing 结果尤其值得强调，因为它们把 pose dimension 与 inverse-scattering spectrum 直接联系起来。

---

## 第二优先级：Full-wave gauge、Born 退化与多频率 transversality

形成三个物理专属结果：

1. \(SE(2)\) invariance 强制产生 map–pose intersection；
2. Born 在 \(\chi_0=0\) 处 \(B=0\)，需要二阶双线性分析；
3. 多频率的 exact kernel 条件为存在同一个 pose compensation：
   \[
   A_fu=B_fz,\quad\forall f.
   \]

这组结果不是一般 Schur complement 文献自动给出的，而是由 inverse-scattering physics 决定。

---

## 第三优先级：Robust trajectory spectral bound

给出

\[
DK_{\rm eff}[h]
\]

的显式公式、full-wave resolvent bounds，以及

\[
\gamma_r(X,\varepsilon)
=
\lambda_r(X)
-
\varepsilon\|\nabla_X\lambda_r\|_*
+
O(\varepsilon^2).
\]

进一步用

\[
\|DK\|
\]

得到不依赖 simple eigenvalue 的 worst-case lower bound。

这可形成：

> 不只追求强信息，还追求对 pose execution error 不敏感的 inverse-scattering trajectory。
