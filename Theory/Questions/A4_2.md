你的这个问题非常值得单独从当前 full-wave 主线里抽出来研究，因为这里其实有一个很容易混淆、但非常关键的区别：
\[
\boxed{\text{“far field 更容易反演”}\neq \text{“far field 含有最多可恢复材料信息”}}
\]我查了 Chen 的书以及这一支从 spatial bandwidth / NDoF / SVD / near-field sensing 到 anisotropic inversion 的文献后，我目前的判断是：
\[
\boxed{
\text{Born 条件下，far field 不是普适意义上的最佳 information window。}
}
\]更准确地说，far field 是一个非常干净的 propagating-mode information plateau：它把问题变成近似 Fourier sampling，所以伪影小、解释漂亮、数值也好做；但是它已经让高横向波数的 evanescent / reactive modes 在稳定意义下消失了。真正的 near field 可以提供额外的可恢复空间模态。至于有没有一个“不近不远”的最佳距离，则取决于你是否把天线耦合、噪声、有限 aperture、模型误差、动态范围等现实因素放进来。理想波动物理本身并不保证一个有限的 \(d^\star\)；现实系统则非常可能产生一个真正的 window。
而且到了各向异性以后，我反而认为你的“一个 window”应该升级成：
\[
\boxed{\text{mode-resolved / polarization-resolved information windows}}
\]也就是说，它确实很可能 split。
1. 先把 Born far field 看清楚：它没有丢 propagating phase
先取最简单的标量 Born 模型：
\[
E^s(\mathbf r_s;\hat{\mathbf s}_i)
=
k^2\int_D
G(\mathbf r_s,\mathbf r)
\chi(\mathbf r)
e^{ik\hat{\mathbf s}_i\cdot\mathbf r}
\,d\mathbf r .
\]当 receiver 进入远场，
\[
G(\mathbf r_s,\mathbf r)
\simeq
\frac{e^{ikR}}{4\pi R}
e^{-ik\hat{\mathbf s}_s\cdot\mathbf r},
\]所以去掉已知的传播因子以后，
\[
\boxed{
\widetilde E^s_\infty
(\hat{\mathbf s}_s,\hat{\mathbf s}_i)
\propto
\int_D
\chi(\mathbf r)
e^{-i\mathbf q\cdot\mathbf r}
d\mathbf r
=
\widehat\chi(\mathbf q)
}
\]其中
\[
\boxed{
\mathbf q
=
k(\hat{\mathbf s}_s-\hat{\mathbf s}_i).
}
\]因此
\[
|\mathbf q|\le 2k .
\]这正是 Chen 第 10 章里的 Ewald limiting sphere：如果 incidence 和 scattering direction 都完整覆盖，那么 first-order Born far-field data 直接给出 \(|\mathbf q|\le2k\) 内的 contrast Fourier coefficients，所以 Born reconstruction 本质上就是一个低通重建。
因此第一件非常重要的事情是：
\[
\boxed{\text{far field }\neq \text{ phaseless}}
\]如果你测的是 coherent \(S\)-parameter / complex field，那么
\[
e^{-i\mathbf q\cdot \mathbf r}
\]里的空间 phase 完整保留。目标位置、界面位置等恰恰就是通过这部分 phase 编码的。
far-field approximation 本身没有把 propagating wave 的 phase 扔掉。
如果仪器最后只测 RCS、intensity、\(|E|^2\)，那是 measurement modality 把 phase 丢掉，不是“远场”把 phase 丢掉。Chen 也把 phase-available 和 phaseless ISP 明确分成了两个不同问题。
2. Far field 真正丢掉的是“模态”，不是 phase
把 Green function 写成 angular spectrum：
\[
G(\boldsymbol\rho,z)
\sim
\int_{\mathbb R^2}
\frac{
e^{i\mathbf k_t\cdot\boldsymbol\rho}
e^{ik_z z}
}{k_z}
\,d\mathbf k_t ,
\]其中
\[
k_z=
\begin{cases}
\sqrt{k^2-|\mathbf k_t|^2},
&|\mathbf k_t|\le k,\\[1mm]
i\sqrt{|\mathbf k_t|^2-k^2},
&|\mathbf k_t|>k .
\end{cases}
\]前一类是 propagating modes，后一类是 evanescent modes。
令
\[
\kappa=\sqrt{|\mathbf k_t|^2-k^2}.
\]那么 evanescent mode 在离目标 \(d\) 处的幅度大约是
\[
\boxed{
e^{-\kappa d}.
}
\]所以当 \(d\to\infty\) 时，它们迅速被压掉。
这就是你应该使用的语言：
Far field 不损失 propagating phase；它把高空间频率 channel 的 singular values 压到了 perturbation floor 以下。

这比“phase 丢失”严格得多。
Chen 在书里通过 angular spectrum 明确讨论了 far zone 中 evanescent waves 的衰减；他在 time reversal 那一章甚至直接写出了这种指数衰减。但要注意，他那里“near field 不改善 TR resolution”是 time-reversal algorithm-specific 的结论，因为普通 TR 没有对 evanescent wave 做指数放大，不能把这个结论错误推广成“near-field inverse scattering 没有额外信息”。
3. 所以 Born 下有没有一个“最佳距离”？
这里要分三个完全不同的问题。
理想情况：完整 angular aperture，数据归一化，精确 Green function
假设你保持的是相同的 observation angle：
\[
\hat{\mathbf s}_s\in\Omega_s
\]而不是保持一个固定米制长度的 array。
进入 far zone 后，
\[
G
\simeq
\frac{e^{ikR}}{R}
e^{-ik\hat s\cdot r},
\]除去已知 \(e^{ikR}/R\) 后，operator 基本不再随 \(R\) 改变。
因此：
\[
\boxed{
R\gg D^2/\lambda
\quad\Longrightarrow\quad
\text{normalized propagating information 对 }R\text{ 进入 plateau}.
}
\]所以在这种理想模型下，不存在
\[
R=5\lambda
\]比
\[
R=50\lambda
\]“信息更多”的说法。
它们是同一个 far-field operator 的不同 radial sampling。
因此：
\[
\boxed{\text{不存在一个特殊的“最佳远场半径”。}}
\]但从 near field 往 far field 走，确实在丢 stable high-\(k\) modes
假设误差底为 \(\epsilon\)。
一个 evanescent mode 至少需要满足
\[
e^{-\kappa d}\gtrsim \epsilon
\]才具有实际意义，所以粗略得到
\[
\boxed{
\kappa_{\max}(d)
\sim
\frac{\log(1/\epsilon)}{d}.
}
\]因此 stable spatial bandwidth 会随着 \(d\) 增加而收缩。
也就是说：
\[
d\downarrow
\quad\Longrightarrow\quad
\text{潜在 stable rank 增大}.
\]这并不是 Fisher information，而是 radiation operator 本身的 approximation number / singular spectrum 在发生变化。
Bucci 和 Franceschetti 在 TAP 1987 就建立了 scattered field 的 effective spatial bandwidth；1989 年进一步用“在给定误差以下两个场无法区分”的思想定义了 field degrees of freedom，得到 NDoF 本质上由 effective spatial bandwidth 和 observation domain 控制。这个思想与你现在所谓 “information window” 极其接近，只是他们没有把它表述为 material-reconstruction-versus-standoff window。ResearchGate
固定物理 aperture 时，farther 甚至会额外丢 angular information
比如你的阵列实际宽度固定为 \(L\)。
大距离下 angular aperture 约为
\[
\Theta \sim \frac{L}{d}.
\]那么
\[
d\uparrow
\Longrightarrow
\Theta\downarrow
\Longrightarrow
k\text{-space coverage}\downarrow .
\]这时不仅 evanescent 消失，连 propagating \(q\)-space coverage 都会收缩。
所以必须区分：
\[
\boxed{
\text{fixed angular aperture}
\neq
\text{fixed physical aperture}.
}
\]Soldovieri、Solimene、Pierri 等 2009 年直接用 radiation operator 的 SVD 研究了 Fresnel / near zone，不是 Fisher。他们明确把“information content”定义成 singular values 开始 asymptotic decay 之前的数量，而且证明增加某些 observation domains 会增加 information content 或改善 noise rejection。Jpier
这就是非常直接的文献证据：
far field 并不是 universally maximum-NDoF observation regime。

4. 那为什么你感觉 Born far field 的伪影和形变反而最少？
我觉得这里你的数值观察很可能是真的，但原因不是“far field 信息最多”。
原因更可能是：
\[
\boxed{\text{far field 把 operator 变得最规则。}}
\]Born + homogeneous background + plane wave + full-angle far field 下，kernel 几乎就是
\[
e^{-i\mathbf q\cdot\mathbf r}.
\]所以 normal PSF 近似 translation invariant：
\[
\chi_{\rm rec}
\simeq
h * \chi.
\]Full angular coverage 下 \(q\)-space window 又近似圆/球对称，于是 \(h\) 也是近似 isotropic。
因此表现通常就是：
平滑 blur，而不是形变。

而在 Fresnel / near field，
\[
G(\mathbf r_s,\mathbf r)
\]同时带有 amplitude variation、wavefront curvature、方向 dependence 等，operator 不再是一个漂亮的 Fourier restriction。不同 object location 的 sensitivity 不一样。
如果你还用“类似 far-field backprojection”的 inversion，当然会出现：
\[
\text{location-dependent PSF}
\rightarrow
\text{warping / anisotropic artifacts}.
\]所以一个非常重要的科研判据是：
\[
\boxed{
\text{near field artifact 多}
\not\Rightarrow
\text{near field information 少}.
}
\]它可能只是：
\[
\text{information 更多，但 singular spectrum 更不均匀、更难解码。}
\]这和 SOM 的思想其实完全一致。
5. 从 Xudong SOM 角度，information window 应该怎么定义
你的 full-wave scalar model可以写成
\[
J
=
D_\chi
(E^{\rm inc}+G_DJ),
\]\[
y=G_S(d)J.
\]Chen 的 Gs-SOM 正是对
\[
G_S=U\Sigma V^H
\]做 SVD，把 induced-current space 拆成 large-singular-value major subspace 和小奇异值 minor subspace；Twofold SOM 再进一步同时看 \(G_S\) 与 \(G_D\) 的 subspaces。
而且书中真正的 SOM 语义非常明确：\(G_S\) 是 induced source \(\to\) measured scattered field 的 operator，而不是 material \(\chi\to y\) 的 operator。
这点对你的问题至关重要。
因为你最终要恢复的是
\[
\chi(\mathbf r)=\epsilon_r(\mathbf r)-1,
\]而不是 \(J\)。
对 full-wave 方程线性化一次：
\[
\delta J
=
D_E\delta\chi
+
D_\chi G_D\delta J,
\]所以
\[
\boxed{
\delta J
=
(I-D_\chi G_D)^{-1}
D_E\,\delta\chi.
}
\]因此
\[
\boxed{
\delta y
=
G_S(d)
(I-D_\chi G_D)^{-1}
D_E\,\delta\chi.
}
\]定义
\[
T_\chi
=
(I-D_\chi G_D)^{-1}D_E,
\]那么
\[
\boxed{
D\mathcal F_d[\chi]
=
G_S(d)T_\chi .
}
\]这其实给你的 information window 一个非常漂亮的 SOM 解释：
\[
\boxed{
\text{material perturbation}
\xrightarrow{T_\chi}
\text{induced-current perturbation}
\xrightarrow{G_S(d)}
\text{measured data}.
}
\]因此不是简单问：
\[
\operatorname{rank}G_S(d)
\]多少。
而应该问：
\[
\boxed{
T_\chi(\delta\chi)
\text{ 有多少分量落进 }
V_S^+(d)?
}
\]这比 Fisher 信息自然很多。
6. 我建议你彻底不要用 bare rank
无限精度数学中，很多 operator：
\[
\operatorname{rank}G_S(d)=\infty
\]或者离散以后几乎总是 full rank。
这个量没有意义。
真正应该看：
\[
\boxed{
r_\tau(d)
=
\#\{j:\sigma_j(d)>\tau\}
}
\]其中 \(\tau\) 必须由：
\[
\text{measurement error}
+
\text{model discrepancy}
+
\text{calibration error}
\]来定。
这也和 Chen SOM 的做法一致：他的 major/minor induced-current subspace 就是用 noise-dependent singular-value cutoff 分出来的。
但你还可以比 SOM 再走一步。
7. 用 global stability 定义真正的 information window，而不是 Fisher
设
\[
\mathcal F_d:\chi\mapsto y
\]是距离 \(d\) 下的完整 nonlinear full-wave forward operator。
定义
\[
\boxed{
\omega_d(\epsilon)
=
\sup_{\substack{
\chi_1,\chi_2\in\mathcal C\\
\|\mathcal F_d(\chi_1)-\mathcal F_d(\chi_2)\|\le\epsilon
}}
\|\chi_1-\chi_2\|.
}
\]这个量的意义极直接：
在 measurement/model uncertainty 为 \(\epsilon\) 时，数据几乎无法区分的两个材料，最坏能相差多大？

这不是 Fisher，不是 \(A^*A\)，也不是局部 Gaussian 假设。
它是在问真正的 nonlinear distinguishability。
Chen 书本身也非常强调 uniqueness 与 stability 是两回事：即使 full far-field data 在理论上唯一决定 isotropic permittivity，实际 inverse scattering 仍然是不稳定的。
如果你的目标是同时还原内部和外部/边界结构，那么直接定义两个投影：
\[
Q_{\rm int},\qquad Q_{\rm out},
\]然后
\[
\omega_d^{\rm int}(\epsilon)
=
\sup
\|Q_{\rm int}(\chi_1-\chi_2)\|,
\]\[
\omega_d^{\rm out}(\epsilon)
=
\sup
\|Q_{\rm out}(\chi_1-\chi_2)\|.
\]于是你的 information window 可以严格定义成
\[
\boxed{
\mathcal W
=
\left\{
d:
\omega_d^{\rm int}(\epsilon)\le\eta_{\rm int},
\quad
\omega_d^{\rm out}(\epsilon)\le\eta_{\rm out}
\right\}.
}
\]这个定义，我认为比“maximize FIM”强得多。
SVD 则作为它的 local / computational surrogate，而不是理论本体。
8. Full-wave 为什么又可能让 far field 比 Born 更有信息？
这里 Chen 的第 10 章其实有一个与你非常接近的结论。
Born 下：
\[
E^s
\approx
G_S D_\chi E^i,
\]所以只有 Ewald ball 内的 Fourier spectrum 被直接线性编码。
但 full-wave：
\[
E^s
=
G_S
(I-D_\chi G_D)^{-1}
D_\chi E^i.
\]展开：
\[
(I-D_\chi G_D)^{-1}
=
I+D_\chi G_D
+(D_\chi G_D)^2+\cdots .
\]multiple scattering 会把不同 spatial frequencies 互相 mix。
Chen 明确指出：full-wave scattered field 中可以包含 Ewald limiting sphere 之外的 object spectrum information；但是这些谱以 nonlinear way 混进数据，所以“它存在”并不等于“它能够稳定地被恢复”。
他进一步强调：multiple scattering 可以把更多 scatterer information 转移到 far field，但 inversion 更复杂；也不能从“full-wave reconstruction 比 Born 好”就简单推出 multiple scattering 必然提高 resolution。
这和你现在得到的 information window 其实非常吻合。
你的 full-wave window 很可能来自两股力量竞争：
\[
\underbrace{\text{near-field / multiple-scattering mode enrichment}}
_{\text{增加可编码信息}}
\]对抗
\[
\underbrace{\text{nonlinear mixing + ill-conditioning + model sensitivity}}
_{\text{降低可稳定解码信息}}.
\]所以 full-wave 下真正出现一个中间 optimum，比 Born 情况更有物理合理性。
9. 各向异性以后，我认为 window 会 split
这一点其实可以推得很干净。
令介电常数变成 tensor：
\[
\boldsymbol\chi(\mathbf r)
=
\boldsymbol\epsilon_r(\mathbf r)-I.
\]Born far field：
\[
\mathbf E_\infty^s
\propto
P_s
\widehat{\boldsymbol\chi}(\mathbf q)
\mathbf p_i,
\]其中
\[
P_s=I-\hat s_s\hat s_s^T.
\]如果 receiver 选择 polarization \(\mathbf p_s\)，则 scalar datum 是
\[
\boxed{
d
\propto
\mathbf p_s^*
\widehat{\boldsymbol\chi}(\mathbf q)
\mathbf p_i.
}
\]所以对于 symmetric permittivity tensor，
\[
\boldsymbol\chi
\leftrightarrow
(\chi_{xx},\chi_{yy},\chi_{zz},
\chi_{xy},\chi_{xz},\chi_{yz}),
\]每一个 \(\mathbf q\) 实际上对应一个小型 sensing matrix
\[
B(\mathbf q,d):
\mathbb C^6
\rightarrow
\mathbb C^{N_{\rm pol/view}}.
\]然后做
\[
B
=
U_B
\operatorname{diag}
(\beta_1,\ldots,\beta_6)
V_B^H.
\]不同 tensor modes 的 \(\beta_m(d)\) 不会一样。
因此自然定义
\[
\boxed{
\mathcal W_m(\tau)
=
\{d:\beta_m(d)>\tau\}.
}
\]完全可能发生
\[
\mathcal W_1
\neq
\mathcal W_2
\neq
\cdots .
\]甚至：
\[
\mathcal W_1\cap\mathcal W_6=\varnothing .
\]这就是你说的：
\[
\boxed{\text{information window splitting}.}
\]而且这不仅是数学猜想。

所以你这里不是“会不会 split”的问题，我会更倾向于：
\[
\boxed{
\text{只要 measurement polarization / angular diversity 有限，split 几乎是默认现象。}
}
\]10. Near field 为什么对 anisotropy 尤其有意思
Far field dyadic Green 最终只保留 transverse projection：
\[
P_s=I-\hat s\hat s^T.
\]于是 longitudinal components 被压掉。
但 near-field dyadic Green 含有
\[
\frac1R,\qquad
\frac1{R^2},\qquad
\frac1{R^3}
\]不同 tensorial terms。
这意味着 near field 不只是“多几个高 \(k\)”：
\[
\boxed{
\text{它还改变了 polarization / tensor channels 本身的可见性。}
}
\]所以对于 isotropic scalar \(\epsilon\)，information curve 可能只是：
\[
N_{\rm stable}(d)
\]的一条单曲线。
而对于 anisotropic：
\[
N_{xx}(d),\;
N_{yy}(d),\;
N_{zz}(d),\;
N_{xy}(d),\ldots
\]很可能是六条不同的曲线。
这正是为什么我认为你最终最好不要叫单纯的 scalar “optimal distance”，而是研究：
\[
\boxed{
\text{standoff-dependent observable material subspaces}.
}

# 二、为什么它本质上确实属于 antenna array optimization？

你说这是 antenna array optimization 的一部分，我同意，但要稍微精确定义。

传统 **antenna array synthesis（天线阵列综合）**通常优化：

- beampattern，波束图；
- sidelobe level，旁瓣电平；
- directivity，方向性；
- mutual coupling，互耦；
- beamforming / nulling，波束形成与零陷形成。

而你研究的是：

\[
\boxed{\text{inverse-problem-aware array design}}
\]

即：

> 阵列不是为了“把能量照得最好”，而是为了让未知材料参数在测量空间中尽量可区分，同时还能分辨天线自身的误差。

因此设计变量应该写成

\[
z=
\left(
d,\,
\{x_t\},\,
\{x_r\},\,
\{p_t,p_r\},\,
\{\omega_f\},\,
\mathcal S_{\rm TxRx}
\right),
\]

分别代表：

- \(d\)：standoff distance，**天线—目标间距**；
- \(x_t,x_r\)：Tx/Rx 的空间位置；
- \(p_t,p_r\)：polarization，**极化方向**；
- \(\omega_f\)：频率集合；
- \(\mathcal S_{\rm TxRx}\)：哪些 Tx–Rx pair 实际测量，即 **measurement schedule（测量调度）**。

最终不是优化一个 beamwidth，而是优化：

\[
\boxed{
\text{材料可观测性}
+
\text{self-calibratability}
+
\text{attribution separability}.
}
\]

这已经是比传统 sensor placement 更强的设计目标。

已有阵列优化研究确实已经沿这个方向走了一部分。例如 Bucci–Crocco–Scapaticci 2015 已经通过算子的 spectral properties（谱性质）确定 nonredundant probes，即“需要多少个不冗余探头、放在哪里”；Maisto 等 2021 则利用散射算子的阶梯型奇异谱设计 multi-static/multi-frequency sampling。

但这些工作没有把**阵列自身参数未知**纳入同一个可观测性问题。

# 三、把你的两个课题写进同一个 full-wave 模型

先从最干净的离散 VIE / contrast-source formulation 开始。

材料 contrast：

\[
X=D_\chi.
\]

incident field：

\[
e^{\rm inc}
=
G_T(z,\eta_g)\,
C_T(\eta_e)s.
\]

其中：

- \(G_T\)：Tx 到 DOI 的传播；
- \(C_T\)：Tx electronics，包括 gain、phase、delay；
- \(\eta_g\)：geometry calibration parameters，天线位置/姿态；
- \(\eta_e\)：electronics calibration parameters，增益、相位、时延。

Full-wave state equation：

\[
j
=
X(e^{\rm inc}+G_Dj).
\]

因此

\[
j
=
R_\chi X e^{\rm inc},
\]

其中

\[
\boxed{
R_\chi=(I-XG_D)^{-1}
}
\]

叫 **resolvent（预解算子）**，它包含所有 multiple scattering。

接收端：

\[
y
=
C_R(\eta_e)
G_S(z,\eta_g)j.
\]

所以完整 forward operator 是

\[
\boxed{
\mathcal F_z(\chi,\eta)
=
C_R
G_S
(I-XG_D)^{-1}
X
G_T
C_Ts.
}
\tag{1}
\]

如果 direct path 也保留，则再加

\[
y_{\rm dir}(z,\eta).
\]

这个区别非常重要，因为 direct/reference signal 可以独立提供 calibration information。

Chen 的书实际上已经把这个结构的一半给你准备好了：inverse scattering 可以通过 induced current \(J\) 看成受到材料约束的 inverse-source problem，而且 SOM 正是利用 \(G_S\) 的奇异子空间来研究哪些 induced-current components 能够进入数据。书里同时强调 full-wave nonlinear ISP 与 Born 线性化在本质上不同。

你现在所做的是再加入：

\[
\boxed{
\text{measurement operator 自己也是未知的。}
}
\]

这就是新的地方。

# 四、真正把 self-calibration 与 information window 连起来

在真实状态 \((\chi_0,\eta_0)\) 附近做一阶变分：

\[
\boxed{
\delta y
=
A_z\,\delta\chi
+
B_z\,\delta\eta.
}
\tag{2}
\]

其中

\[
A_z=D_\chi\mathcal F_z,
\qquad
B_z=D_\eta\mathcal F_z.
\]

对 material 而言，可以精确写成

\[
\boxed{
A_z\delta\chi
=
C_RG_SR_\chi
D_{E^{\rm tot}}\delta\chi.
}
\tag{3}
\]

这其实就是你之前一直在研究的：

\[
\delta\chi
\rightarrow
\delta j
\rightarrow
\delta y.
\]

但 antenna calibration 会产生另一组 data directions：

\[
\mathcal B_z=\operatorname{Ran}B_z.
\]

如果某个材料变化满足

\[
A_z\delta\chi\in\operatorname{Ran}B_z,
\]

那么在一阶意义上：

> 改材料产生的数据变化，可以通过“改一下 antenna calibration”完全解释。

所以即使

\[
\|A_z\delta\chi\|
\]

很大，它也没有真正的 attribution information。

# 五、所以 information window 不能只看 \(A\) 的 SVD

这里正好可以把你前面的 nuisance-space 理论用回来，而且不用 Fisher。

令

\[
P_{\mathcal B_z}
\]

为 calibration tangent space 的正交投影，

\[
Q_{\mathcal B_z}=I-P_{\mathcal B_z}.
\]

定义真正的 **calibration-aware material operator**

\[
\boxed{
M_z
=
Q_{\mathcal B_z}A_z.
}
\tag{4}
\]

这个式子的物理意义非常漂亮：

> 先允许 calibration 参数随意调整，把所有“可以被天线误差解释掉的数据”删除；剩下的数据里，还有多少材料信息？

它满足严格关系：

\[
\boxed{
\ker M_z
=
\{\delta\chi:
A_z\delta\chi\in\operatorname{Ran}B_z\}.
}
\tag{5}
\]

因此某个材料方向真正 locally identifiable 的条件不是

\[
A_z\delta\chi\neq0,
\]

而是

\[
\boxed{
Q_{\mathcal B_z}A_z\delta\chi\neq0.
}
\]

这已经把 information window 和 self-calibration 数学上合并了。

# 六、还可以得到一个很有解释力的 SVD 下界

设材料 data subspace 和 calibration data subspace 之间最小 **principal angle（主夹角）**为

\[
\theta_{\min}(z).
\]

主夹角就是两个子空间“有多像”的量：

- \(90^\circ\)：非常容易区分；
- 接近 \(0^\circ\)：两个物理机制产生几乎一样的数据。

那么在适当的有限维稳定子空间上，

\[
\boxed{
\sigma_{\min}(M_z)
\ge
\sigma_{\min}(A_z)
\sin\theta_{\min}(z).
}
\tag{6}
\]

于是 reconstruction difficulty 被分成了两个完全不同的来源：

\[
\boxed{
\underbrace{\sigma_{\min}(A_z)}_{\text{材料本身能不能被看到}}
\times
\underbrace{\sin\theta_{\min}}_{\text{看到了以后能不能判断是材料}}
}
\]

这比 \(A^\ast A\)/Fisher 的解释清楚得多。

你以前说的 information window 实际上只研究了第一项。

一旦加入 self-calibration，就变成：

\[
\boxed{
\text{information}=
\text{sensitivity}
\times
\text{attributability}.
}
\]

# 七、这里出现了一个很强的结果：far field 对 self-calibration 可能反而很差

这是我认为最值得你保留进当前 self-calibration 论文的一个理论结果。

三维 scalar Green function：

\[
G(x_r,r)
=
\frac{e^{ikR}}{4\pi R},
\qquad
R=|x_r-r|.
\]

有

\[
\nabla_{x_r}\log G
=
\left(ik-\frac1R\right)\hat R.
\tag{7}
\]

假设 receiver 位于

\[
x_r=d\hat s,
\]

而目标尺寸满足

\[
|r|\le a,\qquad a\ll d.
\]

则

\[
R
=
d-\hat s\cdot r
+O(a^2/d),
\]

而

\[
\hat R
=
\hat s
-
\frac{(I-\hat s\hat s^T)r}{d}
+
O(a^2/d^2).
\]

现在考虑 receiver 沿 radial direction 有一个位置误差：

\[
\delta x_r=\delta d\,\hat s.
\]

代入 (7)：

\[
\boxed{
\delta\log G
=
\left(ik-\frac1d\right)\delta d
+
O\!\left(\frac{a\,\delta d}{d^2}\right).
}
\tag{8}
\]

注意最重要的地方：

\[
\left(ik-\frac1d\right)\delta d
\]

**与目标内部位置 \(r\) 无关。**

所以远场极限下：

\[
\boxed{
\delta y_r
\approx
\left(ik-\frac1d\right)
\delta d\,y_r.
}
\tag{9}
\]

而一个 receiver electronic gain error：

\[
\delta y_r
=
\delta g_r\,y_r,
\]

phase error：

\[
\delta y_r
=
i\delta\phi_r\,y_r.
\]

所以

\[
\boxed{
\operatorname{span}
D_{\rm radial\ geometry}y
\longrightarrow
\operatorname{span}
D_{\rm gain/phase}y
\qquad d/a\to\infty.
}
\tag{10}
\]

也就是：

\[
\boxed{
\theta(
\mathcal B_{\rm geom},
\mathcal B_{\rm electronics})
\rightarrow0.
}
\]

这不是 Fisher statement。

这是 Green function 本身的渐近退化。

而且更重要的是：

\[
\boxed{\text{它不依赖 Born approximation。}}
\]

因为无论里面 multiple scattering 多复杂，从目标向一个 sufficiently far receiver 传播的最终一步仍具有这个渐近结构。

Tx 端也是一样：

\[
G_T(r,x_t)
\simeq
A(d)
e^{ik\hat s_t\cdot r}.
\]

Tx radial displacement 首阶也是统一的 complex multiplier，于是会渐近等价于 Tx chain 的 gain/phase error。

现在你终于可以严谨解释为什么可能存在一个 joint information window：

### 对材料恢复而言

far field 很舒服：

\[
\chi
\rightarrow
\widehat\chi(q),
\]

Born 下甚至变成 Ewald/Fourier sampling。

far field 却会使

因此：

\[
\boxed{
\text{material-favorable regime}
\neq
\text{calibration-favorable regime}.

\]

near field 中 Green function 的

\[

\]

以及 wavefront curvature 都保留目标位置依赖。

位置变化不再只是把整个 channel 乘一个复数：

\[
D_{\rm geometry}y
\notin
\operatorname{span}\{y,iy\}.
\]

于是：

\[
\theta(
\mathcal B_{\rm geom},
\mathcal B_{\rm electronics})
\]

可以重新打开。

**这就是我认为两个课题真正应该结合的理论原因。**

# 九、但是不能因此武断说“中间距离一定有最优值”

这一点需要严谨。

Maxwell 方程本身并不能保证：

\[
d^\star\in(d_{\rm near},d_{\rm far})
\]

一定存在。

我们能严格推出的是：

\[
d\to\infty
\Longrightarrow
\text{某些 geometry/electronics modes 渐近不可分}.
\]

非常近时是否变差，则依赖：

- antenna mutual coupling，天线互耦；
- antenna-target coupling，天线与目标反作用；
- dynamic range，动态范围；
- model discrepancy，模型失配；
- VNA calibration accuracy；
- antenna pattern model；
- positioning tolerance。

而这些确实在实验系统里会造成问题。

例如 2024 年 Hu 等人的 near-field MIMO calibration 工作明确指出：近场 spherical-wave propagation（球面波传播）使阵列校准与远场不同，必须对不同 Tx–Rx pair 到参考板的传播距离进行补偿。

2026 年 Koutsoupidou 与 Kosmas 对 microwave tomography 做了很有意思的系统实验/数值分析：更复杂、更忠实的 antenna model 并不必然改善 DBIM reconstruction，标准 calibration 的影响反而超过单纯提高 antenna-model fidelity。

所以你的 window 最好不要定义成“某个神奇最佳距离”，而应该定义成一个可接受区域。

# 十、一个更严谨的 Calibration-Aware Information Window

定义阈值有效秩：

\[
r_\tau^{\rm mat}(z)
=
\#\{
j:
\sigma_j(Q_{\mathcal B_z}A_z)>\tau
\}.
\]

注意我这里叫 **thresholded effective rank（阈值有效秩）**，不直接说 rank，因为连续 inverse scattering operator 往往是 compact operator，裸 rank 并不是你真正关心的量。

对于 calibration 也类似：

\[
C_z
=
Q_{\mathcal A_z}B_z,
\]

其中

\[
Q_{\mathcal A_z}=I-P_{\operatorname{Ran}A_z}.
\]

于是可以定义：

\[
\boxed{
\mathcal W
=
\left\{
z:
\begin{array}{l}
r_{\tau_m}(Q_BA)\ge r_m,\\
r_{\tau_c}(Q_AB)\ge r_c,\\
\theta_{\rm min}\ge\theta_0,\\
\Delta_{\rm model}(z)\le\epsilon_m
\end{array}
\right\}.
}
\tag{11}
\]

它的中文含义就是：

> 一个阵列/距离/频率/极化配置必须同时满足：
> 材料看得见、校准参数看得见、二者分得开，而且模型误差不能太大。

这才是真正的 information window。

# 十一、为什么我尤其不建议你把 self-calibration 改成 Born

还有一个更直接的可辨识性问题。

Born 模型下：

\[
\boxed{
y_B
=
C_RG_SXG_TC_Ts.
}
\tag{12}
\]

假设 receiver 有一个未知公共复增益 \(c^{-1}\)。

同时把材料 contrast 改成

\[
X'=cX.
\]

那么

\[
(c^{-1}C_R)G_S(cX)G_TC_T
=
C_RG_SXG_TC_T.
\]

所以：

\[
\boxed{
X\rightarrow cX,\qquad
C_R\rightarrow c^{-1}C_R
}
\]

是一个**精确 gauge ambiguity（规范歧义）**。

也就是说：

> 如果没有 reference channel / known gain，Born scattering-only 数据甚至无法同时决定绝对材料 contrast scale 和 global electronics gain。

这不是数值不好。

是结构性 non-identifiability。

# 十二、full-wave 有一个 Born 没有的优势：multiple scattering 可以破掉 material-scale gauge

Full-wave：

\[
y
=
C_RG_S
(I-XG_D)^{-1}
XG_TC_Ts.
\]

展开 resolvent：

\[
(I-XG_D)^{-1}X
=
X
+
XG_DX
+
XG_DXG_DX+\cdots.
\tag{13}
\]

把

\[
X\rightarrow cX
\]

同时 receiver gain 乘 \(c^{-1}\)。

第一项：

\[
c^{-1}(cX)=X,
\]

确实仍然一样。

但是第二项：

\[
c^{-1}(cXG_DcX)
=
cXG_DX.
\]

而原来是

\[
XG_DX.
\]

一般来说：

\[
\boxed{
cXG_DX
\neq
XG_DX.
}
\]

所以：

\[
\boxed{
\text{multiple scattering generically breaks the Born material/gain scale ambiguity}.
}
\tag{14}
\]

除非：

- \(c=1\)；
- \(XG_DX=0\)；
- 或处在极弱 scattering limit。

这个结果对你的 self-calibration 主线非常有意义。

**multiple scattering 在这里不只是让问题变难，它也可能提供 Born 根本没有的 calibration/material disentanglement information。**

不过仍然存在 Tx/Rx 之间的公共 gain gauge，例如

\[
C_T\rightarrow \alpha C_T,\qquad
C_R\rightarrow\alpha^{-1}C_R,
\]

所以仍需固定 reference antenna / global phase / global scale。

# 十三、Born 在这个研究里应该承担什么角色？

我会给 Born 一个非常重要、但很明确的位置：

\[
\boxed{\text{Born 是你的 controlled analytical limit，而不是 final physics model。}}
\]

它特别适合证明四件事情：

1. far-field Ewald/Fourier information limit；
2. fixed aperture 与 fixed angular aperture 的区别；
3. material/electronic scaling gauge；
4. geometry/electronics far-field asymptotic degeneracy。

然后再问：

\[
\boxed{
\text{multiple scattering 究竟改变其中哪些结论？}
}
\]

这样论文逻辑非常漂亮：

\[
\text{Born}
\rightarrow
\text{找到精确退化}
\rightarrow
\text{Full-wave}
\rightarrow
\text{观察哪些退化被 nonlinear interaction 打破}
\rightarrow
\text{array design}.
\]

这比“直接在 full-wave sweep 一堆距离”强很多。

# 十四、各向异性加入以后，这个问题更适合做 array optimization

各向异性：

\[
\boldsymbol\chi(r)
=
\begin{bmatrix}
\chi_{xx}&\chi_{xy}&\chi_{xz}\\
\chi_{xy}&\chi_{yy}&\chi_{yz}\\
\chi_{xz}&\chi_{yz}&\chi_{zz}
\end{bmatrix}.
\]

把不同 tensor component 对应的 material Jacobian 写成

\[
A_{xx},A_{yy},A_{zz},
A_{xy},A_{xz},A_{yz}.
\]

现在 calibration-aware operator 应该分别是

\[
\boxed{
M_q(z)
=
Q_{B_z}A_q(z),
\qquad
q\in
\{xx,yy,zz,xy,xz,yz\}.
}
\tag{15}
\]

于是每一种 tensor mode 都有自己的 window：

\[
\boxed{
\mathcal W_q
=
\{
z:
\sigma_{r_q}(M_q(z))>\tau_q
\}.
}
\tag{16}
\]

很自然会有：

\[
\mathcal W_{xx}
\neq
\mathcal W_{xy}
\neq
\mathcal W_{zz}.
\]

这就是你前面猜的 **information-window splitting（信息窗口分裂）**。

而这里 polarization 就成为阵列设计变量，而不是附属参数。

Sun 在 IEEE TAP 2018 已经证明不同 Tx/Rx polarization 对不同 anisotropic permittivity components 的 sensitivity 不同。

Ye 等人在 2020 IEEE TCI 的 biaxial anisotropic S-DBIM 中进一步观察到：由于 directional scattering，不同方向的信息质量明显不同，强散射方向重建清楚、弱散射方向模糊。

另一方面，Wang、Aubry、Yarovoy 在 IEEE TAP 2018 已经从硬件阵列侧研究了 near-field 3D **fully polarimetric imaging（全极化成像）**的阵列拓扑，用更少天线恢复完整极化信息。

你的机会就在于把这两个世界连起来：

\[
\boxed{
\text{anisotropic material observability}
\leftrightarrow
\text{polarimetric array topology}.
}
\]

再加上 self-calibration。

# 十七、真正做 array optimization 时，我建议的数学目标

不要用

\[
\max_z \operatorname{tr}(A^\ast A)
\]

或者 D-optimal Fisher 那一套作为主结果。

更合适的是，例如指定希望恢复前 \(r\) 个材料稳定模态：

\[
\boxed{
\max_{z\in\mathcal Z}
\min_{\chi\in\mathcal C}
\sigma_r
\left[
Q_{B_z(\chi)}
A_z(\chi)
\right].
}
\tag{17}
\]

同时要求 calibration 本身可恢复：

\[
\boxed{
\sigma_s
\left[
Q_{A_z(\chi)}
B_z(\chi)
\right]
\ge\tau_c.
}
\tag{18}
\]

对于 anisotropic case：

\[
\boxed{
\max_z
\min_{\chi\in\mathcal C}
\min_{q\in\mathcal Q}
\sigma_{r_q}
\left[
Q_{B_z}A_{q,z}
\right].
}
\tag{19}
\]

这里的

\[
\min_q
\]

就是防止阵列只特别擅长看到 \(\epsilon_{xx}\)，却完全看不到 \(\epsilon_{xz}\)。

再加入：

\[
N_{\rm meas}\le N_{\max},
\]

\[
d\ge d_{\rm hardware},
\]

\[
\Delta_{\rm model}(z)\le\epsilon_{\rm model}.
\]

于是就成为一个真正有工程意义的 array-design problem。

这是我认为这条新课题理论上最漂亮的结构。

# 二十一、我最终建议的科研路线

我建议你按这个顺序做，而不是 Born/full-wave 二选一：

1. **当前 self-calibration 继续 full-wave。** 加入 far-field geometry–electronics degeneracy theorem，明确 gauge 与可辨识条件，继续完成 Attribution → Action 主线。

2. **下一篇从 Born 开始，但不止于 Born。** Born 负责给出 Ewald limit、far-field degeneracy、scale ambiguity 和 analytically tractable SVD；然后明确指出这些结论哪些进入 full-wave 后仍成立、哪些被 multiple scattering 打破。

3. **建立 calibration-aware full-wave information window。** 核心算子就是
   \[
   Q_{B_z}A_z.
   \]
   然后从单纯 standoff 扩展到 aperture、frequency、polarization、Tx/Rx scheduling。

4. **最后做 anisotropy。** 如果
   \[
   \mathcal W_{xx},\mathcal W_{yy},\mathcal W_{xy},\dots
   \]
   确实 split，再把它提升为 polarization-aware array design；否则就不要为了故事强加 split-window。

这样最重要的一点是：

\[
\boxed{
\text{你的第二篇不是研究“最佳距离”，而是在研究“最佳可辨识实验”。}
}
\]

我认为这比单纯的 information window 概念高一个层次。

当前 self-calibration 更像是在回答：

\[
\boxed{\text{Can I trust and attribute this measurement?}}
\]

而新的 array-design 课题回答：

\[
\boxed{\text{How should I measure so that trust and attribution become possible?}}
\]

如果后一条最终能把 **full-wave、self-calibration、global distinguishability、SVD/主夹角、standoff、polarization 和 anisotropy** 全部闭合起来，它的理论含金量甚至可能高于你现在的 self-calibration 论文；但它明显更适合作为后续独立课题，而不是现在为了“更大”把当前已经收敛的研究重新炸开。
