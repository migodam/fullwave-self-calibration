# 1. 重新评价 2025 MFSOM calibration：是的，它确实存在你说的风险

我重新逐式检查了 Idriss & Raj 2025。

它不是只做实数 gain。论文明确令

\[
\lambda_c\in\mathbb C,
\]

在 MFSOM 的 state equation 中把 incident field 写成

\[
\lambda_c E_{\rm inc},
\]

同时在新增 forward consistency term 中比较

\[
\lambda_c E_s^{\rm sim}
\quad\text{和}\quad
E_s^{\rm meas}.
\]

实验 Fresnel 数据时，他们进一步允许不同 Tx 有不同的 complex calibration factor，并明确说这么做是为了 account for phase factors；纯实数 calibration 的 NSE 不好。 

因此你的判断完全正确：

\[
\boxed{
\lambda_c
\text{ 并不知道自己吸收的是 electronics phase，
还是 geometry phase。}
}
\]

## 从局部 Jacobian 看得非常清楚

对固定频率和 Tx，假设场为

\[
s(\chi,x).
\]

复校准因子的微扰产生

\[
\delta y_g=s\,\delta g.
\]

所以 gain tangent 的 data-space range 本质上包含

\[
\operatorname{span}_{\mathbb C}\{s\}.
\]

而 geometry perturbation 给：

\[
\delta y_x=B\,\delta x.
\]

如果某个位置变化满足

\[
B\delta x\simeq s\,c,
\]

那么

\[
\boxed{
\text{geometry tangent}
\simeq
\text{gain tangent}.
}
\]

算法就没有理由把这一变化解释为 geometry。

尤其远场时，某些 source phase-center/radial displacement 的主导效应就是

\[
s\rightarrow
e^{ik\Delta L}s
\simeq
(1+ik\Delta L)s,
\]

这几乎正好是 complex scalar gain。

所以：

\[
\Delta L
\quad\leftrightarrow\quad
\delta g=ik\Delta L
\]

在一阶上可能完全不可区分。

这与你 A3 的独立推导吻合：消去自由 gain 后，远场最强的 \(O(k)\) propagation-phase 部分可能消失，真正剩下的 geometry information 来自视角变化、parallax 和高阶近场效应。你的 3D 数值实验又观察到 gain 消元后 geometry 最小奇异值约按 \(R^{-1}\) 衰减。

---

## 那这是否意味着 2025 论文的成像结果有问题？

不能这样简单下结论。

它证明了一个真实结果：

Fresnel 的 FoamDielExt 数据上，不 calibration 时 NSE 是

\[
0.201,
\]

加入复 calibration 后：

\[
0.038.
\]

所以它的 flexibility **确实改善了那个数据集上的定量 reconstruction**。

但现在应该重新解释这个结果：

> 它证明的是 **effective complex calibration 有利于成像**，不等于证明其 \(\lambda_c\) 是真实的 antenna gain/phase。

也就是说：

\[
\boxed{
\hat\lambda_c
=
\lambda_{\rm electronics}
+
\lambda_{\rm geometry}
+
\lambda_{\rm antenna-model}
+
\lambda_{\rm surrogate}
+\cdots
}
\]

更准确地说，这是非线性意义上的 aggregate/effective nuisance parameter，而不是可物理解读的单一 calibration quantity。

甚至它使用的 FCNN forward operator 本身也是 approximate model；论文报告网络对测试场的 scattered-field MSE 约 \(8.4\times10^{-4}\)。如果 surrogate error 有一个与 \(E_s\) 共线的分量，\(\lambda_c\) 同样可以吸收它。

论文自己也承认 \(\beta\) 对结果有明显影响，而且自动选择并不简单。

所以我现在会把这篇论文定义为：

\[
\boxed{
\text{successful effective calibration}
\neq
\text{identified physical calibration}.
}
\]

这并不否定论文，但留下了一个你可以真正研究的问题：

> **什么时候 complex calibration factor 是 electronics，什么时候其实在吸收 geometry/model error？**

你自己的 Fresnel 结果其实提供了一点独立佐证：从 plane-wave 换成 line-source model 有小幅改善，但再拟合 \(\pm3\) mm 有效半径几乎不再改善，而且 radius 经常撞边界。这更像是“剩余误差并不是一个单独 radial geometry parameter 能解释”，而不是简单 geometry offset。

# 2. SLAM 思路可以用，而且我认为应该用，但不要“照搬 SLAM”

我更倾向于叫它：

\[
\boxed{\text{Electromagnetic Factor-Graph Calibration}}
\]

而不是简单叫 EM-SLAM。

因为 SLAM 给你的最重要东西不是视觉 feature，而是三个数学工具：

\[
\text{graph topology}
+
\text{gauge handling}
+
\text{Schur marginalization}.
\]

Bundle adjustment/SLAM 中通常把 map landmarks 消去，通过 Schur complement 得到更小的 pose system；这是大规模 BA 的基本结构。

你的问题可以完全类似地写成 factor graph。

节点包含：

\[
\chi,\qquad
x_t,\qquad
g_p^{Tx},\qquad
g_q^{Rx},\qquad
\tau,\qquad
d.
\]

measurement factor 是

\[
r_{fpq}
=
y_{fpq}
-
g_p^{Tx}(f)g_q^{Rx}(f)
F_{fpq}(\chi,x).
\]

然后加：

- pose/trajectory factors；
- electronic reference factors；
- geometry prior/anchor；
- model-discrepancy factors；
- full-wave physics factors。

这其实会比现在一个巨大的 monolithic cost function 更容易分析。

---

## 更漂亮的是：A3 的“树/闭环”现象就是 SLAM loop closure 的电磁版本

设每条 Tx–Rx measurement 是 graph 的一条 edge。

在线性化 log-phase 模型中：

\[
\delta\phi_e
=
\delta\phi_{Tx,p}
+
\delta\phi_{Rx,q}
+
J_{x,e}\delta x+\cdots
\]

把所有 node gains 写成 \(\alpha\)，有

\[
\delta\phi
=
C\alpha+B\delta x,
\]

其中 \(C\) 本质就是 bipartite incidence/design matrix。

消掉 gains：

\[
B_{\rm vis}
=
P_{\operatorname{Ran}C^\perp}B.
\]

而图论告诉我们：

\[
\operatorname{Ran}C^\perp
=
\text{cycle space}.
\]

因此：

\[
\boxed{
B_{\rm vis}
=
P_{\rm cycle}B.
}
\]

这非常重要。

如果 graph 是一棵树：

\[
E=V-1,
\]

cycle space 为零。

于是这种纯 node-wise complex gain 模型下：

\[
P_{\rm cycle}=0.
\]

也就是你 A3 实验看到的：

> 错 geometry、错 material 都可以用 gain 沿着树逐边吸收。

形成 cycle 后，才出现 gain 不能独立解释的量。你的 3D 实验中，树图的错误候选能够把数据拟合到机器精度，而三个独立闭环能够明显区分正确/错误候选。

这和干涉测量中的 closure phase 是同一个基本思想：closure phase 对 element-based multiplicative complex gain 不敏感。

相位同步/angular synchronization 领域则直接用 graph spectral/eigenvector 方法从 noisy pairwise phase differences 恢复节点 phase，它与 pose-graph optimization 有明确联系。

---

## 但这里有一个非常重要的警告

**loop closure 不能自动解决 absolute geometry。**

干涉测量的 closure phase 本身甚至可以对整体 translation 不敏感。

这与你 A3 第 24 节的 exact gauge 完全一致：当前目标和天线一起移动，并用 clock shift 补偿，可以产生完全相同的全波数据。已知 target support 实际上提供了 spatial anchor。

因此最合理的框架是：

\[
\boxed{
\text{SLAM factor graph}
+
\text{gain synchronization}
+
\text{full-wave physics}
+
\text{explicit gauge quotient}.
}
\]

SLAM 可以帮你**暴露** gauge，不会神奇地消灭 gauge。

# 3. 你问得最重要的 D-error：我认为完全可以谱化，而且不应该只是普通 SVD

这是我现在最看好的方向之一。

设高保真模型：

\[
F_H(\theta)
\]

和你的低成本模型：

\[
F_L(\theta).
\]

定义 model discrepancy operator：

\[
\boxed{
d(\theta)=F_H(\theta)-F_L(\theta).
}
\]

A3 目前相当于发现，在某些场景中：

\[
d(\theta)
\simeq
a_1(\theta)u_1,
\]

即一个 dominant data-space direction \(u_1\) 可以解释 94%–96% 的真实高频 discrepancy energy。

普通做法当然可以收集：

\[
D=
[d(\theta_1),\ldots,d(\theta_N)]
\]

再做：

\[
D=U_D\Sigma_DV_D^*.
\]

那么：

\[
u_1,u_2,\ldots
\]

就是 discrepancy eigenfields / POD modes / KL modes。

这与 Bayesian Approximation Error 的思想非常接近：把 coarse/full model 差异作为额外随机误差，通过其均值和 covariance 纳入 likelihood；BAE 已经应用于 coarse mesh、domain geometry、模型降阶等 inverse problem。

但**只做 SVD 还不够**。

---

## 我建议做“任务感知 D-spectrum”

因为最大的 model-error mode 不一定是最应该压掉的 mode。

假设：

\[
C_D=U_D\Lambda_DU_D^*
\]

是 discrepancy covariance。

而 physical information covariance，例如 geometry：

\[
C_x=B B^*,
\]

material：

\[
C_\chi=A A^*.
\]

不要只求：

\[
C_Du=\lambda u.
\]

而求：

\[
\boxed{
C_Du
=
\lambda
(C_{\rm task}+C_n)u.
}
\]

例如 geometry task：

\[
C_{\rm task}=C_x.
\]

大的 \(\lambda\) 表示：

> 这个 data direction 中 model discrepancy 很强，但 geometry information 相对很弱。

这种方向非常适合 downweight。

反过来可以求：

\[
\boxed{
C_{\rm task}u
=
\mu(C_D+C_n)u.
}
\]

大的 \(\mu\) 就是：

> **高信息、低 discrepancy 的可信 measurement mode。**

这其实与 contrastive PCA/common-spatial-patterns/LIS 属于同一个广义 Rayleigh quotient 家族；广义 contrastive PCA 本质上也是 generalized eigenproblem。

Inverse-problem 领域的 likelihood-informed subspace 也用 generalized eigenspectrum 找“数据相对 prior 真正告知的 parameter directions”。

---

## 再进一步：直接看 D 与物理 tangent 的 principal angles

设：

\[
Q_D=\operatorname{orth}(U_D),
\]

\[
Q_x=\operatorname{orth}(B_{\rm vis}),
\]

\[
Q_\chi=\operatorname{orth}(A_{\rm vis}).
\]

计算：

\[
Q_D^*Q_x
\]

的 SVD：

\[
Q_D^*Q_x
=
U\Sigma V^*,
\qquad
\sigma_i=\cos\theta_i.
\]

如果：

\[
\theta_i\approx90^\circ,
\]

说明这个 D mode 与 geometry information 几乎正交：

\[
\boxed{\text{可以比较安全地 suppress}.}
\]

如果：

\[
\theta_i\approx0,
\]

说明：

\[
\boxed{
\text{model error 与真实 geometry signature 几乎重合}.
}
\]

这时候你不能靠 weighting 解决。

因为 downweight 它就是把 geometry information 一起扔掉。

此时算法必须触发：

\[
\text{更高 fidelity}
\quad\text{或}\quad
\text{额外 reference/acquisition}.
\]

---

## 这正好解释你现在“一方向修正有时好、有时坏”的反例

你目前一个 \(D\) direction 对最初场景特别有效。

但压力测试发现：

- 有些场景 material 变好；
- geometry 变好；
- phase prediction 却变差；
- 甚至 geometry 好了但 material 更坏。

从现在这个理论看，这不是奇怪结果。

因为同一个 \(u_D\) 可能满足：

\[
\theta(D,X)\approx70^\circ,
\]

但

\[
\theta(D,\Chi)\approx15^\circ.
\]

也就是说：

> 它对 geometry 是“主要错误”，但同时也是 material 的有效 information direction。

你把它压下去：

\[
x\text{ 改善},
\]

但

\[
\chi\text{ 变差}.
\]

所以我认为：

\[
\boxed{
\text{不存在一个 universal D direction。}
}
\]

应该至少有两个 task-aware spectrum：

\[
D\text{-vs-pose},
\qquad
D\text{-vs-material}.
\]

然后做 multiobjective/Pareto decision。

# 4. 这个谱化还能直接用于计算加速

这是我认为很值得做的部分。

你不需要每次为了找 \(D\) 都大量跑 fine model。

可以建立：

\[
\Delta J
=
J_H-J_L.
\]

然后对 whitened discrepancy operator

\[
\mathcal D
=
[
d,\;
\Delta J\,v_1,\ldots,\Delta J\,v_s
]
\]

做 randomized SVD/Lanczos。

这里 \(v_i\) 不需要随机乱取，最好首先来自 parameter-space 的 likelihood-informed/active directions。

于是只在真正由数据 inform 的 parameter subspace 上询问：

> coarse 与 fine 哪里不一致？

这样 fine solve 数量可以远低于完整参数维数。

高维 inverse problem 使用 Hessian/LIS 的谱衰减来减少计算本来就是成熟思路。

而 EM/CEM 领域本身也有 goal-oriented a posteriori error estimation：不是要求整个电磁场处处准确，而只要求传感器/目标 functional 的预测准确，可以显著减少必要的网格 refinement。

所以你完全可以把两条线结合：

\[
\boxed{
\text{D-spectrum}
+
\text{adjoint/dual-weighted residual}
}
\]

不是问：

> 哪个 mesh cell field error 最大？

而是问：

> **哪个 numerical error 最会污染 geometry/material calibration？**

这是一个真正 goal-oriented 的问题。

---

## 在线阶段甚至不必显式投影掉 D

如果你估计：

\[
C_D
\simeq
U_D\Lambda_DU_D^*
\]

可以直接把 likelihood covariance 改成：

\[
\Sigma_{\rm eff}
=
\Sigma_n+C_D.
\]

然后：

\[
W_{\rm eff}
=
\Sigma_{\rm eff}^{-1/2}.
\]

由于 \(C_D\) 是低秩，

\[
(\Sigma_n+U\Lambda U^*)^{-1}
\]

可以用 Woodbury formula，仅在 \(r_D\)-维空间里求逆。

所以这条路线同时解决：

\[
\boxed{
\text{误差处理}
+
\text{计算量优化}.
}
\]

它和 BAE 是高度一致的，而不是凭空造一个 weighting。

# 5. 现在最重要的问题：为什么 A3 的失败和原理论“不匹配”？

答案是：

> **原来的理论主要是 correctly specified local information theory；你的失败主要发生在 misspecified nonlinear inverse problem。**

Fisher 没有错。

理论的适用对象错了。

## 我建议把 A2 的理论扩展成下面这个基本模型

在某个局部分支，白化后：

\[
y
=
A\,\delta\chi
+
B\,\delta x
+
C\,\delta g
+
d
+
\varepsilon.
\]

其中：

\[
d
=
\text{model discrepancy}.
\]

假设现在关心 geometry。

把 material 和 gain 当作 nuisance：

\[
N=[A,C].
\]

定义：

\[
P_N^\perp
=
I-P_{\operatorname{Ran}N},
\]

\[
B_v=P_N^\perp B.
\]

那么局部 LS 的 geometry error 不是以前只有 noise：

\[
\widehat{\delta x}-\delta x_*
=
B_v^\dagger P_N^\perp\varepsilon.
\]

而应该变成：

\[
\boxed{
\widehat{\delta x}-\delta x_*
=
\underbrace{
B_v^\dagger P_N^\perp d
}_{\text{model-bias}}
+
\underbrace{
B_v^\dagger P_N^\perp\varepsilon
}_{\text{variance}}
+
\underbrace{R_{\rm nonlinear}}_{\text{branch/higher order}}.
}
\]

这一个公式就能解释 A3 的大部分反例。

## 因此原来的 Fisher 应该升级成 risk

忽略高阶项时：

\[
J_x=B_v^*B_v.
\]

那么：

\[
\boxed{
\mathbb E\|\hat x-x_*\|_{M_x}^2
=
\operatorname{tr}(M_xJ_x^{-1})
+
\left\|
M_x^{1/2}
B_v^\dagger P_N^\perp d
\right\|^2.
}
\]

第一项：

\[
\text{variance}.
\]

第二项：

\[
\text{misspecification bias}.
\]

A2 的理论主要控制第一项以及 truncation bias 的特定版本。

A3 现在证明了第二项不能再忽略。

# 6. 这正好严格解释“高频 Fisher 更好，但结果反而更坏”

设原来的低频系统：

\[
H_L=J_L^*J_L,
\]

\[
b_L=J_L^*d_L.
\]

增加高频后：

\[
H_{LH}
=
H_L+J_H^*J_H.
\]

因为

\[
J_H^*J_H\succeq0,
\]

所以：

\[
H_{LH}\succeq H_L.
\]

也就是说：

\[
\boxed{\text{Fisher information 一定不会因添加匹配独立数据而减少。}}
\]

这与你 A3 的理论控制完全一致。

但是 bias forcing 也变成：

\[
b_{LH}
=
b_L+J_H^*d_H.
\]

最终 bias：

\[
\boxed{
h_{\rm bias,LH}
=
H_{LH}^{-1}
(b_L+J_H^*d_H).
}
\]

所以虽然：

\[
H^{-1}\downarrow,
\]

但是：

\[
J_H^*d_H
\]

可能大幅增加。

于是总风险：

\[
R_{LH}
=
\operatorname{tr}(MH_{LH}^{-1})
+
\|M^{1/2}H_{LH}^{-1}b_{LH}\|^2
\]

完全可能比：

\[
R_L
\]

更大。

这就是你实验中：

\[
\boxed{
\text{more information}
\quad\text{but}\quad
\text{worse reconstruction}
}
\]

的数学原因。

而你同模型控制把 \(d_H\) 基本拿掉后，高频效果立刻反转为正：位置和材料都明显改善。

所以这个反例实际上没有推翻 Fisher 理论。

它**验证了需要一个 Fisher + discrepancy bias 理论。**

# 7. 还有一个更重要的新结论：最危险的 D error 不是 residual 最大的 D

这是整个理论里我认为最值得你抓住的一点。

把 discrepancy 分解：

\[
d
=
P_{\operatorname{Ran}J}d
+
P_{\operatorname{Ran}J^\perp}d.
\]

其中：

\[
J=[A,B,C].
\]

第二部分

\[
d_\perp=P_{J^\perp}d
\]

无法被任何参数解释。

所以它会留下 residual：

\[
\|r\|\uparrow.
\]

反而容易被你发现。

真正危险的是：

\[
\boxed{
d_\parallel=P_Jd.
}
\]

因为它可以被参数更新完全或部分吸收。

结果：

\[
\text{residual 很小},
\]

但是：

\[
\hat\chi,\hat x,\hat g
\]

全都可能偏。

所以：

\[
\boxed{
\textbf{最危险的 model discrepancy 是 tangent-aligned discrepancy。}
}
\]

这一点完美解释了 A3 第 15 节：

无 electronic reference：

sensor prediction error 只有约

\[
0.66\%,
\]

但 structural field error 却约

\[
7.29\%.
\]

加 reference 后 sensor prediction 没更小，约 \(0.89\%\)，但 structural error 降到 \(1.49\%\)。

换句话说：

> electronic gain 正在把 model/material error 吸进 parameter tangent，帮助系统预测 sensor，却损害 physical attribution。

这正是 computer-model calibration 领域长期讨论的 parameter–discrepancy confounding：如果 discrepancy 太自由，可以拟合得很好但 calibration parameter 失去物理含义。

Plumlee 的 orthogonal discrepancy 思路甚至直接要求 discrepancy process 与 model-parameter gradient 正交，以减轻这种 identifiability 问题。

这和你现在的 principal-angle 思路几乎天然对应。

这基本可以把 A3 目前所有主要“失败”统一起来。

# 9. 我现在认为你最值得发展的算法，不是单纯 PRASC，也不是单纯 SLAM

我会考虑一个这样的结构：

\[
\boxed{
\textbf{Discrepancy-Aware Spectral Factor-Graph Full-Wave Calibration}
}
\]

它有三个核心算子。

第一个是 **gain/graph projector**：

\[
P_G^\perp.
\]

回答：

> 去掉 Tx/Rx gains 后，还有什么物理信息？

第二个是 **physics attribution spectrum**：

\[
\operatorname{angles}
\left(
P_G^\perp A,\,
P_G^\perp B
\right).
\]

回答：

> material 和 geometry 到底能不能分？

第三个是 **discrepancy spectrum**：

\[
\operatorname{angles}
\left(
U_D,\,
A,\,
B
\right),
\]

或者 generalized eigenproblem：

\[
C_Du
=
\lambda
(C_{\rm physics}+C_n)u.
\]

回答：

> 哪部分 high-frequency data 是“高信息”，哪部分其实是“高 model error”？

然后在线算法不再是简单：

\[
\text{fit everything}.
\]

而是根据谱做决策：

\[
\boxed{
\begin{array}{c}
\text{可信且 informative}
\rightarrow \text{保留}\\
\text{discrepancy-dominant 且 task-orthogonal}
\rightarrow \text{downweight/marginalize}\\
\text{discrepancy 与 task 共线}
\rightarrow \text{升级模型或增加 acquisition/reference}\\
\text{存在 gauge}
\rightarrow \text{报告不可辨识}
\end{array}}
\]

这才是真正意义上的 **certificate-driven calibration**。

# 10. 还有一个可以立刻优化 2025 论文以及你自己算法的地方：Variable Projection

2025 那篇论文对 \(\lambda_c\) 用 CGD。

但从它的 Eq. (8) 可以看到，在固定 \(W,\chi\) 时，\(\lambda_c\) 进入的是 quadratic complex least-squares terms。

这意味着原则上可以把：

\[
\lambda_c
\]

解析或通过一个很小的 ridge least-squares 子问题消掉：

\[
\lambda_c^*(W,\chi)
=
\arg\min_{\lambda_c}J.
\]

然后只优化 reduced objective：

\[
\widetilde J(W,\chi)
=
J(W,\chi,\lambda_c^*(W,\chi)).
\]

这就是 variable projection。

VarPro 的基本优点就是把 linear/separable nuisance variables 消去，只保留真正 nonlinear 的变量，能够明显减少优化维数；现在仍然是 inverse problems 的活跃方法。

对于你的 Tx/Rx 双侧 gains：

\[
g_p^{Tx}g_q^{Rx}
\]

整体是 bilinear，但每一侧固定另一侧以后仍然是线性的，也可以结合 graph spectral initialization / angular synchronization，再做 nonlinear refinement。

# 最终判断

我认为 A3 的这些 failure 不是坏消息。

它们实际上正在把问题从：

\[
\text{“设计一个更聪明的 SOM calibration”}
\]

推进到：

\[
\boxed{
\textbf{“建立一个能区分信息、模型偏差、参数混淆和非线性分支的全波自校准理论。”}
}
\]

其中我现在最看好的理论链是：

\[
\boxed{
\text{graph cycle / gain invariance}
\rightarrow
\text{principal-angle attribution}
\rightarrow
\text{low-rank discrepancy spectrum}
\rightarrow
\text{misspecified-risk criterion}
\rightarrow
\text{active acquisition / fidelity refinement}
}
\]

如果这条链建立起来，**SOM 可以完全降级为一个可替换的数值引擎**；SLAM 可以成为 factor-graph 和 gauge 的数学框架；而真正属于这项工作的核心，会是：

> **如何在 full-wave coherent inverse scattering 中判断“这部分相位究竟是 geometry、gain、material 还是 model error”，并据此决定应该相信、抑制、增加测量，还是升级正演模型。**

这比最初的“SOM + self-calibration”研究问题强得多，而且目前 A3 的反例恰好给了建立这套理论所需要的实验依据。
