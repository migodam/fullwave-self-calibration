# Part I — Scientific Verdict

## 1. 这个课题值得继续，但需要换掉论文的核心承诺

**[NUMERICAL] coherent geometry self-calibration 的价值仍然成立。** 你提供的 49 参数实验中，成功的是 exact/direct full-wave joint inversion：空间地图 RMSE 从错误几何下的 \(0.1054\) 降至 \(0.0261\)，接近 known-pose reference 的 \(0.0251\)；匹配强度实验为 \(0.0430\)。这些结果支持“校准结构化几何误差能够改善 coherent quantitative imaging”，不支持 SOM 优越性。

**[FAILED] 当前 SOM-specific 方法主张没有通过证据门槛。** 本轮新测试确实消除了一个旧问题——算法不再完全没有执行降阶路径——但尚未消除更重要的问题：

| 本轮实际检验 | 结果 | 可以支持什么 |
|---|---|---|
| SOM／Twofold 基底与 generic task-residual basis 的状态、导数近似 | generic 在测试点上通常用更少维数通过误差门槛 | 当前 sensing/domain seed 没有表现出稳定的秩优势 |
| 可执行 nonlinear hybrid | Twofold hybrid 接受了 **235 个降阶 Jacobian 更新步** | 降阶路径确实运行了 |
| 最高频降阶更新 | 两个 hybrid 均为 **0 个** | 高频可用性仍未解决 |
| 总运行时间 | 两个 hybrid 均慢于当前直接实现 | 没有证明 wall-time 收益 |
| 同一最终多频数据下的 basin | 所有方法均成功，无法区分 | 没有证明 SOM 或 continuation 的 basin 优势 |
| 新 acquisition 后的非线性恢复 | 选定动作改善了 3/3 场景的 pose，但只在 1/3 场景胜过随机动作 | acquisition 能产生实际作用；当前选择策略优越性未成立 |

这些只是小规模探索性结果，不是经过完整公平预算控制的终局比较。尤其直接基线使用显式 Jacobian，而不是充分优化的 direct-adjoint GN；经典 independent-current SOM initializer、rational ROM 等仍未完成比较。

## 2. 真正值得收敛的科学问题

**[HYPOTHESIS] 下一阶段最有价值的问题应当是：**

\boxed{
\begin{gathered}
\text{当 geometry、clock、gain 和模型误差同时存在时，}\\
\text{哪些 coherent phase 关系仍然可辨识？}\\
\text{怎样判断当前解释不唯一，并选择真正能区分解释的新测量？}
\end{gathered}

\]

这里有三个层次，不能互相替代：

\[
\boxed{
\text{局部绝对信息}
\quad+\quad
\text{非线性候选分支的可区分性}
\quad+\quad
\text{物理归因的正确性}.
}
\]

\(\rho\) 是其中一个局部相对诊断量，不应继续承担整个 scientific story。

## 3. 最新 prior art 已经进一步压缩了 broad novelty

**[PRIOR ART] 两个必须更新的认识：**

Idriss–Raj 的 MFSOM calibration 不只是笼统的“每个 transmitter 一个因子”。其式（8）明确写出带**频率和发射索引**的复校准因子 \(\lambda_c^{k,p}\)，并在后文说明只是为了记号简洁才省略频率索引。因此，不能把“多频 SOM 联合 complex gain/phase calibration”作为新颖性。

此外，2026 年 8 月的 Weiss 等工作已经联合处理 receiver geometry、clock bias、target position，并连接到 coherent matched-filter image sharpness。它不是这里的定量 full-wave 材料反演，但使“geometry＋clock＋coherent imaging self-calibration”这一宽泛组合也不足以成为核心创新。

**[PRIOR ART] 另一个必须纠正的比较前提是：generic ROM 并不只关心状态误差。** Goal-oriented、primal–adjoint、输出误差和一阶导数匹配的 ROM 已经存在。真正的竞争者必须包括这些方法，不能只与 state-only POD 比较。

## 4. “Why SOM?”目前的回答

**[PROVED] 完整物理 current 坐标不会增加 Fisher 信息；这一点不再重复证明。**

**[DERIVED] 更进一步，对当前 physical-state ROM，Twofold 的顺序投影本身也不是额外的物理约束：**

\[
\operatorname{span}\!\left[
V_S,\;(I-P_S)V_D
\right]
=
\operatorname{span}[V_S,V_D].
\]

证明只需注意 \(V_D=P_SV_D+(I-P_S)V_D\)，其中 \(P_SV_D\in\operatorname{Ran}V_S\)。

因此，当这些方向只是 numerical basis、系数全部由同一个物理状态方程确定时，**它的价值只能来自基底选择是否更便宜、更准确、更可复用，而不是“多了一层特殊信息”。**

这并不否定经典 SOM 的 deterministic-current 处理和 state/data relaxation 路径；它们与当前 dependent-state ROM 不是同一个算法。

**研究判断：TAP 潜力为 Medium；当前稿件仍是 Reject，而不是接近接收。**

最大的三个 blocker 是：

# Part III — Minimal New Theory

以下只保留四项会改变算法设计或停止规则的结果。**[DERIVED] 表示本轮给出证明，不表示首次发现相应数学原理。**

## 定理 1：固定 current chart 的一阶完整性

### 陈述与类型

令

\[
\theta\in\mathbb R^d,\qquad
M(\theta)\in\mathbb C^{n\times n},\qquad
b(\theta)\in\mathbb C^n
\]

在 \(\theta_0\) 附近连续可微，且 \(M\) 可逆。

固定一个满列秩基底

\[
U\in\mathbb C^{n\times r},
\]

定义

\[
j=M^{-1}b,\qquad
\widetilde j=Uc,\qquad
c=\arg\min_z\|MUz-b\|_2^2.
\]

对声明的实参数方向 \(v_a\)，定义物理状态导数

\[
t_a=M^{-1}(b_{v_a}-M_{v_a}j).
\]

则在 \(\theta_0\)，状态和这些状态导数全部精确匹配，当且仅当

\[
\boxed{
j,t_1,\ldots,t_s\in\operatorname{Ran}U.
}
\]

因此，满足这一要求的固定复线性空间的最小维数是

\[
\boxed{
r_{\min}
=
\operatorname{rank}_{\mathbb C}[j,t_1,\ldots,t_s].
}
\]

多 illumination 情形，直接拼接各 illumination 的这些列。

### 证明

若 \(j\in\operatorname{Ran}U\)，则存在 \(c_0\) 使 \(Uc_0=j\)，最小二乘残差为零。由于 \(MU\) 满列秩，系数唯一。

在零残差点微分正规方程，得到

\[
(MU)^*(MU)c_v
=
(MU)^*(b_v-M_vj).
\]

若 \(t_v=Uz_v\)，物理导数方程给出

\[
MUz_v=b_v-M_vj,
\]

因此 \(z_v\) 满足上述唯一正规方程，于是 \(Uc_v=t_v\)。

反之，因为 \(U\) 固定，\(\widetilde j=Uc\) 和 \(\widetilde j_v=Uc_v\) 必然都属于 \(\operatorname{Ran}U\)。若它们精确等于 \(j,t_v\)，则这些列必须包含在该空间中。最小维数就是其列空间维数。证毕。

### 最小反例与边界

取

\[
M=I,\qquad b(\theta)=e_1+\theta e_2,\qquad U=e_1.
\]

在 \(\theta=0\)：

\[
\widetilde j=j=e_1,
\]

但

\[
\widetilde j_\theta=0,\qquad j_\theta=e_2.
\]

再取 \(S=[0,1]\)，输出导数分别为 \(0\) 和 \(1\)。

所以：

\[
\boxed{
\text{状态精确}\not\Rightarrow\text{输出导数精确}.
}
\]

若允许 \(U(\theta)\propto e_1+\theta e_2\)，一个移动基向量可以表示整个状态曲线，但必须计入 \(U_\theta\)。因此，最小维数结论只针对**固定线性 chart**，不是对任意非线性流形的下界。

### 算法意义

**[DERIVED]** rank selection 应至少区分

\[
\text{state accuracy},\qquad
\text{map tangent accuracy},\qquad
\text{pose tangent accuracy}.
\]

但这是一条通用 ROM 要求，不构成 SOM-exclusive 优势。相关的一阶／切向插值机制已有成熟 ROM 文献。

## 定理 2：复 gain 消去后，到底还剩下哪些相干关系？

这是本轮值得保留的一个具体研究工具。它不增加信息，而是明确**哪些相位组合不会被 separable Tx/Rx gains 吃掉**。

### 陈述

设某个频率与 frame 的完整多基地传递矩阵为

\[
H(\alpha,x)\in\mathbb C^{R\times T},
\]

所有元素非零。电子链路作用为

\[
Y=\operatorname{diag}(a)\,
H(\alpha,x)\,
\operatorname{diag}(b),
\]

其中 \(a_r,b_t\neq0\) 为任意复增益。

定义 \(r,t>1\) 的复交比

\[
\mathscr C_{rt}(H)
=
\frac{H_{rt}H_{11}}{H_{r1}H_{1t}}.
\]

则：

\[
\boxed{
\mathscr C(H')=\mathscr C(H)
\iff
H'=\operatorname{diag}(a)H\operatorname{diag}(b).
}
\]

这里的“完整”是指对这一 gain 作用的等价类完整，不是对 material/geometry 完整可辨识。

### 证明

正向的 gain cancellation 直接代入即可。

反向令

\[
Q_{rt}=\frac{H'_{rt}}{H_{rt}}.
\]

交比相等意味着

\[
Q_{rt}Q_{11}=Q_{r1}Q_{1t}.
\]

取

\[
a_r=\frac{Q_{r1}}{Q_{11}},\qquad b_t=Q_{1t},
\]

即可得到 \(Q_{rt}=a_rb_t\)，于是得到结论。证毕。

### 局部信息版本

定义

\[
E_{rt}=\frac{\delta H_{rt}}{H_{rt}},
\]

则

\[
\frac{\delta\mathscr C_{rt}}{\mathscr C_{rt}}
=
E_{rt}+E_{11}-E_{r1}-E_{1t}.
\]

其核恰好是

\[
E_{rt}=u_r+v_t,
\]

即复 row/column gain tangent。

证明：导数为零时，

\[
E_{rt}=E_{r1}-E_{11}+E_{1t};
\]

反向代入也为零。

在**固定、正定、参数无关噪声协方差**下，将局部实验白化、实化。设 gain tangent 为 \(G\)，相应的交比导数矩阵为 \(L\)。有

\[
\ker L=\operatorname{Ran}G,
\]

且

\[
\boxed{
L^T(LL^T)^{-1}L=P_{G^\perp}.
}
\]

因为左侧是到

\[
\operatorname{Ran}L^T=(\ker L)^\perp
\]

的正交投影。

所以，**正确考虑变换后协方差的线性化交比统计量，恰好对应 gain 消元后的局部信息。**

这不是说“直接对带噪测量取比值具有完整统计充分性”。非线性比值噪声会相关、非高斯，在信号零点附近尤其不稳定。最终估计仍应使用 raw coherent likelihood。

### 一个重要的物理负结果

单个点散射体／单一可分离散射项可以给出

\[
H=uv^T.
\]

此时所有交比都等于 \(1\)。

\[
\boxed{
\text{未知独立 Tx/Rx gains 可以完全吸收这一模型的几何变化。}
}
\]

若每个频率都允许独立 gains，单纯增加频率并不自动解除这个问题。

### 一个可检验的正机制

考虑两个可分离分量：

\[
H=uv^T+\eta st^T.
\]

令 \(a_r=s_r/u_r,\ b_t=t_t/v_t\)，则

\[
\boxed{
\mathscr C_{rt}-1
=
\frac{
\eta(a_r-a_1)(b_t-b_1)
}{
(1+\eta a_rb_1)(1+\eta a_1b_t)
}.
}
\]

证明是把交比分子、分母展开后相减，二次项相消。

这个式子说明：**跨 Tx、Rx 都有差异的非可分离传播结构，可以留下不受 separable gain 影响的 coherent 关系。**

但这仍不保证 material 与 geometry 分离。若 \(\eta=0\)，或所有 \(a_r\) 相同，或所有 \(b_t\) 相同，机制立即消失。多重散射可能增强，也可能因抵消而削弱这种关系。

### 算法意义与限制

它可用于检验“残差是否只需要 separable gain 解释”，以及选择能够增加跨 Tx/Rx 差异的新测量；不能从已经消去的 gain 相位中重新恢复 clock。

**[PRIOR ART]** closure／gain-invariant cycles 本身已有研究。本轮贡献只是针对矩形 full-wave transfer matrix 的明确特化与边界，不是发明 closure invariant。

## 定理 3：独立验证测量可以区分候选分支，但不能替代候选覆盖

### 陈述

条件化于全部训练数据和由其作出的 acquisition 决策。对于一个尚未使用的新测量，候选预测为

\[
\mu_1,\ldots,\mu_K\in\mathbb R^m,
\]

均已白化、实化。

假设正确物理分支的代表 \(i_*\) **确实在候选库中**，且

\[
y=\mu_{i_*}+e+n,\qquad
\|e\|\le\beta,\qquad n\sim N(0,I),
\]

新噪声独立于训练过程。

用最近预测选择候选。记

\[
d_{ij}=\|\mu_i-\mu_j\|,
\]

则

\[
\boxed{
\Pr(\widehat i\neq i_*)
\le
\min\!\left\{
1,\,
\sum_{j\neq i_*}
\exp\!\left[
-\frac{(d_{i_*j}-2\beta)_+^2}{8}
\right]
\right\}.
}
\]

### 证明

令 \(\Delta=\mu_j-\mu_{i_*}\)。选择 \(j\) 至少要求

\[
\|e+n-\Delta\|^2\le\|e+n\|^2,
\]

因此

\[
n^T\Delta
\ge
\frac{\|\Delta\|^2}{2}-e^T\Delta
\ge
\frac{d^2}{2}-\beta d.
\]

当 \(d>2\beta\) 时，除以 \(d\)，左侧为标准正态，使用 Gaussian tail bound：

\[
\Pr(i_*\to j)
\le
\exp[-(d/2-\beta)^2/2].
\]

当 \(d\le2\beta\) 时使用平凡上界 \(1\)，再对错误候选求 union bound。证毕。

### 可执行但有条件的 unlock rule

对于 \(K>1\)，一个充分的候选库条件是

\[
\boxed{
\min_{i\ne j}d_{ij}
>
2\beta+\sqrt{8\log\frac{K-1}{\delta}}.
}
\]

它可以用于选择验证频率，也可以选择 receiver configuration：

\[
a^*
=
\arg\max_a\min_{i\ne j}
\|\mu_i(a)-\mu_j(a)\|.
\]

**但必须同时承认三个边界。**

正确分支不在候选库中时，选得再自信也没有用。两个不同物理解具有相同预测时，距离为零。若用同一验证数据重新拟合候选，再套用上界，条件独立性已被破坏。

尤其：

\[
\boxed{
\text{multi-start hypothesis bank}
\neq
\text{有覆盖保证的 feasible set}.
}
\]

真正的覆盖需要全局有效的参数集合外包或安全剪枝界。局部 optimizer 给出的 profile residual 通常是**上界**，不能拿它充当安全排除一个 geometry 区域所需的下界。

**[OPEN]** 对高维未知材料场，低成本的全局分支覆盖仍未解决。本轮没有把这个条件性定理实现成已覆盖的 phase gate。

## 定理 4：输出导向的双残差修正

### 陈述

对可逆状态方程

\[
Mw=b,
\]

数值状态为 \(\widetilde w\)，残差

\[
r=b-M\widetilde w.
\]

目标输出为 \(q^*Lw\)。对任意近似 adjoint \(\widetilde p\)，定义

\[
r_d=L^*q-M^*\widetilde p.
\]

则

\[
\boxed{
q^*L(w-\widetilde w)
=
\widetilde p^*r+r_d^*M^{-1}r.
}
\]

若有经过验证的

\[
\gamma\ge\|M^{-1}\|,
\]

则采用可计算修正 \(\widetilde p^*r\) 后，剩余误差满足

\[
\boxed{
|\text{剩余输出误差}|
\le
\gamma\|r_d\|\|r\|.
}
\]

### 证明

由

\[
w-\widetilde w=M^{-1}r,\qquad
L^*q=M^*\widetilde p+r_d,
\]

直接代入即可。范数界由 Cauchy–Schwarz 得到。证毕。

### 同时保护状态和某个 Jacobian action

对方向 \(v\)，使用扩展状态系统

\[
\begin{bmatrix}
M&0\\
M_v&M
\end{bmatrix}
\begin{bmatrix}
j\\t_v
\end{bmatrix}
=
\begin{bmatrix}
b\\b_v
\end{bmatrix},
\]

输出算子为

\[
\begin{bmatrix}
S&0\\
S_v&S
\end{bmatrix}.
\]

同一恒等式适用。若原状态逆界为 \(\gamma\)，一个充分的扩展逆界是

\[
\left\|
\begin{bmatrix}
M&0\\M_v&M
\end{bmatrix}^{-1}
\right\|
\le
\gamma+\gamma^2\|M_v\|.
\]

### 反例与成本边界

取

\[
M=\operatorname{diag}(1,\epsilon),\qquad
r=\epsilon e_2,\qquad L=e_2^T.
\]

残差趋于零，输出误差仍可为 \(1\)。因此，没有 resolvent 控制时，残差不是严格证书。

**[PRIOR ART]** dual-weighted residual 与 goal-oriented correction 是已有工具。其作用是把旧的全状态大常数界替换成目标相关修正，不是凭空消除病态性。

**算法准则：若获取可靠 \(\gamma\)、adjoint 或输出界的成本接近被保护的直接求解成本，就将严格证书放到 offline verification，不强行进入 online loop。**

## 2. 变量、物理模型与矩阵形状

令

\[
\theta=(\alpha,x,\gamma)
\]

分别代表材料、锚定后的 geometry、电子／相位中心／结构化 coupling 参数。频率相关 contrast 由声明的材料模型生成：

\[
\chi_\ell=f_\ell(\alpha).
\]

对一个 acquisition：

| 对象 | 形状 |
|---|---|
| \(M_\ell\) | \(n\times n\) |
| \(B_\ell^{\mathrm{src}}\)：物理右端，多 Tx | \(n\times T\) |
| \(J_\ell\)：dependent current | \(n\times T\) |
| \(S_\ell\) | \(R\times n\) |
| \(H_\ell=d_\ell+S_\ell J_\ell\) | \(R\times T\) |
| \(U_\ell\) | \(n\times r_\ell\) |
| current coefficients \(C_\ell\) | \(r_\ell\times T\) |
| realified data Jacobian | \(2m\times(q+p+s)\) |

物理约束始终是

\[
M_\ell J_\ell=B_\ell^{\mathrm{src}}.
\]

数值近似允许有受监测的状态残差，但不把残差解释成可自由拟合数据的独立物理源：

\[
\boxed{r_{\mathrm{free}}=0.}
\]

proper complex noise 为 \(\mathcal{CN}(0,\Sigma)\) 时，单位实噪声的 embedding 是

\[
\sqrt2
\begin{bmatrix}
\Re(\Sigma^{-1/2}z)\\
\Im(\Sigma^{-1/2}z)
\end{bmatrix}.
\]

参数度量、prior curvature、noise whitening 分别处理。

## 3. Basis construction：SOM 只是可切换 seed

### 正确的 Twofold 实现来源

**[PRIOR ART]** 作者原书式（6.71）的可实施结构是

\[
j^-\approx
(I-V_{S,+}V_{S,+}^*)V_{D,+}\beta,
\]

而不是假定任意两套 SVD partition 都给出精确对称的 intersection decomposition。原书还明确讨论了 projection 与 intersection 的区别。2009 原论文 PDF 本轮未完整取得，因此这里的式号归属于 2018 monograph。

### 候选 numerical bases

建议只维护一个统一接口：

\[
U_\ell=
\operatorname{orth}_{\mathbb C}
\left[
U_{\mathrm{seed}},
U_{\mathrm{state}},
U_{\mathrm{map}},
U_{\mathrm{pose}},
U_{\mathrm{adj}}
\right].
\]

其中：

- sensing seed：\(V_{S,+}\)；
- Twofold seed：\([V_{S,+},(I-P_S)V_{D,+}]\)；
- material-weighted variant：如 \(\operatorname{diag}(\chi)V_{D,+}\)，必须明确不是经典 TSOM；
- generic seed：物理右端、已有物理状态 snapshot；
- enrichment：状态、map tangent、pose tangent、目标 adjoint residual 的方向。

使用 complex SVD／RRQR，按 Hermitian 内积去冗余。不能随意选一部分实方向后仍称其为复线性 current space。

多频率可以复用空间方向，但**不得假定高频子空间天然包含低频子空间**。每次复用都重新检查状态与任务导数误差。

## 4. Frozen chart 与正确 Jacobian

为简洁先写单个右端。令

\[
C=MU,\qquad
c=\arg\min_z\|Cz-b\|^2,\qquad
r_s=b-Cc.
\]

在固定 \(U\) 的 chart 内：

\[
\boxed{
(C^*C)c_v
=
C^*(b_v-M_vUc)
+
(M_vU)^*r_s.
}
\]

最后一项不能偷偷删除。

它来自微分

\[
C^*(Cc-b)=0.
\]

因此需要区分：

\[
\underbrace{
U(C^*C)^{-1}C^*(b_v-M_v\widetilde j)
}_{\text{物理 tangent equation 的投影近似}}
\]

与

\[
\underbrace{Uc_v}_{\text{固定基底 LS proxy 的精确导数}}.
\]

二者只在残差项为零等条件下相同。

若基底移动，则还必须加入

\[
C_v=M_vU+MU_v,\qquad
\widetilde j_v=U_vc+Uc_v.
\]

**建议：一次 trust-region／line-search trial 内冻结 chart。** 接受、拒绝或 enrichment 后再更新，避免对一个不断换定义的 proxy 声称 exact Jacobian。

本轮参考实现对 physical Jacobian 和 fixed-chart proxy Jacobian 都做了有限差分检查，最大相对误差约为 \(10^{-9}\) 以下；独立 adjoint 检查达到约 \(10^{-14}\) 以下。它们验证实现，不构成物理模型真实性或全局收敛证明。

## 5. Adjoint

令复数表示下

\[
\Phi=\tfrac12\|W(F-y)\|^2+R(\theta),
\]

其中 \(W\) 已包含与实化约定一致的噪声缩放。记

\[
q=W^*W(F-y).
\]

直接物理 adjoint 满足

\[
M^*p=S^*q,
\]

方向导数为

\[
D\Phi[v]
=
\Re\!\left[
q^*(d_v+S_vj)
+
p^*(b_v-M_vj)
\right]
+DR[v].
\]

对 frozen LS proxy，解

\[
(C^*C)\eta=U^*S^*q,
\]

得到

\[
\begin{aligned}
D\widetilde\Phi[v]
=\Re\big[
&q^*(d_v+S_v\widetilde j)\\
&+(C\eta)^*(b_v-M_v\widetilde j)\\
&+(M_vU\eta)^*r_s
\big]+DR[v].
\end{aligned}
\]

实现使用 QR 三角求解，不显式形成正规方程的逆。多 Tx 时按 Frobenius 内积求和。

## 6. 更新、拒绝与 fallback

在 task-scaled coordinates 中，使用 coupled GN/LM：

\[
\left(
\widetilde{\mathcal J}^T\widetilde{\mathcal J}
+H_R+\lambda D
\right)\Delta
=
-\left(
\widetilde{\mathcal J}^Tr+\nabla R
\right).
\]

材料维数大时采用 matrix-free adjoint 或 Schur 消元；不应为每个 material coefficient 都强制做一个 full solve。

一次降阶更新至少经过四类检查：

\[
\boxed{
\begin{array}{l}
\text{数值状态／导数误差是否受控；}\\
\text{目标绝对信息是否足够；}\\
\text{遗漏误差是否可能造成显著 calibration bias；}\\
\text{候选分支是否仍然不唯一。}
\end{array}
}
\]

\(\rho\) 只能补充解释，不能替代后面三项。

Exact objective acceptance 可以防止接受明显错误的数值下降方向，但**不能防止收敛到错误 phase branch**。

### 伪代码

```text
Input:
    raw coherent data, declared noise model, material family,
    anchored geometry, electronic nuisance model, acquisition actions,
    compute budget, task tolerances

Initialize low-frequency candidate bank without using test truth.

For each candidate:
    build or reuse a frozen numerical chart
    choose seed from {generic, sensing, Twofold}
    solve dependent physical state approximately
    check state and declared task-tangent residuals

    if chart is inaccurate and enrichment is affordable:
        add state / map / pose / adjoint residual directions
        rebuild chart
    elif chart is inaccurate:
        use direct state / derivative solve

    compute absolute target information and attribution diagnostics
    compute joint map/calibration step
    evaluate exact discrete physical objective at trial

    if trial gives adequate actual decrease:
        accept; record actual work
    else:
        shrink step / increase damping / enrich or use direct fallback

At a stage boundary:
    if different branches remain plausible:
        choose an independent measurement for branch separation
        do not treat inverse Hessian as coverage
    elif attribution is weak:
        select a view / rotation / reference measurement that separates causes
    elif next-frequency tests pass:
        unlock next frequency
    else:
        report unresolved ambiguity

Terminate:
    projected stationarity plus declared accuracy,
    or explicit budget/refusal status.
    Never equate "optimizer stopped" with "calibration identified".
```

## 7. 成本边界

对于 dense VIE，直接方法的典型成本是

\[
O(n^3)+O(n^2N_{\mathrm{RHS}}).
\]

Reduced-state chart 的主要成本包括

\[
MU:\ O(n^2r),\qquad
QR:\ O(nr^2),
\]

以及输出乘积、导数右端、基底更新和低维求解。

使用 FFT／快速算子时，\(MU\) 应按实际 \(r\) 个 operator actions 统计。**不能把所有 skinny products 都粗暴折算成 dense RHS。**

\(G_D\) 全 SVD 的 \(O(n^3)\) setup 必须计费；其离线复用次数必须声明。比较分别报告 cold start、单次反演和多次反演摊销，而不是只挑其中最有利的一种。

## 2. Geometry 与 clock/gain：一个跨全部频率的严格混淆反例

**[DERIVED]** 考虑单路径模型

\[
\mu_f
=
g\,a_f\frac{e^{ik_fr}}{r}e^{ik_fc\tau},
\]

其中 \(a_f\) 已知，\(g\) 为未知复 gain。

作变换

\[
r'=r+\Delta,\qquad
c\tau'=c\tau-\Delta,\qquad
g'=g\frac{r+\Delta}{r}.
\]

则

\[
\mu_f(r',\tau',g')=\mu_f(r,\tau,g)
\]

对所有频率成立。

这同时吸收了 geometry 引起的相位变化和传播幅度变化。

\[
\boxed{
\text{多频率}\not\Rightarrow
\text{geometry、clock、gain 自动可分。}
}
\]

因此，“geometry 也改变 amplitude”本身不是充分的可辨识性论证：未知 gain 可能把这个区别一并吸收。

## 3. 一个确实能分开的简化条件

对已经隔离的路径相位，设

\[
\phi_{fr}
=
\omega_f\left(\frac{n_r^Th}{c}+\tau\right)+\phi_0.
\]

**[DERIVED]** 若有两个不同频率，并且 \(\{n_r-n_1\}\) 张成 \(\mathbb R^d\)，则 \((h,\tau,\phi_0)\) 在这一局部未缠绕相位模型中可分。

证明：零扰动在两个频率相减后给出

\[
\frac{n_r^Th}{c}+\tau=0.
\]

再与第一视角相减：

\[
(n_r-n_1)^Th=0.
\]

仿射张成条件给 \(h=0\)，进而 \(\tau=0,\phi_0=0\)。证毕。

**这不是 full-wave basin theorem。** 在实际全波模型中，要用包含 illumination、induced-current、sampling、gain、clock 和 coupling 的完整 Jacobian，并在真实 nuisance family 下检查。

一个严格的局部充分条件是：消除精确 gauge 后，联合 Jacobian 满列秩。选取其可逆方阵 minor，逆函数定理给出局部可辨识性。

仅仅 \(B_{\mathrm{vis}}\) 满秩而 nuisance rank 在邻域变化时，不能直接推出非线性 target identifiability；A2 已经对这一边界做过纠正。

## 4. 统一 attribution tangent 与 reject option

定义

\[
\delta y
=
A_\alpha\delta\alpha
+B_x\delta x
+B_\tau\delta\tau
+B_g\delta g
+B_{\mathrm{pc}}\delta p_{\mathrm{pc}}
+B_c\delta c.
\]

对 geometry 的可见部分应使用

\[
B_{x,\mathrm{vis}}
=
P_{\operatorname{Ran}
[A_\alpha,B_\tau,B_g,B_{\mathrm{pc}},B_c]^\perp}
B_x.
\]

这里应检查 task-scaled absolute singular values，而不是只看归一化 angle 或 \(\rho\)。

**不能通过 \(\sigma_{\min,+}\) 自动忽略需要恢复的零方向。** 先声明目标 support 和必须恢复的参数，缺 rank 就报告缺 rank。

以下三种 exact ambiguity 必须直接进入软件的类型检查。

### 任意 per-frequency gain phase 与 clock

若每个 frequency/channel phase 都自由，则 clock 导数已经位于该 gain-phase space 中。

此时要么依靠独立校准限制 gain frequency dependence，要么只报告一个 combined delay／phase correction。人为让 gain basis 与 \(\{1,\omega\}\) 正交可以定义参数，但不自动证明估计到的线性 phase ramp 就是物理 clock。

### Tx/Rx gain gauge

\[
a_r\mapsto za_r,\qquad
b_t\mapsto z^{-1}b_t
\]

不改变数据。必须固定一个复 gain anchor 或相应 quotient。

### Mechanical translation 与 body phase-center offset

若有效位置写为

\[
r_s=t+R_s(r_0+p),
\]

则其不可见方向满足

\[
\delta p\in\bigcap_{s>1}\ker(R_s-R_1),
\qquad
\delta t=-R_1\delta p.
\]

两个不同二维转角可以消除这一特定歧义；三维两个姿态通常仍留下相对旋转轴方向，需要更多非共轴旋转。这个结论以有效位置本身已经可观测为前提。

### Reject 不应只由 residual 决定

输出应允许是：

> “数据与若干解释一致，但不能分清 geometry 与 delay。”

也应允许：

> “当前 nuisance 模型不足，归因为 unknown；不输出可信 pose correction。”

小 residual、较大局部曲率、或者某个模型在几个候选中最优，都不能单独阻止这种拒绝。

## 5. 本轮 attribution 实验：证明了一个有限机制，没有解决一般硬件归因

**[NUMERICAL]** 本轮执行 20 次拟合：

\[
2\ \text{scenes}
\times
5\ \text{真实误差类型}
\times
2\ \text{estimator}.
\]

统一模型包含一个 frame-wide complex gain、common delay、一个实 nearest-neighbour receiver-output mixing coefficient，以及 map/pose。

它不是任意 per-channel gain calibration，也不是 target-loaded electromagnetic mutual coupling。

在真实误差为

\[
c\tau=0.065\ \mathrm m
\]

的两个场景中：

| 指标 | Geometry-only | Unified nuisance |
|---|---:|---:|
| 场景 1 pose error | 0.0791 m | **0.00124 m** |
| 场景 2 pose error | 0.1105 m | **0.00390 m** |
| 两场景 whitened residual RMS | 约 36.5、36.8 | 约 1.04、0.90 |
| Delay error | 未估计 | 0.000143、0.0000717 m |

它说明：**在这个匹配模型中，把 clock 强行解释成 geometry 会产生假 pose；加入正确 nuisance 后能够纠正。**

但有两个限制不能省略。

第一，模型具有已建模的 direct-field reference，clock 改变它，而共同刚体运动不改变直接收发距离。这使归因更容易。去掉或错误建模该 reference 的情况尚未验证。

第二，在另一些 gain/mixing 场景中，扩大 nuisance 后 residual 更合理，却没有总是改善 pose error。这正是 variance–bias／information tradeoff，而不是失败结果可以忽略的理由。

## 6. Acquisition：从局部信息分数转成真实动作

**[HYPOTHESIS]** 建议将 acquisition decision 分为两个不同任务，不再用一个 logdet 包办。

**候选分支不一致时：**

\[
a^*
=
\arg\max_a
\min_{i\ne j}
\|\mu_i(a)-\mu_j(a)\|,
\]

最好使用考虑 branch 内参数不确定性的距离下界。没有可靠下界时，只能称为 candidate-bank heuristic。

**已经进入同一可信分支、但局部精度差时：**

\[
a^*
=
\arg\max_a
\lambda_{\min}\!\left(
D_x^{-T}J_x^{\mathrm{stack}}(a)D_x^{-1}
\right),
\]

或者使用固定目标 support 上的 logdet／Bayes task criterion。

这两种目的有时相反：一个使当前 Hessian 很强的新频率，未必能区分两个错误分支。

| 当前瓶颈 | 优先测试的 acquisition |
|---|---|
| Geometry–clock 混淆 | 改变传播方向的 receiver／Tx view，不是只加频率 |
| Translation–phase-center 混淆 | 改变阵列／天线姿态，并建模方向图 |
| 候选几何存在镜像／周跳 | 能最大化候选预测差异的非对称视角或验证频率 |
| Local pose information 小 | Shared-map 条件下的互补 source／receiver configuration |
| Gain gauge | 独立 reference 或明确 gain anchor |
| 模型错误／coupling 可疑 | 专门诊断测量；不能让 pose 无限吸收误差 |

**[PROVED]** 原 shared-map innovation／information-budget 公式继续使用；它只对所声明的局部模型和 nuisance family 成立。不能把 numerical basis enrichment 也当成信息损失 \(L\)。

### 本轮 nonlinear acquisition 的实际结果

**[NUMERICAL]** 三个场景，每次从 8 个 receiver configurations 中，在已拟合 reference estimate 上按 shared-map Schur logdet 选择一个动作。真值不进入选择。

| 场景 | 加测前 pose error | 选定动作后 | 预设随机动作后 |
|---|---:|---:|---:|
| 6301 | 0.05730 m | **0.01589 m** | 0.07316 m |
| 6302 | 0.06576 m | 0.04912 m | **0.01230 m** |
| 6303 | 0.17489 m | 0.02930 m | **0.00898 m** |

这确实完成了

\[
\boxed{
\text{active measurement}
\rightarrow
\text{nonlinear reconstruction}
}
\]

而不只是画 tangent logdet。

但选定策略只在 **1/3** 场景优于随机；map error 也只在 **2/3** 场景改善。

因此：

\[
\boxed{
\text{“新数据有用”成立于这些测试；}
\quad
\text{“当前设计策略更好”尚不成立。}
}
\]

下一轮比较 greedy、pair look-ahead、beam search 和小动作集 exhaustive search 时，必须比较最终恢复而非只比较设计分数，并计入所有候选 forward/tangent 成本。

# Part VII — Application and Hardware

## 1. 应用定位

| 场景 | 科学相关性 | 当前模型兼容性 | 缺失物理 | 现在可以／不可以声称 |
|---|---|---|---|---|
| Coherent near-field microwave tomography | **最高，主场景** | 2D scalar、静止目标、nominal geometry 兼容 | 真实天线方向图、有限高度、极化、模型误差 | 可研究结构化校准；不可宣称普遍硬件可用 |
| Flexible／mechanically scanned array | 高 | 小维度 shape/extrinsic error 可扩展 | 天线形变、方向变化、相位中心、互耦变化 | 可作为下一验证对象；当前未验证 |
| Robot-mounted antenna | 高，但多一层工程问题 | 已知 nominal trajectory 的小偏差可建模 | 3D extrinsic、姿态、encoder、时钟和运动误差 | 可研究机器人载天线校准；不是已解决 SLAM |
| UAV／swarm | 长期相关 | 当前模型不足 | 分布式振荡器、Doppler、3D Maxwell、airframe scattering、动态目标 | 只能作为远期方向 |

**[OPEN]** 当前 scalar rigid-array 模型不能支撑 UAV/swarm 或 general inverse-scattering SLAM 的 abstract claim。

## 2. 最小而有说服力的 controlled experiment

最有价值的实测不是再拟合一次未知 object center，而是把误差原因单独控制住。

建议在同一套静止目标、同一标定窗口内建立：

| 控制变量 | 必须有的真值 | 检验目标 |
|---|---|---|
| Tx/Rx 已知位移 | 独立位置计量 | 真 geometry 能否恢复 |
| 已知 rotation | 独立角度计量 | rigid rotation 与 phase center 是否混淆 |
| Cable/electronic delay | 独立测得的复传递／group delay | 是否误报 geometry |
| Complex gain | 已知幅相改变 | 是否误报 pose |
| 模型失配 | 明确改变的照射／目标／硬件条件 | 是否触发 unknown／拒绝 |

保留 independent held-out views/frequencies，且训练后不得在测试视角重新拟合 gain。

两个区别必须保留：

\[
\boxed{
\text{数字注入 phase ramp}
\neq
\text{真实硬件 clock/cable validation},
}
\]

\[
\boxed{
\text{已知机械相对位移}
\neq
\text{已知绝对 electromagnetic phase center}.
}
\]

Fresnel 数据可以继续做 measured complex-field model adequacy 和受控 metadata perturbation；它仍然不能证明 blind antenna-offset recovery。当前最终审查已经明确这一点，不能逆转。

## Reviewer A — Inverse Scattering Theory

**Summary.** 论文讨论 full-wave coherent self-calibration，区分 numerical state dimension 与 independent nuisance，连接局部信息、偏差与 acquisition。

**Strengths.** 类型与物理导数比旧版本清楚；不再把 \(\rho\) 当绝对可观测性；保留了不利实验。

**最强 rejection argument：**

> 主体理论仍主要由 Schur complement、principal angles、线性风险和标准 ROM 误差工具组成。SOM-specific 优势没有证明。有限材料基底可能承担了大部分可辨识性，而论文尚未分离这一影响。

**当前能回答多少：** 能正确承认这些工具的来源，能给出具体混淆反例；不能回答“为什么这构成强 TAP 新方法”。

**关闭 concern 所需：** 一个真正针对 full-wave material/geometry/electronics 的非平凡归因或分支分离结果，并由相应 acquisition／恢复实验验证。增加抽象流形描述不能替代它。

**Recommendation：Reject。**

## Reviewer B — Computational Electromagnetics / Numerical Methods

**Summary.** 新 hybrid 有实际降阶更新，但最高频全部 fallback，未展示 computational saving。

**Strengths.** 物理与 proxy Jacobian 已分别检查；新实验没有再次被“零执行路径”掩盖。

## Reviewer C — Array Calibration / Measurement

**Summary.** 理论强调 geometry、clock、gain attribution，但实验证据仍主要是匹配 synthetic。

**Strengths.** clock 被误解释成 geometry 的控制实验具体且有意义；允许拒绝归因的方向正确。

**最强 rejection argument：**

> 一个 frame-wide gain/delay 加简单 output mixing，且存在已建模 direct-field reference，远未验证真实阵列中的 phase center、独立通道相位、方向图与 target-loaded mutual coupling。没有 antenna-offset ground truth。

**当前能回答多少：** 能说明 toy nuisance 模型的归因价值，能避免误用 Fresnel；不能声称 hardware calibration。

**关闭 concern 所需：** 已知位移／角度／电子延迟的独立计量，以及真 clock、真 gain、模型错误时不输出假 pose 的实测控制。

**Recommendation：Reject。**

**Current recommendation：Reject。**

达到 Major Revision 水平，至少需要形成一条闭合链：

\[
\boxed{

\rightarrow
\text{实际执行的算法动作}
\rightarrow
\text{相对强基线的恢复收益}

\text{与 claim 相匹配的验证}.
}
\]

现在已经比旧版本多了实际降阶路径、真实 basin 结果和 nonlinear acquisition；但还没有把这条链闭合。

# Part IX — Final Research Decision

## **B. SOM-specificity failed but self-calibration survived**

这里的 **failed** 指：

> **当前 SOM-specific 主张没有通过保留在论文核心与标题中的证据门槛。**

不是已经证明所有经典 SOM、Twofold SOM 或 SOM initialization 都无效。

下一阶段应当收敛到：

\[
\boxed{
\text{物理归因}
+
\text{候选相位分支的可区分性}
+
\text{能够改善非线性恢复的新 acquisition}.
}
\]

SOM 保留为一个可替换、需要继续接受公平比较的 numerical seed。严格证书保留为成本受控时才启用的辅助工具。只有新的 matched evidence 证明它们真正带来收益，才重新进入标题。

**值得保住的是 coherent full-wave self-calibration 这个科学问题，不是最初给它选择的 SOM 标签。**
