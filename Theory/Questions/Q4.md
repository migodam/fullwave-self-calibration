# 2. 已经锁定、不得重新包装的事实

## 2.1 SOM-specific superiority 已经做出正式有限范围裁决

在预注册的：

- 40 个此前未使用场景；
- 6 种方法；
- 240 次冻结 serial fits；

中：

- 六种方法均成功 \(37/40\)；
- Twofold 相比 Krylov 的预设 10 percentage-point success advantage 被排除；
- successful matched pairs 中 Twofold/Krylov conditional median runtime ratio 约为 \(1.186\)；
- 预设 20% runtime saving 被明确排除。

因此：

\[
\boxed{
\text{当前 Twofold/SOM-informed reduced implementation 不再是论文标题或核心贡献。}
}
\]

不得通过继续挑选有利小场景推翻冻结结论。

这不等于证明整个 SOM family 永远无价值。

但只有当你能一次性给出：

\[
\boxed{
\text{明确、可证明、事前可计算、可实验验证的 SOM-specific electromagnetic sufficient condition}
}
\]

并且该条件使 sensing/Twofold subspace 相比 generic task ROM / Krylov 在至少一个重要指标上具有严格、可计算优势，例如：

- basis dimension；
- computational cost；
- recovery accuracy；
- convergence basin；
- task-tangent approximation quality；

才允许重新提升 SOM。

“恰好包含需要的方向”不是 SOM-specific theorem。

否则：

\[
\boxed{
\text{SOM 只保留为 replaceable numerical engine / historical motivation / negative ablation。}
}
\]

不得修改当前冻结 benchmark 的负结论。

---

## 2.2 当前论文问题已经改变

现在研究的是：

\[
\boxed{
\text{Phase-Preserving Full-Wave Calibration}
}
\]

核心不再是：

> 能不能把 phase 拟合好？

而是：

\[
\boxed{
\text{phase change 到底来自 geometry、electronics、material，
还是 forward-model discrepancy？}
}
\]

必须严格区分四个完全不同的成功概念：

### Fitting success

预测 measurement 与实际 measurement 接近。

### Attribution success

geometry / material / electronics 的贡献被正确区分。

### Branch success

优化落在正确 nonlinear coherent phase branch。

### Numerical / physical fidelity

forward model 本身足够准确。

这四者互不替代。

---

## 2.3 已有重要正负事实

已有结果包括：

- sensor prediction 可以很好，但 structural field / material 明显错误；
- geometry 可以估得很准，但 material 仍可能明显 biased；
- true geometry 也不能自动消除 material bias；
- 小 residual 不保证 material / geometry 正确；
- local full rank / Fisher precision 不保护 against model discrepancy；
- high-frequency coherent information 在 correct-model experiment 中可以有明显收益；
- independent-model discrepancy 可以完全反转 high-frequency benefit；
- residual-only phase-branch rejection 不可靠；
- candidate separation 不等于 candidate coverage；
- adjacent-grid difference 不是自动有效的 true-error enclosure；
- heuristic weighting 下，真实白噪声 estimator variance 是 sandwich form；
- free gains 可以吸收 geometry-induced phase；
- unrestricted separable gains 下 forest acquisition 没有 gain-invariant constraints；
- cycles 只提供 invariant dimension，不保证 geometry 可辨；
- fixed-frequency、far-field receiver translation、free receiver gain 条件下，leading propagation-phase derivative 可以被 gain 吸收；
- profile gain 后 translation information 有条件地随距离衰减；
- known target support 当前实际上提供了 spatial anchor；
- object / receiver translation 与 common delay 存在 exact full-wave symmetry；
- discrepancy 若包含 task tangent，可构造严格不可辨识 two-world model；
- finite-bank Gaussian selection bound 只有在 correct / near-correct candidate 已存在、discrepancy bound 已知、validation data 独立时才成立；
- 当前 full-wave experiments 已经出现 candidate bank 完全没有正确 branch 的情况。

这些不是 appendix 中的注意事项，而是后续任何算法都必须正面处理的约束。

# 4. 第一主问题：Attribution → Action

从 correctly whitened、gauge-fixed 的局部模型开始：

\[
\delta y
=
A\delta\alpha
+
B\delta x
+
G\delta\gamma
+
e+n.
\]

其中：

- \(\delta\alpha\)：material / structural parameter；
- \(\delta x\)：geometry；
- \(\delta\gamma\)：electronics nuisance；
- \(e\)：forward-model discrepancy；
- \(n\)：measurement noise。

其他未知量必须先 profile 掉，再讨论 task tangent。

---

## 4.1 Task-visible tangent

对于 geometry task：

\[
B_{\rm vis}
=
(I-P_{[A,G]})B.
\]

对于 material task：

\[
A_{\rm vis}
=
(I-P_{[B,G]})A.
\]

如果研究 structural-field task，则定义相应 task operator \(T\)，并在 nuisance-profiled 参数误差上衡量 structural risk。

模型 discrepancy 不能默认 orthogonal 于 task tangent。

---

## 4.2 真正优化的对象

必须明确 controller 优化的是：

- geometry risk；
- material risk；
- structural-field risk；

之一或它们经过明确加权后的组合。

不得优化 residual 本身。

定义 task-specific risk：

\[
\boxed{
R_T
=
\text{variance}
+
\text{discrepancy-induced bias risk}.
}
\]

如果只能得到 surrogate，则必须明确称：

\[
\boxed{\text{surrogate risk}}
\]

而不是 certificate。

---

## 4.3 Fixed weighted estimator 的风险必须正确

若：

\[
L_W=(J^TWJ)^{-1}J^TW,
\]

在真实白噪声下，task risk 必须使用 sandwich form：

\[
R_T
=
\operatorname{tr}
\left(
T L_WL_W^T T^T
\right)
+
\|TL_Wd\|^2,
\]

或相应 covariance-scaled 版本。

不得自动写成：

\[
\operatorname{tr}
\left[
T(J^TWJ)^{-1}T^T
\right]
\]

除非噪声模型与 GLS weighting 假设真正匹配。

# 5. Attribution Controller 必须输出物理 Action

最终 decision space 至少包括：

\[
a\in
\{
\text{accept},
\text{reject},
\text{downweight},
\text{refine model},
\text{add electronics reference},
\text{acquire new data}
\}.
\]

每一个 action 必须有明确触发条件。

---

## 5.1 Accept

只有在 task risk 足够低、branch sufficiently covered、discrepancy plausibly controlled、当前 model fidelity 足够时才能 accept。

不能因为 residual 小而 accept。

---

## 5.2 Reject

当：

- candidate coverage 不足；
- discrepancy 与 task tangent 无法区分；
- task risk 无可接受上界或 surrogate 已明显超阈；
- validation 数据与当前 calibration 不一致；

时允许明确输出：

\[
\boxed{\text{reject / insufficient evidence}}
\]

而不是强行给一个参数估计。

---

## 5.3 Downweight

只有当某 frequency / measurement direction 对 task 带来的 discrepancy bias risk 大于 information gain，且这种判断不是靠 ground truth 调参时，才能 downweight。

优先研究：

\[
\text{profiled task tangent}
\]

而不是 raw pose Jacobian。

---

## 5.4 Refine Model

当现有 coarse / approximate forward model 的 discrepancy 与 material / geometry task tangent 有强 overlap 时，应优先提高 physical-model fidelity，而不是盲目降低 phase 权重。

---

## 5.5 Add Electronics Reference

当 dominant ambiguity 主要落在 \(G\)-related nuisance subspace，并且 independent reference 能实际缩小该 nuisance subspace 时，trigger electronics reference。

必须明确：

> reference 到底消除了哪个 nuisance dimension / ambiguity direction。

---

## 5.6 Acquire New Data

当现有 acquisition 对 geometry / material ambiguity 不足时，新 measurement 应最大化真正的 profiled task discrimination 或 worst-case branch separation。

不要只最大化 local Fisher。

---

# 6. Discrepancy Set 的严格要求

如果采用 deterministic discrepancy set：

\[
e\in\mathcal E,
\]

必须回答：

> 为什么真实 forward-model error 属于 \(\mathcal E\)？

不能使用：

> coarse-fine difference 看起来差不多，所以应该覆盖 true error。

特别是：

\[
\text{adjacent-grid difference}
\]

不得自动称为 rigorous enclosure。

允许来源包括：

- analytic truncation / discretization estimate；
- validated interval / a posteriori solver bound；
- independent fine solver；
- experimentally justified model family；
- statistically calibrated approximation-error distribution；
- explicit assumptions under which coverage probability 可证明。

如果无法证明真实 error 属于 set，则风险只能称：

\[
\boxed{\text{surrogate}}
\]

不得称 certificate。

### Action E — New Acquisition

选择真正增加 material-profiled geometry information 或 branch separation 的 measurement rows。

当前信息不足时拒绝输出 confident calibration。

# 19. Branch Reliability 必须分别量化四种失败

不能只报告 success rate。

必须分别分析并统计：

\[
P(\text{true branch not represented})
\]

即 candidate missing / coverage failure。

---

\[
P(\text{wrong branch selected}\mid\text{covered})
\]

即 covered 但 selection 错误。

---

\[
P(\text{wrong calibration accepted})
\]

这是最关键 reliability failure。

---

\[
P(\text{correct calibration rejected})
\]

即 false reject。

必须区分：

- scene sample；
- conditional noise replicate。

不能把 200 noise replicates 称作 200 个 independent full-wave scenes。

# 20. Branch Reliability 的最小 3D/full-wave 实验

从现有 benchmark 建立一个小型但完整的 version：

- 3D receiver translation；
- 1–2 material parameters；
- shared gain / clock；
- low / medium / high frequency；
- Treams / ADDA 或其他 independent forward reference。

比较：

1. naive multistart；
2. local Fisher acquisition；
3. random acquisition；
4. branch-separation acquisition；
5. coverage-aware algorithm。

故意生成：

- coverage easy；
- close competing branches；
- model discrepancy；
- low SNR；
- gain–geometry confounding；
- symmetric object；
- candidate-bank-missing case。

算法必须有专门能击败它的困难反例。

不得只展示成功场景。

# 36. 三个 Major Concerns 的关闭标准

## Major Concern 1

> 你到底提出了什么新的、真正工作的正面方法？

关闭要求：

- 实际执行；
- 有 accept/reject/action mechanism；
- 优于至少一个强 prior baseline；
- 不是 residual-only；
- 不是 oracle；
- 不用真值调 threshold；
- 所有 cost 有账。

否则：

> 当前工作更适合 theory/limits paper，而不是 method paper。

---

## Major Concern 2

> 你真正新的 electromagnetic theory 是什么？

关闭要求至少得到一个：

\[
\boxed{
\text{真正 electromagnetic-specific theorem / mechanism}
}
\]

满足：

- distributed full-wave scattering；
- explicit material/gain nuisance；
- clear measurement condition；
- nontrivial positive result 或必要 impossibility boundary；
- nearest prior checked；
- acquisition consequence。

如果 theorem 已知：

不要伪造 novelty。

---

## Major Concern 3

> 你怎么知道算法没落在错误 phase branch，或者 candidate set 根本没覆盖真解？

关闭要求：

算法明确区分：

\[
\text{“找到可信 branch”}
\]

与：

\[
\text{“当前 candidate coverage 不足，无法确认”}.
\]

在 deliberate wrong-coverage experiment 中：

- 不把错误 branch 高概率当正确；
- 能 trigger reject / acquisition / refinement；
- 有 independent held-out validation。
