# B1-D2：已观察主比较后的强基线分解

本诊断是在观察S/I主结果及部分X结果后增加，明确为事后开发诊断，不是新的最终测试或预先未见主比较。原九方法结果不修改。

periodic_GLS使用目标数据和参考数据共同估计状态；因此不能把其成功计数归于纯reference-only校准。本诊断增加两种真正两阶段方法：periodic_then_image和everyframe_then_image。只用已采集参考估计该时刻的effective z、delay及公共复增益；periodic仅用帧0、3、7的参考，并对z、delay、log幅度和解缠相位做非因果线性插值；再冻结校准，用允许的目标观测估计材料。每帧标准估计从(0,0)初始化，max_nfev=120；材料仍为原三个初值、120次、原容差。

它们分别使用与periodic_GLS/everyframe_reference_GLS完全相同的192复标量采集掩码，不读取额外参考，不用真值初始化。插值不代表已计入所有校准不确定性；联合GLS继续作为更强的噪声一致对照。每帧参考假设同状态、零交换停机是乐观条件，不当成已验证硬件能力。
