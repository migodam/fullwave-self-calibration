# B1完整中文科研报告

# Executive Abstract

选择机械扫描的双接收头：固定两个发射器，两个移动探针，八帧、三频、两个已知支撑材料区域。选择它不是因为已证明其必须自校准，而是因为它是能同时给传统方法和全波候选充分机会的最小困难测试。

传统全姿态旧标定不能预测后来出现的随机创新；但本轮没有证明周期参考在该装置上不经济。full-wave保留内部场反馈、高阶/相对模态与对象间再散射，确实不同于Born线性幅度；然而没有得到满足真实读出条件的全参数域材料/几何分离保证。

实际执行36个开发场景、九主方法、真正两阶段参考、因果前缀和独立模型消融。C1与普通joint同目标，C2无额外材料成功收益；参考辅助方法更强。没有获得exciting的新自校准论文结果。当前裁决NO，限定于所测配置，不是所有移动阵列的不可能性。

# Engineering Background

三个候选依次比较机械扫描、柔性阵列、分布式UAV。机械扫描硬件/数学复杂度最低；柔性互耦形状自校准已有实机；UAV的同步/路径误差很重要但不自动要求非Born材料全波反演。详见01文件，原始来源见02文件。

本轮不是旧Q5窗口定理的重命名：材料误差和动态calibration共同评估；A1–A5、Q5只读，不沿用其中任何成功数。目标是工程优势或独特物理优势，而不是扩大谱定理数量。

# Closest Prior Work

近场平均介电常数与对角收发gain联合估计已有R6；该文还明确指出运行时不可插参考的工程动机。柔性阵列R4/R5使用互耦重建形状。R7利用两个均匀仿体降低实际系统与正演差异。R8/R9已研究图像/增益联合优化和校准时间尺度。这里均不是空白。

# Why Conventional Calibration Fails

写校准状态为可重复姿态函数加新创新q_t=h(x_t^nom)+w_t。前者可以由姿态索引参考表标定；本轮offline基线已经有完整八姿态表，不能说它只在一个点标定。旧表失效来自w，而不是“移动”二字。

对Brownian创新，完美相邻参考间隔Δ的非因果中点条件方差QΔ/4；仅因果最近参考预测是Qu。对|q'|≤L，两端均准确时最坏中点误差LΔ/2。两条解析界及作用域均在04文件。它们没有给出本装置实测Q、L或停机代价，故不能证明周期reference经济失效。

每帧参考假定同状态且零交换停机只作为偏向传统方案的乐观上限。周期GLS还使用目标信息，不等同于两阶段校准；两者结果分开。

# Full-Wave Physical Mechanism

零直接交叉场下，匹配Born具有(s,g)→(cs,g/c)准确规范；合法有限对s=(2,2.7)、s'=(2.24,3.024)。多帧共享不会自动解除这一规范。已知电子学loopback或保留非零直达场，即使Born也可破除它。

二点相互作用响应Z=g(diag(α^-1)-U)^-1的逆矩阵非对角元为-u/g，允许已知几何且完整可读Z时恢复g。此条件机制已解析推导并测试，但当前移动头尚无该完整Z的稳定读出证明。因此它是受限机制，不是full-wave-only成功声明。

点源VSW下同尺度材料变化经过最优公共gain后仍有约.00772相对场差，只是固定几何诊断。不能排除另一个geometry/delay状态把它再次吸收。

# Mathematical Theory

04文件包含五项结论：参考更新界、有限Born规范、相互作用条件识别及噪声界、远场几何/delay规范与2500ps频率别名、profiling目标等价性。不存在把Jacobian满秩当统一材料恢复保证的步骤。

mechanical pose与phase-center只以和进入时无法分别辨识；全频任意gain会移除关键sharing；pure phaseless对公共phase/delay没有信息。坏物理世界分布相同，PINN不能凭PDE损失产生数据里不存在的区分。

# Algorithm

C1每帧准确条件环带gain解，C2经典频率递进后相同GLS。普通joint使用相同动态先验与物理域；三固定材料初值，120次函数评估/初值。C2额外低频初始化成本单独记录。Rician对照使用原始两重复模值，不先相干平均。

主榜为八帧批量平滑；D1真的执行每个前缀只使用当前与过去观测。对于最终静态材料估计，两类方法均可用截至终帧的所有数据；不拿使用未来参考的早帧平滑结果假装实时预测。

# Code and Experiments

S/I/X各12场景：S同模型慢漂移；I独立DDA→VSW慢漂移；X独立DDA并有更快漂移、频率依赖相位中心、Rx倾角和相对通道增益失配。所有组固定相同绝对噪声：proper complex标准差为名义交叉场RMS的.5%。每公平方法192单频复标量，参考或pilot扣除目标重复。

主比较324次方法拟合，D2为72次两阶段拟合；D1为72次八前缀扫描和84次oracle/弱模型诊断。它们重用同一36场景，不是更多独立测试样本。每次优化三条初值保留，失败和中断不删除。

## 独立模型与oracle

I组真gain、真有效位置、真delay的oracle只有3/12材料达标；Born为0/12（target-only）和1/12（loopback）；CM有相互作用为1/12和2/12，无相互作用为2/12和3/12。CM自身已有非线性局部场效应，不应叫Born。全波目标only的11/12比这些弱模型好，但部分自由calibration也可能吸收结构正演偏差；不能由此断言自校准比真实标定更符合物理。

I0/I1的DDA/VSW交叉场相对差在h=.0065时约3.775%/3.580%，h=.0055时约3.573%/3.378%；网格变化约.485%/.474%。这只是数值差，不是连续误差界。VSW4与6的全部场差约6.1e-8；由于强直接场占比大，应同时查看交叉场检查约1.48e-6，不能靠小总场误差掩盖弱通道错误。

# Failure Modes

准确Born尺度规范；几何/电子学delay退化；机械与相位中心和的规范；不足孔径及病态deembedding；自由逐频增益；弱模态SNR不足；未建模倾角/共极化泄漏；采集burst内漂移；参考交换改变状态；结构误差被gain吸收。所有这些有单独数学或实现边界，不以高维自由phase救失败。

# Hardware Feasibility

最小平台可以采用共享相干收发仪、双探针、一维机械扫描，不需要UAV。真正成本为192t_s+移动稳定时间，再加参考交换C_ref或loopback切换C_loop。未实测这些常数，工程成本优越性未成立。

名义共极化场约为交叉场57倍；.002rad倾角可产生约11.4%交叉通道量级泄漏。若要把一级RMS泄漏压到.5%噪声量级，角度约需小于8.8e-5rad或必须显式估计泄漏。这不是硬件验收证书，而是指出主模型为什么脆弱。X不是任意虚构白噪声，而是这种具体混合响应失配。

# Xudong-style Critique

依据诱导源与物理状态约束的研究思路，不冒充本人评价：普通joint已同时满足数据、状态、共享材料与动态正则；新的测量约束才可能产生新信息。T3的完整响应不能免费假定已取得。应优先解释I组为何真值校准oracle更差，而不是扩大S组成功数。Twofold/SOM不作为标题或方法品牌。

# TAP Mock Review

本轮不支持强新方法稿。主要缺口是工程不可替代性、full-wave-specific可测分离、真实模型误差、最近邻原创性。参考辅助基线更强，目标消元与普通joint同目标，所有独立相干结果失配报警。积极价值是复现清楚、对手不弱化、噪声与预算一致、因果处理真实、失败保留。

# Final Verdict

**NO — known-scatterer/reference calibration remains the better solution**

这是一项完整执行的受控否定裁决，不是因为课题长期未解决而停止。它限定于当前canonical scenario和已检验机制。没有发现满足A或B的killer result；继续在同一开发数据上调参、重新包装ordinary joint或跳到UAV，均不能替代缺失的证据。

本轮留下可运行的独立比较、具体规范/噪声边界和可量化的硬件失配警告。它可以帮助淘汰一条不值得按原故事推进的路线，但不自动成为可直接投稿TAP的新方法论文。
