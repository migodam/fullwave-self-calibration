# 已实现的强基线、候选与算法等价性

## 预算和执行矩阵

每帧有12个单频Tx–Rx观测，八帧。每种公平方法共192个复标量；参考/电子学pilot替换而非赠送目标重复。所有相干方法用共同原始目标数组及三个固定材料初值。每方法最小目标的初值获选，不按材料真值选解。

| 方法 | 目标样本 | 已知目标参考 | 电子学/共极化pilot | 状态推断 |
|---|---:|---:|---:|---|
| offline_pose_indexed | 96 | 96（之前的完整8姿态） | 0 | 仅旧参考校准，冻结后反演材料 |
| periodic_GLS | 156 | 36（帧0,3,7） | 0 | 目标+带噪参考联合全波平滑 |
| everyframe_reference_GLS | 96 | 96 | 0 | 每帧同状态参考辅助联合 |
| ordinary_joint | 192 | 0 | 0 | 直接同时优化材料、8位置、8delay、8复gain |
| profile_dynamic（C1） | 192 | 0 | 0 | 同一目标中准确消去公共gain |
| continuation（C2） | 192 | 0 | 0 | 最低频、两频初始化，然后同一三频GLS |
| loopback_GLS | 168 | 0 | 24 | 每帧三个共享电子学pilot，联合拟合 |
| copolar_GLS | 168 | 0 | 24 | 保留直达及目标散射的共极化pilot |
| phaseless | 192 | 0 | 0 | 原始模值Rician似然，不能估计公共phase/delay |

periodic_GLS不是“只靠已知参考先校准再成像”。为避免错误归因，另执行D2两阶段算法：只用相应参考估计d、τ、g，插值并冻结，再拟合材料。periodic_then_image/everyframe_then_image各用同一192样本掩码。D2在看过部分主结果后才登记，因此单独标为事后诊断，不伪称预注册主结果。

## C1：条件精确消元，不冒充新的物理信息

对每个材料/动态状态候选，求解三频Maxwell散射。将白化后的目标和允许参考/pilot按帧拼接为v_t、y_t：

g0=(v_t* y_t)/(v_t* v_t)，g=clip(|g0|,.65,1.35) exp(i arg g0).

优化真实复残差的实白化表示及Δd/.5、Δτ/6正则。先验与ordinary_joint完全相同。该消元只是同一目标的重参数化；没有logdet，没有用与噪声无关的模态比值替代GLS。没有目标能量时返回错误而不是随意输出可信校准。

## C2：频率递进

每个固定初值先最低频30次函数评估，再前两频30次，最后全频120次。比较对象ordinary_joint每初值120次。记录递进额外计算，不能用其额外预算声明公平速度优势。实际全部三个组的材料成功数与C1相同；不再包装递进为独特机制。

## 无相位对照

独立模值r=|Y|的精确Rician密度：

p(r|a)=(2r/σ²)exp[-(r²+a²)/σ²]I0(2ra/σ²)，a=|μ|.

数值用稳定i0e计算。使用两次原始模值，不先相干平均。未知d和正幅度gain仍估计，phase/delay不从该似然宣称可辨识，对应指标为空。该方法的求解器为三初值L-BFGS-B，maxiter120/maxfun5000，与相干LM评价预算不同，不比较毫秒排名。

## 因果前缀，不以平滑冒充online

主榜都可用完整八帧，是batch smoothing。D1另做在线前缀：第m帧只使用≤m的观测；三条分支分别从前缀m-1延续，新增d、τ用上一帧状态初值，每分支每前缀最多80次。共有72次八前缀扫描；这些重复使用同一36场景，不能作为72个额外独立世界。单元测试将未来目标和loopback任意改动，当前前缀目标逐元素不变。

## 求解与失败保留

每个相干初值材料为(1.5,2)、(2,2.7)、(2.6,3.3)；法向误差和delay从零起；三个终止容差都是1e-8。记录每个初值的状态、cost、nfev、termination信息。success材料标签不等于SciPy收敛标签；未收敛但碰巧材料在阈值内不能成为全局正确证明。

原始experiment.py保持冻结。初值极坐标转换导致gain越过边界一个舍入单位的问题，用safe_run.py仅修正≤1e-12边界越界；更大越界仍报错。旧异常日志保留，修复不是算法改进。

## 实现了什么、没有冒充什么

已实现标准全波联合、准确环带消元、周期/逐帧参考辅助、真正两阶段参考、在线loopback、含目标的共极化pilot、Rician无相位、因果前缀、Born和两种CM比较。没有宣称逐式复现每篇近邻论文，也没有声称给标准目标参考加入了未实现的仿体残差学习。后者若加入，可能进一步有利于传统方法。
