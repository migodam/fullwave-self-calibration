# 硬件、参考成本与工程可行性裁决

## 最小装置与未免费提供的信息

两固定发射器、双接收交叉极化探针、一维机械平台、相干网络分析/收发链、三个频点。共享时钟比独立多UAV时钟更可控，但本轮相对Tx幅相和相对Rx模式已知，必须由真实标定确认。已知双区域支撑和校准标准位置也需要外部测量；不能称完全blind。

可以用点源/点探针作为第一层近似，不代表有限天线已被建模。实际馈电端口、互耦、探头扰动和场景相关方向图需要EM多端口模型；公共scalar gain不足以代表它们。此处没有硬件测量，也没有自行编造设备精度或采购报价。

## 样本与停机成本

令t_s为一个单频复标量的采集成本，t_move为每次帧间移动及稳定成本；C_ref为一次完整插入/移除参考、确认位置及恢复目标状态的额外停机，C_loop为一次电子学参考切换成本。每个burst为12t_s。各方法相同的场采样部分为192t_s，不等于全硬件成本相同。

| 方案 | 理想采样成本 | 额外停机/路径 |
|---|---|---|
| 纯目标两burst/帧 | 192t_s+7t_move | 无目标交换 |
| 全姿态离线标定后再扫 | 192t_s+14t_move | 参考取出、目标安装、两扫之间等待；状态可能改变 |
| 三次周期参考 | 192t_s+7t_move | +3C_ref |
| 每帧参考 | 192t_s+7t_move | +8C_ref |
| 每帧loopback | 192t_s+7t_move | +8C_loop，另有参考电路成本 |
| 每帧共极化pilot | 192t_s+7t_move | 极化/通道切换及相对校准成本 |

主实验把参考设为同状态、C_ref=0，是传统方法的乐观上限。没有把同状态参考当成现实中可免费插入。反过来也没有随意指定极大C_ref来让自校准获胜。

若允许未来参考的Brownian桥跟踪，校准分量方差目标δ_q²要求QΔ/4≤δ_q²。若一次参考操作至少耗时n_ref t_s+C_ref，则维持此目标至少需该时间不超过4δ_q²/Q。这只在T1的声明类内成立；本轮尚无实测Q、C_ref及材料误差到δ_q的全域转换，因此“周期参考经济不可行”未获验证。

## 数值读出对实际公差的警告

名义共极化RMS约.436685，交叉极化RMS约.0076513，比值约57。小倾角β可引入β E_z泄漏。以RMS一级预算，β=.002rad产生约11.4%的交叉通道量级，远高于.5%随机噪声。这解释为什么X把很小方向偏差当成严重压力，而不是任意加一个大噪声。

要让此一级泄漏小于交叉通道RMS的.5%，需|β|约小于8.8e-5rad（约.005度），或者显式估计/测量交叉极化泄漏。该数值只是名义RMS比例估算，不是逐通道、全材料域的严格机械公差，更不是已实现的仪器指标。

每个12样本burst内状态必须近似不变。若漂移时间短于这一采集周期，共享g_t与τ_t假设失效；不能给每个datum自由phase来救回不可辨识问题。跨频率相位中心变化不一定等价于一个共同电子学delay，本轮X已经检验这种区别。

## 硬件检验应输出什么，而不是“以后做实验”

验收数据应包括：固定目标重复运动得到的状态创新/重现性；参考交换前后状态差；通过同一链路的loopback漂移；有限探针倾角和相对方向图误差；直接与交叉场动态范围；参考校准开销与实际目标可访问性。若全姿态参考表+外部计量已控制误差，本路线在此装置不具必要性。

本轮没有得到这些实测表，故工程成本胜利判为未成立。当前建议性裁决是保留周期参考/直接路径/loopback/机械计量的混合方案，而不是为了论文抛弃更可靠的已知标准。数值比较已完成，最终NO不以“将来硬件验证”代替本轮证据。

模拟创新按帧生成，不按实际硬件运行秒数生成。增加非零参考停机后所产生的额外漂移尚未仿真；符号成本表不是实测时间—精度Pareto曲线。
