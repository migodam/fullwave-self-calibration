# 三维矢量 Maxwell 模型、sharing 与噪声

## 连续模型和离散实现的区别

采用 exp(-iωt)，非磁、各向同性、空气背景；χ=ε_r-1。J=χE 是本文件的归一化极化变量，不是把含 -iωε0 的物理电流密度与它混用。

J_tf = X_f[G_T(x_T,t,f) C_T,tf s_tf + G_D,f J_tf]

y_tf = C_R,tf [D_tf(x_R,t,x_T,t) + G_S(x_R,t,f) J_tf] + n_tf.

消去状态得到

y_tf = C_R,tf {D_tf + G_S(x_R,t,f)(I-X_f G_D,f)^(-1)X_f G_T(x_T,t,f) C_T,tf s_tf}+n_tf.

D 是直接场；它只有在明确的交叉极化对称性下为零。经典 VSW 或 DDA 是此类物理的不同有限数值近似，不把数值矩阵称为整个连续问题。

d_t 只表示有效法向相位中心偏移。若机械偏移 d_t^mech 与相位中心 p_t 只通过和进入，则 (d_t^mech+h,p_t-h) 完全等价，不能分别报告恢复。

## 实际测量，不赠送空场扣除

两理想 Tx/Rx 的 x 坐标相同，z 源到 x 探针的自由空间 dyadic Green 的 xz 项为零。因此主通道的总场等于散射交叉极化场。该性质可直接检验，不使用未知目标移除后的免费背景测量。目标球心不在 x=0 平面，因此交叉极化散射通常非零。

co-polar pilot 保留直接场和目标散射并共同拟合；不把目标散射当已知。loopback pilot 测量同一 g、τ，振幅选为名义交叉场 RMS 而非无限大 pilot。参考/探头的额外射频链误差未一般建模，属于本研究限制。

## 漂移与压力流

S/I 慢漂移：初始 d 标准差 .5mm、τ 6ps、log|g| .035、相位 .04rad；帧间增量 d .25mm、τ 3ps、log幅度 .012，载频相位按同一 delay 创新改变，并叠加 .008rad 相位创新。完整轨迹越界则重抽。S=同模型；I=DDA 真值。

X：独立 DDA，创新标准差乘3；额外法向相位中心频率斜率 .20mm·(f-f0)/.4GHz；接收方向倾角 .002 sin(1.7t+.3)rad；第二 Rx 额外乘 1+.01 exp(i.7t)。后面三项不在反演参数化内，用于检查失配，不给每个 datum 新增自由相位。

算法的动态惩罚是 Δd/.5mm 和 Δτ/6ps；它不是上述真值轨迹的精确完整先验。相同惩罚给普通联合、profiling 和参考辅助方法；不能由候选独享先验获得伪优势。

## 噪声、采集预算和估计指标

n 为独立 proper complex Gaussian，E|n|²=σ²，实部/虚部方差σ²/2。σ固定为名义(s1,s2)=(2,2.7)、d=0下交叉场 RMS 的 .5%；RMS=.007651262902338192，因此σ≈3.82563e-5。噪声不根据未知真实材料或增益重归一化；全组所有物理世界协方差相同。

每方法192个单频复标量；两次独立重复不是零成本 SNR。复数最小二乘实白化系数为√2/σ。Rician无相位对照直接使用两份原始模值，不能先相干平均再取模。

材料成功只指两实介电常数绝对误差各≤.1；另报有效位置、delay、相位预测、增益幅度、固定真实世界坐标结构场误差和残差报警。结构场在X中保留真实频率相位中心变化，但不含接收倾斜/相对仪器增益；预测不能用估计位置移动观测坐标来掩盖材料偏差。
