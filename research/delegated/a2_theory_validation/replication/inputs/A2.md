# 1. Executive scientific verdict

**最终裁决：目前不足以支持“PRASC-SOM 优于充分调优的 direct joint full-wave inversion”的方法论文，更不足以把它称为颠覆性算法。但本次可以建立一套比现有初稿更强、且能直接约束算法的有限维理论。**

最重要的修正不是再增加一个谱，而是分清三种不同的“秩”：

\[
\boxed{
L_{\mathrm{det}}:\text{数据确定分量数},\qquad
r_{\mathrm{num}}:\text{数值状态近似维数},\qquad
r_{\mathrm{free}}:\text{额外自由 current nuisance 维数}.
}
\]

**你的单调侵蚀定理适用于第三个量，不自动适用于前两个量。** 原 SOM 增大 \(L_{\mathrm{det}}\)，反而缩小 complementary ambiguous space；把同一个物理状态求解得更准确，也不会减少该物理模型自身的 Fisher 信息。这是目前初稿必须修正的核心语义问题。Chen 原书的确定分量、模糊分量以及相关实现分别见式（6.57）、（6.64）、（6.69）。

本次最强可存活的论文主张是：

> **在明确的自由 current 模型或保守 tangent envelope 中，新增 current freedom 消耗多少标定信息，可以精确计算；可以选择不损失现有 pose 信息的 current directions，并计算新增 acquisition 是否足以补回必要 rank expansion 的信息损失。该策略必须同时满足截断偏差、绝对信息强度和数值误差条件。**

其核心不再只是 rank monotonicity，而是

\[
\boxed{
\underbrace{\mathcal L_{\mathrm{rank}}}_{\text{扩展 current 的信息损失}}
\quad\leftrightarrow\quad
\underbrace{\mathcal I_{\mathrm{acq}}}_{\text{共享地图下新增观测的信息增益}},
\qquad
\mathcal I_{\mathrm{acq}}\succeq \mathcal L_{\mathrm{rank}}.
}
\]

下文证明：这个不等式是指定局部模型中“扩 rank 后再加 acquisition，不降低 pose 信息”的**必要充分条件**。

本次已完成的主要理论包括：nuisance 消元后的 coherent-to-phaseless 信息收缩；含奇异支撑与先验的双侧谱；精确 rank loss、rank drop 与 calibration-neutral admission；共享地图 acquisition innovation；截断偏差—方差界；不依赖真值的数值状态误差证书；固定数据、固定光滑分支上的下降与驻点收敛。

尚未成立的是：一般 full-wave 非线性 basin 扩大、真实阵列上的性能优势、总计算成本优势、对 SOM 的排他性优势。旧实验仍然只是约束条件，尤其不支持 \(T_U\)、隐藏方向冻结或可逆重参数化成为成功的自校准机制。

**“为什么必须是 SOM？”的回答是：尚没有必要性答案。** SOM 提供有物理意义的 current basis，但下面的安全控制也能迁移到其他 reduced-current 方法或 direct inversion 的控制器。论文应暂时定位为 **full-wave self-calibration 的 rank–bias–acquisition 理论与可验证控制策略**，而不是已经获得性能优势的 PRASC-SOM 方法论文。

以下先区分物理空间；即使两个离散空间都写成 \(\mathbb C^n\)，也不把它们视为同一种对象。

| 对象 | 类型 / domain–codomain | 度量与共享属性 |

| \(\chi\) | \(\mathbb R^q\)，材料参数 | 各 acquisition 共享 |
| \(\chi_\ell=f_\ell(\chi)\) | \(\mathbb C^n\)，频率相关 contrast | 由共同材料、声明的色散模型生成 |
| \(T_\ell=Df_\ell(\chi)\) | \(\mathbb R^q\to\mathbb C^n\) | 必须出现在 map derivative 中 |
| \(x,h\) | \(\mathbb R^p\)，pose/trajectory 及其切向量 | 共享参数；可以包含各帧位姿，但参数含义固定 |
| \(j_\ell\) | \(\mathcal J_\ell\simeq\mathbb C^n\)，current | acquisition-specific |
| \(e_\ell,E_{\mathrm{tot},\ell}\) | \(\mathcal E_{D,\ell}\simeq\mathbb C^n\)，内部场 | acquisition-specific |
| \(D_\ell\) | \(\mathcal J_\ell\to\mathcal E_{D,\ell}\) | world-fixed 均匀背景下不随 pose 改变 |
| \(D_{\chi_\ell}\) | \(\mathcal E_{D,\ell}\to\mathcal J_\ell\) | 材料乘法算子 |
| \(S_\ell(x)\) | \(\mathcal J_\ell\to\mathbb C^{M_\ell}\) | receiver sampling |

这里补上了初稿中的一个必要链式导数：

\[
\delta\chi_\ell=T_\ell\delta\chi.
\]

固定介电常数的 multifrequency 实验不能通过“不同频率使用同一个未说明缩放的散射势”替代。

## 2.2 两个合法参数化，不能相加冒充第三个

令

\[
G_{\chi,\ell}=D_{E_{\mathrm{tot},\ell}}T_\ell.
\]

**Independent-current 形式：**

\[
\begin{aligned}
\delta y_\ell
&=S_\ell\delta j_\ell+H_{S,\ell}h,\\
M_\ell\delta j_\ell-G_{\chi,\ell}\delta\chi-H_{D,\ell}h&=0.
\end{aligned}
\tag{2.1}
\]

这一 data block 的直接 map derivative 为零。

若 \(M_\ell\) 可逆，则得到 **reduced physical 形式**：

\[
\delta y_\ell=A_\ell\delta\chi+B_\ell h,
\]

\[
\boxed{
A_\ell=S_\ell M_\ell^{-1}G_{\chi,\ell},\qquad
B_\ell=H_{S,\ell}+S_\ell M_\ell^{-1}H_{D,\ell}.
}
\tag{2.2}
\]

此时没有额外自由 \(K_{\ell,r}c_\ell\)。

只有明确声明

\[
F_{\mathrm{aug}}(\chi,x,c)
=
F_{\mathrm{phys}}(\chi,x)+S(x)U_r(x)c
\tag{2.3}
\]

为 **model-error/current-correction model**，或明确称其为 conservative envelope，才可同时使用 \(Kc+A\delta\chi+Bh\)。

式（2.3）等价于给状态方程增加

\[
Mj=b+MU_rc,
\]

因此它不是原来的无缺陷状态方程。

## 2.3 白化实化：有一个常被漏掉的 \(2\)

若

\[
\varepsilon\sim\mathcal{CN}(0,\Sigma),\qquad
\mathbb E[\varepsilon\varepsilon^*]=\Sigma,
\]

则题中 \(\mathcal E(W\varepsilon)\) 的实协方差是 \(I/2\)，不是 \(I\)。

所以可以：

\[
K_{\mathbb R}=\sqrt2\,\mathcal R(WK),\quad
A_{\mathbb R}=\sqrt2\,\mathcal E(WA),\quad
B_{\mathbb R}=\sqrt2\,\mathcal E(WB),
\tag{2.4}
\]

使实噪声协方差为 \(I\)；或者保留题中的 embedding，但注明 **Fisher 等于 \(2\) 倍 Gram**。这个因子不影响 rank、principal angle 和相对 \(\rho\)，却影响绝对精度 gate。

若噪声 improper，或跨 acquisition 相关，应使用完整实协方差白化。此时白化后的 current block 未必继续是逐帧 block diagonal。

## 2.4 Joint quotient 先于 map/pose 分块

设联合参数度量 \(M_\theta\succ0\)，取 gauge 的一个补空间基 \(Z\)，满足

\[
Z^TM_\theta Z=I.
\]

先形成

\[
T=[A\ B]Z.
\]

若目标 \(Lz\) 是 quotient 上定义良好的线性目标，取 \(LR=I\)，令 \(N\) 张成 \(\ker L\)，则目标与 nuisance tangents 分别是

\[
T_{\mathrm{tar}}=TR,\qquad T_{\mathrm{nui}}=TN.
\]

换一个右逆 \(R'=R+NC\)，有

\[
P_{\operatorname{Ran}(TN)^\perp}TR'
=
P_{\operatorname{Ran}(TN)^\perp}TR.
\]

因此 efficient information 不依赖右逆选择。

**绝对 pose 一般不是未锚定 quotient 上的目标。** 只有 external anchor 或明确 gauge fixing 后，才能使用下文简洁的独立 \(A,B\) blocks。新增非锚定 acquisition 不能消除全局刚体 gauge；源模型的 symmetry stabilizer 是另一件事。

## 2.5 任意 current metric 的伪逆与投影

对 \(M_c\succ0,N_y\succ0\)，定义

\[
S^\dagger_{M_c,N_y}
=
M_c^{-1/2}
\left(N_y^{1/2}SM_c^{-1/2}\right)^\dagger
N_y^{1/2}.
\tag{2.5}
\]

它给出最小 \(M_c\)-norm 的 \(N_y\)-weighted least-squares 解。

Current projector 为

\[
P_U^{M_c}
=
U(U^*M_cU)^{-1}U^*M_c.
\tag{2.6}
\]

Data projector 为 \(SS^\dagger_{M_c,N_y}\)，在 \(N_y\) 内积中正交。对 retained basis，令

\[
G=U^*M_cU,\qquad
T=N_y^{1/2}SUG^{-1/2}.
\]

Receiver lift 的 coefficient 是

\[
C=G^{-1/2}T^\dagger N_y^{1/2}H_S.
\tag{2.7}
\]

证明就是令 \(a=G^{1/2}c\)，把 weighted least squares 化为 Euclidean least squares。相应 residual 满足

\[
(SU)^*N_yR=0.
\]

**这里仅提升 \(H_S\)，不提升 total \(B\) 后再加入 \(H_D\)。**

# 3. Complete theorem package

以下所有 data tangents 默认已经按第 2 节完成白化、实化和 joint gauge 处理。

## 3.1 G0：三个最小模型，以及一个物理反例

### 命题 G0-A：完整、精确的 current 坐标不会产生新的信息优势

**假设。** \(M(\chi,x)\) 可逆；current 坐标变换完整且可逆；状态等式精确满足；data likelihood、prior、参数度量相同。

**结论。** Current formulation 与 reduced physical formulation 有相同的预测、可行物理解、目标函数极小值及目标 Fisher 信息。

**证明。** 对每个 \((\chi,x)\)，状态方程唯一确定

\[
j=M^{-1}b.
\]

完整 current 坐标只是这个 \(j\) 的可逆表示。将它代入 data objective 恰好得到 reduced objective。两种模型的可行参数点一一对应，预测相同，因而统计实验相同。在线性化层面，消去

\[
M\delta j=b_\theta\delta\theta-M_\theta[\delta\theta]j
\]

得到同一个 reduced Jacobian。精确 constrained GN 因而一致。LM damping 和 trust-region metric 若随坐标正确拉回，也一致；否则差别只是预条件化。证毕。

**科研解释：** 不能把“换成 SOM 坐标后还能恢复”当成方法优势。

### 命题 G0-B：截断可以条件性降低 pose 风险

考虑

\[
y_1=h+c+\varepsilon_1,\qquad
y_2=\epsilon c+\varepsilon_2,
\qquad
\varepsilon_i\sim N(0,\sigma^2),\quad \epsilon>0.
\]

完整 least squares 给出

\[
\widehat h_{\mathrm{full}}=y_1-\frac{y_2}{\epsilon},
\]

所以

\[
\mathbb E(\widehat h_{\mathrm{full}}-h_*)^2
=\sigma^2(1+\epsilon^{-2}).
\]

冻结 \(c=0\) 得

\[
\widehat h_{\mathrm{trunc}}=y_1,\qquad
\mathbb E(\widehat h_{\mathrm{trunc}}-h_*)^2
=\sigma^2+c_*^2.
\]

因此

\[
\boxed{
\text{截断严格有利}
\iff c_*^2<\sigma^2/\epsilon^2.
}
\tag{3.1}
\]

这是一个完整证明：前者无偏但噪声放大；后者引入偏差但方差下降。若已有声明先验 \(|c_*|\le C\)，条件 \(C^2<\sigma^2/\epsilon^2\) 不需要真值。

但它是 **regularization 优势，不是信息创造，更不是 SOM 独占优势**。允许同样先验和策略的 direct solver 可以复制它。

### 反例 G0-C：同一截断也能明显更差

令噪声为零、\(c_*=T\neq0\)。完整解精确；截断解的 pose error 为 \(T\)，但剩余 data residual 只有 \(\epsilon T\)，可任意小。

所以

\[
\boxed{
\text{小 residual}+\text{良好 truncated Fisher}
\not\Rightarrow
\text{正确 calibration}.
}
\]

再增加一个完全独立的 map observation，可以让 map-side \(\rho=1\)，也不能消除这个截断偏差。

### 反例 G0-D：envelope 不可辨识，不等于物理模型不可辨识

取一个精确离散状态模型：

\[
j=a(1+dj),\qquad
F(a,x)=e^{ikx}\frac{a}{1-ad},
\]

其中 \(a\in\mathbb R\)，\(d\in\mathbb C\) 固定，\(1-ad\ne0\)。

其物理导数为

\[
A=\frac{e^{ikx}}{(1-ad)^2},\qquad
B=ik e^{ikx}\frac{a}{1-ad}.
\]

实 Jacobian 的行列式：

\[
\det[\mathcal E(A),\mathcal E(B)]
=
\operatorname{Im}(\overline AB)
=
\frac{ka(1-a\operatorname{Re}d)}{|1-ad|^4}.
\tag{3.2}
\]

一般条件下它非零，故物理 map/pose 在一个 phase branch 内局部可辨识。

但增加一个自由复 current coefficient 后，\(K=e^{ikx}\) 的 realification 已填满 \(\mathbb R^2\)，于是 envelope 的 \(B_{\mathrm{vis}}=0\)。

**因此旧实验的 nuisance saturation 只能直接证明该 envelope 饱和，不能直接证明精确物理模型也完全失去 pose 信息。**

这是本次对旧解释的进一步收窄，而不是推翻旧矩阵计算。

## 3.2 定理 1：消去 nuisance 后，phaseless 仍不能增加匹配实验的信息

**最小假设。**

统计模型可微、score 平方可积，允许微分通过 observation channel；\(Z\) 由参数无关 Markov channel 从 \(Y\) 生成；两实验比较同一个参数、同一个 nuisance family、同一个 quotient target。

### 结论

\[
s_Z=\mathbb E[s_Y\mid Z],
\]

\[
J_Z\preceq J_Y,
\]

并且对 pose 或 map 任一目标，

\[
\boxed{
J_{\mathrm{eff},Z}\preceq J_{\mathrm{eff},Y}.
}
\tag{3.3}
\]

这包括 singular nuisance Fisher。

### 完整证明

对任意有界 \(g(Z)\)，对其期望求导：

\[
\mathbb E[g(Z)s_Z]
=
\nabla_\theta\mathbb E[g(Z)]
=
\mathbb E[g(Z)s_Y].
\]

由条件期望定义，

\[
s_Z=\mathbb E[s_Y\mid Z].
\]

因此

\[
J_Y-J_Z
=
\mathbb E[\operatorname{Cov}(s_Y\mid Z)]
\succeq0.
\]

下面证明不能由“分块 Loewner”直接跳过的 efficient-information 结论。

令 \(T\) 为条件期望算子，\(\mathcal H_Y\) 为闭 nuisance-score space，

\[
\mathcal H_Z=\overline{T\mathcal H_Y}.
\]

对目标方向 \(v\)，令 coherent efficient score

\[
e_Y=(I-P_{\mathcal H_Y})s_v.
\]

因为 \(s_v-e_Y\in\mathcal H_Y\)，其变换属于 \(\mathcal H_Z\)，故

\[
e_Z=(I-P_{\mathcal H_Z})Te_Y.
\]

两次正交分解给出精确恒等式：

\[
\boxed{
\|e_Y\|^2-\|e_Z\|^2
=
\|e_Y-Te_Y\|^2+
\|P_{\mathcal H_Z}Te_Y\|^2.
}
\tag{3.4}
\]

右端非负，对所有 \(v\) 成立，得到矩阵不等式。

等号成立必有 \(e_Y=Te_Y\)。反之，若 \(e_Y\) 是 \(Z\)-measurable，则对任意 \(n\in\mathcal H_Y\)，

\[
\langle e_Y,Tn\rangle
=
\langle e_Y,n\rangle=0,
\]

故第二项也为零。

因此：

\[
\boxed{
\text{efficient information 等号}
\iff
\text{coherent efficient score 可由 }Z\text{恢复}.
}
\]

有限维 nuisance 时，对
\(\|s_v-b^Ts_\eta\|^2\) 最小化，即得

\[
J_{\mathrm{eff}}
=
J_{\tau\tau}
-J_{\tau\eta}J_{\eta\eta}^{\dagger}J_{\eta\tau}.
\]

若某 nuisance direction 的 score 为零，它与所有目标 score 的 covariance 都为零，所以 generalized Schur 所需的 range condition 自动满足。证毕。

### 必须同时给出的反例与边界

若

\[
Y=ae^{ix}+\varepsilon,\quad
\varepsilon\sim\mathcal{CN}(0,\sigma^2),
\]

且 \(a>0\) 已知，则 \(|Y|\) 的分布与 \(x\) 无关，而 coherent information 为 \(2a^2/\sigma^2\)。

但若有未知 nuisance phase \(\eta\)：

\[
Y=ae^{i(x+\eta)}+\varepsilon,
\]

则 \(x\) 的 efficient information 在两实验中都为零。**Joint inequality 严格，不保证目标 efficient inequality 严格。**

另一个正信息等号例子是零均值圆对称 Gaussian scale family：score 仅依赖 \(|Y|^2\)，故 magnitude 保留全部 scale information。

固定 covariance 的 coherent Gaussian mean model 有

\[
J=2\operatorname{Re}(D\mu^*\Sigma^{-1}D\mu).
\]

若 covariance 本身依赖参数，还需 covariance-score 项，不能只算 mean Jacobian Gram。

**原始观测必须匹配。** Pan 等 phaseless SOM 使用 total-field intensity。若 incident receive field 依赖未知 pose，则

\[
|Y^{\mathrm{sca}}+e_{\mathrm{rx}}(x)|^2
\]

不是从 scattered-field \(Y^{\mathrm{sca}}\) 出发的参数无关 channel。应使用 raw coherent total field 作为共同母实验，或把 reference measurement 连同噪声一起纳入模型。

例如

\[
|c+ae^{ix}|^2=c^2+a^2+2ac\cos x
\]

仍含 phase sensitivity。不能把“scattered field 的纯相位切向量”自动当成“total intensity 的零方向”。

**状态标签：** [proved]；数学性质属于统计实验比较，不是逆散射专属创新。

## 3.3 定理 2：高频局部精度与 phase branch 的条件性界

### 物理假设

实背景波数 \(k>0\)，远离 Green singularity；使用 outgoing convention；路径和极化耦合不退化；渐近式及其导数在考虑区域内一致有效。

二维与三维标量 Green function：

\[
G_2(r)=\frac{i}{4}H_0^{(1)}(kr),\qquad
G_3(r)=\frac{e^{ikr}}{4\pi r}.
\]

由 Hankel 渐近及其导数，

\[
\partial_r\log G_2
=
ik-\frac1{2r}+O((kr^2)^{-1}),
\]

\[
\partial_r\log G_3=ik-\frac1r.
\tag{3.5}
\]

所需渐近来源为 DLMF §10.17，特别是式 10.17.5 与 differentiated expansion。

所以一阶

\[
\delta\phi=k\,\delta r+
O\!\left(\frac{|\delta r|}{kr^2}\right).
\]

三维 dyadic 的 far-field leading term 是

\[
\mathbf G_k
\sim
G_3(r)(I-\widehat r\widehat r^T),
\]

故相同结论要求发射—接收极化耦合不为零。

### 哪些 \(O(k)\)、\(O(k^2)\) 说法成立

相对幅度有界、路径导数有界时，相对 pose Jacobian 为 \(O(k)\)。固定 coherent SNR 下，raw pose Fisher 为 \(O(k^2)\)。

但要得到**有效信息的 \(\Theta(k^2)\)**，还需要 nuisance 分离角有一致正下界。否则 \(B\) 很大也可以完全落入 nuisance range。

固定绝对噪声时，二维 \(G_2\) 的幅度约为 \(k^{-1/2}\)，因此仅这一个传播因子给出的绝对 Fisher scaling 可以是 \(O(k)\)，不是 \(O(k^2)\)。材料缩放、源功率、spreading 和接收噪声都会改变幂次。

### 一个可证明的局部 phase basin

考虑已经分离路径、已知正权重的模型

\[
f(h)=\sum_iw_i\left[1-\cos(k\ell_i^Th)\right],
\qquad w_i>0.
\]

若一个凸区域内满足

\[
|k\ell_i^Th|\le\gamma<\frac\pi2
\quad\forall i,
\]

则

\[
\nabla^2f(h)
=
k^2L^T\operatorname{diag}
\{w_i\cos(k\ell_i^Th)\}L
\succeq
k^2\cos\gamma\,L^TWL.
\tag{3.6}
\]

若 \(L\) 满列秩，该区域内强凸。

**证明**就是逐项两次求导，并利用
\(\cos(k\ell_i^Th)\ge\cos\gamma>0\)。证毕。

这是一个真正的 sufficient local condition；但不是一般 multiple-scattering objective 的凸性定理。

单路径、单频、沿 \(v\) 的 phase periodicity 是

\[
\Delta h=\frac{2\pi}{k|\ell^Tv|}.
\]

这解释 \(O(k^{-1})\) 的单路径 ambiguity spacing。多频可能消除共同 alias，因此不能把这个尺度宣称为所有多频系统的全局唯一性尺度。

### 可执行 frequency gate

假设 pose error 被一个**有覆盖保证**的椭球包含：

\[
h^T\Sigma_x^{-1}h\le c_\alpha^2,
\]

路径 Taylor remainder 满足

\[
|\Delta r_i-\ell_i^Th|
\le \frac{C_{\mathrm{path}}}{2}\|h\|^2.
\]

则

\[
|\Delta r_i|
\le
c_\alpha\sqrt{\ell_i^T\Sigma_x\ell_i}
+
\frac{C_{\mathrm{path}}c_\alpha^2}{2}
\lambda_{\max}(\Sigma_x).
\]

因此一个充分 gate 是

\[
\boxed{
k_{\mathrm{next}}
\left[
c_\alpha\max_i\sqrt{\ell_i^T\Sigma_x\ell_i}
+
\frac{C_{\mathrm{path}}c_\alpha^2}{2}
\lambda_{\max}(\Sigma_x)
\right]
+\delta_{\phi,\mathrm{model}}
\le\gamma<\pi/2.
}
\tag{3.7}
\]

可以用
\(\sqrt{\lambda_{\max}(L\Sigma_xL^T)}\)
替代最大对角标准差，得到更保守的界。

**证书等级必须注明：**

- 椭球确有覆盖、路径假设成立：条件性 theorem。
- 线性无偏 Gaussian error：可用 \(\chi^2\) quantile 得概率版本。
- \(\Sigma_x\) 只是当前 Hessian 的逆：仅是 surrogate。
- 当前解已经落入错误 phase branch：小 covariance 不能认证 branch 正确。

Fisher 逆一般是方差下界，不是误差上界。有限孔径、路径抵消、multiple scattering 共振或 source stabilizer 都可能破坏这里的假设。

## 3.4 定理 3：奇异支撑上的双侧谱与 prior extension

记

\[
C=\operatorname{Ran}K,\quad
\Pi=P_{C^\perp},\quad
A_c=\Pi A,\quad B_c=\Pi B.
\]

定义

\[
K_0=A_c^TA_c,
\]

\[
K_{\mathrm{eff}}=A_c^T(I-P_{B_c})A_c,
\]

\[
J_x=B_c^T(I-P_{A_c})B_c.
\tag{3.8}
\]

令 \(a=\operatorname{rank}A_c\)、\(b=\operatorname{rank}B_c\)，\(Q_A,Q_B\) 为两个 range 的正交基，

\[
C_{\mathrm{can}}=Q_A^TQ_B.
\]

### 结论

在相应 observable supports 上，两个**归一化 Schur complements**分别合同于

\[
R_A=I_a-C_{\mathrm{can}}C_{\mathrm{can}}^T,
\]

\[
R_B=I_b-C_{\mathrm{can}}^TC_{\mathrm{can}}.
\tag{3.9}
\]

若 \(c_i=\cos\theta_i\)，\(i=1,\ldots,\min(a,b)\)，则 map-side generalized spectrum 为

\[
\{\sin^2\theta_i\}_{i=1}^{\min(a,b)}
\cup\{1\}^{a-\min(a,b)}.
\tag{3.10}
\]

Pose-side **归一化**谱相同地补 \(b-\min(a,b)\) 个 \(1\)。

### 完整证明

在 \(K_0\) 的非零支撑上取满秩坐标，使

\[
A_c=Q_AR_A^{(0)}
\]

且 \(R_A^{(0)}\) 可逆。则

\[
K_0=(R_A^{(0)})^TR_A^{(0)},
\]

\[
K_{\mathrm{eff}}
=
(R_A^{(0)})^T
(I-Q_A^TQ_BQ_B^TQ_A)
R_A^{(0)}.
\]

令 \(w=R_A^{(0)}v\)，广义特征值问题化为式（3.9）的第一个普通特征值问题。

对 \(B_c\) 做同样分解，得到第二个。矩阵
\(C_{\mathrm{can}}C_{\mathrm{can}}^T\) 和
\(C_{\mathrm{can}}^TC_{\mathrm{can}}\)
具有相同非零特征值 \(c_i^2\)，其余为零，结论成立。证毕。

### 几何、多重性和 singular case

\[
\operatorname{mult}(\rho=0)
=
\dim(\operatorname{Ran}A_c\cap\operatorname{Ran}B_c).
\]

\[
\operatorname{mult}(\rho=1)
=
a-\operatorname{rank}C_{\mathrm{can}}.
\]

\(K_0\) 的 nullspace 上 pencil 是 \(0/0\)，不能任意赋值为 \(\rho=0\) 或 \(1\)。

原始 \(\sigma_i(B_{\mathrm{vis}})\) 与 \(\rho_i\) **不是同一谱**：前者包含绝对尺度，后者经过 known-pose information 归一化。

特别地，\(B=0\) 时所有可见 map modes 都可能有 \(\rho=1\)，但 pose 完全没有信息。这说明 dual gate 不能删去 pose-side 检查。

### 半正定 pose prior

令 \(\Lambda_x\succeq0\)，则

\[
K_{\mathrm{eff},\Lambda}
=
K_0-A_c^TB_c
(B_c^TB_c+\Lambda_x)^\dagger
B_c^TA_c.
\tag{3.11}
\]

它满足

\[
K_{\mathrm{eff}}
\preceq K_{\mathrm{eff},\Lambda}
\preceq K_0.
\]

证明可逐方向写为

\[
v^TK_{\mathrm{eff},\Lambda}v
=
\min_h
\left\{
\|A_cv-B_ch\|^2+h^T\Lambda_xh
\right\}.
\tag{3.12}
\]

增加非负项使最小值不减；取 \(h=0\) 给上界。

它仍有 principal-angle 解释，但必须换成 augmented spaces：

\[
A_{\mathrm{aug}}=
\begin{bmatrix}A_c\\0\end{bmatrix},
\qquad
B_{\mathrm{aug}}=
\begin{bmatrix}B_c\\\Lambda_x^{1/2}\end{bmatrix}.
\tag{3.13}
\]

于是

\[
K_{\mathrm{eff},\Lambda}
=
A_{\mathrm{aug}}^T
(I-P_{B_{\mathrm{aug}}})
A_{\mathrm{aug}}.
\]

**不能把原 data space 中的非幂等 shrinkage matrix 称为正交 projector。**

Map prior 同理。若 prior 有 map–pose cross block，应对联合 prior 做 augmentation，不能拆成两份独立 precision 后忽略交叉项。确定性 regularization 的 curvature 也不应直接称为“新增 data Fisher”。

## 3.5 定理 4：pose visibility、sharp dimension bounds 与 nonlinear 边界

令

\[
N=\operatorname{Ran}[K,A],\quad d=\dim N,\quad
B_v=P_{N^\perp}B,\quad b=\operatorname{rank}B.
\]

### 结论

线性化模型中，pose 可由 data 唯一确定，当且仅当

\[
\operatorname{rank}B_v=p.
\]

精确 hidden dimension 为

\[
\boxed{
\dim\ker B_v
=
p-b+\dim(\operatorname{Ran}B\cap N).
}
\tag{3.14}
\]

因此 sharp bounds 是

\[
\boxed{
\max\{p-b,\ p+d-m\}
\le \dim\ker B_v
\le p-b+\min\{b,d\}.
}
\tag{3.15}
\]

### 证明

线性化 pose \(h\) 被隐藏等价于 \(Bh\in N\)，也等价于 \(B_vh=0\)。

将 \(B\) 的参数核先去掉后，\(B\) 是到其 range 的同构。投影 \(P_{N^\perp}\) 在 \(\operatorname{Ran}B\) 上的核正是
\(\operatorname{Ran}B\cap N\)，故得到式（3.14）。

两个维数分别为 \(b,d\) 的子空间在 \(m\) 维空间中，其交集维数介于

\[
\max(0,b+d-m)
\quad\text{与}\quad
\min(b,d)
\]

之间。代入即得式（3.15）。通过让两个空间共享指定数量的坐标轴、其余坐标轴互不相交，即可达到两端，故界 sharp。证毕。

若满列秩，则线性误差满足

\[
\|\widehat h-h_*\|_{M_x}
\le
\frac{\|\varepsilon\|+\|\delta_{\mathrm{model}}\|}
{\sigma_{\min}(B_vM_x^{-1/2})}.
\tag{3.16}
\]

这是由唯一 least-squares 解和伪逆算子范数直接得到的。

### 必须推翻的 nonlinear “iff”

“\(B_v\) 满秩当且仅当非线性局部可辨识”在一般情况下不成立。

- \(F(x)=x^3\) 在 \(0\) 附近可辨识，但导数为零。
- \(F(u,h)=h-u^2\) 在 \((0,0)\) 有 \(A=0,B=1\)，所以一阶 pose visibility 完整；但 \(h=u^2\) 是相同数据的非线性曲线。

最窄修正是：

> \(B_v\) 满秩等价于**一阶 quotient pose identifiability**。若 nuisance Jacobian 在邻域内保持常秩，且 pose visibility 在该邻域内满秩，则 constant-rank theorem 给出局部光滑的 pose recovery map。

第二个反例恰好违反 nuisance 常秩假设。

## 3.6 定理 5：nested rank 的精确信息损失、rank drop 与非单调 \(\rho\)

固定所有物理 tangents、度量、白化、gauge、frequency 和 linearization。设

\[
C_r\subseteq C_{r+1},\qquad
N_r=C_r+\operatorname{Ran}A.
\]

令

\[
E_r=N_{r+1}\cap N_r^\perp.
\]

### 结论

\[
\boxed{
J_x(r)-J_x(r+1)=B^TP_{E_r}B\succeq0.
}
\tag{3.17}
\]

并且：

\[
J_x(r)=J_x(r+1)
\iff P_{E_r}B=0;
\]

\[
h^T[J_x(r)-J_x(r+1)]h>0
\iff P_{E_r}Bh\ne0;
\]

\[
J_x(r)-J_x(r+1)\succ0
\iff P_{E_r}B\text{ 对 pose chart 单射}.
\]

更精确的 rank drop 为

\[
\boxed{
\operatorname{rank}B_v(r)-\operatorname{rank}B_v(r+1)
=
\dim\!\left(
\operatorname{Ran}B_v(r)\cap E_r
\right).
}
\tag{3.18}
\]

### 证明

嵌套子空间有正交直和

\[
N_{r+1}=N_r\oplus E_r.
\]

故

\[
P_{N_r^\perp}-P_{N_{r+1}^\perp}=P_{E_r}.
\]

左右乘 \(B^T,B\) 得式（3.17）。等号和严格性由

\[
h^TB^TP_{E_r}Bh=\|P_{E_r}Bh\|^2
\]

得到。

又有

\[
B_v(r+1)=(I-P_{E_r})B_v(r).
\]

这个投影在 \(\operatorname{Ran}B_v(r)\) 上的核就是与 \(E_r\) 的交集，rank–nullity 给出式（3.18）。证毕。

**信息严格下降不等于 rank 下降。** 例如 \(B=e_1+e_2\)，新增 nuisance \(e_1\)，信息从 \(2\) 降到 \(1\)，rank 始终为 \(1\)。

还可加强为：

\[
K_{\mathrm{eff}}(r)
=
A^TP_{(C_r+\operatorname{Ran}B)^\perp}A
\]

也随自由 current 空间扩张而 Loewner 不增。

所以正确说法是：

> 更多自由 current 可以改善表示能力或减小 model bias，却不会在这个固定统计实验中增加 map 或 pose 的绝对有效信息。

### \(\rho(r)\) 非单调的三维反例

取

\[
A=(1,1,0)^T,\quad B=(1,0,1)^T,
\]

\[
C_0=\{0\},\quad
C_1=\operatorname{span}e_1,\quad
C_2=\operatorname{span}\{e_1,e_2+e_3\}.
\]

直接投影得到

\[
\boxed{\rho(0)=3/4,\qquad \rho(1)=1,\qquad \rho(2)=0.}
\tag{3.19}
\]

第一步消除了 map–pose 的共同分量，第二步使剩余 map 与 pose signature 共线。所有步骤都可以保持 \(K_0\) 非零。

## 3.7 定理 6：calibration-neutral current admission

这是比“选一个更小的 \(r\)”更有用的控制定理。

现有 nuisance 为 \(N\)，pose-visible tangent 为

\[
V=P_{N^\perp}B.
\]

设候选新增 current signatures 为

\[
Q=P_{N^\perp}K_+.
\]

从候选 coefficient space 中选一个子空间 \(Z\)。

### 结论

新增 \(QZ\) 不降低现有 pose information，当且仅当

\[
\boxed{V^TQZ=0.}
\tag{3.20}
\]

若 \(Q\) 有 \(d\) 个独立实 columns，则最大的安全 coefficient space 是

\[
\ker(V^TQ),
\]

其维数为

\[
\boxed{
d-\operatorname{rank}(V^TQ)\ge d-p.
}
\tag{3.21}
\]

### 证明

新增 nuisance 的正交增量是 \(\operatorname{Ran}(QZ)\)。由定理 5，零损失等价于

\[
P_{\operatorname{Ran}(QZ)}V=0,
\]

即两个 range 正交，也即 \(V^TQZ=0\)。最大 admissible coefficient space 因此是该矩阵的 kernel，维数由 rank–nullity 得到。证毕。

### 复 current coefficient 的附加限制

不能在 \(2r\) 个实 coordinates 中任意挑方向，再声称仍是一个复线性 current space。

令

\[
J_c=
\begin{bmatrix}0&-I\\I&0\end{bmatrix},
\qquad F=V^TQ.
\]

最大的复线性安全空间实化后是

\[
\boxed{
\ker F\cap\ker(FJ_c).
}
\tag{3.22}
\]

它在 \(J_c\) 下不变，因为 \(J_c^2=-I\)。若原候选复维数为 \(r\)，则安全复维数至少为 \(r-p\)，前提是 candidate push-forward 单射。

这给出一个真正可实现的设计：

> 不一定按 singular-value 顺序整块放开 current；可以在候选 SOM/TSOM current family 中，先放开与当前 pose-visible data tangent 正交的组合。

但“calibration-neutral”不代表“足以表达真实 current”。必要的 current 可能恰好位于被排除方向，因此必须加下一条 bias gate。

**状态标签：** [proved recombination]；用于 SOM 的 rank policy 是检索边界内的候选贡献，不是新的线性代数。

## 3.8 定理 7：bias-aware calibration risk

在固定线性实验中，

\[
y=Na+Bh+D_rz+\varepsilon,
\quad
\|z\|\le1,\quad
\varepsilon\sim N(0,I),
\]

其中 \(D_rz\) 是由声明的 truncation/model-error set 给出的遗漏项。假设 \(B_v=P_{N^\perp}B\) 满列秩。

采用

\[
\widehat h=B_v^\dagger y.
\]

### 结论

\[
\boxed{
\sup_{\|z\|\le1}
\mathbb E\|\widehat h-h\|_{M_x}^2
=
\operatorname{tr}(M_xJ_x^{-1})
+
\|M_x^{1/2}B_v^\dagger D_r\|_2^2.
}
\tag{3.23}
\]

### 证明

因为 \(B_v^\dagger N=0\) 且 \(B_v^\dagger B=I\)，

\[
\widehat h-h
=
B_v^\dagger D_rz+B_v^\dagger\varepsilon.
\]

噪声均值为零，交叉项期望为零。噪声 covariance 为

\[
B_v^\dagger(B_v^\dagger)^T
=(B_v^TB_v)^{-1}=J_x^{-1}.
\]

故风险为方差 trace 加 squared bias。对单位球取上确界恰好得到算子范数平方。证毕。

这个定理说明原来的四个 relative gates 不充分：

\[
\eta_S,\ g_S,\ \eta_x,\ \eta_\rho
\]

都可以很好，但 \(\|B_v^\dagger D_r\|\) 很大。

正确的 Pareto 比较至少包括：

\[
\boxed{
\text{表示误差上界 }\beta_r,\quad
\text{绝对 pose/map 精度},\quad
\text{计算成本}.
}
\]

\(D_r\) 必须来自声明的模型集合、uniform approximation bound 或可验证数值误差界，不能由 test truth 事后构造。

若 rank 由同一数据自适应选择，式（3.23）的固定线性估计器 covariance 不应直接作为选择后的精确 covariance。可以使用对所有 admissible ranks 同时成立的噪声/误差界，或做独立 selection/validation。

## 3.9 状态约束、soft filter 和 moving-projector 定理

### A. State-feasible nesting 的正确版本

设固定 pose tangent \(h\) 下，可行 current/map variations 构成集合 \(\mathcal F_r(h)\)，profile 信息方向值为

\[
I_r(h)
=
\inf_{z\in\mathcal F_r(h)}
\|L_r(z,h)\|^2.
\]

若各 rank 使用同一 residual 映射，所有 \(\mathcal F_r(h)\) 非空，且

\[
\mathcal F_r(h)\subseteq\mathcal F_{r+1}(h),
\]

则

\[
I_{r+1}(h)\le I_r(h).
\]

**证明：** 同一函数在更大的可行集合上取下确界不可能增大。证毕。

Bare \(U_r\subseteq U_{r+1}\) 不足够。

反例取 \(M=S=I,H_D=e_2\)，\(U_1=e_1,U_2=I\)。若采用投影/Galerkin state，rank 1 得到近似 induced response \(0\)，rank 2 得到 \(e_2h\)，pose Gram 从 \(0\) 增到 \(1\)。这不是反驳定理 5，而是因为这里扩张的是**数值状态近似空间**。

若坚持精确 state equality，则 rank 1 对 \(h\ne0\) 根本不可行，不能拿其“零 response”计算合法 Fisher。

### B. Soft filter 不是自动产生的 soft nuisance projector

若只是把每个自由 coefficient 的列乘上非零 \(f_i\)，

\[
K\longmapsto K\operatorname{diag}(f_i),
\]

则 range 完全不变，free-nuisance information 完全不变。

真正的 ridge profile 是

\[
\min_c\{\|z-Kc\|^2+\lambda\|c\|^2\}
=z^TL_\lambda z,
\]

\[
L_\lambda
=
I-K(K^TK+\lambda I)^{-1}K^T.
\tag{3.24}
\]

注意是 \(L_\lambda\)，不是 \(L_\lambda^2\)。它来自把 penalty 也保留在 profile objective 中。

增加 \(\lambda\) 提高 profile curvature，是因为增加了对 nuisance 的约束，不是增加了测量信息。对应 scalar filter 的噪声放大与 bias 为

\[
\frac{\sigma}{\sigma^2+\lambda}
\le\frac1{2\sqrt\lambda},
\qquad
\text{bias factor}=\frac{\lambda}{\sigma^2+\lambda}.
\]

### C. 常秩 projector derivative

对常秩矩阵 \(T(t)\)，令 \(P=TT^\dagger\)，则

\[
\boxed{
\dot P
=
(I-P)\dot T T^\dagger
+(T^\dagger)^T\dot T^T(I-P).
}
\tag{3.25}
\]

**证明。** 由 \(P^2=P\) 得 \(\dot P\) 的对角 blocks 为零；由 \(PT=T\) 得

\[
\dot PT=(I-P)\dot T.
\]

右乘 \(T^\dagger\) 得一个 off-diagonal block，转置得到另一个。二者相加即式（3.25）。证毕。

因此

\[
\|\dot P\|
\le
\frac{2\|\dot T\|}{\sigma_{\min}^{+}(T)}.
\]

若 \(H=S^*S\) 的 retained/discarded eigenvalue gap 为 \(\delta>0\)，则

\[
DP=
\sum_{i\le r,j>r}
v_j
\frac{v_j^*(DH)v_i}{\lambda_i-\lambda_j}
v_i^*
+\text{adjoint}.
\tag{3.26}
\]

Retained cluster 内部重根不妨碍 projector 光滑；真正需要的是跨 retained boundary 的 gap。

对 \(\|\Delta H\|\le\epsilon<\delta\)，可得保守界

\[
\|P(H+\Delta H)-P(H)\|
\le\frac{2\epsilon}{\delta-\epsilon}.
\tag{3.27}
\]

证明由 retained/discarded blocks 的 Sylvester equation 得到：两谱区间相距至少 \(\delta-\epsilon\)，其指数积分解的范数至多 \(\epsilon/(\delta-\epsilon)\)，合并两个 off-diagonal blocks 即得。

### D. 三种事件不能混叫

\[
H(t)=\operatorname{diag}(1+t,1-t)
\]

的 top-one projector 在 \(t=0\) 两侧跳变，但 retained rank 始终为 \(1\)：这是 **gap closure / coordinate-instability event**。

Scalar hard threshold 穿越则可以改变 rank。

\(\rho_i\) 在固定 rank 下穿过决策阈值只是 **observability event**。

Soft spectral function

\[
F_\lambda(H)=H(H+\lambda I)^{-1}
\]

满足

\[
DF_\lambda
=
\lambda(H+\lambda I)^{-1}(DH)(H+\lambda I)^{-1},
\]

\[
\|DF_\lambda\|\le\|DH\|/\lambda.
\]

这证明连续性改善，不证明 calibration 改善。

## 3.10 定理 8：共享地图 acquisition 的精确增益

先消去 acquisition-specific current，写每帧 cleaned tangents 为 \(a_\ell,b_\ell\)。

### A. 精确 hiding 条件

堆叠 pose direction \(h\) 被隐藏，当且仅当存在**同一个** \(u\)：

\[
a_\ell u=b_\ell h,\qquad\forall\ell.
\tag{3.28}
\]

等价地，各帧补偿集合

\[
\mathcal U_\ell(h)
=
a_\ell^\dagger b_\ell h+\ker a_\ell
\]

非空且具有共同交点。

这是线性方程组 solvability 的直接等价，已是必要充分条件，不需要“多源一般有帮助”的措辞。

若每个 \(a_\ell\) 都满列秩，每帧 pose 都被隐藏，令

\[
T_\ell=a_\ell^\dagger b_\ell.
\]

则 stacked pose identifiable 当且仅当

\[
\boxed{
\begin{bmatrix}
T_2-T_1\\ \vdots\\ T_L-T_1
\end{bmatrix}
\text{ 满列秩}.
}
\tag{3.29}
\]

证明：每帧唯一补偿为 \(u=T_\ell h\)；所有补偿相同等价于上式矩阵乘 \(h\) 为零。

这一条件下必要 acquisition 数量界为

\[
(L-1)q\ge p,
\qquad
L\ge1+\lceil p/q\rceil.
\tag{3.30}
\]

它在一般代数矩阵族中可达到，但不能未经证明称为 Helmholtz/Maxwell 采样族的 generic theorem。

### B. 为什么不能逐帧消去 shared map 后相加

对任意 \(h\)，

\[
h^TJ_{\mathrm{stack}}h
=
\min_u\sum_\ell\|a_\ell u-b_\ell h\|^2
\]

\[
\ge
\sum_\ell\min_{u_\ell}
\|a_\ell u_\ell-b_\ell h\|^2.
\]

因此

\[
\boxed{J_{\mathrm{stack}}\succeq\sum_\ell J_\ell.}
\tag{3.31}
\]

等号当且仅当每个 \(h\) 的逐帧最优补偿存在共同选择。

最小例子：

\[
a_1=a_2=1,\qquad b_1=1,\ b_2=-1.
\]

每帧单独 \(J_\ell=0\)，但

\[
J_{\mathrm{stack}}
=
\min_u[(u-h)^2+(u+h)^2]/h^2
=2.
\]

重复 \(b_2=b_1\) 则仍然为零。

如果新帧自由 current 已填满该帧 data space，cleaned \(a,b\) 都为零，新增观测没有此处的收益。

### C. Acquisition innovation formula

旧 cleaned blocks 为 \(A,B\)，假设

\[
G=A^TA\succ0
\]

对**完整声明的 shared-map nuisance chart**成立。定义

\[
H=G^{-1}A^TB,\qquad
J=B^T(I-P_A)B.
\]

新增一组 cleaned blocks \(a,b\)，则

\[
\boxed{
J_{\mathrm{new}}
=
J+
V^T(I+aG^{-1}a^T)^{-1}V,
\qquad
V=b-aH.
}
\tag{3.32}
\]

### 完整证明

旧 residual 完成平方：

\[
\|Au-Bh\|^2
=
(u-Hh)^TG(u-Hh)+h^TJh.
\]

令 \(z=u-Hh\)，新增 residual 为

\[
au-bh=az-(b-aH)h=az-Vh.
\]

因此新增 profile 值为

\[
h^TJh+
\min_z\left[z^TGz+\|az-Vh\|^2\right].
\]

正规方程给出

\[
z_*=(G+a^Ta)^{-1}a^TVh.
\]

代回后，括号最小值为

\[
h^TV^T
\left[I-a(G+a^Ta)^{-1}a^T\right]Vh.
\]

由直接乘法可验证

\[
I-a(G+a^Ta)^{-1}a^T
=(I+aG^{-1}a^T)^{-1},
\]

得到式（3.32）。证毕。

所以：

\[
J_{\mathrm{new}}=J\iff V=0,
\]

\[
\ker J_{\mathrm{new}}=\ker J\cap\ker V.
\tag{3.33}
\]

新增 acquisition 真正有用，不是因为“多了一帧”，而是因为它不服从旧数据所允许的 map compensation。

若 \(G\) 奇异，应回到 variational formula。**不能只在旧 map observable support 上偷偷截掉其余 map directions，再使用新 acquisition；新 acquisition 可能正好看见那些旧 null directions。** 有合法固定 map prior 时，可以把 prior rows 加入旧系统，使 \(G\) 可逆。

### D. Acquisition design 的保证边界

对固定秩、满列 map block，令

\[
R=B-AH,\qquad A^TR=0.
\]

微分得到

\[
\boxed{
dJ=2\,\operatorname{sym}
\{R^T(dB-dA\,H)\}.
}
\tag{3.34}
\]

这是可实现的设计梯度，因为含 \(dH\) 的项被 \(A^TR=0\) 消去。

但 pose-Schur \(\log\det(J+\Lambda_x)\) **一般不 submodular**。上面的两帧反例中，单帧增益为零，两帧联合增益为正，直接违反 diminishing returns。加小的正定 map prior 仍可保留这个违反关系。

因此可以做 greedy 或 pair look-ahead，但不能自动宣称 \(1-1/e\) approximation。该保证属于另一种固定 additive joint-information log-det 设计，不能移植到这里。

E-optimal、D-optimal、A-optimal 分别保护最弱方向、体积和平均方差；\(\min\rho\) 保护相对混淆，并不等同于前三者。

## 3.11 定理 9：rank–acquisition 信息预算

这是建议放进论文摘要和主定理中的结果。

先在旧 acquisitions 上把 current nuisance 从 \(r\) 扩到 \(r+1\)，损失

\[
\mathcal L_{\mathrm{rank}}=B^TP_{E_r}B.
\]

再针对扩张后的模型加入 acquisition，按定理 8 计算

\[
\mathcal I_{\mathrm{acq}}
=
V^T(I+aG^{-1}a^T)^{-1}V.
\]

则

\[
\boxed{
J_{\mathrm{final}}-J_{\mathrm{original}}
=
\mathcal I_{\mathrm{acq}}-\mathcal L_{\mathrm{rank}}.
}
\tag{3.35}
\]

因此

\[
\boxed{
J_{\mathrm{final}}\succeq J_{\mathrm{original}}
\iff
\mathcal I_{\mathrm{acq}}\succeq\mathcal L_{\mathrm{rank}}.
}
\tag{3.36}
\]

**证明：** 对扩 rank 使用式（3.17），对新增 acquisition 使用式（3.32），两式相加。必要性与充分性都由精确等式直接得到。证毕。

这不是 global basin theorem，但确实给出一个此前初稿没有的**可检验安全策略**：必要的 current refinement 若消耗 calibration information，就必须由新 acquisition 或合法 prior 明确补偿，而不是凭经验说“高频应该有帮助”。

## 3.12 定理 10：无真值的 numerical-physics certificate

设物理状态

\[
Mj=b,
\]

近似状态 \(\widetilde j\) 的可计算 defect 为

\[
z_0=M\widetilde j-b.
\]

若有可验证上界

\[
\|M^{-1}\|\le\kappa,
\]

则

\[
\boxed{
\|\widetilde j-j\|\le\kappa\|z_0\|,
\qquad
\|WS(\widetilde j-j)\|
\le\|WS\|\kappa\|z_0\|.
}
\tag{3.37}
\]

对参数方向 \(v\)，真实 derivative \(t_v\) 满足

\[
Mt_v=b_v-M_vj.
\]

令近似 derivative defect

\[
z_v=M\widetilde t_v-b_v+M_v\widetilde j.
\]

则

\[
\boxed{
\|\widetilde t_v-t_v\|
\le
\kappa\left(
\|z_v\|+\|M_v\|\kappa\|z_0\|
\right).
}
\tag{3.38}
\]

**证明。** 第一式由
\(M(\widetilde j-j)=z_0\)；
第二式由

\[
M(\widetilde t_v-t_v)
=
z_v-M_v(\widetilde j-j)
\]

取范数得到。Data derivative 再乘 \(S\)，并加入 \(S_v(\widetilde j-j)\) 即可。证毕。

例如存在预条件器 \(C\)，且真正验证了

\[
\|I-CM\|\le\eta<1,
\]

则 Neumann argument 给出

\[
\kappa\le\frac{\|C\|}{1-\eta}.
\]

这不是新的 state 信息，也不是复活失败的 \(T_U\) penalty；它只用于防止把“不准确的状态求解”冒充“原 full-wave objective”。

### 无 oracle rank 的限制

假设 nuisance matrix 的误差界为 \(\epsilon_N\)。Projector perturbation 需要结构性常秩，不能由“丢掉小 singular values”自行认证。

最小反例：

\[
N(t)=te_1,\qquad B=e_1.
\]

则

\[
J_x(0)=1,\qquad J_x(t)=0\quad(t\ne0).
\tag{3.39}
\]

任意小矩阵误差都可能改变精确 free-nuisance information。

一个可验证的充分情况是：完整 nuisance generator 有已知的 \(d\) 个 columns，且其最小 column singular value 大于认证的误差界；或 exact dependencies 已通过结构证明消去。否则只能报告 **numerically resolvable rank** 或 conditional diagnostic，不能报告 exact-rank certificate。

另外，式（3.37）是**相同参数处的数值 forward error**。若要用它控制 estimator bias，仍需在声明的参数区域内得到 uniform bound，不能把单点 state defect 自动当成全局材料模型误差界。

# 4. PRASC-SOM algorithm package

## 4.1 首先决定到底求解哪个 objective

推荐主版本使用严格物理 objective：

\[
\boxed{
\Phi(\chi,x)
=
\frac12\sum_\ell
\|\sqrt2\,\mathcal E(W_\ell[F_\ell(\chi,x)-y_\ell])\|^2
+
R(\chi,x).
}
\tag{4.1}
\]

共同材料通过 \(f_\ell(\chi)\) 产生各频率 contrast；pose/trajectory 共享；各 acquisition 的 physical current 不同。

这叫 **coherent stacking**，不是把不同频率的 complex fields 直接相加。

SOM basis 用来构造数值状态近似：

\[
\widetilde j_{\ell,r_{\mathrm{num}}}
=
j_{\det,L}(x;y)+U_{\ell,r_{\mathrm{num}}}(x)c_\ell.
\tag{4.2}
\]

在固定 \((\chi,x)\) 下，\(c_\ell\) 由完整 state residual 的 least squares 求得，而不是自由地拟合 data。

令

\[
R_s=MU,\qquad d_s=b-Mj_{\det},
\]

则对固定数值 residual metric \(M_s\succ0\)，

\[
c=(R_s^*M_sR_s)^{-1}R_s^*M_sd_s.
\tag{4.3}
\]

常秩下，

\[
Dc=
(R_s^*M_sR_s)^{-1}
\left[
D(R_s^*M_sd_s)
-
D(R_s^*M_sR_s)c
\right].
\tag{4.4}
\]

因此 Jacobian 必须包含

\[
Dj_{\det},\qquad (DU)c,\qquad U\,Dc.
\]

只在当前点计算 \(U\)，再把它当常量进行有限位姿更新，会漏掉这些 moving-coordinate terms。

**重要限制：** 若 \(j_{\det}\) 来自 noisy data，仅允许 complementary current 变化，未必能逼近精确 physical state。必要时应加入声明的 numerical residual-current coordinates，或回退到完整 physical state solve。不能把这个回退时的 \(r_{\mathrm{num}}=n\) 当成 \(r_{\mathrm{free}}=n\) 而人为宣告物理信息饱和。

真正的自由 correction model 则应使用式（2.3），同时给 direct baseline 同样的 correction 和 prior。两版本不得混算 Fisher。

## 4.2 修正后的 rank/filter gates

题中的 \(\mathcal F_k\) 不充分，应改为包含以下四类证据的可行集。

**Current support 与 coordinate stability。** 对

\[
WSM_c^{-1/2}
\]

做 SVD。Threshold 要由噪声预算与允许 coefficient error 决定；singular gap 必须大于 operator uncertainty，而不只是相对 \(\sigma_1\) 的固定比例。

**绝对 pose 精度。** 对所分析的真实模型或明确 envelope，要求

\[
\underline{\sigma}_{\min}
(B_{\mathrm{vis}}M_x^{-1/2})
\ge
\frac{\delta_{\mathrm{noise}}+\beta_r}
{\epsilon_x^{\mathrm{target}}},
\tag{4.5}
\]

其中下划线表示扣除数值、模型、线性化不确定性后的 certified lower bound。

相对 pose retention 可以定义为

\[
\eta_{x,\mathrm{all}}
=
\inf_{h:\,Bh\ne0}
\frac{h^TJ_xh}{h^TB^TBh}.
\]

它衡量从“current/map 已知”到“它们未知”的相对损失；定理 3 的双侧 canonical normalization 则使用 cleaned \(B_c^TB_c\)。两者含义不同。

若 \(\operatorname{rank}B<p\)，all-pose gate 直接失败，不能靠 denominator 加 \(\epsilon\) 掩盖。

**Map target。** 目标应由声明的空间分辨率、物理 basis 或独立选择数据确定，而不能每次删除低 \(\rho\) modes 后宣布所有目标通过。

若目标是 \(L_\chi\chi\)，其余 map coordinates 必须作为 nuisance 正确消去；不能只取 \(Q^TK_{\mathrm{eff}}Q\) 的主子矩阵，就假设其他未知 map coordinates 已知。

既要 \(\rho\) margin，也要 absolute effective information。空 observable support 是失败，不是通过。

**Bias 与统计校准。** 要求 uniform \(\beta_r\) 或定理 7 的风险界满足预算。使用同一数据自适应调 rank 时，应采用同时有效的噪声/误差界；单次 \(\chi^2\) 门限不能未经选择校正反复使用。

候选 policy 可以是

\[
\boxed{
\min_{r,\text{filter}}\operatorname{Cost}(r)
\quad
\text{s.t. absolute accuracy、bias、gap、relative survival 均通过}.
}
\tag{4.6}
\]

也可以在已声明的 reconstruction utility 上最大化，但 utility 不应冒充 Fisher information。

## 4.3 完整 pseudocode

```text
Input:
    raw complex coherent data and noise model;
    shared material/dispersion model and trajectory parameterization;
    gauge anchor or quotient target;
    fixed priors and parameter metrics;
    numerical-state basis family and any separately declared free-current family;
    accuracy, bias, phase, computation, and event budgets;
    admissible acquisition actions.

1. At the lowest informative frequency, form a finite set of coarse anchored
   initial candidates. Charge every candidate to the common budget.
   Do not start calibration from a zero-scatterer B=0 and call it informative.

2. Rebuild S(x), e(x); cache pose-independent D.
   Solve the physical state, exactly or with certified error.

3. Form total physical A and B.
   Compute physical information separately from any free-current envelope.

4. Update metric-aware SOM/TSOM candidate projectors.
   Compute support singular values, retained gaps, B_vis, J_x,
   K_0, K_eff, and target retention spectra.

5. Enumerate admissible ranks/filters.
   First consider calibration-neutral candidate directions.
   Reject candidates lacking support, bias control, numerical rank certainty,
   or absolute target precision.

6. Choose the least costly admissible numerical approximation.
   If a genuine free-current expansion is required, compute its information loss.

7. If required, score new acquisitions using the shared-map Schur complement.
   Use the innovation formula and rank-acquisition budget.
   Include pair look-ahead when individual gains vanish.

8. Compute a joint GN/LM step on the fixed smooth chart.
   Include D_x U, D_x j_det, and differentiated state solves.

9. Accept only against the full physical objective or certified objective intervals.
   Check noise consistency, gauge, model validity, parameter change,
   derivative accuracy, and phase-region validity.

10. At rank events, transport the represented current/projector and reset curvature.
    At retention-threshold events, reclassify supported targets without silently
    deleting unresolved unknowns.
    At gap closure, merge the cluster, use a genuine soft model, or reject the chart.

11. Increase frequency only when the covered-error phase gate passes.
    Label covariance-only gates as surrogates.

12. Stop with supported estimates and explicit unresolved modes,
    or return a reason-specific failure and the last valid iterate.
```

如果只是 envelope visibility 失败，但 physical \(A/B\) 良好，正确动作可以是撤掉不必要的自由 envelope 或回到 direct solve，而不是宣称物理上必须再采样。

## 4.4 固定 stratum 的收敛定理

**假设。**

固定 active data、固定 objective；gauge 已处理；\(\Phi\) 下有界，梯度在相关 level set 上 Lipschitz；retained/discarded gap 和状态可逆性保持；近似梯度满足

\[
\|g_k-\widetilde g_k\|
\le\kappa_g\|\widetilde g_k\|,
\]

步矩阵满足

\[
h_-I\preceq H_k\preceq h_+I,\qquad
\kappa_g<h_-/h_+.
\]

令

\[
d_k=-H_k^{-1}\widetilde g_k.
\]

采用针对 physical objective 的 Armijo backtracking。

### 结论

目标下降，\(\|g_k\|\to0\)；所有聚点为驻点。一般不能推出真值恢复、全局最优或整个序列收敛。

### 证明

\[
g_k^Td_k
=
-\widetilde g_k^TH_k^{-1}\widetilde g_k
-(g_k-\widetilde g_k)^TH_k^{-1}\widetilde g_k
\]

\[
\le
-\left(\frac1{h_+}-\frac{\kappa_g}{h_-}\right)
\|\widetilde g_k\|^2
=-c\|\widetilde g_k\|^2,
\quad c>0.
\]

又有

\[
\|d_k\|\le\|\widetilde g_k\|/h_-.
\]

Descent lemma 因而保证所有足够小、且有统一正下界尺度的步长满足 Armijo。Backtracking 的接受步长有统一正下界。把每步下降相加，利用 \(\Phi\) 下有界，得到

\[
\sum_k\|\widetilde g_k\|^2<\infty.
\]

因此 \(\widetilde g_k\to0\)，相对误差条件给 \(g_k\to0\)。梯度连续性给出聚点驻点性。证毕。

若状态误差有固定非零 floor，只能得到 approximate stationarity。临近驻点时要收紧 inner solve tolerance，或增加数值 basis，而不是继续使用相同误差。

零残差、局部 Jacobian 最小奇异值至少 \(s\)、Jacobian Lipschitz 常数为 \(L\) 时，精确 GN 另有

\[
\|e_{k+1}\|\le\frac{L}{2s}\|e_k\|^2.
\]

证明是积分 Jacobian remainder 后乘当前伪逆。它只在同一个有效 chart 内成立；chart 半径还受 singular gap、状态 resolvent 和 phase branch 限制。

## 4.5 Event-safe dynamics

Hysteresis **单独不能证明有限事件**。例如在同一点，低 rank 的 reconstruction gate 要求增 rank，高 rank 的 calibration gate 又要求降 rank，可永久来回。

两个可证明修正：

- 使用预先有限的单调 promotion ladder，失败后不立刻反向重复同一事件；
- 每个可逆 event 必须在一个共同的下有界 merit function 上获得至少 \(\delta>0\) 的下降。

第二种情况下 event 数量不超过

\[
\frac{\Phi_0-\inf\Phi}{\delta}.
\]

Changing frequency 会改变 objective，故共同 merit 的证明只能分 stage 使用，不能跨频率直接套用。

## 4.6 复杂度与正式方法裁决

Reduced state normal solve 在 operator products 完成后可有

\[
O(nr_{\mathrm{num}}^2+r_{\mathrm{num}}^3)
\]

的代数成本；但形成 \(MU\)、更新 SVD、求导、认证误差和 full-physics acceptance 都可能占主导。

Direct factorization 虽有 \(O(n^3)\) 成本，却可以跨多个 illuminations 与 derivative right-hand sides 复用；迭代型 full-wave solver 还会改变比较。因此 **\(r<n\) 不是总成本优势定理**。

本次 P4.3 的正式裁决：

| 主张 | 裁决 |
|---|---|
| 完整 SOM 重参数化自动提高信息或 basin | **否定** |
| 增大数值 state rank 自动侵蚀物理 pose Fisher | **否定** |
| Free-current expansion 的信息损失可精确计算 | **已证明** |

| 截断在 bias 足够小时降低风险 | **条件性证明** |
| PRASC-SOM 比充分调优 direct inversion 更快、更准或 basin 更大 | **未建立；性能型 method claim 当前判 fail** |

**因此，后续论文应继续使用降级定位：理论与诊断/控制策略，而不是假定已有性能突破。**

Unknown array geometry can corrupt coherent inverse-scattering measurements through a low-dimensional, physically structured phase error. ### Introduction replacement

The central question is not whether material and geometry can be included in one optimizer. Consequently, an apparent improvement in a projected information matrix is not sufficient evidence of improved calibration: the associated model bias must be controlled.

# 7. Theory-validation experiment blueprint

完整预注册协议：

以下是必须保留的执行要点。**这些是设计，不是结果。**

## E1：matched coherent versus phaseless information

**Hypothesis。** 匹配实验中 joint 和 efficient information 都不增加；严格性取决于 efficient score 是否仍由 magnitude 决定。

**Null / controls。** 纯相位已知幅度、未知 nuisance phase、圆对称 variance family、带 known reference 的 total field，以及故意不匹配的 independent intensity noise。

**模型。** Scalar complex Gaussian parent observation；phaseless likelihood 使用正确的 magnitude/intensity 分布，不用随意同方差 Gaussian intensity 代替。

**Metrics / plots。** Joint 和 efficient Fisher eigenvalues、式（3.4）两项、score-conditioning 误差、CRB 与局部估计方差。

**预算。** Seeds 101–110；每个模型每 seed 2,000 个拟议样本。最小复现先做四个 scalar controls。

**失败判据。** 在精确模型或数值积分误差之外违反 contraction；或者报告的 strictness 与 equality controls 冲突。

## E2：rank monotonicity、neutral admission 和 rank uncertainty

**Hypothesis。** 式（3.17）、（3.18）、（3.20）成立；\(\rho\) 不必单调；relative-only threshold 会在 saturation 处误判。

**Controls。** 新增方向正交、部分对齐、完全对齐；复线性安全空间；式（3.19）非单调例；\(N(t)=te_1\)；固定 rank 的 gap closure。

**模型。** 先精确小矩阵，再用 12 个固定 full-wave linearizations，seeds 201–212。

**Metrics / plots。** Loewner difference、预测与实际 rank drop、neutral-block loss、absolute backward-error rank threshold、projector distance。

**成功判据。** 误差随算术精度或认证误差收缩；不把 nonlinear reconstruction 成败用于验证线性定理。

## E3：双谱的独立预测作用与 bias gate

**Hypothesis。** \(\rho\) 预测相对 map degradation，\(B_{\mathrm{vis}}\) 的绝对尺度预测 pose noise amplification；二者都不能替代 bias bound。

**Null。** 在包含绝对尺度、残差与 bias 后，双谱不提供额外预测作用。

**Controls。** 固定 \(\rho\) 缩放全部信号；固定 pose rank 改变最小奇异值；加入强 prior；构造 small-residual/large-bias 截断例。

**Metrics。** 线性 Gaussian covariance、定理 7 风险、目标 coverage、relative versus absolute error。

**预算。** Seeds 301–310；每个固定设计 1,000 次拟议噪声重复；nonlinear 小扰动测试作为单独外推，不和线性定理混合。

## E4：PRASC versus tuned direct joint inversion——预注册核心

### 固定 primary endpoint

在共同 forward/adjoint budget 内，

\[
\Delta P_{\mathrm{succ}}
=
P(\text{PRASC joint success})
-
P(\text{direct joint success}).
\]

成功必须同时满足 pose、map task、full-physics residual 和 failure-status 条件。

### 小而足够的主模型

2D scalar full-wave；固定材料及声明的 Ohmic dispersion；9 个实 RBF map parameters；inverse grid \(16^2\)、data-generation grid \(32^2\)；3 个 acquisition poses，首 pose 锚定；每帧 2 Tx、12 Rx；频率集合

\[
\{k_{\max}/4,\ k_{\max}/2,\ 3k_{\max}/4,\ k_{\max}\}.
\]

这不是 3D Maxwell 验证，也不把它包装成真实阵列结果。

### 初值、seed 和计算预算

Tuning seeds 1–10，调完锁定；test seeds 1001–1020。

每个 test seed 使用 12 个固定初始化：平移尺度 \(\lambda/8,\lambda/2,\lambda\)，各四个方向；旋转通过阵列 lever arm 换算到同一物理位移尺度。每方法共 240 个 paired runs。

每个 run 固定 **200 个 forward/adjoint-equivalent solve units**。所有 state solves、adjoints、Jacobian right-hand sides、SVD/basis 更新、认证计算和 acceptance solves 都收费；factorization reuse 明确记录。另报告原始 operator applications 和 wall time，防止单位换算掩盖成本。

Direct baseline 也获得相同 frequency continuation、先验、初值、优化器调优与预条件化机会。

### Pose/map margins

定义

\[
\|h\|_{M_x}^2=t_x^2+t_y^2+R_{\mathrm{eff}}^2\theta^2.
\]

Map task 由固定 resolution operator \(Q_{\mathrm{res}}\) 定义，其尺度至少为

\[
\ell_{\mathrm{res}}
\ge \max\{2\,\text{grid spacing},\lambda_{\min}/(2\,\mathrm{NA})\}.
\]

从**预先声明的 nominal reference design**和 noise model 计算 \(C_x^{\mathrm{ref}},C_\chi^{\mathrm{ref}}\)，不得使用 test truth 选择 margins。

一个可执行预注册选择为

\[
d_x=\min\{\lambda_{\min}/16,\ell_{\mathrm{res}}/4\},
\]

\[
d_\chi=
2\sqrt{
\operatorname{tr}(Q_{\mathrm{res}}C_\chi^{\mathrm{ref}}Q_{\mathrm{res}}^T)/q_T
},
\]

\[
\Delta_x^{\mathrm{NI}}
=
\min\{\lambda_{\min}/32,\sqrt{\operatorname{tr}C_x^{\mathrm{ref}}/p}\},
\qquad
\Delta_\chi^{\mathrm{NI}}=d_\chi/2.
\]

这些常数是预注册工程容差，不是普适理论常数。若 nominal design 对所声明目标也没有有限 uncertainty scale，应先宣布设计不合格，而不是用伪逆零值构造 margins。

### 置信区间与 multiplicity

以 seed 为 cluster，对同 seed 的 12 个初值共同 resample，做 10,000 次 paired cluster bootstrap。

主要结论需同时通过三个单侧门槛，使用 Bonferroni familywise \(\alpha=0.05\)：

\[
\operatorname{LCB}(\Delta P_{\mathrm{succ}})>0,
\]

\[
\operatorname{UCB}(\Delta\mathrm{RMSE}_x)<\Delta_x^{\mathrm{NI}},
\]

\[
\operatorname{UCB}(\Delta\mathrm{RMSE}_\chi)<\Delta_\chi^{\mathrm{NI}}.
\]

Secondary comparisons 用 Holm；不得用某个 secondary subgroup 的显著结果挽救失败的 primary endpoint。20 个 seed clusters 可能导致区间较宽，应报告 inconclusive，而不是只报中位数。

失败 runs 不删除：使用最后有效 iterate 的误差；若没有有效 iterate，按预声明 compact admissible domain 的最大误差计入。另用独立 noisy replicate 做 validation residual，不用于调 rank。

### 强制 adversarial controls

**Limited aperture。** 加入旧 known-map pose-only oracle 已出现 false basin 的 aperture regime，检查 covariance gate 是否会错误通过 cycle skipping。

**Non-pose phase corruption。** 加入 clock drift、mutual coupling 或独立 phase noise，但 pose-only solver 故意不建模；预期其优势消失甚至输给合适 phaseless baseline。这个失败不违反信息定理，因为它比较的是失配算法，而不是匹配统计实验。

### 方法成功 / 失败判据

只有 primary superiority 与两项 noninferiority 同时通过，才能写方法优势。否则性能主张失败或证据不足。

## E5：shared-map stacking、symmetry 与 acquisition budget

**Hypothesis。** 新信息来自 shared-map compensation 的不一致，而不是帧数本身。

**Controls。** \(a_1=a_2=1,b_1=-b_2\)；重复 acquisition；新增 frame-specific nuisance 同步填满新数据；未锚定 global gauge；单 isotropic source stabilizer 与 directional/multiple sources。

**模型与预算。** 小矩阵精确验证加 8 个物理 acquisition candidates，seeds 401–412。比较 single greedy、pair look-ahead、random 与小集合穷举。

**Metrics / plots。** 精确共同-map Schur 与错误逐帧求和的差；hidden dimension；innovation rank；预测 \(\mathcal I_{\mathrm{acq}}-\mathcal L_{\mathrm{rank}}\) 与实际矩阵差。

**失败判据。** 把 replicated data 的 precision 增加写成 rank 增加；把 source stabilizer 消失写成 global gauge 消失；或者实际增益不满足声明的安全预算。

# 8. Citation audit、SOM 接入与原创性边界

## 8.1 Chen SOM 的精确接入

在上传原书的印刷页 150–153：

\[
j_{\det,L}
=
\sum_{i=1}^{L}
v_i\frac{u_i^*y}{\sigma_i},
\]

\[
j=j_{\det,L}+V_S^-\alpha^-.
\tag{8.1}
\]

数据确定分量与自由优化分量的角色不同。原书式（6.64）优化 \(\alpha^-\) 与 material，通过 data/state residual 耦合；式（6.69）写成

\[
j^-=(I-V_S^+V_S^{+*})\beta.
\]

所以初稿中“leading \(U_r=V_{1:r}\) 的自由 coefficient rank”等同于原 SOM rank，是不准确的。它最多是另一种 declared current-correction family。

## 8.2 Twofold SOM：原书确实区分 intersection 与 projection

上传原书印刷页 161–163 已核验：

\[
V_D^+=\text{前 }M_0\text{ 个 }G_D\text{ right singular vectors}.
\]

式（6.70）给 intersection 表述：

\[
j=V_S^+\alpha^+
+B_{S^-D^+}\beta.
\]

式（6.71）给实际近似：

\[
B_{S^-D^+}\beta
\approx
P_{S^-}V_D^+\widetilde\beta.
\tag{8.2}
\]

原书明确讨论了 intersection 与 projection 不同，以及不同 coefficient 维数。还明确描述了以较低 \(M_0\) 的结果初始化较高 \(M_0\)；因此 current-basis continuation 是 prior art。

但把

\[
V_S^+\oplus(V_S^-\cap V_D^+)\oplus(V_S^-\cap V_D^-)
\]

当成任意两个 SVD partitions 的普遍精确正交分解，是错误的。

最小反例在 \(\mathbb R^2\)：

\[
V_S^+=\operatorname{span}e_1,\quad
V_S^-=\operatorname{span}e_2,
\]

\[
V_D^\pm=\operatorname{span}(e_1\pm e_2).
\]

两个交集都为零，右端只剩一维；但

\[
P_{S^-}V_D^+=\operatorname{span}e_2\ne0.
\]

最窄修正版是增加 commuting/reducing-space 条件，或者老实使用式（8.2）的 sequential projected space，并计算其实际 rank。

这是对一般数学解释的限制，**不是宣称原 TSOM 数值算法无效**。

此外：

\[
G_D:\text{current}\to\text{internal field},
\]

\[
D_U=H_D+MUC_U:\text{real pose tangent}\to\text{state-current residual}.
\]

它们不同型。P-side 只能通过共同 data tangent、push-forward 或 Schur complement 连接，不能和 S/D-fold 直接作第三组 current-space intersections。

## 9.2 TGRS 与 TAP 的最窄定位

**TGRS 路线：**

> *Bias-aware rank and acquisition control for coherent full-wave quantitative imaging under geometry uncertainty.*

需要证明或展示：控制器在共同计算预算下改善一个预注册 imaging/calibration endpoint，且没有靠牺牲 map task、缩小目标集合或使用更强先验换取成功。仅有 projector identities、几张重建图和优化器 success status，不足以支持这一定位。

**TAP 路线：**

> *Calibration-information limits and safe current-space refinement for coherent electromagnetic arrays.*

需要更明确的 electromagnetic array model，至少说明 pose、phase center、clock/gain、mutual coupling 哪些被建模、哪些是 expected-loss controls；并在一个可解释阵列几何中证明安全策略非空且可用。

这些是对稿件说服力的科学判断，不是声称期刊存在某个固定实验数量要求。

## 最后的科学判断

**本次最有分量的进展，不是证明了“低秩 SOM 一定更好”，而是证明了什么时候这种说法没有意义、什么时候它只是 bias–variance regularization，以及怎样把 rank refinement 的 calibration 代价与新 acquisition 的收益精确对账。**

真正值得凝练成论文核心的是：

\[
\boxed{
\begin{gathered}
\text{物理模型与自由 current envelope 分离},\\
\text{calibration-neutral current admission},\\
\text{shared-map acquisition innovation},\\
\text{rank-loss/acquisition-gain 必要充分预算},\\
\text{bias 与 numerical-physics certificate}.
\end{gathered}
}
\]

**这已经是一套可证明、可实现、可被反驳的理论骨架；但目前还不是已经达到 TGRS/TAP“极为闪耀、颠覆”验收标准的方法体系。** 要跨过那条线，下一块必须是一个真正电磁化的结果：在明确的 full-wave 物理族中，证明上述安全区间非空、具有可用宽度，并且其代价小于它避免的 calibration failure。否则，无论再增加多少谱、流形或 penalty，论文仍会停留在通用线性代数的组织层面。
