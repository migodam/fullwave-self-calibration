# 硬问题清单（仅问题）

供后续 GPT Pro 综合使用；只列问题，不附答案。

1. `r=M-2` 的隐藏跃迁在多大程度上只是均匀整圆阵列 + 方位角 Fourier/Hankel
   简并（成对奇异值）的产物？要把它升级为可发表的结构性现象，需要陈述并证明
   一个怎样的定理（假设、被丢弃的谐波对、对比度/实化项的作用、截断孔径下的
   失效方式）？

2. 若机器简并的 `s6=s7` 对被微小物理不对称劈开，硬截断本身的病态是否会使
   "r=M-2 规则"消失？该规则对角度抖动、奇数 M、偏心旋转轴有多脆弱？

3. `V_P=Range(Q_U) ⊆ Range(U)`、`dim ≤ p` 是否还能被称为"第三空间"？用
   `(Q_U h, R_U h, D_U h)` 图结构取代"TriSpace"是否不仅更准确，也避免读者误读
   出 `2^3` 八个交集的假分解？

4. `T_U` 在每个已测角色中都失效：在什么模型条件下（近共振 `M^{-1}` 放大、
   更强对比度、更高频多散射）state 通道才可能成为约束而非被实 contrast tangent
   吸收？当前负结果是否足以在摘要中定性为"state 通道不提供区分力"，还是只是
   设置过弱？

5. E4 的"隐藏方向"只满足数据侧（`resid_vs_Sdata≈5e-16`）而 state 侧
   `T_U=0.733≠0`：命题 2 的 state 半支从未成为约束。应如何改述"已验证隐藏
   条件"，才不算过度宣称？

6. reduced 与 direct 在可见方向完全相等只证明重新参数化无损；要主张算法收益，
   最少需要哪些 runtime/DOF/迭代数/盆地宽度证据？若无收益，"lossless"应否一律
   改为 "coincides with"？

7. 多发射/相控偶极子把 theta 从零方向变为可辨识方向：这究竟是"打破 pose gauge"
   还是"消除点源旋转对称的秩亏"？全球 SE(2) 地图-位姿规范（`B ξ_X = -A ξ_χ`）
   是否完全不受影响？L=1 偶极子第三奇异值仅为首位的 ~4%，"逃出 gauge"的措辞
   是否应降为"弱可辨识"？

8. 与 source/receiver-extension FWI（Huang 等、Metivier-Brossier、da Silva）
   全文对照：其中是否已存在等价的"受限提升 + 残差对"构造？若存在，本文只剩
   什么检索有界增量？

9. Bellomo 等（TAP 62(5):2450-2462, 2014）已用实测入射场 + 多极展开修正入射场
   与数据方程 Green 算子并处理相位中心：本文"联合估计低维位姿 + current 坐标
   可辨识结构"与之的最小边界语句应如何写？

10. Li-Lee-Bresler 的通用双线性可辨识理论（含 gauge 商）是否已在代数层面蕴含
    命题 2？若蕴含，Helmholtz 特化新增的究竟是物理分裂还是保留基泄漏？

11. 无限维非闭值域下 `G_S^†` 无界：闭化与正则化语义应作为 [open] 保留，还是
    可以给出一个 norm-budget 版本的最小范数提升定理？

12. `Q_U` 依赖白化、current norm、保留基与场景：在什么条件下"规范提升"才唯一？
    `V_P` 的 scene-dependence 是否排除了任何预计算/摊销的声称？

13. TSOM domain fold 未经核实，实验只用截断 SOM 基：论文中所有 "TSOM" 措辞应
    统一降级为什么？

14. 半圆孔径 `known_alpha` 在全部种子收敛到伪极小（pose error 0.86）：这是否
    意味着"收敛门通过 ≠ 全局成功"，以及局部极小盆地分析应成为必需实验而非
    脚注？

15. 若 r=M-2 定理与 runtime 收益都无法给出，论文应定稿为：方法论文、理论/
    负结果短文，还是警示性可辨识性 letter？
