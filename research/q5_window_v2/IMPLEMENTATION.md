# 实现、复现与预算

## 环境和命令

已执行环境：Python 3.13.5、NumPy 2.3.5、SciPy 1.17.0、mpmath 1.3.0。设置 BLAS 为单线程以控制小矩阵开销。整数区间证明只用 Python 标准库；mpmath 只用于回归点检，不是证书的三角函数后端。Treams 与 python-flint 安装遇到 DNS 限制，采用执行前注册允许的透明 SciPy 球波实现；未把依赖失败写成成功。

在项目根目录执行：

```bash
python -m pip install -r research/q5_window_v2/requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python research/q5_window_v2/reproduce.py --out /tmp/q5-v2-fresh-run
```

目标目录必须不存在。脚本复制本轮代码和未修改的 `research/trispace_self_calibration/a3_research/maxwell3d.py`，依次生成两个材料区间证书、模态读出预算、有限几何窗口、几何到读出的预算差、求解器核对、12 场景恢复、有限竞争对、审阅结果及测试日志。任一步失败即非零退出，不自动缩减物理条件。`resume_recovery.py` 只用于已保存原始观测的明确中断恢复，不允许重新抽样后混写同一次运行。

PR 中的精简结果不代替原始观测。完整原始观测和历史日志随交付 ZIP 提供；新目录复现会自行生成。18 项测试含输出证书检查，须先生成证书再运行，不能仅在缺少结果的空目录运行测试后宣称通过。

## 参数和随机数

C 类：k=18 m^-1，球心 (-0.06,0,0)、(0.055,0.02,0) m，半径 0.035、0.025 m；固定损耗 0.03、0.05；实介电常数范围 [1.5,4]×[2,5]。12 个三分量接收器在半径 0.6 m 的 Fibonacci 方向，四个平面波/极化；框架 x 位移在 ±2 mm；公共增益模长 [0.75,1.25]、相位 [-pi,pi]。

RNG 主流为 2026091107，随机附加通道流为 2026091108。每场景原始复噪声标准差为增益后真值场 RMS 的 1%，保存后所有拟合和该场景竞争对保持同一协方差。复参考标准差 0.01。M 类另用实幅度参考标准差 0.001，不混用。

DDA 网格 0.011 m、fill quadrature=4；前四场景另作 0.009、0.0075 m 诊断。多极反演 lmax=3，角积分 12×24，平移投影半径 0.04 m。相同三初值 (2,3,0)、(1.6,2.2,-1)、(3.8,4.8,1)，位移单位 mm；每初值最多 80 次 scipy 函数评估，三个容差均为 1e-8。另记残差回调次数，并明确附加 EM 分支的两次场评价和系数缓存，不能混同为线性系统求解次数。

## 可执行的计算流程

```text
固定参数域、噪声定义、参考路径、损失和随机流
逐盒外向包围 Mie 响应及导数
    若分母含零、导数不正或覆盖不完整：UNRESOLVED
    否则导出向外舍入界、盒计数与源哈希
枚举有限几何参数对盒
    只按严格的任务距离条件排除无关盒
    检查未知方向的端点比较与公共增益 profiling
    若任一相关盒分离不足：该名义箱无证书，不输出不可能
展开实际读出误差预算
    同时计随机噪声、尺寸、节点校准、参考漂移、交叉项和无限尾
    重复只减随机噪声，不减共同偏差
    未测得硬件界：H_UNVERIFIED
冻结全部原始观测和各方法初值
    对每方法求环带约束复增益的精确 GLS 消元
    以两材料误差 <=0.1 统计成功，保留所有初始化与失败
    比较独立网格/阶数差，仅标 DIAGNOSTIC，不写成模型误差界
全域 C 证明缺少包围器或连续误差界：C_F_UNRESOLVED
```

对需要通用有限覆盖的后续 C 实现，必须提供每个参数盒的场值包含和每个世界的合法误差集合；可用中心差下界减两边严格包围半径。分枝耗尽、覆盖缺口或未证明的模型界都只能返回 unresolved。当前程序没有悄悄提供一个以采样最大误差替代上界的 C 认证器。

## 成本

M 的可计算条件方案使用每球 32 个径向复读数、16 次独立重复，合计 1024 个散射复读数，加 16 个实幅度参考；背景减除可使原始读数达到 2048。±100 ppm 半径、0.1% 相对通道/照明误差、绝对 0.001 参考漂移及投影后 5e-7 其他误差均为验收要求，尚非实测。

C 的四方法残差回调评估数分别为 1480、1412、1568、1520。原始 JSON 的 `forward_evaluations` 字段命名过宽：固定/随机额外 EM 每次回调包含两个场评价，因此相应 `model.forward` API 调用数为 1480、1412、3136、3040；线性系统求解次数受缓存影响，未单独计数。详见 `audit/CALL_COUNT_AUDIT.json`。每方法的局部优化耗时不含真值生成、预计算及全部收敛诊断，不能拿来宣传完整工作流速度优势。原始运行在容器 200 秒调用超时后恢复；完整新目录复现已无此中断地通过。新目录复现中的恢复脚本墙钟为 40.277 秒，其中原始数据生成为 0.844 秒；Linux `ru_maxrss` 为 497688 KiB（约 486 MiB），仅指该 Python 进程，不是整个工作流的逐阶段峰值或真实仪器预算；DDA 稠密耦合矩阵的主要存储随 (3Ncell)^2 个 complex128 增长，矩阵分解和临时副本另计。
