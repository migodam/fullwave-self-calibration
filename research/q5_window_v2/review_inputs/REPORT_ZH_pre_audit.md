本轮获得了一个闭合的**受限模态有限误差定理**，补齐了材料导数和端点结论的区间证明，并给出了一个可计算的 **Information Window Splitting（任务分辨的信息窗口分裂）**实例。另完成了新注册的三维双球独立模型恢复实验。

但本轮**尚不能宣称完整的双有损球、未知接收器位移、未知复增益问题已经达到 TAP 投稿完成状态**。缺的不是排版，而是该物理类的可信连续模型误差界、覆盖有限分离结论，以及在这些条件下通过的独立恢复。未获得这些界，也未获得可替代它们的、经过连续误差认证的 Maxwell 竞争世界反例。

旧 A5、Q5 V1 及失败选择器均不修改。V1 的 11/12、12/12、1/12、6/12、1/12、3/12 保持原证据级别。本轮结果属于独立的 V2 诊断流，不是原最终集，不是总体成功率，也不是新的自适应采集策略胜利。

### 2.1 真正的新推导是什么

设 h_i(ε_i) 为准确 Mie 电偶极振幅，而不是 Born 线性振幅。幅度观测为

$$W_i=a h_i(\epsilon_i)+e_i,\quad |e_i|\le B_i;\qquad Z=a+e_a,\quad |e_a|\le B_a.$$

记 a_- 为增益幅度下界，a_+ 为上界，d_a=min(2B_a,a_+-a_-)。在文档给出的通道重叠条件下，两材料误差均不超过 δ 的统一估计存在，当且仅当

$$a_-h_i(U_i)-(a_-+d_a)h_i(U_i-2\delta)\ge 2B_i,\qquad i=1,2.$$

它不是 Jacobian 满秩、不是 Fisher 信息，也不是重新推导 Gaussian testing。它直接比较**有限材料变化产生的场差**与**允许的增益补偿和误差集合**。必要性的反例仅属于这个幅度统计实验，不能用于宣称完整相干测量也不可能。

这一结果是在本轮推导并核验的；“我们本轮推导出来”不等于“文献中从未出现”。原创性尚未达到排除最近邻工作的程度。

### 2.2 Information Window / Splitting 如何进入 Calibration

窗口改为任务指定：材料、接收器位移、复增益分别有窗口。联合任务需要同时满足；不同采集可以通过共同世界、共同增益下的坏世界集合交集互补。参考只减少允许的电子学补偿，不能自动纠正几何或结构模型误差。

本轮还给出了一个真实使用 Maxwell 电偶极径向函数的受限例子。令 z=kR，理想切向电偶极读取的径向振幅满足

$$c(z)^2=z^{-2}-z^{-4}+z^{-6},\qquad [c(z)^2]'=-2[(z^2-1)^2+2]/z^7<0.$$

若两个原始投影通道的绝对误差界都固定为 10^-6，参考误差界为 0.003291，则归一化后误差为 10^-6/c(z)。取 δ=0.1，得到

- 第一材料幅度任务窗口：0.2 < kR ≤ 26.7393102838…；
- 第二材料幅度任务窗口：0.2 < kR ≤ 6.5683473710…；
- 同时恢复两材料，取二者交集。

端点由外向预算和有理数二分包围，不是扫网格读出来的。**分裂的是不同材料任务的可接受距离范围**，不是声称距离轴出现多个不连通峰，也不是未知形状或各向异性结论。本例没有内部最佳距离：距离增大，误差归一化后单调变差。这里采用固定原始误差，不能与继承的固定归一化噪声混用。

## 三、误差预算：旧 5.78e-7 太保守，但硬件尚未认证

受限模态模型采用 proper complex 噪声 E|n_i|²=σ_i²。两个模态各取 0.001 尾事件；继承的独立实幅度参考取双侧 0.001 尾事件。联合覆盖概率至少 0.997。模态 σ 向上取 2.666408132e-6、1.804798621e-6；参考总界 0.003291。这个实参考模型与 C 类的复参考 σ=0.01 不相同。

新的有限割线边界给第二通道留下

$$b_{2,\mathrm{model}}\le1.900510966013140538\times10^{-6},$$

约为旧 5.78e-7 充分证书的 3.29 倍。因此，旧证书失败不能直接解释成物理不可行。

一个非空、但尚未通过硬件测量认证的分配是：

| 项目 | 明确要求 |
|---|---:|
| 归一化增益幅度参考的共同漂移，绝对值 | ≤ 1e-5 |
| 模态读取相对复误差矩阵，每行绝对值之和 | ≤ 2e-4 |
| 更高模态额外泄漏，增益后绝对量 | ≤ 2e-7 |
| 尺寸/位置误差导致的场偏差，增益后绝对量 | ≤ 2e-7 |
| 剩余数值和源模型偏差，增益后绝对量 | ≤ 2e-7 |

第二通道总分配 1.2719416581e-6，剩余余量大于 6.15926e-7。这里的“尺寸/位置场偏差”只是需要完成的可测/可界定要求，尚未换算为经过验证的机械尺寸公差；不能把表格当实际仪器规格。

16 次独立重复，在参考共同偏差 1e-4 时，可把允许第二通道模型误差提高到 8.4523449777e-6。重复只能降低独立随机噪声，不能降低共同漂移或结构偏差；一次模态读取本身可能需要许多原始天线采样。

## 四、新注册 V2 独立恢复：实际运行结果

C 类包含两个同时存在的有损球：中心 (-0.06,0,0)、(0.055,0.02,0) 米；半径 0.035、0.025 米；k=18；固定损耗 (0.03,0.05)；材料实部范围 [1.5,4]×[2,5]；接收器 x 平移 ±2 毫米；复增益幅度 [0.75,1.25]。四平面波/极化，12 个三分量接收器，半径 0.6 米。

生成器为继承的体离散偶极模型，spacing=0.011 米、fill_quadrature=4；反演为新写的向量球谐 Mie 多球求解器，lmax=3。无法安装 Treams，使用的是注册协议已经允许的透明回退实现。球内全波响应与球间重复散射均保留，但该数值模型本身仍是截断的。

seed=2026091107；12 个新场景；同场景方法共用原始噪声数据；proper complex 噪声 σ 为该场真实增益后 RMS 的 1%；参考复 σ=0.01。这个逐场景噪声约定适用于配对恢复比较，不可用于未经调整的两世界共同协方差证明。

| 方法 | 两材料都满足绝对误差 ≤0.1 | 两材料绝对误差中位数 |
|---|---:|---:|
| 无参考 | 2/12 | 0.2300 / 0.4549 |
| 正确加权的带噪参考 GLS | 7/12 | 0.0471 / 0.0402 |
| 一个预先固定的额外 EM 复标量 | 2/12 | 0.2263 / 0.4479 |
| 一个独立随机的额外 EM 复标量 | 2/12 | 0.2299 / 0.4548 |
| 已知真实增益和真实位移的 oracle | 7/12 | 0.0047 / 0.0792 |

所有方法均使用三个固定初值、80 次函数评估上限、同样容差、增益环带约束与正确实白化；没有 logdet。每个初值、失败、材料误差和验证误差均保留。

### 4.1 为什么参考有用，但不是万能的

参考缩小了材料幅度与增益之间的补偿空间，因此本批数据由 2/12 提升到 7/12。但这不等于模型正确：即使把真实增益和真实位移直接给优化器，也只有 7/12。

更重要的是两组 7/12 不是相同场景：场景 3、5 中参考方案材料合格，但 oracle 不合格；场景 6、11 则相反。这说明不能只比较总成功数，必须检查增益是否在补偿正演误差。这里是数值诊断证据，不是已证明的 Maxwell 因果归因定理。

前四场景更细 DDA 网格和更高 Mie 阶数也做了比较。DDA 相对高阶 Mie 的场差约 0.4%–1.7%，并非随网格单调下降；l=3 与 l=5 的差约 2.3e-6。两类数字都只叫“观察到的差异”，不能代替连续误差上界。

本轮 Linux 环境下完整恢复与附加诊断约 16.37 秒，峰值 RSS 约 454 MiB；这些是小型诊断的实测开销，不是相对既有算法的速度优势。39 个回归/单元测试通过，不是 39 个定理验证。另保留直接三角函数包含失败、参考漂移标签修正和径向证书序列化检查失败及修复记录。

## 五、对天线与接收链设计的直接指导

应优先设计能区分现存坏世界的观测，而不是只最大化场强或 Jacobian 奇异值。不同角度、极化、电/磁相对响应或高阶模态，只有其有限差异在共同增益、几何补偿和误差预算之后仍然存在，才有材料价值。电子学参考必须真的与物体通道共享对应增益；耦合器参考不能自动校准天线方向图、相位中心或收发位置。

在固定照射、非扰动接收条件下，移动接收器改变读取算子，不改变物体内部 resolvent。固定物理孔径与固定角孔径、固定功率与固定相对 SNR 必须分开。

放大器可按增益与噪声因子分析：若输出噪声为 |A|²σ_in²+σ_post²，则可分离场差的有效尺度为 |AΔF|/sqrt(|A|²σ_in²+σ_post²)。增益只能抑制后级噪声相对影响；不能消除前端噪声和共同偏差，更不能把完全相同的两世界分开。本轮没有把无法确认定义的“Gain-F”包装成新方法。

## 六、最近邻对照与原创性裁决

Lee 等 2007 的全息 Mie 拟合已经同时处理粒子位置、尺寸、折射率和照明幅度参数；其 Eq.(4) 为归一化背景下的散射/参考干涉表达式。Prokopiou–Tsitsas 2018 在已知球几何、已知外部偶极和已知幅度归一化下，由不同极化及低频阶次分离材料参数，Eq.(6.1) 明确给 ε_r=(1+2ψ)/(1−ψ)。因此“材料、几何、幅度联合估计”与“用极化/阶次区分参数”不能作为本轮首创。

HoloPy、标准区间集合反演、带噪参考 GLS、多球 T-matrix 都不宣称新。具体已读公式、假设及未能获取全文的邻近论文见 `PRIOR_WORK.md`。目前最值得保留的候选贡献是：**有界参考与完整误差预算下的有限模态判据，以及它导出的任务窗口和实现边界**。其优先权仍需补足未读最近邻，不可写“首次”。

## 七、投稿裁决与下一道真正的验收

本轮已从“主要是失败分析”推进到“受限正面定理 + 可运行独立诊断”。但完整 TAP 强结论仍需要：C 类连续正演/截断/模型误差包含界；在同一材料与电子学先验下的覆盖有限分离或合法竞争世界；独立冻结恢复；实际参考/模态读取误差的资格验证。缺任何一项，就不能声称整个双球校准信息窗口已建立。

heartbeat/respiration 的分类类比仅放在 `EXTENSION_NOT_FOR_PAPER.md`，不混入本论文贡献，也不把两个球的静态定理当成人体动态模型验证。

完整原始观测随本轮交付包保存；仓库代码可重新生成，精简结果记录保留源哈希、全部初值和失败。所有补充实验仍是诊断，不是对撤回选择器的重新调参。
