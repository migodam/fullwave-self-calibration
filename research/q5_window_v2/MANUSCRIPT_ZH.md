# Q5：有限误差校准窗口、有限模态读出与独立验证

## 1. 本轮裁决

本轮取得了受限问题中的正面闭环：准确 Mie 材料响应 → 有限球面采样可读取的模态 → 包括串扰、漂移和随机噪声的误差预算 → 整个材料区间上的有限恢复保证。还核验了一个真正发生材料任务窗口分裂的径向例子。它们不只是局部 SVD。

但“同时存在的两个有损球＋未知接收器位移＋未知复增益”仍未形成完整的 TAP 投稿证据链。当前没有该物理类的可信连续模型误差半径，也没有覆盖全部坏世界对的有限分离证书，数值竞争世界尚未变成经过认证的 Maxwell 反例。仪器误差规格的真实可达性也没有实测验证。本轮不能宣称已完成一篇可直接投稿的 TAP 方法论文。

不可变 A5、父级修正后的 Q5 V1 和失败选择器均保持原样。旧的 0.443423189256 不作为本轮新成果。新试验不是旧最终集；未提出或调参一个新的自适应策略。

## 3. Information Window 如何真正帮助 calibration

对设计 d 和物理世界 θ，把所有允许的噪声、模型误差和参考误差写成观测集合 Y_d(θ)。定义某个任务坐标的最大相容差异 Ω_j(d)：在两个世界仍能产生同一允许观测的前提下，该任务参数最多能差多少。

任务窗口就是 Ω_j(d)≤2δ_j 的设计集合。几何、复增益、第一材料、第二材料可以分别定义窗口；联合任务必须同时满足。这里的设计不仅是距离，还包括极化、孔径、频率、原始噪声、采样次数、参考漂移与模型精度。

参考的作用是删掉一部分“材料变化可以被增益变化抵消”的坏世界对，而不是神奇地校正所有误差。若两个材料坏世界本来就具有相同增益，任何只读取这个增益的电子学参考都不能把它们区分开。跨采集融合必须共享同一材料、几何和电子学参数；每个块各自释放一个任意 gain 会改变问题。

### 3.1 一个经过覆盖验证的窗口分裂例子

电偶极切向模态的径向因子满足 c(z)^2=z^-2−z^-4+z^-6，z=kR，其导数严格为负。固定原始投影误差 10^-6、幅度参考总误差 0.003291、材料容差 0.1 后，归一化误差为 10^-6/c(z)。精确有限割线判据给出：

| 材料任务 | 理想幅度实验的可接受距离 |
|---|---|
| 第一材料 | 0.2<kR≤26.7393102838… |
| 第二材料 | 0.2<kR≤6.5683473710… |

这两个上端点都有宽度小于 10^-12 的有理包围区间。分裂的是两个材料任务的窗口，不是证明距离轴上出现两个不连通峰。这个例子没有内部最优距离；不能把继承的固定相对信噪比几何窗口最优点当成材料最优点。

理想完整模态投影与下述 kR=2 的有限 18 方向读出是不同证书。没有把有限读出定理擅自推广到整条距离轴。

### 3.2 原 5.78e-7 不是物理极限

在严格限制的幅度误差实验中，令 d_a=min(2B_a,a_+−a_-)，准确 Mie 幅度为 h_i。统一容差 δ 的有限条件为：

    a_- h_i(U_i) − (a_-+d_a) h_i(U_i−2δ) ≥ 2B_i。

必要性还要求另一个材料通道能补偿允许的增益比例；代码在本类中验证了这一条件。这个边界利用有限割线，而不是把局部斜率外推为最坏情况。

在继承的一次读取噪声事件下，第二模态可留给模型偏差的保守预算至少为 1.9004269431e-6，约为旧 5.78e-7 证书的 3.29 倍。本比较未额外分配参考共同漂移；漂移会消耗预算。故旧充分证书失败不能被说成普遍物理不可能。

此公式在原工作分支新增报告中也出现过；本轮作了独立推导核验和整数区间实现，不把“本轮推导”说成文献首创。

## 4. 一个明确的有限读出与误差预算

类 M 两球分别照射：ka=0.2、0.15，实介电区间分别 [1.5,4]、[2,5]，共同增益幅度 [0.75,1.25]，几何和背景已知。每次采用沿 x 传播、z 极化的单位平面波，在 kR=2 球面测两切向复分量。三点 Gauss–Legendre 极角乘六个方位角，共 18 个方向，投影到 N_10。

低阶投影是球面多项式精确积分；高阶不是直接扔掉。对全部 l≥5 用球 Bessel、Hankel 和 Mie 系数的解析尾界求和，得到两球理想模态泄漏上界分别 1.899e-10、8.019e-12，尚未乘 gain。读取行的平方噪声增益精确为 224/1053。相对通道算子误差还单独作用于全部场，不能只乘目标模态振幅，也不能把一般 nuisance 列当几何误差界。

| 项目 | 明确规格／结果 |
|---|---:|
| 每方向切向复通道的相对算子误差上限 | 0.0005，即 0.05% |
| 幅度参考共同漂移／偏差绝对值 | ≤0.00025 |
| 每球其余投影后误差总和 | ≤2e-6 |
| 独立重复次数 | 16 |
| 原始复场样本总数 | 18×2×16×2=1152 |
| 原始实幅度参考数 | 16 |
| 第一材料统一绝对误差上界 | 0.0446230 |
| 第二材料统一绝对误差上界 | 0.0761618 |
| 所用联合噪声事件失败概率上界 | 191/252000<0.001 |

“其余误差”必须包括节点定位、已知尺寸／频率的不确定性、照明、背景扣除及未另计入的模型误差。本轮没有把 2e-6 换成已经实测通过的机械公差。0.05% 也不是宣称任意天线都能达到的精度。

估计器先用实幅度参考 Z 归一化 |Y_i|，截断到已知 h_i 区间，再单调反演。准确上界为：

    |εhat_i−ε_i| ≤ [b_model,i+b_noise,i+H_i B_a] / [(a_min−B_a)m_i]。

m_i 是整个区间的下斜率，H_i 是幅度上界。正余量意味着这个数学仪器规格类非空；并不意味着真实设备已经通过验收。重复只降低独立随机噪声，不降低共同漂移和结构偏差。实高斯幅度参考也不等于复高斯 IQ 参考的模长；后一实现需要独立的噪声事件和原始成本记账。

## 5. 独立双球恢复：实际执行数据，而非期望结果

类 C：两球同时存在，中心 (-0.06,0,0)、(0.055,0.02,0) 米；半径 0.035、0.025 米；k=18；损耗 (0.03,0.05)；接收器 x 平移 ±2 毫米。四照射，12 个三分量接收器，144 个基础复观测。DDA 网格 0.011 米、填充分数积分阶数 4；反演使用保留球内响应和球间重复散射的标准向量球谐多球模型，阶数 3。不是新正演算法。

同场景共用原始噪声，proper complex σ 为真实增益后基础场 RMS 的 1%，参考复 σ=0.01。三个固定初值，每初值最多 80 次函数评估；相同容差、增益环带约束、实白化 sqrt(2)/σ。没有添加 logdet。

| 冻结方法 | 两材料误差都≤0.1 | 第一／第二材料误差中位数 |
|---|---:|---:|
| 无参考 | 2/12 | 0.235603 / 0.485966 |
| 正确带噪参考 GLS | 7/12 | 0.055420 / 0.069353 |
| 固定一个额外 EM 复标量 | 2/12 | 0.230857 / 0.476972 |
| 随机一个额外 EM 复标量 | 2/12 | 0.235808 / 0.485799 |

这里匹配的是新增复标量数，不是已经证明相等的硬件成本。12 个场景不能支撑总体成功率或 TAP 强优势结论。原始观测、噪声、真值、全部主比较初值与失败记录均保留。

### 5.1 为什么 reference 改善一些，却不能改善全部

事后机制对照：同模型无参考 11/12、有参考 12/12；独立数据给真实 geometry 加带噪 reference 7/12；给真实 complex gain 7/12；两者都给 7/12；无噪声且两者都给仍为 8/12；只给 gain 的真实幅度也是 7/12。

带噪参考成功集合为 {0,1,3,4,5,7,9}；真实 gain 与 geometry 的 oracle 成功集合为 {0,1,4,6,7,9,11}。总数相同但对象不同，说明某些拟合 gain 正在代偿正演差异，参数恰好落进容差也不等于模型被正确校准。

这支持优先检查结构模型误差，而不是无限增加 calibration 自由度。它没有排除优化误差，也没有证明每次失败都唯一由结构误差造成。局部投影显示模型差异范数的约 60.5%–94.1% 可落入联合参数切线，只作为偏差诊断，不作为误差上界。

前四场景提高 Mie 阶数和角积分、细化 DDA 均已检查。DDA 差异约 0.64%–1.67%，细网格并不单调改善；这些差异都不是连续 Maxwell 误差界。

### 5.2 有限竞争世界推进到什么程度

固定世界 A 为材料 (3.8,4.8)、位移 0.4 mm、gain=exp(0.2i)。世界 B 第二材料为 4.59，使 0.1 成功区间不相交；优化其余允许参数，并强制两世界协方差相同。

数值实白化距离：无参考约 3.39773051；带 σ_r=0.01 参考约 5.20127714。对应数值均值下二元风险约 0.0446723、0.00465252。这些是优化产生的上距离候选，不是覆盖下界，也还不是经过认证的 Maxwell 反例。

若将来能把参考候选的合计连续模型实白化误差严格界在 0.2942856 以下，该候选便足以否定当前受限采集的统一 0.997 成功保证。这里给出了明确认证目标，而没有宣称它已完成。

## 6. 从分类到天线设计：保留哪些信息

Geometry、Complex Gain、Material 的作用空间可以重叠，不存在天然唯一的三块正交物理标签。gain 的列是 F 与 iF；几何列必须来自真实 Maxwell 场的空间导数；材料列来自介电扰动。只看投影后局部满秩不够，必须检查有限坏世界。

内部 Mie 响应、相对电／磁响应、高阶角模、对象多样性、球间再散射是五个不同机制。本轮不把其中任何两个混称为“multiple scattering helps”。在同一个固定损耗与未知电子学模型下，Born 也可能凭已知损耗先验获得幅度信息；只有合法的比例子族仍保留增益歧义。q=30、q'=40 的合法反例保留，不使用越界 q'=45、g=1。

天线设计应把设计集合分为材料窗口、几何窗口、电子学参考窗口。增加阵元或极化之前，先问它是否排除了尚存材料坏对；增加 reference 之前，先问坏对是否具有不同 electronics；当真实 gain/geometry 的 oracle 仍失败时，不应仅用更精细 gain 拟合解释为成功。

已知可逆数字放大若连同协方差正确变换，不会增加可辨识信息。模拟增益可能压低后级噪声相对贡献，但不能消除前级噪声和模型偏差。文稿用明确的前／后级噪声公式处理这一点；未找到可唯一指认的“Gain-F”方法，不杜撰同名理论。

## 7. 近邻文献与论文定位

已检查 Prokopiou–Tsitsas 2018 的实际逆映射：ε_r=(1+2ψ_1)/(1−ψ_1)、μ_r=(1+2ψ_2)/(1−ψ_2)，以及其已知源、已知归一化、低频阶数提取等假设。故不能把球体材料反演或源／材料分类本身说成新发现。Epp–Janz 的相对场导数已经能消去偶极分量并恢复距离；球谐采样和被动性界也有明确先例。

本轮潜在价值是将任务级有限歧义、可读取模态、误差预算与校准干预连成可验证链条，而不是换名字。2013 球体近场逆介质论文、2012 未知入射场反演论文的关键全文公式仍未取得；原创性审查不能据此宣布通过。逐篇公式、假设、访问状态见 LITERATURE_AUDIT.md。

## 8. 非论文拓展：心跳与呼吸

可以把两个运动分量作为两个任务参数，电子学漂移、整体位移和静态散射作为共享 nuisance。但“都是信号处理”不保证可分：若两个分量在所有通道具有成比例的时空响应，只能观察它们的和，任何滤波器都不能唯一拆分。不同频率只是一种可能的区分条件；频率重叠、谐波或共同相位扰动时需要别的空间／极化／时间结构。

可迁移的是坏世界与参考干预的检验方法，不是本轮球体定理或医疗有效性。本轮没有相应人体模型、实测数据或性能验证，不写进论文贡献。
