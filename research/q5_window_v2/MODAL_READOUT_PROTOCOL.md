# 受限模态读出构造：执行前冻结

此分支只服务类 M（球分别读取、无损、尺寸已知），不是类 C 的测量替代，也不回写 V1 结果。目标是为抽象模态读出给出有限 Maxwell 采样实现，并检查误差预算是否非空；不宣称新的反演算法。

固定构造：单位平面波沿 x 传播、z 极化；在各球中心的 kR=2 球面测量两切向分量。使用三点 Gauss–Legendre 极角与六点等距方位角，共 18 方向，投影到 N_10 电偶极模。理论证明应包括所有高阶模式的解析尾界，不能用 L 与 L+1 差代替。数值检查使用 L=8。

固定加预算方案：每方向两复分量，16 次独立重复；两个分别读出的球共 1152 个复样本，另有 16 次实幅度参考。允许误差上限：相对通道算子误差 0.0005；参考绝对漂移/偏差 0.00025；其他已换算到模态输出的几何、背景扣除、照明误差合计每球 0.000002。这些是必须独立检验的仪器验收规格，不是声称已测得的硬件精度。

随机模态噪声沿用 A5 单次标准差 2.6664081e-6、1.8047986e-6，参考实标准差 0.001。平均后按 sqrt(16) 缩小；共同系统误差不得除以 sqrt(16)。证明可使用更保守的 3 sigma 复误差圆盘和 3.5 sigma 实参考事件。记录每项常数和严格外向边界。这个方案改变了采集预算，不能与一次参考的原极小性或 V2 类 C 单标量基线偷换。
