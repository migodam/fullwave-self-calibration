# V2 实现锁定（在新恢复实验执行前）

依赖安装实际遇到网络/DNS 限制，当前运行环境没有 treams/python-flint。本轮采用注册协议允许的 SciPy 向量球波数值平移实现；单球 Mie 系数解析计算，球间耦合通过 (I-TU)^{-1} 求解。它不是新算法。整数定点区间算术另行实现，不依赖浮点三角库。

恢复主模型固定 lmax=3、Gauss-Legendre 极角节点12、方位节点24、平移投影半径0.04米。粗 DDA spacing=0.011、fill_quadrature=4；前四场景额外 spacing=0.009、0.0075 的场差诊断，不以差值作为连续误差界。若内存不允许，保留失败日志而不缩减未声明的物理条件。

随机数：物理场景和基础噪声用 numpy.default_rng(2026091107)；附加随机 EM 索引用独立 default_rng(2026091108)。固定 EM 索引0；候选场以 (receiver,component,illumination) C-order 展平，16个Fibonacci方向、半径0.6米。先生成全部场景原始观测后再拟合，避免优化分支影响随机流。no_reference / noisy_reference_GLS / fixed_EM / random_EM 四种主条件全部保持预注册三个初值与80次函数评估上限。

额外固定机制诊断：每个新场景进行无噪声DDA数据的无参考和精确已知增益拟合，并另报已知真实几何时的材料拟合；这些是 oracle 诊断，不加入四方法成功率排名，不作为可部署算法。保存同一真值位置上的 DDA/多极模型差，分解它沿电子学增益切线、增益消除后几何切线、再消除后材料切线和剩余正交部分的投影。此顺序分解仅为诊断，明确不是独一无二的因果归因。

测试程序还将核对解析边界条件、平面波重建、无损光学定理、数值平移角积分和阶数收敛。上述数值核对与正式整数区间覆盖分栏报告。此前已经生成的受限模态区间证书及求解器单元核对不属于材料恢复结果。
