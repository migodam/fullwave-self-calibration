\boxed{

\boxed{

# 一、先把 literature 摊开：别人到底已经做到哪一步了？

最容易产生误判的地方，是“以前没人把 3DGS 搬到我的具体问题”，但其实周边每一个零件都已经有人碰过。

| 路线 | 已有工作 | 已经解决了什么 | 对你的 novelty 意味着什么 |
|---|---|---|---|
| EM shape inversion + RBF | Naik et al., *Inverse Problems*, 2009 | 用少量 RBF centers + normals 表示物体边界，同时反演 shape 和 EM parameter | “不用 voxel，直接参数化边界”早就有了  |
| 3D microwave RBF inversion | Li–Abubakar–Habashy, IEEE TAP 2012 | 3D 点 + RBF 连成平滑表面，恢复 shape + material，未知量少于 pixel inversion | “RBF/平滑 primitive 做 3D 微波成像”也不是新东西  |
| Full-wave Gaussian basis | Kanaun, PIER B 2010 | 用 Gaussian approximating functions 离散 3D dielectric VIE；matrix element 有解析式；规则网格 Toeplitz + FFT | **直接堵死“Gaussian 让 full-wave forward 有解析式”这个创新点**  |
| Gaussian surface EM basis | Shlivinski–Lomakin, JCP 2016 | PMCHWT surface integral + Gabor/Gaussian window；phase-space localization；Gaussian beam propagation | “Gaussian 放 surface Maxwell solver”也已经有邻近 prior art  |

\[
\boxed{
\text{Gaussian 不是 novelty。Splatting 也不是 novelty。}
}
\]

真正还可能新的只能是：

\[
\boxed{
\text{一个 Gaussian representation 特有、且由 wave physics 推出来的新算法/定理。}
}
\]

而不是换了一个 basis。

# 二、你说的 2023 TAP “外表成像”是不是已经把这事做了？

你说的应该是 Tiantian Yin、Kai Tan、Xudong Chen 的：

**“Far-Field Approximation Learning Method for Millimeter-Wave Short-Range Imaging,” IEEE TAP, 2023.**

它利用 far-field approximation 做 short-range millimeter-wave imaging，再用 CNN 校正 far-field approximation 和 limited aperture 引入的 distortion；而且单频就可以生成 3D high-resolution reflectivity map，对 antenna placement 也比较灵活。

但是它和我现在说的东西有一个本质区别。

它的未知量仍然可以理解成：

\[
\boxed{\text{3D reflectivity image}}
\]

而不是：

\[
\boxed{
\text{一组具有物理 material jump、normal、scale、geometry 的界面 primitives}.
}
\]

换句话说，它会因为毫米波散射机制而经常把目标的外表、轮廓、强反射区域成出来，但：

> **它不是从数学上假设“未知量就是界面”，再由 Maxwell/Born 推导一个 surface primitive inverse problem。**

所以它没有占掉下面我要讲的关键结构。

# 三、但是“直接做物体外表”本身有没有人做过？

有，而且非常多。

传统 electromagnetic shape inversion 就是在恢复

\[
\partial D
\]

而不是整个

\[
\chi(\mathbf r).
\]

2009 年 Naik 的工作甚至已经用 implicit RBF zero-level set 去表示边界，可以让 topology 变化，同时恢复 electromagnetic parameter；2012 TAP 的 Li–Abubakar–Habashy 又直接做到了 3D smooth target surface + material inversion。

另一方面，如果物体本身就是 piecewise homogeneous，full-wave Maxwell 里使用 PMCHWT 等 surface integral equations，本来就可以只在界面上求 electric/magnetic equivalent currents。这是成熟的 computational electromagnetics 路线。

因此：

\[
\boxed{
\text{“我要把体问题改成 surface problem”也不能成为 novelty。}
}
\]

但下面出现了一个重要区别。

# 四、Born 条件下，为什么 Gaussian **surface** primitive 其实特别自然？

这里有一个非常干净的结果。

Born 条件下：

\[
d(\mathbf q)
=
C(\mathbf q)\widehat\chi(\mathbf q),
\]

其中

\[
\mathbf q=\mathbf k_s-\mathbf k_i
\]

就是 Ewald scattering vector。

考虑一个均匀 dielectric object：

\[
\chi(\mathbf r)
=
\Delta\chi\,1_D(\mathbf r).
\]

那么对于

\[
\mathbf q\neq0,
\]

利用

\[
e^{-i\mathbf q\cdot\mathbf r}
=
\frac{i}{|\mathbf q|^2}
\mathbf q\cdot\nabla
e^{-i\mathbf q\cdot\mathbf r},
\]

直接用 divergence theorem：

\[
\boxed{
\widehat\chi(\mathbf q)
=
\frac{i\Delta\chi}{|\mathbf q|^2}
\int_{\partial D}
(\mathbf q\cdot\mathbf n)
e^{-i\mathbf q\cdot\mathbf r}
\,dS.
}
\]

这非常重要。

它意味着，对于一个均匀物体：

\[
\boxed{
\text{所有非 DC 的 Born coherent scattering data}
}
\]

都可以完全由：

\[
\boxed{
\text{surface geometry}+\text{material jump}
}
\]

描述。

不是 high-frequency approximation。

不是 physical optics。

不是经验上“反射主要在表面”。

而是 **Born model 里面的精确恒等式**。

对于 piecewise homogeneous object，只需要对所有 material interfaces 求和：

\[
\boxed{
\widehat\chi(\mathbf q)
=
\frac{i}{|\mathbf q|^2}
\sum_\Gamma
\Delta\chi_\Gamma
\int_\Gamma
(\mathbf q\cdot n_\Gamma)
e^{-i\mathbf q\cdot r}\,dS.
}
\]

所以这里第一次出现了一个非常合理的 3DGS 类比：

> 光学 3DGS 最后会把 Gaussians 聚集到可见 surface；
>
> **Born scattering 对 piecewise-homogeneous material 从数学上就能直接写成 surface measure。**

但是注意：这个 divergence theorem identity 本身不是新数学。

新的东西必须发生在它之后。

# 五、真正像“电磁 splat”的东西是什么？

不要用 3D Gaussian blob。

应该用：

\[
\boxed{\textbf{2D anisotropic Gaussian surfel}}
\]

每个 primitive 有：

\[
(\mu_j,n_j,\Lambda_j,A_j,\Delta\chi_j).
\]

其中 \(\Lambda_j\in\mathbb R^{2\times2}\) 是 tangent-plane covariance。

取 tangent basis

\[
T_j=[t_{1j},t_{2j}],
\]

定义

\[
q_t=T_j^Tq,\qquad q_n=n_j^Tq.
\]

Gaussian patch：

\[
w_j(u)
=
\frac{A_j}{2\pi\sqrt{\det\Lambda_j}}
\exp
\left(
-\frac12u^T\Lambda_j^{-1}u
\right).
\]

那么上面的 Born boundary integral **直接闭式化**：

\[
\boxed{
d_j(q)
=
C(q)
\frac{i\Delta\chi_j A_j}{|q|^2}
q_n
e^{-iq^T\mu_j}
e^{-\frac12q_t^T\Lambda_jq_t}.
}
\]

我把它叫作一个 **Ewald splat**。

这条公式的各项不是 3DGS 随便学习的 color：

\[
e^{-iq^T\mu}
\]

是 coherent position phase；

\[
q\cdot n
\]

是 surface orientation coupling；

\[
e^{-\frac12q_t^T\Lambda q_t}
\]

是 patch 在 Ewald space 中的 angular/spatial-frequency aperture；

\[
\Delta\chi
\]

是真正的 dielectric jump。

这比“Gaussian 上挂一个 SH color”物理得多。

---

# 六、甚至 curvature 也可以闭式进去

这是我认为第二个比较漂亮的性质。

把 surface patch 不近似为 plane，而近似成 local paraboloid：

\[
r(u)
=
\mu+Tu+
\frac12n\,u^TKu,
\]

其中

\[
K=
\begin{bmatrix}
\kappa_1&\cdots\\
\cdots&\kappa_2
\end{bmatrix}
\]

包含 local curvature。

定义

\[
M=\Lambda^{-1}+iq_nK.
\]

Gaussian integral 仍然能精确做完：

\[
\boxed{
\begin{aligned}
\mathcal S(q)
&=
e^{-iq^T\mu}
\frac{A}
{\sqrt{\det\Lambda\,\det M}}
\\
&\quad\times
\left[
q_n+
i q_t^TKM^{-1}q_t
\right]
\exp
\left(
-\frac12q_t^TM^{-1}q_t
\right).
\end{aligned}}
\]

然后

\[
d(q)
=
C(q)\frac{i\Delta\chi}{|q|^2}\mathcal S(q).
\]

所以一个 primitive 可以携带：

\[
\boxed{
\text{position + normal + tangent shape + curvature + material}.
}
\]

而且不需要 triangle quadrature。

不过这里我要克制一下 novelty claim：Gaussian-window surface integral / Gaussian beam / curvature scattering 周围已有不少文献，例如 Shlivinski–Lomakin 的 Gaussian-windowed SIE。因此**“这个积分可闭式”单独不足以成为论文核心**。

# 七、真正开始变得有意思的数学结果：Ewald-shell identifiability

这是这轮我认为比 closed-form forward 重要得多的结果。

先回到一个单独的 3D Gaussian volume primitive：

\[
d(q)
=
Ca
e^{-iq^T\mu}
e^{-\frac12q^T\Sigma q}.
\]

假设 monostatic single-frequency，因此：

\[
|q|=Q.
\]

令

\[
q=Q\hat s.
\]

取 complex log：

\[
\log d
=
\log(Ca)
-iQ\hat s^T\mu
-\frac{Q^2}{2}\hat s^T\Sigma\hat s.
\]

分解 covariance：

\[
\Sigma
=
\frac{\operatorname{tr}\Sigma}{3}I
+
\Sigma_0,
\qquad
\operatorname{tr}\Sigma_0=0.
\]

于是

\[
\boxed{
\begin{aligned}
\log d(\hat s)
=&
\underbrace{
\log(Ca)
-\frac{Q^2}{6}\operatorname{tr}\Sigma
}_{l=0}
\\
&
-\underbrace{iQ\hat s^T\mu}_{l=1}
\\
&
-\underbrace{\frac{Q^2}{2}
\hat s^T\Sigma_0\hat s}_{l=2}.
\end{aligned}}
\]

这个结构很漂亮：

\[
\boxed{
\begin{array}{c|c}
\text{Gaussian parameter}&\text{spherical harmonic sector}\\
\hline
\text{amplitude + isotropic scale}&l=0\\
\text{position}&l=1\\
\text{anisotropic shape/orientation}&l=2
\end{array}}
\]

所以一个 Gaussian primitive 的 geometry 在 Ewald sphere 上不是乱七八糟纠缠在一起的。

它有一个精确的 angular decomposition。

---

# 八、并且这里存在一个**精确不可辨识 gauge**

这是目前最像一个 theorem 的结果之一。

由于

\[
|q|=Q,
\]

取任何 admissible \(\tau\)：

\[
\boxed{
\Sigma'
=
\Sigma+\tau I,
}
\]

同时

\[
\boxed{
a'
=
a\,e^{\frac12\tau Q^2}.
}
\]

那么：

\[
\begin{aligned}
a'e^{-\frac12q^T\Sigma'q}
&=
a
e^{\frac12\tau Q^2}
e^{-\frac12q^T\Sigma q}
e^{-\frac12\tau Q^2}
\\
&=
a e^{-\frac12q^T\Sigma q}.
\end{aligned}
\]

所以：

\[
\boxed{
d'(q)=d(q)
\qquad
\forall\,|q|=Q.
}
\]

意思非常具体：

> **任你在单频 monostatic 情况下环绕物体 360°、采无穷多个角度，也无法把 Gaussian 的 isotropic size 和 material amplitude 分开。**

这不是噪声问题。

不是 conditioning。

不是 Fisher approximation。

而是 **exact gauge**。

所以 single-shell 数据只能识别：

\[
5
\]

个 traceless covariance DOF，而不是完整六个 covariance DOF。

第二个 frequency，或者 bistatic geometry 使得

\[
|q|
\]

发生变化，立刻可以打破这个 gauge。

这实际上直接变成了一个：

\[
\boxed{
\text{measurement-design theorem}.
}
\]

# 九、我做了一个 numerical sanity check：它确实是精确的

我随机生成 1000 个全方向 measurement：

\[
|q|=8.
\]

然后取：

\[
\Sigma'=\Sigma+0.005I,
\]

并按照上面的公式重新调整 amplitude。

两组数据的 relative difference：

\[
\boxed{
1.29\times10^{-16}.
}
\]

也就是 numerical machine precision。

不是“非常接近”。

而是理论意义上的 same data。

对应 magnitude design matrix：

\[
[1,\operatorname{vech}(qq^T)]
\]

一共七列，但在 fixed \(Q\) 条件下：

\[
\boxed{\operatorname{rank}=6}.
\]

加入第二个 radial Ewald shell，例如：

\[
Q=6,\quad Q=10,
\]

立即：

\[
\boxed{\operatorname{rank}=7}.
\]

所以这个 theorem + experiment 是完全对上的。

# 十、更狠的一点：为什么 coherent phase 对 Gaussian reconstruction 极重要？

看单 primitive：

\[
d(q)
=
a
e^{-iq^T\mu}
e^{-\frac12q^T\Sigma q}.
\]

取 intensity：

\[
|d(q)|^2
=
|a|^2
e^{-q^T\Sigma q}.
\]

你会发现：

\[
\boxed{
\mu
\quad
\text{彻底消失了。}
}
\]

因此：

\[
\boxed{
\text{单个 Gaussian 的 intensity-only data 根本不包含其 absolute position。}
}
\]

而 complex data：

\[
\arg d(q)
=
\arg a-q^T\mu
\]

直接把 position 放进 phase slope。

对于多个 primitive：

\[
d(q)
=
\sum_j
a_j
e^{-iq^T\mu_j}\cdots
\]

intensity 变成 pairwise interference / autocorrelation，仍然具有 global translation invariance 和典型 phase-retrieval ambiguity。

这正好解释了一个当前 literature 的现象。

2026 的 SAR-3DGS 明确使用 **single-polarization intensity observations**；论文自己承认不显式使用 phase，因此 point cloud 主要恢复 relative geometry，不能像 TomoSAR 那样直接得到 metric-scale absolute height，并把“未来使用 complex-valued observations”列成后续方向。

所以你的 coherent Gaussian 方法如果做对了，不能仅仅说：

> “我们用了 phase，因此效果更好。”

真正可以说：

\[
\boxed{
\text{complex phase changes the identifiability class of the Gaussian geometry.}
}
\]

这个强很多。

# 十一、还有一个我觉得很可能成为核心贡献的东西：**physics-aware densification**

这可能才是真正有机会从 3DGS 迁移出一个原创算法机制的地方。

普通 3DGS 会做：

\[
\text{clone / split / prune / densify}
\]

通常根据 screen-space gradients、opacity、size 等 heuristic 来决定。

SAR-GS 等也继承了类似的 adaptive Gaussian refinement 思路。

问题是：

> 在 inverse scattering 里，新增两个 Gaussian 不代表 measurement 真的有能力区分它们。

于是考虑一个 Gaussian surfel：

\[
G_p(u;0,\Lambda).
\]

把它沿 tangent direction \(d\) split 成两个 children：

\[
\mu_\pm=\pm d,
\]

各自 weight 为 \(1/2\)，并令

\[
\boxed{
\Lambda_c=\Lambda-dd^T.
}
\]

这恰好保持 parent 的：

\[
\text{mass},\quad
\text{mean},\quad
\text{covariance}.
\]

这种 moment-preserving Gaussian mixture splitting 本身不是新的；Gaussian-mixture literature 已经研究这种 split。

但是看看它在 **Ewald data** 里发生什么。

设

\[
x=q_t^Td.
\]

split 后的 scattering / split 前 scattering：

\[
\boxed{
\frac{F_{\rm child}}{F_{\rm parent}}
=
e^{x^2/2}\cos x.
}
\]

展开：

\[
\boxed{
e^{x^2/2}\cos x
=
1-\frac{x^4}{12}
-\frac{x^6}{45}
+O(x^8).
}
\]

注意：

\[
\boxed{
O(x^2)\text{ 项完全消掉了。}
}
\]

如果你直接把一个 Gaussian 复制成两个而 covariance 不改，则：

\[
\cos x
=
1-\frac{x^2}{2}+O(x^4).
\]

所以 moment-preserving electromagnetic split 有一个非常特别的性质：

\[
\boxed{
\text{split 会以四阶而不是二阶扰动当前 measured wavefield。}
}
\]

---

# 十二、于是可以直接定义“measurement 是否允许这次 split”

假设相对 data uncertainty / residual floor 是：

\[
\eta.
\]

小 split 下：

\[
\frac{|\delta d|}{|d|}
\approx
\frac{|q_t^Td|^4}{12}.
\]

因此：

\[
\boxed{
|q_t^Td|
\lesssim
(12\eta)^{1/4}
}
\]

意味着：

> measurement 实际上看不出来 parent 是一个 Gaussian 还是两个 children。

这时 split 只是在增加一个 nuisance degree of freedom。

反过来，只有当 acquired Ewald set \(\mathcal Q\) 中存在足够大的：

\[
|q_t^Td|
\]

时，才应该允许 densification。

因此你得到：

\[
\boxed{
\textbf{Ewald-resolvable densification criterion}.
}
\]

这和 computer-graphics GS 有一个质的区别：

\[
\boxed{
\text{不是“图像看起来哪里需要更多 Gaussian”，}
}
\]

而是：

\[
\boxed{
\text{“你的电磁 measurement 到底有没有 information 支撑更多 Gaussian”。}
}
\]

这个我认为非常有价值。

---

# 十三、我还数值算了这个 split 到底能有多大差别

定义允许 split 后 forward data 改变不超过 \(\epsilon\)。

对于 moment-preserving split：

| 容许 data perturbation | \( |q_t^Td|_{\max}\) | 相对 naive split 可允许的 separation |
|---:|---:|---:|
| 0.1% | 0.329 | **7.35×** |
| 1% | 0.576 | **4.07×** |
| 5% | 0.839 | **2.64×** |
| 10% | 0.981 | **2.17×** |

所以它也给出了非常实际的 optimization 作用：

你可以：

\[
1\ {\rm splat}
\rightarrow
2\ {\rm splats}
\]

却几乎不改变当前 predicted data。

然后让新增自由度沿 measurement actually observable 的方向慢慢分离。

这实际上相当于一个：

\[
\boxed{
\text{model-order continuation / homotopy}.
}
\]

我认为这个比“Gaussian forward 可以解析算”强得多。

# 十四、还有一个更底层的 subspace 结构：任意 surfels 其实会产生巨大的非物理 nullspace

这个是进一步推导出来的，也非常重要。

定义 piecewise-constant material 的 boundary measure：

\[
b(r)=-\nabla\chi(r).
\]

对一个界面：

\[
b
=
\Delta\chi\,n\,\delta_\Gamma.
\]

Fourier 域：

\[
\widehat b(q)
=
-iq\,\widehat\chi(q).
\]

所以：

\[
\boxed{
\widehat b(q)\parallel q.
}
\]

并且：

\[
\boxed{
\widehat\chi(q)
=
\frac{i}{|q|^2}
q^T\widehat b(q).
}
\]

现在假设你像 3DGS 一样，让每个 surfel 的：

\[
n_j,\quad \Delta\chi_j
\]

全部独立自由优化。

那么一般会出现：

\[
\widehat b
=
\widehat b_\parallel
+
\widehat b_\perp,
\]

其中：

\[
q^T\widehat b_\perp=0.
\]

而 scattering measurement 根本看不到：

\[
\boxed{\widehat b_\perp}.
\]

也就是说，一个 naive Gaussian surfel renderer 会人为引入一个巨大的 **solenoidal/transverse gauge**。

但真正物理的 interface field 是：

\[
b=-\nabla\chi,
\]

因此必须满足：

\[
\boxed{
\nabla\times b=0
}
\]

的 distributional integrability。

这给了你一个非常重要的设计原则：

> **不能把 3DGS 的 independent normal + independent opacity 直接照搬过来。**

你必须：

要么从一个 implicit scalar material field 产生 normals；

要么显式加入 closed-surface / curl-free / integrability constraint。

这又是一条 Gaussian inverse scattering 相对于普通 graphics splatting 非常根本的物理差异。

# 十五、于是还能得到一个很漂亮的“参数 → measurement subspace”图

对于单 Gaussian：

\[
\boxed{
\begin{array}{ccl}
\text{global magnitude / isotropic size}
&\rightarrow&
l=0
\\[2mm]
\text{position}
&\rightarrow&
l=1\text{ phase}
\\[2mm]
\text{anisotropic covariance/orientation}
&\rightarrow&
l=2\text{ magnitude}
\\[2mm]
\text{arbitrary surfel transverse vector field}
&\rightarrow&
\text{Born nullspace}
\end{array}}
\]

因此不是普通“我求个 Fisher matrix 看 eigenvalue”。

这是一个相当具体的 structural decomposition。

采集设计也直接出来：

完整 3D position 要求 \(q_m\) span \(\mathbb R^3\)；

完整 anisotropic shape 要求 lifted vectors

\[
\operatorname{vech}(q_mq_m^T)
\]

覆盖对应 Sym(3) subspace；

single radial shell 永远缺一个 trace direction；

multi-frequency / bistatic 改变 \(|q|\) 才能补回来。

# 十六、limited aperture 会发生什么？

这个我也做了 toy conditioning test。

对于固定 \(Q=8\)，从完整球面逐渐把 measurement 缩成 cone，单 Gaussian 的 shape/position estimation condition number 急剧恶化。

例如 cone half-angle 只有约 \(5^\circ\) 时，我得到的 toy design：

\[
\kappa_{\rm shape}\sim6.4\times10^2,
\]

而

\[
\kappa_{\rm position}\sim7.3\times10^3.
\]

到 \(20^\circ\) 时大约下降到：

\[
37,\qquad441.
\]

完整 sphere 则降到个位数量级——除了上面那个**无论 aperture 多大都去不掉的 exact trace/amplitude gauge**。

所以：

\[
\boxed{
\text{angular diversity 解决方向 conditioning，}
}
\]

但：

\[
\boxed{
\text{radial diversity 才解决 scale/material gauge。}
}
\]

这就是一个相当简洁的 acquisition law。

# 十七、Gaussian 对“高精度外表成像”是不是天然特别好？

这里有一个非常重要的**负结果**。

如果你把一个完整物体直接替换成一个 3D Gaussian blob：

\[
\chi_G(r),
\]

对一个 radius \(a\) 的 homogeneous sphere，真实 Born form factor 是：

\[
F_{\rm sphere}(x)
=
3\frac{\sin x-x\cos x}{x^3},
\qquad
x=qa.
\]

匹配二阶 moment 的 Gaussian：

\[
F_G(x)=e^{-x^2/10}.
\]

我算出来：

| \(qa\) | sphere | matched Gaussian | absolute error |
|---:|---:|---:|---:|
| 0.5 | 0.97522 | 0.97531 | \(8.8\times10^{-5}\) |
| 1 | 0.90351 | 0.90484 | 0.00133 |
| 2 | 0.65310 | 0.67032 | 0.0172 |
| 3 | 0.34568 | 0.40657 | 0.0609 |
| 4 | 0.08708 | 0.20190 | 0.1148 |
| 5 | **−0.0571** | **+0.0821** | 0.1391 |

到高 \(q\) 连符号都错了。

原因非常本质。

Gaussian Fourier tail：

\[
\sim e^{-q^2\sigma^2}
\]

指数衰减。

而 sharp boundary 的 Fourier/scattering response 有 oscillatory algebraic tail。

所以：

\[
\boxed{
\text{3D Gaussian blobs 非常不适合用少量 primitive 表示高分辨率 sharp boundary。}
}
\]

这直接改变了我上一轮的推荐。

# 十八、所以如果你追求“外表特别精细”，应该做 surfel，而不是 blob

也就是：

\[
\boxed{
\text{thin 2D Gaussian tangent patches}
}
\]

而不是

\[
\boxed{
\text{fat 3D Gaussian ellipsoids}.
}
\]

这也和 3DGS 实际优化之后大量 Gaussian 最终贴附在 surface 上的现象比较一致。

对于 isotropic tangent Gaussian：

\[
\Lambda=\sigma_t^2I,
\]

monostatic 时大致有：

\[
q\simeq -2k\hat s.
\]

如果 incidence/scattering vector 和 normal 夹角为 \(\alpha\)，单 surfel response approximately：

\[
|d(\alpha)|^2
\propto
\cos^2\alpha\,
e^{-(2k\sigma_t)^2\sin^2\alpha}.
\]

因此 footprint 越大：

\[
\sigma_t\uparrow
\]

angular response 越窄。

我数值算出的 power-lobe FWHM：

| \(\sigma_t\) | FWHM |
|---:|---:|
| \(0.25\lambda\) | \(29.2^\circ\) |
| \(0.5\lambda\) | \(15.0^\circ\) |
| \(1\lambda\) | \(7.6^\circ\) |
| \(2\lambda\) | \(3.8^\circ\) |
| \(4\lambda\) | \(1.9^\circ\) |

所以 Gaussian surfel 的 spatial footprint 和 scattering angular lobe 之间有一个非常直接的 duality：

\[
\boxed{
\Delta\theta
\sim
\frac{1}{k\sigma_t}.
}
\]

这也是 measurement design / densification 能用到的。

# 十九、但是 Gaussian surfel 并不是“数值积分神器”

这点我也专门测了一下，结果反而帮我们杀掉了一个可能的错误 story。

我用一个 sphere 的 exact Born form factor 做 ground truth，把 sphere surface 分成不同数量的 approximate Gaussian patches。

在

\[
qa\in[0.5,10]
\]

范围：

| surfels | flat Gaussian patch error | quadratic-curvature patch error |
|---:|---:|---:|
| 50 | 4.88% | 3.88% |
| 100 | 2.54% | 1.97% |
| 200 | 1.30% | 0.99% |
| 400 | 0.66% | 0.50% |
| 800 | 0.33% | 0.25% |
| 1600 | 0.17% | 0.13% |

曲率 closed form 确实有改善。

但是——

对这个非常 smooth 的 sphere，一个普通的 good surface point quadrature 在相同点数下甚至比 Gaussian window 更准。

所以：

\[
\boxed{
\text{不能写“Gaussian forward 比传统 quadrature 更准确”。}
}
\]

这是不成立的。

Gaussian 真正可能赢的是：

\[
\boxed{
\text{adaptive inverse representation}
+
\text{continuous geometry}
+
\text{model-order control}
+
\text{analytic geometry gradients}.
}
\]

不是 quadrature。

# 二十、那么只做 Born，反而是不是比 full-wave 更合适？

现在我的答案是：

\[
\boxed{\textbf{是。作为第一篇，我反而强烈倾向 Born。}}
\]

不是因为 Born 更简单所以偷懒。

而是因为：

### Born 下真正出现了 clean mathematical structure

\[
\text{Ewald geometry}
\rightarrow
\text{interface Fourier measure}
\rightarrow
\text{Gaussian closed form}
\rightarrow
\text{exact gauge}
\rightarrow
\text{resolution-certified split}.
\]

整个故事是一条线。

而 full-wave：

\[
E=E_i+G(\chi E)
\]

之后 Gaussian primitives 之间开始通过 total field 全局耦合。

这时漂亮的 Ewald-shell structure 被 multiple scattering 打散。

# 二十一、那 full-wave 对 Gaussian 到底有没有特殊优势？

有，但没有我上一轮想象得那么大。

Kanaun 2010 已经证明了 Gaussian approximating functions 可以用于 full-wave dielectric VIE，而且 interaction matrix element 可以解析算、规则 grid 还能 FFT acceleration。

所以：

\[
\boxed{
\text{“Gaussian 可以把 full-wave 算快”不能作为新贡献。}
}
\]

而对于 piecewise homogeneous object，传统 PMCHWT/SIE 本来就只 discretize surface。

所以：

\[
P_{\rm surface}\ll N_{\rm volume}
\]

也不是 Gaussian 独有优势。

Gaussian 在 full-wave 真正还可能有优势的是：

\[
\text{meshless / continuously movable geometry}
\]

和

\[
\text{adaptive topology}.
\]

传统 BEM 改 shape 时常涉及 remeshing、mesh quality、topological changes。

Gaussian surfels 天然允许：

\[
\mu_j,\Lambda_j,n_j
\]

连续移动，然后 split/prune。

但 RBF implicit shape inversion 已经部分解决过 continuous geometry/topology 的问题。

所以这仍不足以让我把 full-wave 放在 headline。

# 二十三、如果目标是金属车辆/特别强散射外表呢？

那就不要硬用 dielectric Born。

应该切换到：

\[
\boxed{
\text{Physical Optics / Kirchhoff / surface-current Gaussian splatting}.

对于 electrically large PEC/high-contrast targets，外表确实是更自然的未知量，但 local scattered field 来自 surface current，而不是简单的 dielectric contrast jump。

SAR-3DGS 本身也明确讨论了 echo-level SAR simulators 常用 GO、PO、Kirchhoff、GTD 等高频模型。

所以我目前不选它作为第一主线。

# 二十六、我认为真正够资格作为 Contributions 的应该是这几个

这里我只列一次，因为这几个是整个方向真正的核心：

1. **Coherent interface splatting formulation**：对 piecewise-homogeneous Born scattering，从 exact interface representation 出发，用 adaptive Gaussian surfels 表示 material-jump surface，而不是 volumetric radiance field；flat/quadratic primitive 都有解析 coherent response。

2. **Ewald-shell identifiability theorem**：Gaussian geometry 在 fixed Ewald shell 上形成 \(l=0/1/2\) decomposition；证明 single-frequency monostatic 存在 exact isotropic-scale/material-amplitude gauge，并给出 multi-frequency/bistatic breaking condition。

3. **Phase-identifiability theorem**：intensity-only single primitive 完全丢失 center；complex phase 恢复位置 slope，从数学上解释为什么 coherent raw measurements 相对于现有 SAR Gaussian image reconstruction fundamentally different。

4. **Ewald-resolvable densification theorem**：moment-preserving Gaussian split 使 measured scattering perturbation从 \(O((q_td)^2)\) 提升到 \(O((q_td)^4)\)，由此得到 noise-aware resolution gate 和 loss-continuous model-order continuation。

5. **Physical-integrability constraint**：证明独立 Gaussian normal/jump field 存在 data-invisible transverse gauge；利用 \(b=-\nabla\chi\) 的 curl-free/closed-interface structure 删除 graphics-style nonphysical degrees of freedom。

6. **Adaptive algorithm**：residual-driven birth + Ewald-certified split + physics-aware merge/prune；不是照抄 3DGS densification。Generic matched-filter birth 本身不是 novelty，所以论文重点必须放在“什么时候允许增加自由度”上。

这五个理论结构中的后四个，才是让我从“Gaussian basis 已经被做烂了”重新觉得这个方向值得看的原因。

# 二十七、它在 computational complexity 上真正的优势是什么？

不要宣传：

\[
O(MP)<O(N\log N)
\]

这种很容易被 reviewer 打掉的话。

FFT Born inversion 在规则 grid 上非常快。

真正的 complexity argument 是**未知量维数**。

对于 characteristic size \(L\)、desired resolution \(h\)：

volume voxel 数量：

\[
N\sim\frac{L^3}{h^3}.
\]

surface primitive：

\[
P\sim\frac{L^2}{h^2}.
\]

所以：

\[
\boxed{
\frac PN
\sim
\frac hL.
}
\]

分辨率越高，codimension-one representation 的优势越明显。

Direct analytic surfel renderer：

\[
O(MP).
\]

每个 primitive 大约只有：

\[
\mu,\quad n,\quad \Lambda,\quad A,\quad \Delta\epsilon
\]

这么一组参数。

但我仍然不会把 runtime 当 headline，因为 BEM/RBF shape methods同样利用 surface dimensionality。

headline 应该是：

\[
\boxed{\text{representation complexity follows measurable complexity}.}
\]

也就是说 measurement 分辨不到的 scale 根本不允许生成 primitive。
