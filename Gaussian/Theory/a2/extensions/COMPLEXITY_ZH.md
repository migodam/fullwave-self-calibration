# 新分支的复杂度：参数少，不等于正演更便宜

设N为空间状态单元数（N128时N=16384），K为Gaussian个数，p=6K为实材料参数数，F为频率数，T为发射数，R为接收数，I为线性求解迭代数。本实现接收矩阵显式保存、内部传播使用FFT；省略常数和FFTpadding比例。

|计算|主要计算量|主要存储|含义|
|---|---|---|---|
|全波正演或伴随|O(FT I N log N + FRTN)|O(FTN + FRN)|Gaussian和voxel都需要物理状态求解；不会因为p小就消失|
|Gaussian渲染与反传|O(NK)|O(NK)，当前朴素向量化|本实现会保存所有点与Gaussian的中间量；可能比voxel更费临时存储|
|voxel材料映射|O(N)|O(N)|自由度大，先验与优化条件不同；不等于图像一定更差|
|一次完整隐式梯度|每频每发射一次正演+一次伴随，加表示反传|无需完整m×p Jacobian|因此材料p增加不要求逐参数解一次状态方程|
|显式参数切空间Jacobian|约FTp个线性RHS，加状态准备|O(mp)，m为实测量维数|先构建完整J再SVD，不能凭参数截断宣称节省构建成本；当m<p时还应比较接收伴随/对偶构建|
|有限secant探索|每个物理候选另付FT个RHS|候选状态与既有J|候选多、成功少时可能比完整更新更贵；需要质量—预算比较|
|8二值区域精确posterior|2⁸状态场构建；每数据组O(2⁸m)|O(2⁸m)|是小规模可信参照，扩到L区域为指数2^L，不能叫可扩展概率成像|
|固定RBF-logit VI|每次目标遍历2⁸状态，另加小参数优化|同一场缓存|低维参数没有消除字典构建，且可能限制后验模式|

GPU主比较每法120步：4320个forward RHS、4320个adjoint RHS，终点评价另有36个forward RHS。批量BiCGSTAB的迭代数是每次批量系统的共同循环次数，不是所有独立RHS迭代数之和。最终每步真实残差均被检查，阈值不包含离散/模型误差。

`actual_optimization_seconds`含逐步checkpoint写入；它是此执行策略下的优化与存档墙钟，不是纯CUDA kernel时间。数据生成、首次接收/传播算子构建、反演算子首次构建分别报告。模拟数据生成不是实际部署获取测量的成本，不能混入每次反演来人为摊薄/放大优势。

main128的显存字段为进程累计峰值；只能报全程峰值，不能拿每case末尾的历史峰值比较各表示。CPU峰值由远端进程快照观察，是截至观测时刻的进程峰值，未必覆盖全程最大值，更不是各方法独立峰值。

这里的torch.nn.Module只封装待反演参数，逐物体Adam拟合也不是跨样本训练的NN方法。多频batch、隐式伴随和FFT求解都是工程实现与已知数值结构；任何Gaussian原生SOM或NN贡献，仍须证明它比这些强实现多带来什么。

三类大规模目标处于同一40cm视场、1.25–2.75GHz频段。尖边并不只受Gaussian容量影响；有限带宽/接收孔径、迭代与正则化也会使voxel边界变圆。比较材料误差和留出场出现相反排序时，不能仅由较低场残差推出边界受数据支持。诊断需要显式界面/TV强基线、采集变化和模型误差控制；训练图像锐化网络并不能跳过这些步骤。
