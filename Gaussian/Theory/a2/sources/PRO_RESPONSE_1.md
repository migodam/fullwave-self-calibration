## 我的裁决：可以立项，但主线应收敛到“误差认证的材料结构选择”，而不是 Gaussian＋GNN

我建议选择 **问题一＋问题三中必要的有限幅度结构判定**，暂时取消 NN 主贡献，也不加入 geometry/phase calibration。

整篇论文最值得检验的机制是：

> **当新增材料结构带来的测量变化，小于电流截断、数值求解与正演失配可能造成的变化时，不允许把它解释成材料细节；应先补电流空间，或者明确输出“无法确定”。**

本轮我已经补出了一个**适用于明确非空有损材料类的离散全波误差证书**，并实现了不使用 NN 的端口增广原型。在三个已知材料的 3 GHz 正演探针中，最终用 **168、176、168 个端口**通过了校正散射场 **0.25% 相对误差**的认证门槛。

但必须同时收紧原创性判断：2024 年已经有研究把**参数空间自适应、状态空间降阶、误差认证和信赖域优化**结合起来。因此，“材料与电流共同自适应”本身也不能直接作为新贡献。真正需要证明和验证的区别，是它能否控制全波成像中的**假分裂、假结构**，并胜过成熟的误差驱动方法。citeturn861883view2

下面给出本轮能够成立的理论、实际计算结果和算法。原始 A1、A1_2 未修改；本轮没有重新执行原来的 84 次材料反演。

# 一、先把“增加节点还是增加模式”改成一个语义正确的问题

这里实际有三种复杂度：

\[
\boxed{
K_{\mathrm{mat}}=\text{材料 Gaussian 数量}
}
\]

\[
\boxed{
n_{\mathrm{patch}}=\text{电流空间的局部区域数量}
}
\]

\[
\boxed{
p_i=\text{第 }i\text{ 个区域的电流模式数},
\qquad R=\sum_i p_i.
}
\]

**增加电流 patch，不等于增加一个材料夹杂；增加材料 Gaussian，也不要求自动增加一个散射网络节点。**

你的当前实现中，16 个网络节点是电流区域，而材料只有 3 个 Gaussian 分量。它们不是同一种节点。

这一区分直接决定算法应该回答什么：

- 需要更多**电流自由度**，是因为现有空间不足以表达当前候选材料产生的物理状态。
- 需要更多**材料自由度**，是因为经过可靠正演和旧参数重新拟合之后，数据仍排除了原材料模型。
- 两者都不能可靠判定时，答案应当是**证据不足**，而不是继续增加 Gaussian。

下面的证书先解决第一件事，再为第二件事提供可信的误差预算。

# 二、一个不依赖 Born 近似、也不需要全维逆矩阵的稳定性证书

从你包里的模型出发：

\[
A_\chi j=f_\chi,\qquad
A_\chi=I-X_\chi D,\qquad
f_\chi=X_\chi E.
\]

这里允许 \(j,E\) 的不同列对应不同照明。令

\[
C=WS
\]

表示固定白化后的接收算子。

## 2.1 关键不是直接估计 \(\|A_\chi^{-1}\|\)，而是换到本构形式

在非零对比度的活动单元上定义

\[
B_\chi=X_\chi^{-1}-D.
\]

于是

\[
B_\chi j=E.
\]

对于当前二维标量、均匀网格、出射 Hankel-1 的离散核，非对角项满足

\[
D_{ij}
=
\frac{i k^2h_g^2}{4}
H_0^{(1)}(k|x_i-x_j|).
\]

其中 \(h_g\) 是网格间距。把实际代码的对角自作用项记为 \(d_0\)，定义

\[
\delta_g
=
\operatorname{Im}d_0-\frac{k^2h_g^2}{4}.
\]

**这个离散自作用修正不能省掉。**

### 定理 1：可计算的吸收稳定性下界

若

\[
\boxed{
\beta_\chi
=
\min_i
\frac{\operatorname{Im}\chi_i}{|\chi_i|^2}
+\delta_g
>0,
}
\]

则

\[
\boxed{
-\operatorname{Im}_{H}B_\chi\succeq\beta_\chi I,
\qquad
\|B_\chi^{-1}\|_2\le\frac1{\beta_\chi}.
}
\]

这里

\[
\operatorname{Im}_{H}B=\frac{B-B^*}{2i}
\]

是矩阵的反 Hermitian 部分所对应的 Hermitian 算子。

### 证明

利用

\[
J_0(k|x_i-x_j|)
=
\frac1{2\pi}
\int_0^{2\pi}
e^{ik\widehat s(\phi)\cdot(x_i-x_j)}
\,d\phi,
\]

可知矩阵

\[
G_{ij}=J_0(k|x_i-x_j|)
\]

是半正定 Gram 矩阵。因此

\[
\operatorname{Im}_{H}D
=
\frac{k^2h_g^2}{4}G+\delta_g I
\succeq\delta_g I.
\]

另一方面，

\[
-\operatorname{Im}\frac1{\chi_i}
=
\frac{\operatorname{Im}\chi_i}{|\chi_i|^2}.
\]

所以，对任意 \(v\)，

\[
\beta_\chi\|v\|^2
\le
-\operatorname{Im}(v^*B_\chi v)
\le
|v^*B_\chi v|
\le
\|v\|\,\|B_\chi v\|.
\]

即得结论。

---

## 2.2 这不是一个“只有极弱散射才成立”的空条件

对你代码采用的材料形式

\[
\chi_i=a_i(1+i\tau),\qquad 0<a_i\le a_{\max},
\]

有统一下界

\[
\boxed{
\beta_{\mathrm{unif}}
=
\frac{\tau}{a_{\max}(1+\tau^2)}
+\delta_g.
}
\]

本轮直接按实际核计算：取整个材料类 \(0<a_i\le1\)，在三个采样频点分别得到：

| 频率 | 当前损耗比 \(\tau\) | 统一稳定下界 |
|---|---:|---:|
| 1.5 GHz | 0.030 | 0.0297363 |
| 2.25 GHz | 0.020 | 0.0187966 |
| 3 GHz | 0.015 | 0.0112322 |

这证明存在一个**明确非空、包含非 Born 情形的材料类**，其稳定常数不需要通过全维 SVD 或全维求逆取得。计算该下界只需材料幅值范围和已知离散自作用项。

还可以得到

\[
A_\chi^{-1}=I+B_\chi^{-1}D,
\]

从而

\[
\boxed{
\|A_\chi^{-1}\|
\le
1+\frac{\|D\|}{\beta_\chi}.
}
\]

这避免了 Gaussian 尾部 \(\chi\) 很小时，粗暴使用 \(\|X^{-1}\|\) 造成的人为发散。

**边界也很明确：**损耗趋零、对比度过大或离散核改变时，这个下界可能失效。失效不等于原物理问题不可解，只意味着这份证书不能用了。当前证明也不能直接推广成三维向量 Maxwell 定理。

# 三、把稳定性变成真正检查“端口够不够”的场误差证书

## 3.1 必须检查全维残差，而不是约化残差

设当前近似为 \(j_Q=Qb\)，定义

\[
r=f_\chi-A_\chi j_Q.
\]

若 \(Q^*Q=I\)，则

\[
r=
Q(Q^*r)+(I-QQ^*)r.
\]

第一部分对应约化系统的求解误差；第二部分对应当前电流空间无法表达的部分。

即使精确求解了

\[
Q^*A_\chi Qb=Q^*f_\chi,
\]

也只是令

\[
Q^*r=0,
\]

并不会令 \(r=0\)。

**这正是“96 端口精确求解仍然成像错误”的数学位置。**

## 3.2 定理 2：本构修正＋原—伴随残差的接收场认证

先进行一次本构修正：

\[
j_c=j_Q+r=X_\chi(E+Dj_Q).
\]

取一个近似伴随解 \(\widetilde Z\)，目标方程为

\[
B_\chi^*Z=C^*,
\]

其残差记为

\[
T=C^*-B_\chi^*\widetilde Z.
\]

定义**校正后的接收场**

\[
\boxed{
F_c=Cj_c+\widetilde Z^*Dr.
}
\]

则有

\[
\boxed{
\|Cj-F_c\|_F
\le
\eta_\chi
:=
\frac{\|T\|_2\,\|Dr\|_F}{\beta_\chi}.
}
\]

### 证明

由本构修正可得

\[
B_\chi j_c=E-Dr,
\]

因此

\[
j-j_c=B_\chi^{-1}Dr.
\]

又因为

\[
C=\widetilde Z^*B_\chi+T^*,
\]

所以

\[
Cj-F_c
=
T^*B_\chi^{-1}Dr.
\]

代入定理 1 即得。

这个结果具有三个实际用途。

**第一，它检查的是全维物理闭合。**遗漏的电流模式不能靠把约化系统解得更精确来掩盖。

**第二，它针对接收场，而不是要求所有内部电流分量同等准确。**伴随问题把“哪些状态误差会进入测量”放进了估计器。

**第三，它不要求知道全维精确解。**本轮脚本中的全维解只用于检验实际误差，没有参与端口选择或停止规则。

不过，原—伴随残差乘积本身属于已有的目标导向误差估计思想，不能把它包装成全新理论。已有参数识别降阶研究也明确使用原、伴随残差及稳定常数来认证目标函数误差。citeturn861883view3

### 两个不能混淆的结论

\[
\boxed{
\eta_\chi\text{ 认证的是 }F_c，
\text{不是原始 }Cj_Q。
}
\]

原始场只能用

\[
\|Cj-Cj_Q\|_F
\le
\|F_c-Cj_Q\|_F+\eta_\chi
\]

来界定。

另外：

> **证书比较的是“同一个候选材料下”的约化正演与全维正演，不是在证明这个候选材料就是真材料。**

材料正确性还需要下一节的逆问题与模型比较。

# 四、本轮实际跑出来了什么

## 4.1 一个值得保留的负结果

我先测试了局部耦合范数构造的非负比较矩阵：

\[
G_{ij}
=
\|A_{ii}^{-1}A_{ij}\|_2.
\]

这类估计器通常需要 \(\rho(G)<1\)。

三个目标在 3 GHz 下的比较矩阵谱半径约为

\[
1.235,\qquad1.516,\qquad1.695.
\]

**三个都无法通过这个充分条件。**

部分低频情形虽然通过了，但得到的相对场误差上界达到百分之一百乃至数百，实用性很差。问题在于块范数丢掉了相位抵消，界过于保守。

因此，不能拿这个简单局部耦合界作为主要理论结果。

## 4.2 吸收证书成立，但固定 HG 空间仍可能很难认证

在同样三个 3 GHz 目标上，实际材料对应的 \(\beta_\chi\) 都为正。

不过，固定 336 端口时，校正场的认证半径仍分别约为：

\[
1.93\%,\qquad2.36\%,\qquad16.20\%.
\]

也就是说：

> **校正场实际很准确，不代表我们已经有足够紧的证书。**

这是第二个必须保留的限制。

## 4.3 不用 NN，改用原—伴随残差增广

我实现了一个很直接的经典基线：

每轮求约化原问题和互易伴随问题；计算全维残差；在各局部区域求残差修正；去掉旧空间分量；局部 SVD 后，从八个最大的候选中各增加一个模式。

从 96 端口开始，停止条件为

\[
\boxed{
\eta_\chi
\le
0.0025\,
\bigl(\|F_c\|_F-\eta_\chi\bigr),
}
\]

且右侧括号必须为正。这里使用的是未知真场范数的可信下界，**没有用真值决定何时停止**。

得到：

| 已知材料，3 GHz | 最终端口数 | 原始场实际误差 | 校正场实际误差 | 校正场认证半径 |
|---|---:|---:|---:|---:|
| 分开的平滑区域 | 168 | 0.10042% | 0.0000177% | 0.05529% |
| 相邻平滑区域 | 176 | 0.10468% | 0.0000401% | 0.14953% |
| 尖边＋平滑区域 | 168 | 0.07312% | 0.0000176% | 0.08614% |

**这是本轮最有实质意义的正面结果：端口空间的选择方式，比机械增加 HG 阶数更重要。**

但是，准确解释这张表需要保留以下边界：

这些是**已知材料的正演探针**，不是新材料反演；没有证明端到端更快；构造过程中支付了局部全维逆、全维残差和 SVD 的成本；新模式是复数残差自适应模式，不再全部是固定 HG 模式。

尤其是第三行：它只说明在同一个 \(32^2\) 离散模型里闭合得很好。**它不能消除你报告里尖边目标的网格误差，更不能据此证明真实尖边恢复成功。**

因此，这个结果支持继续研究，但不支持宣布“Gaussian 网络已经胜过传统方法”。

# 五、怎样把场误差真正转化成材料误判控制

这里需要同时回答两个层次：材料参数的局部偏差，以及新增结构是否有独立解释力。

## 5.1 有条件的材料偏差界

设 \(\mathcal F(\theta)\) 为实化、白化后的全维离散正演。在一个凸邻域内，假设

\[
\sigma_{\min}(J_0)=s>0,
\qquad
\sup_{\theta}\|J(\theta)-J_0\|\le L_Jr<s.
\]

沿两点间的线段积分 Jacobian，可以直接证明

\[
\boxed{
\|\mathcal F(\theta_1)-\mathcal F(\theta_2)\|
\ge
(s-L_Jr)\|\theta_1-\theta_2\|.
}
\]

因此，对邻域内的恢复结果 \(\widehat\theta\) 和可表示的参考材料 \(\theta_0\)，

\[
\boxed{
\|\widehat\theta-\theta_0\|
\le
\frac{
\|F_c(\widehat\theta)-y\|
+\eta(\widehat\theta)
+\varepsilon_{\mathrm{noise}}
+\varepsilon_{\mathrm{grid/model}}
+\varepsilon_{\mathrm{class}}
}{
s-L_Jr
}.
}
\]

其中：

\(\varepsilon_{\mathrm{grid/model}}\) 是离散与物理模型误差；\(\varepsilon_{\mathrm{class}}\) 是真实材料不能被当前材料族表达所造成的测量误差。

**这两个量不能被端口证书替代。没有可信的上界，就不能声称材料偏差已经认证。**

这个结果也不是全局 Fisher 保证。它要求局部参数表示规则、没有冗余、没有未处理的 gauge。你目前用三分量拟合两个区域，可能存在冗余分量或近重合分量，不能不检查就假定 \(s>0\)。

## 5.2 A1 已有四阶分裂，真正需要加强的是“旧参数重新拟合后”

A1 已经包含 full-wave 下的四阶分裂论证，所以我不把它算作今天的新发现。

考虑保矩分裂：

\[
g_h
=
\frac12g(\mu+hv,\Sigma-h^2vv^T)
+
\frac12g(\mu-hv,\Sigma-h^2vv^T),
\]

其中协方差保持正定。则

\[
\chi_h-\chi_0
=
h^4\psi+O(h^6),
\qquad
\psi=-\frac a{12}(v\cdot\nabla)^4g.
\]

全波材料导数为

\[
\boxed{
D\mathcal F_\chi[\Delta\chi]
=
CA_\chi^{-1}\Delta X\,u_\chi,
\qquad
u_\chi=E+Dj_\chi.
}
\]

令

\[
v_4=D\mathcal F_{\chi_0}\psi.
\]

**不能直接用 \(\|v_4\|\) 当新增结构的解释力。**因为旧 Gaussian 的幅值、位置、尺度和形状可以重新调整，吸收掉其中一部分。

设旧材料模型的 Jacobian 为 \(J_{\mathrm{old}}\)，在实化白化度量下定义

\[
P_\perp
=
I-J_{\mathrm{old}}J_{\mathrm{old}}^\dagger.
\]

在旧模型像是规则光滑流形、局部最近投影唯一等条件下，可得：

\[
\boxed{
D_{\mathrm{old}}(h)
:=
\inf_{\theta\in\text{旧模型局部邻域}}
\|\mathcal F(\chi_h)-\mathcal F(\theta)\|
=
|h|^4\kappa_4+O(|h|^6),
}
\]

其中

\[
\boxed{
\kappa_4=\|P_\perp v_4\|.
}
\]

**证明要点：**材料扰动从 \(h^4\) 开始；全波非线性对该扰动的二次余项是 \(O(h^8)\)；旧模型重新拟合在最低阶消去切向分量，剩下 \(P_\perp v_4\)。因此主余项仍由材料展开的 \(O(h^6)\) 控制。

于是，在一个有明确余项常数的邻域内，

\[
\boxed{
D_{\mathrm{old}}(h)
\ge
\kappa_4|h|^4-C_6|h|^6.
}
\]

如果 \(\kappa_4=0\)，就没有正的四阶分辨下界。它可能从更高阶开始，也可能存在真正歧义。

### 这里可以给出不只写作 \(O(\cdot)\) 的全波余项控制

令

\[
T_\Delta=A_0^{-1}\Delta X D,\qquad t=\|T_\Delta\|<1.
\]

则精确地有

\[
j_1-j_0
=
(I-T_\Delta)^{-1}A_0^{-1}\Delta X u_0,
\]

因此

\[
\boxed{
\|F_1-F_0-CA_0^{-1}\Delta X u_0\|_F
\le
\|C\|\frac{t}{1-t}
\|A_0^{-1}\Delta X u_0\|_F.
}
\]

这是**围绕一个允许强散射的基材料的小扰动条件**，不是要求基材料满足 Born 近似。前面的吸收界可以提供保守但可计算的 \(\|A_0^{-1}\|\) 上界。

## 5.3 一个直接解释“假分裂”的公式

经过旧参数重新拟合后，假设新增分裂方向最低阶为

\[
h^4v.
\]

如果正演误差在测量中留下了残差 \(b\)，优化器可能在解

\[
\min_{h\ge0}\|b-h^4v\|^2.
\]

这个最低阶问题的解是

\[
\boxed{
h_{\mathrm{apparent}}^4
=
\frac{\max\{\langle v,b\rangle,0\}}{\|v\|^2}.
}
\]

这给出了一个很具体的机制：

> **与新增结构方向对齐的数值物理误差，可以被解释成四次根尺度的材料分裂。**

这不是说所有误差都会产生分裂，而是说明：在允许旧 Gaussian 重新调整协方差的情况下，**较小的场误差可能对应不那么小的结构参数变化**。

因此，可信结构门槛应比较

\[
\kappa_4h^4-C_6h^6
\]

与噪声、端口误差、网格误差和优化不确定性的总预算，而不是只检查分裂 Jacobian 是否非零。

在所声明的局部条件下，会出现类似

\[
h_{\min}\sim
\left(
\frac{\varepsilon_{\mathrm{total}}}{\kappa_4}
\right)^{1/4}
\]

的尺度关系。**它不是普适 Rayleigh 极限，也不是超分辨保证。**

Gaussian 位置—尺度混合的弱可辨识性和高阶退化已有统计学研究，因此“四阶”这个指数本身不能作为新的普适数学发现。这里值得研究的是它与**全波正演误差、旧模型重拟合和结构接受规则**的具体结合。citeturn692513search6

### 本轮也检查了这个关系

在一个新构造的单 Gaussian、3 GHz 全波例子中，Born 场误差约为 **101.74%**。对保矩分裂后产生的数据，实际重新拟合旧模型的六个参数。

当 \(t=h/\sigma_x=0.08,0.12,0.18\) 时，局部重拟合距离与预测的 \(\kappa t^4\) 之比分别约为

\[
1.0105,\qquad1.0238,\qquad1.0546.
\]

这支持局部四阶关系，并显示有限幅度增大后的修正。**但数值优化得到的是局部拟合结果，不是全局 profile minimum 的认证下界。**

还有一个非常重要的语义限制：

\[
\boxed{
\text{两个 Gaussian 分量}\neq\text{两个已经分辨的物理缺陷。}
}
\]

小幅保矩分裂后的材料仍可能只有一个峰。这个定理首先控制的是**新增形状自由度**；真正的双缺陷分辨，必须另行定义峰谷、连通区域等结构事件。

# 六、可直接实现的联合选择算法

## 6.1 用可信区间比较材料候选

对一个候选材料，令

\[
d_c=\|F_c-y\|.
\]

真实离散正演的拟合残差满足

\[
\boxed{
d_{\mathrm{exact}}
\in
[\ell,u]
=
[\max(0,d_c-\eta),\,d_c+\eta].
}
\]

于是平方损失位于

\[
\left[\frac12\ell^2,\frac12u^2\right].
\]

若使用事先固定的复杂度惩罚，只有当

\[
\boxed{
\frac12u_{\mathrm{new}}^2+\lambda_{\mathrm{new}}
<
\frac12\ell_{\mathrm{old}}^2+\lambda_{\mathrm{old}}
}
\]

时，才能确定这两个候选之间的改进不是由降阶误差制造的。

但是，**这仍然只比较两个候选点。**

要证明整个旧模型不够，必须得到旧模型最优损失的下界。例如，有可信优化间隙 \(g_{\mathrm{opt}}\) 时，

\[
L_{\mathrm{old}}^{\min}
\ge
\frac12\ell_{\mathrm{old}}^2-g_{\mathrm{opt}}.
\]

仅仅做多起点拟合、找到一个较好的旧模型解，得到的仍主要是最小值的**上界**，不能反过来声称已排除所有旧模型。

## 6.2 算法流程

```text
固定当前材料族、当前电流空间 Q 和信赖域。

1. 拟合已有材料参数；计算原问题、伴随问题和全维残差。
2. 计算稳定下界 beta、校正场 Fc、误差半径 eta。

3. 如果约化代数误差过大：
       改善状态求解，不增加材料复杂度。

4. 如果端口闭合不确定性足以掩盖候选结构信号：
       比较局部模式增广与电流 patch 细分；
       按实测的“认证误差下降 / 新增总成本”选择；
       保留旧空间，重新正交化，再启动内层拟合。

5. 如果正演已足够可靠：
       先重新拟合旧材料参数；
       生成合法的移动、形变、分裂候选；
       消除旧切空间解释，再做有限幅度正演比较。

6. 只有通过可信损失区间的候选，才接受为数值模型更新。
   只有排除了旧结构可行性，才宣称新结构得到数据支持。

7. 如果差异低于噪声、网格或模型误差预算：
       输出“无法确定”，而不是强制增加 Gaussian。
```

**当前交付已经实现第 1–4 步中的正演认证与端口增广原型；完整材料外循环没有在本轮执行。**

改变 \(Q\) 时，不应假装整个过程仍然光滑。建议每次内层材料拟合冻结 \(Q\)，增广发生在外层；改变空间后重新检查目标函数，并重启不再一致的优化历史。

同样，非自伴系统中的嵌套 Galerkin 空间，不保证原始输出误差逐次单调下降。候选增广的效果应当实际认证，不能从“模式更多”直接推断。

## 6.3 怎样正确输出“无法确定”

定义保守的可行材料集合

\[
\mathcal C_y
=
\left\{
\theta:
\|F_c(\theta)-y\|
\le
\varepsilon_{\mathrm{noise}}
+\varepsilon_{\mathrm{grid/model}}(\theta)
+\eta(\theta)
\right\}.
\]

只有当所有可行模型都具有某个结构事件，才有资格把该事件称为数据支持。

这里存在一个很有用的不对称性：

> **找到一个满足误差预算的单结构解，就足以否定“数据必须要求双结构”；证明“必须双结构”，却需要排除整个允许的单结构模型类，或者明确限定为某个局部邻域。**

这比输出一张“看起来分开了”的图像更有工程意义。

# 七、NN 与现有方法：哪些应该明确取消新颖性主张

## 7.1 “相互作用可达端口”首先是经典 Krylov 思想

令

\[
P=\operatorname{blkdiag}(A_{ii}^{-1}),
\qquad
K_{\mathrm{it}}=I-PA.
\]

从外部激励开始，有限次相互作用产生的空间为

\[
\mathcal R_s
=
\operatorname{span}
\{Pf,K_{\mathrm{it}}Pf,\ldots,K_{\mathrm{it}}^sPf\}.
\]

**在未截断、未压缩的情况下，这正是 block Krylov 空间。**这不是相似，而是定义上的相同。

再加入伴随可见性、局部压缩，就进入了目标导向降阶和局部端口空间构造的范畴。Smetana–Patera 已经通过传递算子及谱贪心构造最优或近最优局部端口空间，虽然他们的证明设置与这里的散射系统不同。citeturn176998view2

也要反过来避免过度等同：把原、伴随快照拼起来做 SVD，**不等于严格的 balanced truncation**。后者需要匹配的可控、可观 Gramian 与平衡结构，不能借名称自动继承误差定理。

## 7.2 现有组合已经很多

| 最近邻 | 已经覆盖的部分 | 你的路线不能据此宣称什么 |
|---|---|---|
| Ye 等的 T-matrix＋SOM | 用 T-matrix 建模并扩展 SOM 处理混合散射体 | “首次将散射矩阵与 SOM 结合”。citeturn861883view5 |
| Uysal–Akleman 的 HG/GSM | 用 HG 基函数建立级联两端口传播关系；本轮核对到机构摘要 | “HG＋散射网络”本身就是新机制。citeturn692513search7 |
| 自适应参数／状态降阶 | 联合减少参数与状态空间，并使用误差感知信赖域 | “共同选择材料和状态维数”本身新颖。citeturn861883view2 |
| PhiGRL、U-PINet | 物理残差、图结构、近远场相互作用等神经求解结构 | “NN 嵌入散射状态方程”就足以构成贡献。citeturn911336view0turn176998view0 |
| 粒子散射图网络 | 用图网络处理气溶胶粒子的光学散射性质 | “散射粒子之间传消息”此前没人做。citeturn861883view1 |

这些论文的任务并不完全相同，不能把其性能数字直接拿来排名；但足以否定仅靠组合名称建立原创性的做法。

## 7.3 对问题二，我的主方案就是：当前不需要 NN

不是四条路线都留着，而是先把当前学习阻尼器从核心贡献中拿掉。

本轮的正面端口结果完全不依赖 NN。此时继续增加网络深度或训练轮数，很可能仍然只是在解决次要误差。

以后唯一值得优先考虑的学习角色，是**提出或排序端口增广候选**：学习哪一个局部模式最可能以较低成本降低认证误差，而不是直接决定材料图像。接受与否仍由物理证书判断，训练目标应包含完整验证成本和失败候选成本。

我不建议现在学习一个“测量唯一决定的内部 Schur 矩阵”。因为

\[
M=CKB
\]

只能约束输入—输出组合；只要

\[
C\Delta K B=0,
\]

就无法从这些数据区分 \(K\) 与 \(K+\Delta K\)。

而且消去隐藏状态后，改变的不仅是 Schur 自能，还包括有效激励、有效读出和直达修正。只学习一个矩阵而保持其他映射不变，通常并不构成一致的消元模型。

至于物理约束，当前电流系数矩阵并不是功率归一化 S 参数。不能把奇异值裁剪到 1 以下就称为“保证被动性”。本轮真正用到的替代条件是**明确材料类下的耗散稳定性与场误差认证**。

# 八、成本、决定性实验与最终去留标准

## 8.1 本轮没有证明更快

当前原型必须支付以下成本：

| 环节 | 稠密实现的主要成本 |
|---|---|
| 构造／存储传播算子 | \(O(N^2)\) |
| 新建或更新 \(DQ\) | \(O(N^2R)\)，增量更新可按新增列计算 |
| 材料相关投影装配 | \(O(NR^2)\) |
| 约化分解与多右端求解 | \(O(R^3)+O(R^2(L+m_g))\) |
| 全维残差、校正与伴随相关作用 | 通常 \(O(N^2(L+m_g))\) |
| 局部全网格逆与候选压缩 | \(\sum_iO(n_i^3)\) 加局部 SVD 成本 |

这里 \(m_g\) 是实际认证的输出／伴随方向数量。

尤其要注意：本轮局部候选使用的是 **64×64 全网格局部块**，不能把它记成只有几个端口的小矩阵成本。

因此：

\[
\boxed{
R\text{ 从 }336\text{ 降到 }168
\quad\not\Rightarrow\quad
\text{端到端速度提高一倍。}
}
\]

在 \(N=1024\) 这种规模，直接解依然可能非常有竞争力。本轮也没有完成峰值 RSS 测量。

## 8.2 应当冻结的核心实验

我建议主任务锁定为：

> **在一个已粗定位的异常区域内，系统能否正确决定：补电流空间、更新原材料形状、接受额外结构，还是拒绝作出结构结论？**

先做明确限定的局部／低维材料类别，不宣传从任意初值出发的全局结构识别。

新测试不能复用当前三个探针或已参与开发的场景。建议每个主条件至少 30 个独立材料结构，配多个噪声实现；不同方法共享对象、噪声与初值，置信区间按**材料对象**聚合，不能把数千个右端当成数千个独立样本。

最关键的比较不是再赢一次块 Jacobi，而是：

**完整预条件 GMRES、固定高阶 HG、普通残差增广、成熟原—伴随降阶、参数／状态联合误差感知信赖域方法，以及适当匹配后的 TSOM/CSI。**

下面是一组可预注册的验收标准，属于建议的工程阈值，不是定理自带常数：

| 验收项 | 建议门槛 |
|---|---|
| 离散证书有效性 | 在声明模型和算术容限内不出现错误上界；证书不可用必须显式计数 |
| 实用性 | 大多数声明材料类中的场景在预算内达到目标物理精度，而不是只报告成功案例 |
| 假结构控制 | 独立单结构对象上的假分裂率，其单侧 95% 上置信界不超过 5% |
| 有效分辨能力 | 对具有独立确认分离裕量的对象，达到预注册的检出率，同时报告拒判率 |
| 完整成本收益 | 在相同物理精度和假结构上限下，相对最强适用基线获得例如 20% 的总耗时下降，且配对置信区间排除无收益 |

例如，100 个独立单结构对象中没有一次假分裂，对应的单侧 95% 二项上界约为 2.95%。同一对象的多个噪声重复不能未经处理就当作独立对象来计算这个上界。

独立网格和独立正演必须进入验收。尤其是尖边：如果网格误差已经高于噪声和结构信号，算法的正确表现可能是**拒绝新增结构结论**，而不是恢复一张更锐利的图。

# 最终判断

**可立项，但目前只能认定为一条有实际起点、能够被明确证伪的研究路线，不能认定为已经建立 TAP 主贡献。**

本轮真正推进了三件事：

**第一，**在明确的有损二维标量离散材料类中，给出了不依赖 Born 条件、不需全维求逆取得稳定常数的接收场误差证书。

**第二，**实际实现了原—伴随残差驱动的端口增广，证明至少在三个困难正演探针里，问题不是“必须堆到很多固定 HG 模式”，也不是“必须依靠 NN”。

**第三，**把 A1 的四阶分裂论证收紧为“旧参数重拟合后的结构信号”，并明确了数值物理偏差如何制造假分裂、怎样用有限误差预算拒绝不可信结构。

尚未成立的是：**完整联合反演是否更可靠、更省成本，以及这种优势是否超出成熟自适应降阶方法。**如果冻结实验显示后者已经能做到同样的结构判定、且总成本更低，就应该取消这条路线的独立方法贡献，而不是再换一个 Gaussian 名称。

所以我建议保留的论文中心句是：

> **重建允许增加多少材料细节，必须由测量能够支持的结构变化与正演能够认证的误差共同决定，而不能由优化器还有多少拟合自由度决定。**
