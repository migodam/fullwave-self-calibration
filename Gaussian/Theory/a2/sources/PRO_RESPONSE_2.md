# 二、问题一的第一个闭合点：找到不依赖 Born 的廉价稳定性证书

## 2.1 改写状态方程，但必须承认有限维算法变了

## 2.2 定理一：耗散给出可计算的全波稳定性

先考虑质量白化后的离散坐标，记

\[
\operatorname{Im}D=\frac{D-D^\ast}{2i}.
\]

假设已经知道

\[
\operatorname{Im}D\succeq-\delta_h I,
\]

并定义

\[
\boxed{
\Gamma_\chi
=
\operatorname{diag}
\left(
\frac{\operatorname{Im}\chi_n}{|\chi_n|^2}
-\delta_h
\right).
}
\]

只要

\[
\Gamma_\chi\succ0,
\]

就有

\[
\boxed{
-\operatorname{Im}(z^\ast L_\chi z)
\ge z^\ast\Gamma_\chi z,
}
\]

以及

\[
\boxed{
\|L_\chi^{-1}r\|_{\Gamma_\chi}
\le
\|r\|_{\Gamma_\chi^{-1}}.
}
\]

这里

\[
\|z\|_\Gamma^2=z^\ast\Gamma z.
\]

### 证明

因为

\[
\operatorname{Im}\frac1\chi
=
-\frac{\operatorname{Im}\chi}{|\chi|^2},
\]

所以

\[
-\operatorname{Im}(z^\ast L_\chi z)
=
z^\ast
\left[
\operatorname{diag}
\left(\frac{\operatorname{Im}\chi}{|\chi|^2}\right)
+\operatorname{Im}D
\right]z
\ge \|z\|_\Gamma^2.
\]

令 \(L_\chi z=r\)，再用加权 Cauchy–Schwarz：

\[
\|z\|_\Gamma^2
\le |z^\ast r|
\le \|z\|_\Gamma\|r\|_{\Gamma^{-1}}.
\]

约去 \(\|z\|_\Gamma\) 即得结论。严格耗散同时保证有限维可逆性；将向量限制到任意子空间，也保证 \(L\)-Galerkin 的可逆性。

**这里没有用 \(\|XD\|<1\)，也没有截断多次散射。**

用耗散限制 T 算子或极化电流响应，是已有电磁理论的重要起点；这里给出的是针对你这套状态方程和离散规则的加权残差版本，不把耗散思想本身算作新发现。citeturn789257view0

由

## 一个必须主动取消的“伪增益”

分别对应材料类失配、离散误差、未建模物理和测量噪声。不能把前三项都重新命名为噪声。

证明是沿连线积分，以固定 \(J_0\) 为主项控制余项。**它是带半径条件的局部结果，不是 Fisher 意义上的全局恢复保证。**

## 4.1 四阶 Gaussian 分裂已经在 A1 中，不是本轮新发现

这里 \(a\) 是质量幅度，不是保持不变的峰高。

真正需要补充的是：**它经过完整全波传播、并允许旧参数重新拟合之后，还剩多少信号？**

## 4.2 完整全波余项：不是只写一句 Taylor 展开

记

\[
\mathcal R_\chi=A_\chi^{-1},
\qquad
U_\chi=E+DJ_\chi.
\]

对任意有限材料变化 \(\Delta\)，有精确恒等式

\[
F(\chi+\Delta)-F(\chi)
=
C\mathcal R_{\chi+\Delta}
\operatorname{diag}(\Delta)U_\chi,
\]

因此

\[
DF_\chi[h]
=
C\mathcal R_\chi\operatorname{diag}(h)U_\chi.
\]

更重要的是，

\[
\boxed{
\begin{aligned}
&F(\chi+\Delta)-F(\chi)-DF_\chi[\Delta]\\
&=
C\mathcal R_{\chi+\Delta}
\Delta X D
\mathcal R_\chi
\Delta X U_\chi.
\end{aligned}
}
\]

这来自两组状态方程相减与 resolvent 恒等式，保留了全部多次散射。

所以可以计算一个明确的余项上界 \(E_t\)，使

\[
\boxed{
\|F(\chi_t)-F(\chi_0)-t^4v_4\|
\le E_t,
\qquad
v_4=DF_{\chi_0}[\psi_4],
}
\]

且在统一稳定邻域内

\[
E_t=O(t^6+t^8).
\]

完整文档给出了用耗散界、\(\|D\|\)、总场上界及实际 \(r_\chi(t)\) 计算 \(E_t\) 的公式，不要求用全维真值选秩。

## 4.3 定理三：旧参数重拟合后的有限幅度间隔

以下数据已经实化、白化。

令旧材料模型的 Jacobian 为 \(J_0\)，并定义

\[
P_\perp=I-J_0J_0^\dagger,
\qquad
\boxed{c_4=\|P_\perp v_4\|.}
\]

如果有 nuisance，应把它放入同一个旧参数 Jacobian，先去掉真实 gauge。

令

\[
D_t=t^4\|v_4\|+E_t,
\]

并考虑旧参数可以在半径 \(r\) 内重新拟合时的最小距离：

\[
d_{\mathrm{old}}(t)
=
\inf_{\|\zeta\|\le r}
\|F(\chi_t)-F_{\mathrm{old}}(\theta_0+\zeta)\|.
\]

假设这个旧参数球内满足上一节的局部逆稳定性 \(\kappa>0\)，以及 Jacobian 的 Lipschitz 常数 \(L_J\)。

若

\[
2D_t<\kappa r,
\]

则

\[
\boxed{
d_{\mathrm{old}}(t)
\ge
t^4c_4-E_t-\frac{2L_JD_t^2}{\kappa^2}.
}
\]

若同时

\[
t^4\|J_0^\dagger v_4\|\le r,
\]

还有

\[
\boxed{
d_{\mathrm{old}}(t)
\le
t^4c_4+E_t
+\frac{L_Jt^8}{2}\|J_0^\dagger v_4\|^2.
}
\]

### 证明

取 \(\zeta=0\)，最优拟合误差至多为 \(D_t\)。任一最优 \(\zeta\) 因而满足

\[
\kappa\|\zeta\|
\le
\|F_{\mathrm{old}}(\theta_0+\zeta)-F_{\mathrm{old}}(\theta_0)\|
\le2D_t.
\]

展开旧模型：

\[
F_{\mathrm{old}}(\theta_0+\zeta)
=
F_0+J_0\zeta+R_{\mathrm{old}},
\qquad
\|R_{\mathrm{old}}\|\le\frac{L_J}{2}\|\zeta\|^2.
\]

施加 \(P_\perp\)，旧参数的一阶重拟合项消失，得到下界。上界取

\[
\zeta=t^4J_0^\dagger v_4
\]

即可。

**这个定理控制的是重拟合之后的独立解释力，而不是未投影的 Gaussian 导数强度。**

当 \(c_4=0\) 时，四阶信号完全可以被旧参数吸收。此时必须研究更高阶，或者直接做有限幅度模型比较，不能把一个很小的数值阈值当作物理可分性的证明。

# 五、一个更尖锐的结论：H4 分裂并不等于两个夹杂

对孤立的一维等权双 Gaussian，子分量中心为 \(\pm d\)，子方差为

\[
s^2=\sigma^2-d^2.
\]

非零临界点满足

\[
x=d\tanh(dx/s^2).
\]

当 \(d^2\le s^2\) 时，只存在中央峰；当 \(d^2>s^2\) 时，中央点成为局部最小，出现两个峰。因此

\[
\boxed{
\text{保矩等权分裂出现双峰}
\iff
\frac d\sigma>\frac1{\sqrt2}.
}
\]

这意味着：

> **小位移 H4 信号首先描述的是一个目标的形状或峰度改变，而不是两个目标已经被分辨。**

所以，新增一个 Gaussian 可以只是提高单个夹杂的形状自由度。论文中的“两个夹杂”必须由真实材料事件定义，例如两个满足最小质量要求的区域，以及足够深的峰间谷，不能由混合模型的分量个数定义。

本次检查中，小位移的重拟合后场差确实近似四阶；但当 \(d/\sigma=0.8\)、材料已经双峰时，实际重拟合距离约为四阶预测的 **3.34 倍**。

这不否定四阶渐近式，恰恰说明：**不能拿小扰动公式直接充当有限双目标分辨率定律。**

# 六、问题三如何真正闭合：有限模型比较与“无法确定”

## 6.1 定义有限幅度分辨率，而不是只画局部谱

对预先声明的紧材料类和结构事件 \(E\)，定义

\[
\mathscr D_E
=
\inf_{(\chi_1,\chi_2)\in E}
\|F(\chi_1)-F(\chi_2)\|_{\Sigma^{-1}}.
\]

若总误差球半径为 \(b\)，则

\[
\mathscr D_E>2b
\]

保证两类允许数据球不相交。

如果存在一对模型距离不超过 \(2b\)，两个数据球有公共点，任何算法都不能对所有允许扰动保证正确区分。这是有限幅度的结论，与 Jacobian 是否满秩无关。

此外，如果“两 Gaussian 类”允许零幅度子分量、重合或任意弱的小峰，它包含或逼近“一 Gaussian 类”，统一间隔直接变成零。必须先定义检测尺度与最低结构强度。

---

## 6.2 一个完整全波反例

把所有发射和接收点放在 \(x\) 轴，背景和区域关于该轴对称。记 \(P\) 为 \(y\mapsto-y\) 的反射，则

\[
PD=DP,\qquad PE=E,\qquad SP=S.
\]

镜像材料满足

\[
X'=PXP^{-1},
\qquad
J'=PJ,
\]

所以

\[
SJ'=SJ.
\]

**这是所有散射阶、所有这些频率下的精确歧义，不依赖 Born。**

本次三频检查中，两份镜像材料的相对差约为 **105.1%**，散射场相对差约为

\[
6.29\times10^{-16},
\]

但局部位置导数仍然非零。

这个反例针对线阵，不是在声称你当前全环阵必然具有同样歧义。它否定的是更宽泛的主张：

**局部信息为正，并不能排除远处存在另一个等数据材料。**

---

## 6.3 正确的结构输出来自置信集合

在声明的材料类 \(\mathcal M\) 内，定义

\[
\mathcal C(d)
=
\{\chi\in\mathcal M:\|F(\chi)-d\|\le b\}.
\]

其中 \(b\) 包含白化噪声的置信半径及可靠的离散、物理误差界。

正确的输出规则是：

| 证据 | 输出 |
|---|---|
| 较简单结构类被排除，新增结构类有相容见证 | 新结构受到数据支持 |
| 两种结构各有相容见证 | 无法确定 |
| 两种结构都被排除 | 材料类、物理模型或误差预算不足 |

必须避免一个常见错误：

**“新模型拟合得好，旧模型的某次局部优化拟合得差”不等于旧模型类被排除。**

---

## 6.4 可实施的全局排除

对一个旧参数盒 \(B\)，中心为 \(\theta_c\)，半径为 \(\rho_B\)，若有盒内统一 Lipschitz 上界 \(L_B\)，则

\[
\boxed{
\inf_{\theta\in B}\|F(\theta)-d\|
\ge
\max\left(
0,\,
\|\widetilde F(\theta_c)-d\|
-\eta_c-L_B\rho_B
\right).
}
\]

据此进行 branch-and-bound：

- 所有剩余盒的下界都大于 \(b\)，才能排除该类。
- 存在一个合法参数点满足预测距离上界不超过 \(b\)，就得到相容见证。
- 计算预算耗尽，返回“无法确定”。

交付代码实现了这个判定核心，并测试了三种分支。**它不是完整 Gaussian 反演流水线，也没有把局部优化结果伪装成全局下界。**

### 安全性与终止条件

只要真材料属于声明类、噪声置信事件成立、前向与模型误差界可靠，真材料就不会被错误排除。这个包含关系也适用于适应性选候选，不要求每次试探彼此独立。

如果旧类最小距离至少为 \(b+\zeta\)，新类存在距离不超过 \(b-\zeta\) 的见证，且 \(\zeta>0\)，随着前向误差和参数盒直径趋零，算法有限终止。

但最坏复杂度为

\[
O\!\left(
\frac{L_F\operatorname{diam}\Theta}{\zeta}
\right)^p.
\]

因此，**不能承诺 18 参数上的廉价全局认证。**主验证应先采用有工程含义的 3–4 参数族；自由度更高时，没有完成全局排除就保留局部标签或不确定输出。

---

# 七、真正可执行的“加材料还是加模式”算法

首先，原有 Gaussian 的位置、尺度和幅度应当先重新拟合。只有在它们不能解释数据之后，才讨论增加材料自由度。

```text
输入：固定采集、噪声与物理误差预算、材料类、初始 Q/V、总计算预算。

1. 检查耗散条件与离散误差条件。
   条件不成立：不发“已认证”标签。

2. 固定 Q、V，在当前材料类中更新原有位置、尺度、幅度。
   目标函数用误差区间判断，而不是只看近似损失。

3. 分开检查：
   a. 约化系统是否解准确；
   b. 电流空间是否足以描述完整状态。

4. 计算经过旧参数重拟合后的候选结构信号及其误差。
   不具有独立解释力的方向，不作为新增结构证据。

5. 若前向误差阻碍了模型比较：
   试增广 HG / 局部 primal residual / adjoint residual / interaction 模式；
   按“认证误差减少量 / 新增实际成本”选择；
   给电流空间预算，不急着加材料 Gaussian。

6. 若前向误差已足够小：
   检验旧材料类是否仍相容；
   需要宣告新结构时，执行旧类排除与新类相容性检查。

7. 旧类排除 + 新类相容：允许新增结构。
   两类相容：无法确定。
   两类排除：报告模型不足，不强迫继续加 Gaussian。

8. Q、V 只在外循环改变；改变后重启内循环。
   总预算耗尽：保留当前结果、误差账本和不确定原因。
```

这给出的是**可接受结论的安全性**，不是贪心资源分配的全局最优性。

---

## 外部照明与内部可达性，究竟是不是新方法？

令

\[
P=\operatorname{blockdiag}(L_{ii}),
\qquad
K=I-P^{-1}L,
\qquad
B_0=P^{-1}E.
\]

外部响应与交互扩充空间为

\[
\mathcal R_q
=
\operatorname{span}\{B_0,KB_0,\ldots,K^{q-1}B_0\}.
\]

由二项式展开，

\[
\boxed{
\mathcal R_q
=
\mathcal K_q(P^{-1}L,P^{-1}E).
}
\]

**它就是 block Krylov 空间。**

逐 patch 限制快照、再作 SVD，是局部 POD 类型的压缩。接收相关的双边空间属于 goal-oriented reduction；最优局部端口的 transfer-operator 思路也已有代表性研究。citeturn573387view3

所以我明确取消“内部相互作用可达性本身是一种新降阶理论”的主张。

你的差异只能来自：**这个成熟降阶器如何被有限结构信号驱动，以及是否比成熟误差驱动方法更少产生假结构、更省总体计算。**

# 八、第二问：当前无需 NN，但 Schur 与物理约束可以明确回答

## 8.1 只观测 \(M=CKB\)，不能普遍识别 \(K\)

定义

\[
P_C=C^\dagger C,
\qquad
P_B=BB^\dagger.
\]

则唯一能直接确定的是

\[
\boxed{
P_CKP_B=C^\dagger M B^\dagger.
}
\]

其余部分属于

\[
\ker(\Delta K\mapsto C\Delta K B).
\]

若 \(C,B\) 的秩分别为 \(r_C,r_B\)，任意 \(n\times n\) 复矩阵 \(K\) 的不可观测自由度为

\[
n^2-r_Cr_B.
\]

因此，不能默认实验数据唯一决定某个内部自能矩阵。

当然，使用全维仿真产生固定规范的内部标签可以监督训练；这个定理不否定那种做法。它只是说明：**仿真标签定义了一个实现，不等于外部实验唯一识别了这个实现。**

---

## 8.2 Schur 消元不仅改变“自能”

把

\[
Lj=Bu,\qquad y=Cj
\]

按保留与遗漏状态分块，消元后得到

\[
L_{\mathrm{eff}}
=
L_{vv}-L_{vd}L_{dd}^{-1}L_{dv},
\]

同时还必须改变

\[
B_{\mathrm{eff}}
=
B_v-L_{vd}L_{dd}^{-1}B_d,
\]

\[
C_{\mathrm{eff}}
=
C_v-C_dL_{dd}^{-1}L_{dv}.
\]

完整传递矩阵为

\[
\boxed{
M
=
C_{\mathrm{eff}}L_{\mathrm{eff}}^{-1}B_{\mathrm{eff}}
+
C_dL_{dd}^{-1}B_d.
}
\]

**只学习自能，却不处理有效激励、有效接收与直通项，一般不是正确的隐藏状态消元。**

---

## 8.3 约束应该施加在哪里？

当前 current 系数不是功率归一化 S 参数。合适的条件是

\[
-\operatorname{Im}L\succeq\gamma I,
\]

以及在正确互易度量下的对称关系，而不是随意要求某个 current 耦合矩阵为收缩映射。

Schur 算子也继承耗散。取

\[
z=
\begin{bmatrix}
v\\-L_{dd}^{-1}L_{dv}v
\end{bmatrix},
\]

则

\[
-\operatorname{Im}(v^\ast L_{\mathrm{eff}}v)
=
-\operatorname{Im}(z^\ast Lz)
\ge\gamma\|v\|^2.
\]

因此需要约束的是 \(L_{\mathrm{eff}}\)，不是单独给自能套一个无依据的“被动 S 参数”条件。

如果 NN 只是数值迭代器，它可以依赖右端而非线性；只要完整物理误差可控，其叠加缺陷也可控。**求解器的非线性与物理散射算子的非线性是两件事。**

---

## 8.4 为什么现在不选 NN 主线？

因为原包已经给出直接负证据：当前 GNN 的约化误差没有超过 GMRES，反演墙钟也更慢；而且原先按层数统计还低估了实际矩阵作用次数。fileciteturn3file2L59-L68 fileciteturn3file2L114-L116

近邻也相当明确：PhiGRL 已有物理残差驱动的图迭代；U-PINet 已有近场图、层次远场、物理残差训练及求解器初始化；HG/GSM 和物理粒子图也都已有直接先例。citeturn495745view3turn806697view1turn495745search0turn806697view2

**当前最合理的选择不是寻找一个更复杂的网络，而是先用可靠的非学习降阶器证明结构判定机制。**以后网络只有在候选排序或预条件上产生可计量净收益时才加入。

# 九、本次实际检查支持了什么，又没有支持什么？

完整数字在交付包中。核心结果如下。

| 本次检查 | 结果 | 能支持的结论 |
|---|---:|---|
| 三频强散射例中 \(\|XD\|\) 的下界 | 1.71、2.71、3.48 | 不满足 Born 小范数条件 |
| 同例 Born 场误差 | 242%、368%、433% | 不是靠极弱散射让认证成立 |
| 36 个离散场误差界检查 | 均覆盖对应真误差 | 支持离散实现与推导一致 |
| 3 GHz，primal 256、adjoint 320 模式 | 修正场误差 0.0143%，界 0.8427% | 可靠，但界约保守 59 倍 |
| 小分裂的重拟合后场差斜率 | 约 4.046 | 支持所测局部区域的四阶行为 |
| 镜像材料的三频场差 | \(6.29\times10^{-16}\) | 复算了有限幅度全波歧义 |

此外，固定基的完整修正场导数、嵌套伴随退化、完整 Schur 传递矩阵恒等式都做了有限维核查。

但必须把下面这句话写进证据账本：

> **这些检查没有证明比 block-preconditioned GMRES 或成熟双边 ROM 更快，也没有证明完整材料自适应已经成功。**

尤其是误差界约保守 59 倍，说明实用性风险真实存在。加模式最终能让界下降，并不代表代价值得。

# 十、成本与决定性验收

## 10.1 必须计入的成本

令总 primal 秩为 \(R\)，adjoint 秩为 \(R_d\)，照明数为 \(L_s\)，接收数为 \(M\)。

| 环节 | 主要成本 |
|---|---|
| 稠密传播矩阵 | 存储与构造 \(O(FN^2)\) |
| \(DQ,D^\ast V\) 与投影 | 通用实现含 \(O(FN^2(R+R_d))\)，可按真实局部支撑优化 |
| 每次材料更新 | 局部质量块 \(O(F\sum_i N_i(p_i^2+q_i^2))\) |
| 两侧分解与回代 | \(O(F(R^3+R_d^3+R^2L_s+R_d^2M))\) |
| 全维残差与修正 | 包含 \(O(FN(RL_s+R_dM))\)，不是只算 reduced residual |
| 模式构造 | 局部 fine-block LU、传播作用、SVD、重正交化全部计入 |
| 候选评估 | 所有试过的候选都计费，不只计最终选中的 |
| 全局类排除 | 最坏随参数维度指数增长，超时必须返回不确定 |

固定基时可以复用装配；基变化则新增传播列、投影和正交化都要入账。

当前方案没有 NN 训练成本。未来若加入网络，只有当单次部署成本确实减少时，摊销才有意义：

\[
N_{\mathrm{break-even}}
=
\frac{T_{\mathrm{data}}+T_{\mathrm{train}}+T_{\mathrm{extra\ setup}}}
{T_{\mathrm{baseline}}-T_{\mathrm{NN}}}.
\]

分母不为正，就没有“用得越多越划算”的拐点。

---

## 10.2 冻结实验

建议主测试采用三个预先定义的材料组：真实单结构、接近判别边界的邻近结构、明确可分的双结构。每组 **100 个独立材料实例，每实例 3 次噪声**；另设尖边/材料失配和弱损耗两组 OOD。

噪声重复按材料实例聚类，不能当成增加了几何样本量。所有 A1/A1_2 数据与本次探针都归开发集。

基线必须包括固定高阶 Q、普通残差增广、双边 goal-oriented POD/Krylov、参数—状态联合认证信赖域、完整 block-preconditioned GMRES 反演，以及完整 TSOM/CSI。T-matrix 逆散射和实测验证已有明确先例，不能只与简化残差迭代比较。citeturn573387view1

**最重要的消融：保持状态求解器、候选库和误差证书完全一样，仅移除“有限幅度结构准入”规则。**

否则，即使结果改善，也可能只是从固定 HG 换成了更成熟的 Krylov/POD。

独立正演必须改变网格和离散/积分实现。你当前尖边网格变化与圆柱对照已有显著误差，不能把它们忽略后解释成超分辨。fileciteturn3file2L110-L116

Fresnel 的复数实测数据适合外部检查，但近乎无损目标不能自动算作这里耗散定理的正面验收；正面的有损认证需要损耗得到独立表征、噪声可由重复采集估计的试件。citeturn573387view0

---

## 10.3 建议冻结的生死门槛

以下是**拟议协议，不是已经通过的结果**。

| 验收项目 | 建议门槛 |
|---|---|
| 证书可靠性 | 声明条件内不得出现可重复的越界 |
| 假新增结构 | 材料实例级事件的单侧 95% 上置信界不超过 5% |
| 防止总是拒绝 | 预先定义可分组中，“正确且非拒绝”比例的 95% 下界至少 80% |
| 净成本 | 达到匹配质量时，成本比的 95% 上界低于 0.80 |
| 质量非劣 | 材料误差差值上界不超过 2 个百分点，留出复场误差比上界不超过 1.05 |
| 认证开销 | 主适用组中位数不超过在线总时间的 25% |

超时、RSS 越界、非收敛、\(\Gamma\) 失败和不确定样本全部保留。成本不能只对两个方法都成功的子集平均；应报告固定预算质量、截尾的时间到质量门槛，以及成功概率。

**若认证最终需要接近全维的端口、判定大多返回未知，或者不能胜过匹配的成熟误差驱动方法，就否决高性能方法论文定位。**

# 最终结论

我支持继续，但支持的是下面这一条，而不是原来的组合名称：

\[
\boxed{
\text{用可认证的全波误差，阻止状态截断被误认成材料新结构。}
}
\]

这轮已经能够闭合的部分，是：

**非 Born 耗散类别上的误差证书；旧参数重拟合后的有限幅度结构间隔；以及带正确拒绝输出的结构判定安全性。**

需要否决的部分，是：

**普适 HG 分辨率定律、把小幅 H4 分裂直接叫双夹杂分辨、把嵌套伴随修正叫免费降阶增益，以及当前 GNN 的核心贡献定位。**

真正决定论文是否值得继续投入的，不再是“还能不能增加一个漂亮模块”，而是一个明确可证伪的主张：

> **在同样计算预算下，这个结构准入机制，是否比成熟的误差驱动降阶更少产生假结构，同时保留足够的真实结构判定能力？**

数学正确性现在有了可检查的基础；**强 TAP 所需的净优势仍未被证明，必须由冻结实验裁决，不能用现有的好看图像替代。**
