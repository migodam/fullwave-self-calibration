# 一、先统一三个“我要拟合什么”的物理意义

\boxed{

\boxed{

这里：

- \(D\)：domain \(\rightarrow\) domain 的内部 Green operator；
- \(\chi\)：permittivity contrast；
- \(j_\ell\)：contrast source / induced current；
- \(u_\ell\)：total field。

\boxed{

\end{array}
}
\]

# 二、Gaussian 直接拟合电流：最容易，但也是最危险的

写：

\[
j_\ell^G(r)
=
\sum_{p=1}^P c_{p\ell}g_p(r).
\]

如果只是从函数逼近角度看，这当然能做。

但是：

\[
\boxed{
\text{“能拟合一个 current field”}
\neq
\text{“这个 current 能由任何真实介质产生”。}
}
\]

这里有一个很强的物理约束。

---

## 2.1 多 illumination 下存在一个严格的 **constitutive consistency condition**

因为：

\[
j_\ell(r)=\chi(r)u_\ell(r),
\]

同一点 \(r\)，所有 illumination 必须共享**同一个** \(\chi(r)\)。

因此对于任意 \(\ell,m\)：

\[
\boxed{
j_\ell u_m-j_m u_\ell=0.
}
\]

换句话说，把所有 illumination 写成两个向量：

\[
\mathbf u(r)
=
\begin{bmatrix}
u_1(r)\\
\vdots\\
u_L(r)
\end{bmatrix},
\qquad
\mathbf j(r)
=
\begin{bmatrix}
j_1(r)\\
\vdots\\
j_L(r)
\end{bmatrix},
\]

必须满足：

\[
\boxed{
\mathbf j(r)=\chi(r)\mathbf u(r).
}
\]

也就是：

\[
\boxed{
\operatorname{rank}
[\mathbf u,\mathbf j]
=1.
}
\]

这个结果非常有用。

---

## 2.2 甚至可以直接算“这个 Gaussian current 到底有多物理”

给任意拟合出来的 \(j_\ell\)，最接近它的 isotropic contrast 是：

\[
\boxed{
\chi^\star(r)
=
\frac{\mathbf u(r)^H\mathbf j(r)}
{\mathbf u(r)^H\mathbf u(r)}.
}
\]

对应最小 constitutive error：

\[
\boxed{
C_{\rm phys}(r)
=
\|\mathbf j\|^2
-
\frac{|\mathbf u^H\mathbf j|^2}
{\|\mathbf u\|^2}.
}
\]

归一化以后：

\[
\boxed{
c_{\rm phys}
=
1-
\frac{|\mathbf u^H\mathbf j|^2}
{\|\mathbf u\|^2\|\mathbf j\|^2}.
}
\]

这个东西实际上就是一个：

\[
\boxed{\sin^2\text{ constitutive angle}.}
\]

它的意义非常清楚：

\[
c_{\rm phys}=0
\]

当且仅当当前 Gaussian currents 可以由某个共同的 isotropic \(\chi\) 产生。

---

# 三、这实际上给 Gaussian-SOM 提供了一个很重要的新约束

普通 SOM 会允许：

\[
j_\ell
=
j_\ell^{\rm det}
+
j_\ell^{\rm amb}.
\]

ambiguous current 可以在很大的 current space 里优化。SOM 确实利用 \(G_S\) 的 spectrum，把 current 分成 deterministic 和 ambiguous portions；Twofold-SOM 再利用 internal current-to-field mapping 的 spectrum 进一步缩小 ambiguous current subspace。

问题是：

> receiver-fit 很好的 ambiguous current，未必属于任何 shared material。

所以 Gaussian-SOM 可以加入：

\[
\boxed{
\mathcal L_{\rm constitutive}
=
\int
C_{\rm phys}(r)\,dr.
}
\]

这不是普通 L2 regularization。

而是：

\[
\boxed{
\text{禁止 SOM 在非物理 current directions 中“作弊”。}
}
\]

这个我认为很值得保留。

# 四、Maxwell vector 情况更严格

用 \(e^{-i\omega t}\) 约定：

\[
\mathbf J
=
-i\omega\epsilon_0
\chi\mathbf E

对于 isotropic dielectric。

所以在每个点：

\[
\boxed{
\mathbf J_\ell
\parallel
\mathbf E_\ell
}
\]

是复数意义下的平行关系。

并且所有 illumination 的 proportionality coefficient 都必须相同：

\[
\frac{\mathbf E_\ell^H\mathbf J_\ell}
{\|\mathbf E_\ell\|^2}
=
-i\omega\epsilon_0\chi.
\]

如果你用三个独立 Gaussian vector components 随便拟合：

\[
\mathbf J
=
\sum_j
\mathbf a_j g_j,
\]

它很容易产生一个数据 fit 很好但满足

\[
\boxed{
\mathbf J\times\mathbf E\neq0
}
\]

的结果。

对于 isotropic material，这是**严格不可能的物理 current**。

这给 Gaussian-current model 划了一条非常明确的红线。

# 五、你说的“毛球定理”什么时候真的出现？

这个问题问得非常好。

## 5.1 对普通 3D volume current：毛球定理不管

如果：

\[
\mathbf J:\Omega\subset\mathbb R^3
\rightarrow
\mathbb C^3,
\]

只是 volume current，

没有：

\[
\mathbf J\cdot n=0
\]

这种 tangent-bundle constraint。

所以 hairy-ball theorem 不适用。

# 六、但如果你拟合的是 closed-surface current，那就真的有 topology

例如 PEC surface 上：

\[
\mathbf J_s\cdot n=0.
\]

现在 \(\mathbf J_s\) 是一个 tangent vector field。

对于 genus \(g\) 的闭合 orientable surface，

Poincaré–Hopf 给：

\[
\boxed{
\sum_p\operatorname{index}(p)
=
\chi_{\rm Euler}
=
2-2g.
}
\]

所以 sphere：

\[
g=0
\]

得到：

\[
\boxed{
\sum\operatorname{index}=2.
}
\]

也就是说任何连续 tangent current 如果不是恒零，都不可能“每一个地方都有一个非零毛发方向”。

必须存在 zero/stagnation points。

这就是你的“长毛电流球”。

# 七、Gaussian 会不会违反毛球定理？

### 正确构造不会。

### naive 3DGS-style orientation 很容易违反物理。

例如每个 Gaussian 存：

\[
(\mu_j,\Sigma_j,\hat t_j,a_j),

然后规定：

\[
\|\hat t_j\|=1
\]

且每个 patch 独立学习一个 tangent direction。

那么网络很可能通过：

- patch overlap discontinuity；
- orientation seam；
- patch boundary jump；

偷偷避开 hairy-ball obstruction。

得到的不是一个 global continuous surface current。

# 八、真正正确的 Gaussian surface-current 表示应该是 **Hodge-Gaussian**

闭合 surface 上 tangent vector field 可以写成：

\[
\boxed{
\mathbf J_s
=
\nabla_s\phi
+
n\times\nabla_s\psi
+
\mathbf h.
}
\]

其中：

- \(\nabla_s\phi\)：non-solenoidal / gradient component；
- \(n\times\nabla_s\psi\)：solenoidal component；
- \(\mathbf h\)：harmonic component。

这种 surface Hodge decomposition 在 electromagnetics 中本来就是成熟的工具；电磁积分方程长期使用 divergence-conforming / curl-conforming bases，正是因为任意 vector basis 不会自动尊重这些连续性和 differential constraints。

现在令：

\[
\phi
=
\sum_j a_jg_j,
\]

\[
\psi
=
\sum_j b_jg_j.
\]

于是：

\[
\boxed{
\mathbf J_s
=
\sum_j
a_j\nabla_sg_j
+
\sum_j
b_jn\times\nabla_sg_j
+
\sum_{m=1}^{2g}c_m\mathbf h_m.
}
\]

这才是我推荐的：

\[
\boxed{\textbf{Gaussian current representation}.}
\]

# 九、这里还有一个很漂亮的 topology result

闭合 genus-\(g\) surface 的 harmonic 1-form space dimension：

\[
\boxed{
\dim\mathcal H^1=2g.
}
\]

所以：

### sphere

\[
g=0
\Rightarrow
\mathbf h=0.
\]

Gaussian scalar potentials \(\phi,\psi\) 就够。

### torus

\[
g=1
\Rightarrow
\dim\mathcal H^1=2.
\]

如果你只用：

\[
\nabla_sg_j,\quad n\times\nabla_sg_j

而没有两个 global harmonic currents，

那么存在两类**永远无法正确表示的 circulating current**。

这个不是 approximation quality 问题。

而是：

\[
\boxed{\textbf{topological incompleteness}.}
\]

这个非常像你说的“有没有物理上永远满足不了的东西”。

有。

在 \(e^{-i\omega t}\) convention 下。

于是：

\boxed{

\sum_j a_j\nabla g_j
+

}
\]

这样就可以显式区分：

真正应该验证三个**生死命题**：

1. **Stable-subspace compression**：相同 reconstruction accuracy 下，adaptive Hermite-Gaussian 需要的物理 DOF 是否显著少于 voxel / FFT-TSOM Fourier basis。

2. **Order-prediction law**：\(q\sigma\) / full-wave dressed spectrum 是否真的能准确预测“什么时候 \(H_1/H_2/H_4\) 可恢复、什么时候 split 必然失败”。

3. **Physical-current advantage**：加入 constitutive-angle + Hodge constraints 后，是否能在 high contrast / sparse receivers / noise 下显著压制传统 SOM ambiguous-current 的非物理解，同时保持或提升 resolution。

如果这三条实验全过，尤其第二条做到：

\[
\boxed{
\text{理论预测某一 Gaussian feature 不可见}
\rightarrow
\text{重建确实失败}
\rightarrow
\text{增加相应测量后 feature 恢复}

# 25. 但是有三个物理大坑

这是这条路线能不能真的赢的关键。

### 第一：一个 Gaussian 的 local \(T_i\) 不一定是低秩

如果：

\[
k\sigma_i\gg1
\]

或者 strong resonant dielectric，

很多 multipoles 都会活跃。

于是：

\[
r_i
\]

变大。

最后：

\[
R=\sum r_i
\]

可能并不比 voxel solver 小多少。

所以必须验证一个：

\[
\boxed{
r_i(\epsilon)
\text{ vs }
k\sigma_i,\chi_i
}
\]

的 port-rank law。

---

### 第二：Gaussian 过度重叠

如果几千个 Gaussian 全部高度重叠，

那么把它们解释成：

\[
\text{independent physical scatterers}
\]

就会非常别扭。

数学上把：

\[
V=\sum_iV_i
\]

分成 component potentials 后仍然可以写 multiple-scattering/Faddeev equations，但 decomposition 本身不唯一。

于是 network parameters 会存在 gauge/ill-conditioning。

所以更好的做法可能是：

\[
\boxed{
\text{Gaussian cluster / soft material cell = 一个 node},
}
\]

而不是每一个渲染 splat 都变成一个独立 n-port。

---

### 第三：collective resonance

如果：

\[
\det(T^{-1}-U)\simeq0,
\]

那么：

\[
K=(T^{-1}-U)^{-1}
\]

会很大。

这不是数值算法“坏了”，而可能是实际 collective resonance。

但 inverse sensitivity 同样会非常严重。

这种区域要特别处理。

# 26. S-matrix 本身还有一个很好用的物理约束

如果真正使用 power-normalized modal ports，

passive local scatterer 应满足：

\[
\boxed{
S_i^\dagger S_i\preceq I.
}
\]

lossless 并且 channels 完整时：

\[
\boxed{
S_i^\dagger S_i=I.
}
\]

reciprocal system 合适的 port normalization 下：

\[
\boxed{
S_i^T=S_i.
}
\]

所以你反演 Gaussian local \(S_i\) 时，不能让 NN 随便输出一个 complex matrix。

可以直接 enforce：

\[
\boxed{
\text{passivity}
+
\text{reciprocity}
+
\text{causality}.
}
\]

这又给 Gaussian inverse 一个很强的 physical prior。

如果只保留有限 ports，即便材料无损，未建模的 radiation channels 会表现成 energy leakage，因此 reduced \(S_i\) 一般是 contractive 而不一定 unitary。

这个肯定不成立。
