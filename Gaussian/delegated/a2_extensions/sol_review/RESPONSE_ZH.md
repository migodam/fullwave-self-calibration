# Root 对首轮 Sol 评审的处理

原评审全文保留。接受 M1/M3 的实质问题：v2 在满秩时探测了仍可见的最弱方向，随机基线也不是同补空间。v2 只保留为开发诊断；新 manifold_revised.py（v3）只在有补空间时探测，并将随机向量投影到同一补空间，数值核查 Vᵀh≈0。使用新种子，未在旧图上调超参数。

接受 M2 的口径限制，但“共享上限”并不等于“应浪费计算补齐完全同数RHS”。v3 保存每次有效状态的材料误差和留出误差标量（图像只保存终点），最终比较共同可达预算处的质量曲线/阶梯值，同时报告实际消耗。不会将不同终止预算的单个终值写成严格同预算收益。

M4：增加最小相对下降阈值；有限探测h固定，单独限制正交可见修正使总步长满足半径，避免原来整体裁剪改变h。仍称阻尼Gauss–Newton提案加全波单调接受，未实现标准信赖域ratio。

M5：新增12参数×2频率的端到端VIE场导数有限差分，并记录依赖源码哈希。M6：协议已明确log幅度/0.03m中心/SPD Frobenius乘积度量；v3 config也记录尺度与权重。M7：改用阈值谱截断描述，不宣称continuation。

T2：仍仅为条件离散定理、小矩阵检查，不越界称实际VIE矩证书。T3：静态共同标签与逐通道重采样现在从显式2×2条件似然表求和/乘积实际计算，不再硬编码输出。T4：公式中的C在文字中明确为无共轭pseudo-covariance。

P1–P3：主v2保留近点质量结果；弱通道、容量LP、多初始化均另标post-hoc。只有当前固定4维RBF族及其优化流程的失败，不推广到所有Gaussian概率场。后验“精确”仅对N32有限字典模型精确。

以上修订不构成TAP通过。GPU大规模表示比较是新增独立分支，其结果也不能自动修复原生SOM理论和概率后验门槛。
