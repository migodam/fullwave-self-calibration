# GPU 成像视觉审查

根任务直接查看实际生成PNG，未使用生成式图像替换实验图。共用视场与色标，材料和留出场数字并列；以下是图像观察，不是因果归因或分辨率保证。

- case00，离网格多Gaussian：K144保留更多小结构，K16出现合并/遗漏；K144背景下部仍有很淡的细长条。不能把这些条纹解释成已确认材料。
- case10，多夹杂尖边：各方法都让尖边变圆，体素材料误差较低但Gaussian留出场可能更低。不是所有边界误差都能归给Gaussian；采集带宽、孔径、离散误差、迭代和有效正则同样需要控制。
- case20，相交细曲线：K144的曲线更连续，K16将相近曲线混成宽带；体素在若干位置断裂、出现局部块状变化。K144背景里出现低振幅长条/斜条，曲线交点峰值也未完整恢复。“曲线连续”不等于每段均由数据独立支持。

具体可检验的改进方向：分开测材料表示容量与有限孔径信息不足；加入TV/界面等强基线；对低振幅细长Gaussian做经旧参数重拟合的删减检查，以留出场和重复噪声验证；检查本实现中心限制在±18cm而视场为±20cm的边缘影响。这些仅是由图提出的机制假设，本轮未把它们当作已完成的消融，也未据此改动冻结测试或训练U-Net。

完整每组最好/最差选取规则：按同一个对象上K144材料L2减voxel材料L2的差值取最小/最大，展示同对象真值、两种重建及像素绝对误差差图；它是事后展示，不参与优化或超参数选择。最终完整图审查补充见统一报告。

终审已查看完整三类代表图及六个配对最好/最差对象（case7/9、15/17、27/22）。曲线组在最差相对案例中仍优于体素，但保留了局部幅度/连续性误差；尖边多数材料排序不利于Gaussian。参数短轴诊断及120次N256固定场检查均已完成，主要留出排序保留，因而未支持“主要由原网格造成低场残差”的解释。该检查没有定位每条低幅细节的真实性，不能替代删分量重拟合或新观测。
