# 研究题目：位姿不确定性下全波逆散射 SLAM 的谱可观测性极限

我希望研究一个偏理论、可做近似分析和数学推导的问题：

> **在 full-wave inverse-scattering SLAM 中，传感器位姿本身未知时，原本属于逆散射系统的可观测子空间会损失多少信息？这种损失如何由轨迹、采样几何、频率和位姿不确定性决定？能否得到解析表达、上下界、渐近式或稳定性条件？**

重点是数学推导，而不是设计一个新的深度学习算法。

## 1. 基础物理模型

先从二维频域标量 Helmholtz 逆散射开始。假设背景介质已知、场景静态。

对第 (t) 个机器人位姿 (x\_t)，使用 contrast-source formulation：

[
j\_t


D\_\chi
\left[
e\_t^{\mathrm{inc}}(x\_t)
\+
G\_Dj\_t
\right],
]

[
y\_t


G\_S(x\_t)j\_t+n\_t,
]

其中：

[
D\_\chi=\operatorname{diag}(\chi),
]

(\chi) 为未知介质 contrast，(j\_t) 为第 (t) 次照射产生的 contrast source，(G\_D) 为目标区域内部传播算子，(G\_S(x\_t)) 为从目标区域到接收阵列的测量算子。

等价地：

[
M\_tj\_t=D\_\chi e\_t^{\mathrm{inc}},
\qquad
M\_t=I-D\_\chi G\_D,
]

因此

[
j\_t=M\_t^{-1}D\_\chi e\_t^{\mathrm{inc}}.
]

整体前向模型记为

[
y=F(\chi,X)+n,
\qquad
X=(x\_1,\ldots,x\_T).
]

先以这个模型为主，后续才考虑三维 Maxwell。

---

## 2. 第一层问题：对 full-wave 模型做严格的一阶线性化

在真实或名义状态

[
(\chi\_0,X\_0)
]

附近，推导

[
\boxed{
\delta y
========

A,\delta\chi
\+
B,\delta X
+n
}
\tag{1}
]

其中

[
A=D\_\chi F,
\qquad
B=D\_XF.
]

不要只把 (A,B) 当成抽象 Jacobian，希望尽量从 contrast-source 方程显式推出它们。

特别检查下面的结构是否正确。

对单个位置，

[
M\_t\delta j\_t
===============

\operatorname{diag}(E\_t^{\mathrm{tot}})
,\delta\chi,
]

因此候选表达式为

[
\boxed{
A\_t
====

G\_S(x\_t)
M\_t^{-1}
\operatorname{diag}
(E\_t^{\mathrm{tot}})
}
\tag{2}
]

其中

[
E\_t^{\mathrm{tot}}
===================

e\_t^{\mathrm{inc}}+G\_Dj\_t.
]

位姿 Jacobian 则至少包含：

[
\boxed{
B\_t
====

\frac{\partial G\_S}{\partial x\_t}j\_t
\+
G\_S
M\_t^{-1}
D\_\chi
\frac{\partial e\_t^{\mathrm{inc}}}{\partial x\_t}
}
\tag{3}
]

如果 transmitter/receiver 同时运动、(G\_D) 或坐标系也随位姿变化，应给出完整形式。

请严格推导而不是直接接受这些式子。

# 3. 最核心的数学问题

假设先把噪声白化。

即若

[
n\sim\mathcal N\_{\mathbb C}(0,\Sigma),
]

定义

[
\tilde A=\Sigma^{-1/2}A,
\qquad
\tilde B=\Sigma^{-1/2}B.
]

为简洁，后文仍写成 (A,B)。

如果位姿完全已知，地图的局部信息算子为

[
\boxed{
K\_{\mathrm{IS}}=A^\*A.
}
\tag{4}
]

这对应普通 inverse scattering。

但在 SLAM 中 (\delta X) 也是未知量。

由

[
\delta y=A\delta\chi+B\delta X
]

可知：

如果

[
A\delta\chi
\in
\operatorname{Range}(B),
]

那么这种地图变化完全可以被某个位姿变化解释。

因此定义

[
P\_{B^\perp}
============

I-BB^\dagger
]

并定义：

[
\boxed{
K\_{\mathrm{SLAM}}
==================

A^\*
P\_{B^\perp}
A.
}
\tag{5}
]

请把式 (5) 作为整个研究的核心对象。

# 4. 首先证明几个最基础、但可能很重要的结果

希望得到严格证明，而不是数值观察。

### A. 信息单调损失

证明：

[
0
\preceq
K\_{\mathrm{SLAM}}
\preceq
K\_{\mathrm{IS}}.
]

从而利用特征值单调性讨论：

[
\lambda\_i(K\_{\mathrm{SLAM}})
\le
\lambda\_i(K\_{\mathrm{IS}}).
]

解释：

> 未知位姿原则上只能减少而不会增加已有地图的局部可观测信息。

### B. 精确描述“哪些地图变化会被位姿吞掉”

A\delta\chi
\in
\operatorname{Range}(B)

}
\tag{6}
]

这实际上给出了 inverse-scattering SLAM 的局部不可辨识条件。

进一步研究：

[
\operatorname{rank}
(P\_{B^\perp}A)
]

与

[
\operatorname{Range}(A)
\cap
\operatorname{Range}(B)

之间的关系。

我预计有：

[
\boxed{
\operatorname{rank}(K\_{\mathrm{SLAM}})
=======================================

## \operatorname{rank}(A)

\dim
\left[
\operatorname{Range}(A)
\cap
\operatorname{Range}(B)

请严格检查条件。

这个结果如果成立非常重要，因为它说明：

> SLAM 真正损失的“独立地图自由度数”，就是 map-induced data variations 与 pose-induced data variations 的交集维数。

# 5. 不使用 hard threshold，定义连续的“位姿信息损失谱”

Chen 的 SOM 通常使用 dominant subspace / complementary subspace。

我希望不要依赖人为 threshold。

对任意地图扰动 (\delta\chi)，定义：

[
\boxed{
R(\delta\chi)
=============

\frac{
\delta\chi^\*
K\_{\mathrm{SLAM}}
\delta\chi
}{
\delta\chi^\*
K\_{\mathrm{IS}}
\delta\chi
}
}
\tag{8}
]

只考虑分母非零的方向。

由于：

[
\delta\chi^\*K\_{\mathrm{IS}}\delta\chi
=======================================

|A\delta\chi|^2,
]

以及

[
\delta\chi^\*K\_{\mathrm{SLAM}}\delta\chi
=========================================

|P\_{B^\perp}A\delta\chi|^2,
]

所以：

[
\boxed{
R(\delta\chi)
=============

\frac{
|P\_{B^\perp}A\delta\chi|^2
}{
|A\delta\chi|^2
}.
}
\tag{9}
]

希望证明它实际上等于：

[
\boxed{
R(\delta\chi)
=============

\sin^2
\angle
\left(
A\delta\chi,,
\operatorname{Range}(B)
\right).
}
\tag{10}
]

这会给出一个非常直接的解释：

- (R=1)：这个地图变化与任何 pose change 都正交，因此没有信息损失；
- (R=0)：这个地图变化完全可以伪装成 pose change；
- (0\<R<1)：只有一部分信息在消除 pose uncertainty 后保留下来。

# 6. 定义一个真正连续的“SLAM observability spectrum”

不要简单比较

[
\lambda\_i(K\_{\mathrm{SLAM}})
/
\lambda\_i(K\_{\mathrm{IS}})
]

因为两套 eigenvectors 不一定一一对应。

应研究 generalized eigenvalue problem：

[
\boxed{
K\_{\mathrm{SLAM}}v
===================

\rho
K\_{\mathrm{IS}}v.
}
\tag{11}
]

或者在 (K\_{\mathrm{IS}}) 的可观测支撑空间上定义：

[
\boxed{
R\_{\mathrm{op}}
================

K\_{\mathrm{IS}}^{\dagger/2}
K\_{\mathrm{SLAM}}
K\_{\mathrm{IS}}^{\dagger/2}.
}
\tag{12}
]

研究其特征值：

[
0\le\rho\_i\le1.
]

我希望探索：

[
\boxed{
\rho\_i
}
]

是否可以解释成：

> 普通 inverse scattering 第 (i) 类可观测结构中，在 pose 同时未知后仍然保留下来的信息比例。

进一步研究这些 (\rho\_i) 与

[
\operatorname{Range}(A)
\quad\text{和}\quad
\operatorname{Range}(B)
]

之间夹角的关系。

如果可以，应尽量使用初等线性代数表述；只有确实有必要时再引入 principal angles / canonical correlations 等成熟理论。

# 7. 加入 SLAM 的运动先验之后

真实 SLAM 不会让每个位姿完全自由。

IMU、里程计或 motion model 会提供位姿信息矩阵：

[
J\_X.
]

于是联合信息矩阵：

[
\mathcal I=
\begin{bmatrix}
A^\*A&A^\*B\\
B^\*A&B^\*B+J\_X
\end{bmatrix}.
]

消除位姿 nuisance parameter 后，地图有效信息应为 Schur complement：

[
\boxed{
K\_{\mathrm{eff}}
=================

## A^\*A

A^\*B
(B^\*B+J\_X)^\dagger
B^\*A.
}
\tag{13}
]

研究：

[
J\_X\to0
]

是否恢复式 (5)；

以及：

[
J\_X\to\infty
]

是否得到：

[
K\_{\mathrm{eff}}
\to
K\_{\mathrm{IS}}.
]

定义：

[
\boxed{
L\_X
====

## K\_{\mathrm{IS}}

K\_{\mathrm{eff}}
}
\tag{14}
]

作为 **pose-induced information loss operator**。

分析它的：

[
\operatorname{rank},
\quad
\operatorname{tr},
\quad
\lambda\_{\max},
\quad
|L\_X|.
]

特别研究：

[
\operatorname{rank}L\_X
\le
\operatorname{rank}B
]

是否成立以及物理意义。

# 8. 轨迹 (X\_T) 如何进入这个谱？

对于：

[

]

[
A=A(X\_T),
\qquad
B=B(X\_T),
]

因此：

[
\boxed{
K\_{\mathrm{eff}}
=================

K\_{\mathrm{eff}}(X\_T).
}
]

这就是把：

[
\text{现实采样轨迹}
]

映射到：

[
\text{地图可观测谱}.
]

下一步研究：

[
X\_T\rightarrow X\_T+\Delta X
]

[
K\_{\mathrm{eff}}(X\_T+\Delta X)
================================

K\_{\mathrm{eff}}(X\_T)
\+
DK\_{\mathrm{eff}}[\Delta X]

[
DK\_{\mathrm{eff}}.
]

[
K\_{\mathrm{eff}}v\_i=\lambda\_i v\_i

\boxed{

# 9. 最终形成一个 robust trajectory problem

假设要求至少稳定恢复 (r) 个环境自由度。

定义：

[
\boxed{
\gamma\_r(X\_T,\varepsilon)
===========================

\min\_{|\Delta X|\le\varepsilon}
\lambda\_r
\left[
K\_{\mathrm{eff}}
(X\_T+\Delta X)
\right].
}
\tag{16}
]

然后研究：

[
\boxed{
\max\_{X\_T\in\mathcal X}
\gamma\_r(X\_T,\varepsilon).
}
\tag{17}
]

其中 (\mathcal X) 是允许的机器人轨迹集合。

解释：

> 找一条轨迹，使机器人位置存在最大 (\varepsilon) 误差时，最坏情况下第 (r) 个地图模式仍然尽可能可观测。

希望做一阶近似。

如果 (\lambda\_r) 是单特征值，尝试证明：

[
\gamma\_r(X,\varepsilon)
\approx
\lambda\_r(X)
-------------

\varepsilon
|\nabla\_X\lambda\_r(X)|\_\*
\tag{18}
]

其中 (|\cdot|\_\*) 是与位姿扰动范数对应的对偶范数。

这会给一个非常直观的 trade-off：

[
\boxed{
\text{模式本身的信息强度}
----------------

\text{模式对 pose error 的敏感度}.
}
]

# 10. 希望特别分析的几个简化 regime

不要一开始全部同时解决。按下面顺序：

1. **Born approximation**
   [
   M\_t^{-1}\approx I.
   ]
   先得到最清晰的解析结构。

2. **Full-wave, small pose error**
   保留
   [
   M\_t^{-1}
   ]
   和 multiple scattering，但只对 (X) 做一阶扰动。

3. **Single-frequency vs multi-frequency**
   研究增加频率究竟：

   - 增加绝对信息；
   - 改善 (A) 与 (B) 的分离；
   - 还是只是重复已有模式。

4. **不同轨迹**
   比较：

   - 直线；
   - 圆周；
   - 部分圆周；
   - 多视角；
   - 主动优化轨迹。

5. 如果有可能，再做 far-field / large-distance asymptotics，得到：
   [
   \lambda\_i(R)
   ]
   或
   [
   \rho\_i(R)
   ]
   随距离、孔径、波长的 scaling law。
